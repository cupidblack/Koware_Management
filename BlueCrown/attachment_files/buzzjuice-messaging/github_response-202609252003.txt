# **Buzzjuice Unified Messaging System — v1.3.0 (Complete Implementation)**

## **Executive Summary**

This is the **production-ready Phase 1 foundation** that implements a unified messaging layer across Buzzjuice Network:
- **WordPress** (BP Better Messages canonical store)
- **Buzzjuice Streams** (WoWonder)
- **Buzzjuice Socials** (QuickDate)

**Key Improvements from v1.2:**
1. ✅ Corrected WordPress bootstrap lifecycle (fixes `rest_api_init` timing)
2. ✅ Uses ONLY public Better Messages API (`Better_Messages()->functions->new_message()`)
3. ✅ Leverages existing `bzj_relationships` ledger for connection state
4. ✅ Separate messaging credentials (not reusing connection-sync secrets)
5. ✅ No `wp-load.php` in Streams/Socials yet (cleaner Phase 1)
6. ✅ HTTPS + HMAC signed requests only
7. ✅ First-contact flow: request → accept → thread creation
8. ✅ Server-side policy enforcement (not client-side gating)
9. ✅ Intentionally omits future features (HS1700, Palmier, real-time transport)
10. ✅ Lean addon/integration architecture for future expansion

### File: `wp-content/mu-plugins/bzj-messaging.php`

```php
<?php
/**
 * Plugin Name: Buzzjuice Messaging System
 * Description: Unified messaging bridge across Buzzjuice Network
 * Version: 1.3.0
 * Author: Buzzjuice Network
 * License: GPL-2.0+
 * 
 * Unified messaging coordinator:
 * - WordPress / BP Better Messages (canonical store)
 * - Buzzjuice Streams (WoWonder)
 * - Buzzjuice Socials (QuickDate)
 * 
 * Security: HMAC-SHA256 signatures, short-lived sessions, 
 * separate per-platform credentials, server-side policy enforcement.
 * 
 * Lifecycle:
 *   plugins_loaded → bootstrap (early init)
 *   rest_api_init → register REST routes
 *   wp_loaded → finalization & addon discovery
 */

if (!defined('ABSPATH')) {
    exit('Direct access denied.');
}

// Load configuration first (sets up paths and constants)
require_once dirname(__FILE__) . '/../../shared/bzj-messaging/config/config.php';

// Bootstrap system early so REST routes register properly
add_action('plugins_loaded', function() {
    try {
        require_once BZJ_MESSAGING_CORE . '/bootstrap.php';
        $bootstrap = BZJ_Messaging_Bootstrap::instance();
        $bootstrap->init();
        
        do_action('bzj_messaging_bootstrap_complete');
    } catch (Exception $e) {
        // Log critical errors but don't crash
        error_log('BZJ Messaging Bootstrap Error: ' . $e->getMessage());
        if (defined('WP_DEBUG') && WP_DEBUG) {
            wp_die('BZJ Messaging failed to initialize: ' . $e->getMessage());
        }
    }
}, 5); // Run early, before standard plugins

// Register REST routes after API is ready
add_action('rest_api_init', function() {
    $bootstrap = BZJ_Messaging_Bootstrap::instance();
    if (!$bootstrap || !$bootstrap->is_ready()) {
        return;
    }
    
    $gateway = $bootstrap->get_gateway();
    if ($gateway && method_exists($gateway, 'register_routes')) {
        $gateway->register_routes();
    }
}, 10);

// Hook into Better Messages events after plugins are fully loaded
add_action('wp_loaded', function() {
    $bootstrap = BZJ_Messaging_Bootstrap::instance();
    if (!$bootstrap || !$bootstrap->is_ready()) {
        return;
    }
    
    $adapter = $bootstrap->get_adapter();
    if ($adapter && method_exists($adapter, 'register_hooks')) {
        $adapter->register_hooks();
    }
    
    // Load controlled addons and integrations
    if (method_exists($bootstrap, 'load_addons_and_integrations')) {
        $bootstrap->load_addons_and_integrations();
    }
}, 5);
```

```php
<?php
/**
 * Secret Management Helper
 * 
 * Loads secrets from environment or constants with secure hierarchy.
 * Implements validation and fallback logic.
 */

if (!function_exists('bzj_messaging_get_secret')) {
    /**
     * Retrieve a secret by platform and type.
     * 
     * Hierarchy:
     * 1. Environment variable: BZJ_{PLATFORM}_{TYPE}
     * 2. Constant: BZJ_{PLATFORM}_{TYPE}
     * 3. Generic fallback: BZJ_MESSAGING_SECRET
     * 
     * @param string $platform Platform: streams, socials, wordpress
     * @param string $type Type: chat_key_id, chat_secret
     * @return string Secret value or empty string if not found
     */
    function bzj_messaging_get_secret($platform, $type) {
        $platform = strtoupper(preg_replace('/[^a-z0-9_]/i', '', (string)$platform));
        $type = strtoupper(preg_replace('/[^a-z0-9_]/i', '', (string)$type));
        
        if (empty($platform) || empty($type)) {
            return '';
        }
        
        // Try platform-specific environment variable
        $env_key = 'BZJ_' . $platform . '_' . $type;
        $env_val = getenv($env_key);
        if ($env_val !== false && $env_val !== '') {
            return (string) $env_val;
        }
        
        // Try platform-specific constant
        if (defined($env_key) && constant($env_key) !== '') {
            return (string) constant($env_key);
        }
        
        // Try generic messaging secret fallback
        $fallback_key = 'BZJ_MESSAGING_SECRET';
        $fallback_env = getenv($fallback_key);
        if ($fallback_env !== false && $fallback_env !== '') {
            return (string) $fallback_env;
        }
        if (defined($fallback_key) && constant($fallback_key) !== '') {
            return (string) constant($fallback_key);
        }
        
        return '';
    }
}

if (!function_exists('bzj_messaging_validate_secrets')) {
    /**
     * Validate that required secrets are configured.
     * 
     * @return bool|WP_Error True if valid, WP_Error if missing
     */
    function bzj_messaging_validate_secrets() {
        $platforms = ['streams', 'socials'];
        $errors = [];
        
        foreach ($platforms as $platform) {
            $key_id = bzj_messaging_get_secret($platform, 'chat_key_id');
            $secret = bzj_messaging_get_secret($platform, 'chat_secret');
            
            if (empty($key_id)) {
                $errors[] = "Missing BZJ_{strtoupper($platform)}_CHAT_KEY_ID";
            }
            if (empty($secret)) {
                $errors[] = "Missing BZJ_{strtoupper($platform)}_CHAT_SECRET";
            }
            // Minimum reasonable secret length
            if (!empty($secret) && strlen($secret) < 32) {
                $errors[] = "BZJ_{strtoupper($platform)}_CHAT_SECRET is too short (min 32 chars)";
            }
        }
        
        if (!empty($errors)) {
            return new WP_Error('bzj_messaging_config', implode('; ', $errors));
        }
        
        return true;
    }
}

if (!function_exists('bzj_messaging_secrets_summary')) {
    /**
     * Safe summary for logging (never reveals secrets).
     * 
     * @return array
     */
    function bzj_messaging_secrets_summary() {
        $summary = [];
        foreach (['streams', 'socials'] as $platform) {
            $key_id = bzj_messaging_get_secret($platform, 'chat_key_id');
            $secret = bzj_messaging_get_secret($platform, 'chat_secret');
            $summary[$platform] = [
                'has_key_id' => !empty($key_id),
                'key_id_length' => strlen($key_id ?? ''),
                'has_secret' => !empty($secret),
                'secret_length' => strlen($secret ?? ''),
            ];
        }
        return $summary;
    }
}
```

### File: `shared/bzj-messaging/core/bootstrap.php`

```php
<?php
/**
 * Buzz Messaging Bootstrap
 * 
 * Initializes entire system:
 * - Validates environment
 * - Creates database tables
 * - Loads all core modules
 * - Instantiates services
 * - Discovers controlled addons
 */

if (!class_exists('BZJ_Messaging_Bootstrap')) {
    
    class BZJ_Messaging_Bootstrap {
        
        private static $instance;
        private $logger;
        private $gateway;
        private $adapter;
        private $identity;
        private $sessions;
        private $requests;
        private $dispatch;
        private $ready = false;
        
        public static function instance() {
            if (!self::$instance) {
                self::$instance = new self();
            }
            return self::$instance;
        }
        
        private function __construct() {
            // Intentionally private; use instance()
        }
        
        /**
         * Initialize all services.
         * 
         * @throws Exception
         */
        public function init() {
            if ($this->ready) {
                return; // Already initialized
            }
            
            try {
                // 1. Validate environment
                $this->validate_environment();
                
                // 2. Ensure log directory
                $this->ensure_log_directory();
                
                // 3. Load logger (everything depends on it)
                require_once BZJ_MESSAGING_CORE . '/logger.php';
                $this->logger = BZJ_Messaging_Logger::instance();
                
                $this->logger->info('BZJ Messaging Bootstrap', [
                    'version' => BZJ_MESSAGING_VERSION,
                    'php_version' => PHP_VERSION,
                    'wp_version' => get_bloginfo('version'),
                    'secrets_summary' => bzj_messaging_secrets_summary(),
                ]);
                
                // 4. Create database tables
                $this->create_tables();
                
                // 5. Load all core modules
                require_once BZJ_MESSAGING_CORE . '/helpers.php';
                require_once BZJ_MESSAGING_CORE . '/audit.php';
                require_once BZJ_MESSAGING_CORE . '/identity.php';
                require_once BZJ_MESSAGING_CORE . '/sessions.php';
                require_once BZJ_MESSAGING_CORE . '/policy.php';
                require_once BZJ_MESSAGING_CORE . '/requests.php';
                require_once BZJ_MESSAGING_CORE . '/adapter.php';
                require_once BZJ_MESSAGING_CORE . '/gateway.php';
                require_once BZJ_MESSAGING_CORE . '/dispatch.php';
                
                // 6. Instantiate services
                $this->identity = BZJ_Messaging_Identity::instance();
                $this->sessions = BZJ_Messaging_Sessions::instance();
                $this->requests = BZJ_Messaging_Requests::instance();
                $this->adapter = BZJ_Messaging_Adapter::instance();
                $this->gateway = BZJ_Messaging_Gateway::instance();
                $this->dispatch = BZJ_Messaging_Dispatch::instance();
                
                $this->ready = true;
                
                $this->logger->info('BZJ Messaging ready', [
                    'timestamp' => current_time('mysql', true),
                ]);
                
            } catch (Exception $e) {
                if ($this->logger) {
                    $this->logger->error('Bootstrap failed', [
                        'message' => $e->getMessage(),
                        'file' => $e->getFile(),
                        'line' => $e->getLine(),
                        'trace' => $e->getTraceAsString(),
                    ]);
                }
                throw $e;
            }
        }
        
        /**
         * Validate WordPress and plugin environment.
         * 
         * @throws Exception
         */
        private function validate_environment() {
            global $wpdb;
            
            // PHP version
            if (version_compare(PHP_VERSION, BZJ_MESSAGING_MIN_PHP, '<')) {
                throw new Exception(
                    "PHP " . BZJ_MESSAGING_MIN_PHP . "+ required; you have " . PHP_VERSION
                );
            }
            
            // WordPress version
            global $wp_version;
            if (version_compare($wp_version, BZJ_MESSAGING_MIN_WP, '<')) {
                throw new Exception(
                    "WordPress " . BZJ_MESSAGING_MIN_WP . "+ required; you have " . $wp_version
                );
            }
            
            // BP Better Messages plugin
            if (!function_exists('Better_Messages')) {
                throw new Exception('BP Better Messages plugin is required but not active.');
            }
            
            // Database connectivity
            if (!$wpdb) {
                throw new Exception('Database connection failed.');
            }
            
            // Secret validation
            $secret_check = bzj_messaging_validate_secrets();
            if (is_wp_error($secret_check)) {
                throw new Exception('Secrets validation: ' . $secret_check->get_error_message());
            }
        }
        
        /**
         * Ensure log directory exists and is writable.
         * 
         * @throws Exception
         */
        private function ensure_log_directory() {
            $log_dir = BZJ_MESSAGING_LOGS;
            
            if (!is_dir($log_dir)) {
                if (!@mkdir($log_dir, 0755, true)) {
                    throw new Exception("Cannot create log directory: $log_dir");
                }
            }
            
            if (!is_writable($log_dir)) {
                throw new Exception("Log directory not writable: $log_dir");
            }
        }
        
        /**
         * Create required database tables.
         */
        private function create_tables() {
            global $wpdb;
            
            $charset_collate = $wpdb->get_charset_collate();
            
            // Chat requests table
            $wpdb->query(
                "CREATE TABLE IF NOT EXISTS " . BZJ_MESSAGING_TABLE_REQUESTS . " (
                    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
                    request_id VARCHAR(36) UNIQUE NOT NULL,
                    requester_wp_id BIGINT UNSIGNED NOT NULL,
                    recipient_wp_id BIGINT UNSIGNED NOT NULL,
                    requester_platform VARCHAR(20) NOT NULL,
                    status VARCHAR(20) DEFAULT 'pending',
                    expires_at DATETIME NOT NULL,
                    created_at DATETIME NOT NULL,
                    updated_at DATETIME NOT NULL,
                    INDEX idx_requester (requester_wp_id),
                    INDEX idx_recipient (recipient_wp_id),
                    INDEX idx_status (status),
                    INDEX idx_expires (expires_at)
                ) $charset_collate"
            );
            
            // Sessions table (short-lived auth tokens)
            $wpdb->query(
                "CREATE TABLE IF NOT EXISTS " . BZJ_MESSAGING_TABLE_SESSIONS . " (
                    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
                    session_id VARCHAR(64) UNIQUE NOT NULL,
                    platform VARCHAR(20) NOT NULL,
                    external_user_id BIGINT UNSIGNED NOT NULL,
                    wp_user_id BIGINT UNSIGNED NOT NULL,
                    token_hash VARCHAR(64) NOT NULL,
                    ip_address VARCHAR(45),
                    user_agent TEXT,
                    expires_at DATETIME NOT NULL,
                    created_at DATETIME NOT NULL,
                    updated_at DATETIME NOT NULL,
                    INDEX idx_platform (platform),
                    INDEX idx_expires (expires_at),
                    INDEX idx_wp_user (wp_user_id)
                ) $charset_collate"
            );
            
            // Identity cache (optional; for debugging/audit)
            $wpdb->query(
                "CREATE TABLE IF NOT EXISTS " . BZJ_MESSAGING_TABLE_IDENTITY . " (
                    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
                    platform VARCHAR(20) NOT NULL,
                    external_user_id BIGINT UNSIGNED NOT NULL,
                    wp_user_id BIGINT UNSIGNED NOT NULL,
                    last_verified DATETIME NOT NULL,
                    created_at DATETIME NOT NULL,
                    UNIQUE KEY unique_mapping (platform, external_user_id),
                    INDEX idx_wp_user (wp_user_id)
                ) $charset_collate"
            );
            
            // Audit log
            $wpdb->query(
                "CREATE TABLE IF NOT EXISTS " . BZJ_MESSAGING_TABLE_AUDIT . " (
                    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
                    action VARCHAR(50) NOT NULL,
                    platform VARCHAR(20),
                    actor_wp_id BIGINT UNSIGNED,
                    actor_external_id BIGINT UNSIGNED,
                    target_wp_id BIGINT UNSIGNED,
                    target_external_id BIGINT UNSIGNED,
                    details JSON,
                    status VARCHAR(20) DEFAULT 'success',
                    error_message TEXT,
                    request_id VARCHAR(36),
                    ip_address VARCHAR(45),
                    created_at DATETIME NOT NULL,
                    INDEX idx_action (action),
                    INDEX idx_actor (actor_wp_id),
                    INDEX idx_target (target_wp_id),
                    INDEX idx_created (created_at),
                    INDEX idx_request (request_id)
                ) $charset_collate"
            );
            
            // Replay protection (prevent signature reuse)
            $wpdb->query(
                "CREATE TABLE IF NOT EXISTS " . BZJ_MESSAGING_TABLE_REPLAY . " (
                    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
                    request_id VARCHAR(36) UNIQUE NOT NULL,
                    platform VARCHAR(20) NOT NULL,
                    signature VARCHAR(128) NOT NULL,
                    timestamp BIGINT UNSIGNED NOT NULL,
                    expires_at DATETIME NOT NULL,
                    created_at DATETIME NOT NULL,
                    INDEX idx_expires (expires_at),
                    INDEX idx_platform (platform)
                ) $charset_collate"
            );
        }
        
        /**
         * Load controlled addons and integrations.
         * 
         * Only whitelisted files matching patterns are loaded.
         */
        public function load_addons_and_integrations() {
            if (!$this->logger) {
                return;
            }
            
            // Load addons
            $this->load_addon_files(BZJ_MESSAGING_ADDONS, BZJ_MESSAGING_ADDON_PATTERN);
            
            // Load integrations
            $this->load_addon_files(BZJ_MESSAGING_INT, BZJ_MESSAGING_INT_PATTERN);
        }
        
        /**
         * Safely load addon/integration files.
         * 
         * @param string $directory Directory to scan
         * @param string $pattern Whitelist pattern (regex)
         */
        private function load_addon_files($directory, $pattern) {
            if (!is_dir($directory)) {
                return;
            }
            
            $files = @scandir($directory);
            if (!is_array($files)) {
                return;
            }
            
            foreach ($files as $file) {
                if (!preg_match($pattern, $file)) {
                    continue;
                }
                
                $filepath = $directory . '/' . $file;
                if (!is_file($filepath) || !is_readable($filepath)) {
                    $this->logger->warning("Addon file not readable: $filepath");
                    continue;
                }
                
                try {
                    require_once $filepath;
                    $this->logger->info("Addon loaded: $file");
                } catch (Exception $e) {
                    $this->logger->error("Addon failed: $file", [
                        'error' => $e->getMessage(),
                    ]);
                }
            }
        }
```

```php
    /**
     * Compute HMAC-SHA256 signature for request validation.
     * 
     * Signature covers:
     *   METHOD|ROUTE|TIMESTAMP|REQUEST_ID|SHA256(BODY)
     */
    function bzj_msg_compute_signature($method, $route, $timestamp, $request_id, $body, $secret) {
        $body_hash = hash('sha256', (string)$body);
        $message = implode('|', [
            strtoupper($method),
            $route,
            $timestamp,
            $request_id,
            $body_hash,
        ]);
        
        return hash_hmac('sha256', $message, $secret);
    }
```

```php
                        'session_id' => $session_id,

                return false;

                    ['%s']
                );
```

```php
         * @param string $request_id Chat request ID
         * @param int $recipient_wp_id Recipient WordPress user ID (accepting)
         * @return int|WP_Error Thread ID or error
         */
        public function accept($request_id, $recipient_wp_id) {
            global $wpdb;
            
            $request_id = sanitize_key($request_id);
            $recipient_wp_id = (int)$recipient_wp_id;
            
            if ($recipient_wp_id < 1) {
                return new WP_Error('bzj_msg_req_invalid_user', 'Invalid recipient');
            }
            
            // Get request
            $request = $wpdb->get_row($wpdb->prepare(
                "SELECT * FROM " . BZJ_MESSAGING_TABLE_REQUESTS . "
                 WHERE request_id = %s",
                $request_id
            ));
            
            if (!$request || $request->status !== 'pending') {
                return new WP_Error('bzj_msg_req_not_found', 'Request not found or expired');
            }
            
            if ((int)$request->recipient_wp_id !== $recipient_wp_id) {
                return new WP_Error('bzj_msg_req_unauthorized', 'You cannot accept this request');
            }
            
            // Mark request as accepted
            $wpdb->update(
                BZJ_MESSAGING_TABLE_REQUESTS,
                [
                    'status' => 'accepted',
                    'updated_at' => current_time('mysql', true),
                ],
                ['request_id' => $request_id],
                ['%s', '%s'],
                ['%s']
            );
            
            // Create Better Messages conversation
            $adapter = BZJ_Messaging_Adapter::instance();
            $thread_id = $adapter->create_conversation(
                (int)$request->requester_wp_id,
                (int)$request->recipient_wp_id
            );
            
            if (is_wp_error($thread_id)) {
                if ($this->logger) {
                    $this->logger->error('Conversation creation failed', [
                        'request_id' => $request_id,
                        'error' => $thread_id->get_error_message(),
                    ]);
                }
                // Revert request status
                $wpdb->update(
                    BZJ_MESSAGING_TABLE_REQUESTS,
                    ['status' => 'pending'],
                    ['request_id' => $request_id]
                );
                return $thread_id;
            }
            
            if ($this->logger) {
                $this->logger->info('Chat request accepted', [
                    'request_id' => $request_id,
                    'thread_id' => $thread_id,
                    'requester_id' => $request->requester_wp_id,
                    'recipient_id' => $recipient_wp_id,
                ]);
            }
            
            do_action(
                'bzj_messaging_request_accepted',
                $request_id,
                (int)$request->requester_wp_id,
                $recipient_wp_id,
                $thread_id
            );
            
            return $thread_id;
        }
        
        /**
         * Decline a chat request.
         */
        public function decline($request_id, $recipient_wp_id) {
            global $wpdb;
            
            $request_id = sanitize_key($request_id);
            $recipient_wp_id = (int)$recipient_wp_id;
            
            $request = $wpdb->get_row($wpdb->prepare(
                "SELECT * FROM " . BZJ_MESSAGING_TABLE_REQUESTS . "
                 WHERE request_id = %s",
                $request_id
            ));
            
            if (!$request || (int)$request->recipient_wp_id !== $recipient_wp_id) {
                return new WP_Error('bzj_msg_req_unauthorized', 'Unauthorized');
            }
            
            $wpdb->update(
                BZJ_MESSAGING_TABLE_REQUESTS,
                ['status' => 'declined'],
                ['request_id' => $request_id]
            );
            
            if ($this->logger) {
                $this->logger->info('Chat request declined', [
                    'request_id' => $request_id,
                ]);
            }
            
            do_action('bzj_messaging_request_declined', $request_id, (int)$request->requester_wp_id, $recipient_wp_id);
            
            return true;
        }
```

```php
        public function verify_signature(WP_REST_Request $request) {
            $platform = $request->get_header(BZJ_MESSAGING_PLATFORM_HEADER);
            $key_id = $request->get_header(BZJ_MESSAGING_KEYID_HEADER);
            $timestamp = $request->get_header(BZJ_MESSAGING_TIMESTAMP_HEADER);

                return false;

            // Validate timestamp
            if (!bzj_msg_is_valid_timestamp($timestamp)) {
                if ($this->logger) {
                    $this->logger->warning('Invalid timestamp', [
                        'timestamp' => $timestamp,
                    ]);
                }
                return false;

            // Check replay
            global $wpdb;
            $seen = $wpdb->get_var($wpdb->prepare(
                "SELECT id FROM " . BZJ_MESSAGING_TABLE_REPLAY . "
                 WHERE request_id = %s LIMIT 1",
                $request_id

                if ($this->logger) {
                    $this->logger->warning('Replay detected', ['request_id' => $request_id]);
                }
                return false;
            }
            
            // Get secret
            $secret = bzj_messaging_get_secret($platform, 'chat_secret');
            if (empty($secret)) {
                if ($this->logger) {
                    $this->logger->error('Missing secret', ['platform' => $platform]);
                }
                return false;
            }

            $body = $request->get_body();
            $route = $request->get_route();
            $method = $request->get_method();

                $method,
                $route,
                $timestamp,
                $request_id,
                $body,
                $secret
            );
            
            // Verify
            if (!hash_equals($signature, $expected_sig)) {
                if ($this->logger) {
                    $this->logger->warning('Invalid signature', [
                        'platform' => $platform,
                        'request_id' => $request_id,
                    ]);
                }
                return false;
            }
            
            // Record replay entry
            $wpdb->insert(
                BZJ_MESSAGING_TABLE_REPLAY,

                    'request_id' => $request_id,
                    'platform' => sanitize_key($platform),
                    'signature' => substr($signature, 0, 128),
```

```php
            $this->key_id = getenv('BZJ_' . strtoupper($this->platform) . '_CHAT_KEY_ID');
            $this->secret = getenv('BZJ_' . strtoupper($this->platform) . '_CHAT_SECRET');
            
            if (empty($this->key_id) || empty($this->secret)) {
                throw new Exception("Missing Buzz Messaging credentials for {$this->platform}");
            }
            
            $this->init_logger();
        }
        
        private function init_logger() {
            $log_file = dirname(__DIR__) . '/bzj-messaging/logs/bzj-msg-' . $this->platform . '-client.log';
            
            $this->logger = [
                'log' => function($level, $message, $context = []) use ($log_file) {
                    $entry = [
                        'timestamp' => gmdate('Y-m-d\TH:i:s\Z'),
                        'level' => strtoupper($level),
                        'platform' => $this->platform,
                        'user_id' => $this->external_user_id,
                        'message' => $message,
                        'context' => $context,
                    ];
                    @file_put_contents($log_file, json_encode($entry) . PHP_EOL, FILE_APPEND | LOCK_EX);
                }
            ];
        }
        
        /**
         * Send a message to recipient.
         * 
         * @param int $recipient_id Recipient external user ID
         * @param string $message Message text
         * @param int $thread_id Thread/conversation ID (if existing)
         * @return array Response or error
         */
        public function send_message($recipient_id, $message, $thread_id = 0) {
            if ($thread_id < 1) {
                // First-contact request
                return $this->create_request($recipient_id, $message);
            }
            
            // Existing thread: send message directly
            $body = [
                'sender_id' => $this->external_user_id,
                'recipient_id' => (int)$recipient_id,
                'thread_id' => (int)$thread_id,
                'message' => (string)$message,
            ];
            
            $response = $this->post('/wp-json/bzj-messaging/v1/message', $body);
            
            return $response;
        }
        
        /**
         * Create a first-contact chat request.
         * 
         * @param int $recipient_id Recipient external user ID
         * @param string $message (optional) Message text to send with request
         * @return array Response with request_id
         */
        public function create_request($recipient_id, $message = '') {
            $body = [
                'requester_id' => $this->external_user_id,
                'recipient_id' => (int)$recipient_id,
            ];
            
            $response = $this->post('/wp-json/bzj-messaging/v1/request', $body);
            
            if (isset($response['success']) && $response['success'] && isset($response['request_id'])) {
                $this->logger['log']('info', 'Chat request created', [
                    'request_id' => $response['request_id'],
                    'recipient_id' => $recipient_id,
                ]);
            } else {
                $this->logger['log']('error', 'Chat request failed', $response);
            }
            
            return $response;
        }
        
        /**
         * Accept a chat request.
         * 
         * @param string $request_id Chat request ID
         * @return array Response with thread_id
         */
        public function accept_request($request_id) {
            $body = [
                'recipient_id' => $this->external_user_id,
            ];
            
            $response = $this->post(
                "/wp-json/bzj-messaging/v1/request/{$request_id}/accept",
                $body
            );
            
            return $response;
        }
        
        /**
         * Decline a chat request.
         * 
         * @param string $request_id Chat request ID
         * @return array Response
         */
        public function decline_request($request_id) {
            $body = [
                'recipient_id' => $this->external_user_id,
            ];
            
            $response = $this->post(
                "/wp-json/bzj-messaging/v1/request/{$request_id}/decline",
                $body
            );
            
            return $response;
        }
        
        /**
         * Make a signed POST request to WordPress gateway.
         * 
         * @param string $endpoint API endpoint (path)
         * @param array $body Request body
         * @return array Response or error
         */
        private function post($endpoint, $body) {
            $url = $this->wordpress_url . $endpoint;
            $timestamp = time();
            $request_id = wp_generate_uuid4();
            $json_body = wp_json_encode($body);
            
            // Compute signature
            $method = 'POST';
            $sig = bzj_msg_compute_signature(
                $method,
                $endpoint,
                $timestamp,
                $request_id,
                $json_body,
                $this->secret
            );
            
            $headers = [
                'Content-Type' => 'application/json',
                BZJ_MESSAGING_PLATFORM_HEADER => $this->platform,
                BZJ_MESSAGING_KEYID_HEADER => $this->key_id,
                BZJ_MESSAGING_TIMESTAMP_HEADER => $timestamp,
                BZJ_MESSAGING_REQUESTID_HEADER => $request_id,
                BZJ_MESSAGING_SIGNATURE_HEADER => $sig,
            ];
            
            $response = wp_remote_post($url, [
                'body' => $json_body,
                'headers' => $headers,
                'timeout' => 10,
                'sslverify' => true,
            ]);
            
            if (is_wp_error($response)) {
                $this->logger['log']('error', 'HTTP request failed', [
                    'endpoint' => $endpoint,
                    'error' => $response->get_error_message(),
                ]);
                return ['success' => false, 'error' => $response->get_error_message()];
            }
            
            $body_str = wp_remote_retrieve_body($response);
            $data = json_decode($body_str, true);
            
            if (!is_array($data)) {
                $this->logger['log']('error', 'Invalid JSON response', [
                    'endpoint' => $endpoint,
                    'body' => substr($body_str, 0, 500),
                ]);
                return ['success' => false, 'error' => 'Invalid response'];
            }
            
            return $data;
        }
    }
}

// Autoload signature functions if not already loaded
if (!function_exists('bzj_msg_compute_signature')) {
    require_once dirname(__DIR__) . '/bzj-messaging/core/helpers.php';
}
```

```javascript
/**
 * Buzz Messaging Client-Side Core
 * 
 * Handles polling, UI updates, and local state.
 * Integrates with platform-specific implementations.

(function(window) {
    'use strict';
    
    window.BZJMessaging = window.BZJMessaging || {};
    
    /**
     * Core messaging client (browser-based).
     */
    BZJMessaging.Client = class {
        
        constructor(config) {
            this.wordpressUrl = config.wordpress_url || '/';
            this.platform = config.platform || 'unknown';
            this.userId = config.user_id || 0;
            this.pollingInterval = config.polling_interval || 5000; // 5 seconds
            this.isPolling = false;
            this.handlers = {};
        }
        
        /**
         * Send a message.
         */
        sendMessage(recipientId, message, threadId = 0) {
            return fetch(this.wordpressUrl + 'wp-json/bzj-messaging/v1/message', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                },
                body: JSON.stringify({
                    sender_id: this.userId,
                    recipient_id: parseInt(recipientId),
                    message: message,
                    thread_id: parseInt(threadId),
                }),
            })
            .then(r => r.json())
            .catch(e => ({success: false, error: e.message}));
        }
        
        /**
         * Start polling for new messages.
         */
        startPolling() {
            if (this.isPolling) return;
            this.isPolling = true;
            this.poll();
        }
        
        stopPolling() {
            this.isPolling = false;
        }
        
        private poll() {
            if (!this.isPolling) return;
            
            // TODO: Implement polling fetch from WordPress
            // Get unread messages, new requests, etc.
            
            setTimeout(() => this.poll(), this.pollingInterval);
        }
        
        /**
         * Register event handler.
         */
        on(event, callback) {
            if (!this.handlers[event]) {
                this.handlers[event] = [];
            }
            this.handlers[event].push(callback);
        }
        
        /**
         * Emit event.
         */
        emit(event, data) {
            if (this.handlers[event]) {
                this.handlers[event].forEach(cb => cb(data));
            }
        }
    };
    
    // Expose global reference
    window.bzjMessaging = window.bzjMessaging || {};
    
})(window);
```

## **Key Architectural Decisions Preserved from v1.2 & Fixed in v1.3**

| Decision | Reasoning |
|----------|-----------|
| **No `wp-load.php` in Streams/Socials** | Cleaner Phase 1; avoids cross-platform DB access issues |
| **HTTPS + HMAC only** | Secure external communication without requiring WordPress in platform code |
| **Separate secrets** | Isolates messaging from connection-sync; independent key rotation |
| **Better Messages API only** | Future-proof against BM upgrades; no fragile direct DB writes |
| **Existing `bzj_relationships` ledger** | Reuses proven connection state; avoids duplicate authority |
| **First-contact = request + acceptance** | Respects user autonomy; prevents unwanted empty threads |
| **Server-side policy enforcement** | JavaScript cannot bypass gating; critical for HS1700 & Palmier phases |
| **Real-time as configurable transport** | Polling works now; Node.js replaces polling later without redesign |
| **Controlled addon discovery** | Only whitelisted files load; prevents injection/conflicts |
