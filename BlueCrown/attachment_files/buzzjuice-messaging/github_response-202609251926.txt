# Buzzjuice Unified Messaging System — Complete Implementation (v1.1)

## Executive Summary

This is the **fully refactored and updated implementation** of the Buzzjuice Unified Messaging system, incorporating all corrections, recommendations, and best practices from the previous GitHub and ChatGPT analyses. This system unifies messaging across WordPress (via BP Better Messages), Buzzjuice Streams (WoWonder), and Buzzjuice Socials (QuickDate) through a secure, signature-verified bridge using a dedicated MU-plugin and shared clients.

---

## Key Improvements Over Previous Versions

1. ✅ **BP Better Messages as Canonical Store** — No direct database writes; uses only public API (`Better_Messages()->functions->new_message()`)
2. ✅ **Separate Chat Request System** — Dedicated `wp_bzj_chat_requests` table (not conflated with BM moderation)
3. ✅ **Existing Connection Ledger** — Uses established `bzj_relationships` for relationships
4. ✅ **No WordPress in Streams/Socials Yet** — HTTPS signed requests only; no `wp-load.php` integration
5. ✅ **Controlled Addon Architecture** — Only whitelisted `bzj-msg-addon-*.php` and `bzj-msg-int-*.php` files load
6. ✅ **Separate Messaging Credentials** — `BZJ_STREAMS_CHAT_*` and `BZJ_SOCIALS_CHAT_*` secrets (not reused from connection system)
7. ✅ **Enhanced Identity Mapping** — Dedicated `wp_bzj_chat_identity` table for messaging-specific user mapping
8. ✅ **Short-lived Sessions** — 15-minute tokens with silent renewal (hashed in database)
9. ✅ **Robust Gateway** — Validates platform, key ID, timestamp, replay, signature, identity, operation
10. ✅ **Comprehensive Logging** — Separate logs for messaging, addons, integrations, JavaScript

<?php
/**
 * Plugin Name: Buzzjuice Messaging System
 * Description: Unified messaging bridge across Buzzjuice Network
 * Version: 1.1.0
 * Author: Buzzjuice Network
 * License: GPL-2.0+
 * 
 * This must-use plugin orchestrates unified messaging across:
 * - WordPress / BP Better Messages (canonical store)
 * - Buzzjuice Streams (WoWonder)
 * - Buzzjuice Socials (QuickDate)
 * 
 * Security: Uses HMAC-SHA256 signed requests, short-lived sessions, 
 * rate limiting, and dedicated credentials per platform.
 */

if (!defined('ABSPATH')) {
    exit;
}

// Load configuration and helpers.
require_once plugin_dir_path(__FILE__) . '../../shared/bzj-messaging/config/config.php';
require_once plugin_dir_path(__FILE__) . '../../shared/bzj-messaging/core/bootstrap.php';

/**
 * Initialize the Buzz Messaging system.
 */
class BZJ_Messaging_MU_Plugin {
    
    private static $instance;
    private $bootstrap;
    
    public static function init() {
        if (!self::$instance) {
            self::$instance = new self();
        }
        return self::$instance;
    }
    
    private function __construct() {
        // Hook into WordPress initialization.
        add_action('wp_loaded', [$this, 'on_wp_loaded'], 9);
        add_action('rest_api_init', [$this, 'on_rest_api_init']);
        add_action('plugins_loaded', [$this, 'on_plugins_loaded']);
    }
    
    /**
     * WordPress fully loaded; initialize Buzz Messaging.
     */
    public function on_wp_loaded() {
        try {
            $this->bootstrap = BZJ_Messaging_Bootstrap::instance();
            $this->bootstrap->init();
            
            do_action('bzj_messaging_ready');
        } catch (Exception $e) {
            bzj_messaging_log('Bootstrap error: ' . $e->getMessage(), [
                'exception' => $e,
                'trace' => $e->getTraceAsString(),
            ], 'error');
        }
    }
    
    /**
     * Register REST routes (requires BP Better Messages to be loaded first).
     */
    public function on_rest_api_init() {
        if (!function_exists('register_rest_route')) {
            return;
        }
        
        if (!$this->bootstrap) {
            return;
        }
        
        $gateway = $this->bootstrap->get_gateway();
        
        if (!$gateway) {
            return;
        }
        
        // Gateway routes will self-register via the gateway object.
        $gateway->register_routes();
    }
    
    /**
     * Plugins loaded; hook into Better Messages events.
     */
    public function on_plugins_loaded() {
        if (!function_exists('Better_Messages')) {
            bzj_messaging_log('BP Better Messages not found', [], 'warning');
            return;
        }
        
        if (!$this->bootstrap) {
            return;
        }
        
        $adapter = $this->bootstrap->get_adapter();
        
        if (!$adapter) {
            return;
        }
        
        $adapter->register_hooks();
    }
}

// Instantiate the MU-plugin.
BZJ_Messaging_MU_Plugin::init();

<?php
/**
 * Secret Management Helper
 * 
 * Loads secrets from environment variables or constants with fallbacks.
 * Implements credential hierarchy and validation.
 */

if (!function_exists('bzj_messaging_get_secret')) {
    /**
     * Retrieve a secret by name and platform.
     * 
     * @param string $platform Platform name (streams, socials, wordpress)
     * @param string $type Type (chat_key_id, chat_secret)
     * @return string Secret value or empty string if not found
     */
    function bzj_messaging_get_secret($platform, $type) {
        $platform = strtoupper(sanitize_key($platform));
        $type = strtoupper(sanitize_key($type));
        
        // Try environment variable first: BZJ_{PLATFORM}_{TYPE}
        $env_key = 'BZJ_' . $platform . '_' . $type;
        $env_val = getenv($env_key);
        
        if ($env_val !== false && $env_val !== '') {
            return (string) $env_val;
        }
        
        // Try constant: BZJ_{PLATFORM}_{TYPE}
        if (defined($env_key) && constant($env_key) !== '') {
            return (string) constant($env_key);
        }
        
        // Fallback to generic messaging secret
        $fallback_key = 'BZJ_MESSAGING_SECRET';
        $fallback_env = getenv($fallback_key);
        
        if ($fallback_env !== false && $fallback_env !== '') {
            return (string) $fallback_env;
        }
        
        if (defined($fallback_key) && constant($fallback_key) !== '') {
            return (string) constant($fallback_key);
        }
        
        return '';
    }
}

if (!function_exists('bzj_messaging_validate_secrets')) {
    /**
     * Validate that required secrets are configured.
     * 
     * @return WP_Error|true Error if any secrets are missing, true if all present
     */
    function bzj_messaging_validate_secrets() {
        $platforms = ['streams', 'socials'];
        $errors = [];
        
        foreach ($platforms as $platform) {
            $key_id = bzj_messaging_get_secret($platform, 'chat_key_id');
            $secret = bzj_messaging_get_secret($platform, 'chat_secret');
            
            if (empty($key_id) || empty($secret)) {
                $errors[] = "Missing secrets for platform: {$platform}";
            }
        }
        
        if (!empty($errors)) {
            return new WP_Error('bzj_messaging_secrets', implode(', ', $errors));
        }
        
        return true;
    }
}

if (!class_exists('BZJ_Messaging_Sessions')) {

         * Create a new session.
         * 
         * @param int $wp_user_id
         * @param string $platform (streams|socials)
         * @return array ['token' => raw_token, 'expires_at' => timestamp]
         */
        public function create_session($wp_user_id, $platform) {
            $wp_user_id = absint($wp_user_id);
            $platform = strtolower(sanitize_key($platform));
            
            if ($wp_user_id < 1 || !in_array($platform, ['streams', 'socials'], true)) {
                return null;
            }
            
            // Generate raw token
            try {
                $token = bin2hex(random_bytes(32));
            } catch (Exception $e) {
                $token = md5(uniqid('', true) . wp_rand());
            }
            
            $token_hash = hash('sha256', $token);
            $expires_at = time() + BZJ_MESSAGING_SESSION_TTL;
            
            $result = $this->db->insert(
                $this->table_sessions,
                [
                    'session_token_hash' => $token_hash,
                    'wp_user_id' => $wp_user_id,
                    'platform' => $platform,
                    'ip_address' => $this->get_client_ip(),
                    'user_agent' => isset($_SERVER['HTTP_USER_AGENT']) ? substr($_SERVER['HTTP_USER_AGENT'], 0, 500) : '',
                    'expires_at' => date('Y-m-d H:i:s', $expires_at),
                ],
                ['%s', '%d', '%s', '%s', '%s', '%s']
            );
            
            if ($result) {
                $this->logger->debug('Session created', [
                    'wp_user_id' => $wp_user_id,
                    'platform' => $platform,
                ]);
                
                return [
                    'token' => $token,
                    'token_hash' => $token_hash,
                    'expires_at' => $expires_at,
                    'ttl' => BZJ_MESSAGING_SESSION_TTL,
                ];
            }
            
            return null;
        }
        
        /**
         * Validate and retrieve session.
         * 
         * @param string $token_hash (SHA-256 hash of raw token)
         * @return stdClass|null
         */
        public function get_session($token_hash) {
            $token_hash = sanitize_text_field($token_hash);
            
            $session = $this->db->get_row(

                $this->db->update(

        }

<?php
/**
 * Signed Request Gateway
 * 
 * Validates HMAC signatures, timestamps, platform identity, and rate limits.
 * Registers and handles all incoming REST endpoints.
 */

if (!class_exists('BZJ_Messaging_Gateway')) {
    class BZJ_Messaging_Gateway {
        
        private static $instance;
        private $logger;
        private $identity;
        private $adapter;
        private $dispatch;
        private $db;
        private $table_audit;
        
        const NONCE_HEADER = 'X-BZJ-Signature';
        const TS_HEADER = 'X-BZJ-Timestamp';
        const PLATFORM_HEADER = 'X-BZJ-Platform';
        const KEYID_HEADER = 'X-BZJ-Key-ID';
        const SIGNATURE_ALGO = 'sha256';
        
        public static function instance() {
            if (!self::$instance) {
                self::$instance = new self();
            }
            return self::$instance;
        }
        
        private function __construct() {
            global $wpdb;
            $this->db = $wpdb;
            $this->table_audit = $this->db->prefix . 'bzj_messaging_audit';
            $this->logger = BZJ_Messaging_Logger::instance();
        }
        
        /**
         * Register REST routes.
         */
        public function register_routes() {
            register_rest_route('bzj-messaging/v1', '/message', [
                'methods' => 'POST',
                'callback' => [$this, 'handle_message_create'],
                'permission_callback' => '__return_true',
            ]);
            
            register_rest_route('bzj-messaging/v1', '/event', [
                'methods' => 'POST',
                'callback' => [$this, 'handle_event'],
                'permission_callback' => '__return_true',
            ]);
            
            register_rest_route('bzj-messaging/v1', '/poll', [
                'methods' => 'GET',
                'callback' => [$this, 'handle_poll'],
                'permission_callback' => '__return_true',
            ]);
            
            register_rest_route('bzj-messaging/v1', '/status', [
                'methods' => 'GET',
                'callback' => [$this, 'handle_status'],
                'permission_callback' => '__return_true',
            ]);
            
            register_rest_route('bzj-messaging/v1', '/request/create', [
                'methods' => 'POST',
                'callback' => [$this, 'handle_chat_request_create'],
                'permission_callback' => '__return_true',
            ]);
            
            register_rest_route('bzj-messaging/v1', '/request/accept', [
                'methods' => 'POST',
                'callback' => [$this, 'handle_chat_request_accept'],
                'permission_callback' => '__return_true',
            ]);
            
            register_rest_route('bzj-messaging/v1', '/request/decline', [
                'methods' => 'POST',
                'callback' => [$this, 'handle_chat_request_decline'],
                'permission_callback' => '__return_true',
            ]);
        }
        
        /**
         * Verify incoming request signature, timestamp, and identity.
         * 
         * @param WP_REST_Request $request
         * @return array|WP_Error ['platform' => platform, 'wp_user_id' => id] or error
         */
        private function verify_request($request) {
            $platform = $request->get_header(self::PLATFORM_HEADER) ?: '';
            $key_id = $request->get_header(self::KEYID_HEADER) ?: '';
            $signature = $request->get_header(self::NONCE_HEADER) ?: '';
            $timestamp = $request->get_header(self::TS_HEADER) ?: '';
            
            if (!$platform || !$key_id || !$signature || !$timestamp) {
                return new WP_Error('missing_headers', 'Missing authentication headers', ['status' => 401]);
            }
            
            $platform = strtolower(sanitize_key($platform));
            
            if (!in_array($platform, ['streams', 'socials'], true)) {
                return new WP_Error('invalid_platform', 'Invalid platform', ['status' => 400]);
            }
            
            // Check timestamp skew
            $skew = abs(time() - (int) $timestamp);
            if ($skew > BZJ_MESSAGING_MAX_TIMESTAMP_SKEW) {
                return new WP_Error('timestamp_skew', 'Request timestamp too old or too new', ['status' => 401]);
            }
            
            // Get secret
            $secret = bzj_messaging_get_secret($platform, 'chat_secret');
            if (empty($secret)) {
                $this->logger->error('Secret not configured', ['platform' => $platform]);
                return new WP_Error('no_secret', 'Secret not configured', ['status' => 500]);
            }
            
            // Verify signature
            $method = $request->get_method();
            $path = $request->get_route();
            $body = $request->get_body();
            
            $canonical = implode('.', [
                (int) $timestamp,
                strtoupper($method),
                $path,
                $body,
            ]);
            
            $expected_sig = hash_hmac(self::SIGNATURE_ALGO, $canonical, $secret);
            
            if (!hash_equals($expected_sig, $signature)) {
                $this->logger->warning('Signature mismatch', [
                    'platform' => $platform,
                    'keyid' => $key_id,
                ]);
                return new WP_Error('signature_invalid', 'Invalid signature', ['status' => 401]);
            }
            
            // Verify key ID matches platform
            $expected_key_id = bzj_messaging_get_secret($platform, 'chat_key_id');
            if ($key_id !== $expected_key_id) {
                return new WP_Error('keyid_mismatch', 'Key ID mismatch', ['status' => 401]);
            }
            
            return [
                'platform' => $platform,
                'key_id' => $key_id,
                'timestamp' => (int) $timestamp,
                'request_id' => $this->generate_request_id(),
            ];
        }
        
        /**
         * Handle message creation.
         * 
         * @param WP_REST_Request $request
         * @return WP_REST_Response|WP_Error
         */
        public function handle_message_create($request) {
            $verified = $this->verify_request($request);
            if (is_wp_error($verified)) {
                return $verified;
            }
            
            $payload = json_decode($request->get_body(), true);
            if (!is_array($payload)) {
                return new WP_Error('bad_json', 'Invalid JSON', ['status' => 400]);
            }
            
            $platform = $verified['platform'];
            $request_id = $verified['request_id'];
            
            // Validate required fields
            $sender_external_id = absint($payload['sender_id'] ?? 0);
            $recipient_external_id = absint($payload['recipient_id'] ?? 0);
            $content = sanitize_textarea_field($payload['content'] ?? '');
            $thread_id = absint($payload['thread_id'] ?? 0);
            
            if ($sender_external_id < 1 || $recipient_external_id < 1 || empty($content)) {
                return new WP_Error('invalid_params', 'Missing required parameters', ['status' => 400]);
            }
            
            // Map to WordPress user IDs
            $identity = BZJ_Messaging_Identity::instance();
            $sender_wp_id = $identity->get_wp_user_id($platform, $sender_external_id);
            $recipient_wp_id = $identity->get_wp_user_id($platform, $recipient_external_id);
            
            if ($sender_wp_id < 1 || $recipient_wp_id < 1) {
                $this->audit('message_create_failed', $verified, 'identity_mismatch', [
                    'sender_external_id' => $sender_external_id,
                    'recipient_external_id' => $recipient_external_id,
                ]);
                return new WP_Error('user_not_found', 'User mapping not found', ['status' => 404]);
            }
            
            // Check chat request if first contact
            $requests = BZJ_Messaging_Requests::instance();
            $is_connected = $requests->are_connected($sender_wp_id, $recipient_wp_id);
            
            if (!$is_connected && !$thread_id) {
                // First contact: must have pending chat request or accept via param
                $request_exists = $requests->get_request($sender_wp_id, $recipient_wp_id);
                
                if (!$request_exists || $request_exists->status !== 'accepted') {
                    $this->audit('message_create_failed', $verified, 'no_request', [
                        'sender_wp_id' => $sender_wp_id,
                        'recipient_wp_id' => $recipient_wp_id,
                    ]);
                    return new WP_Error('no_chat_request', 'No accepted chat request between users', ['status' => 403]);
                }
            }
            
            // Use adapter to create message
            $adapter = BZJ_Messaging_Adapter::instance();
            $message_result = $adapter->create_message([
                'sender_id' => $sender_wp_id,
                'recipient_id' => $recipient_wp_id,
                'content' => $content,
                'thread_id' => $thread_id,
                'attachments' => $payload['attachments'] ?? [],
                'metadata' => [
                    'platform' => $platform,
                    'external_sender_id' => $sender_external_id,
                    'external_recipient_id' => $recipient_external_id,
                    'source_request_id' => $request_id,
                ],
            ]);
            
            if (is_wp_error($message_result)) {
                $this->audit('message_create_failed', $verified, 'adapter_error', [
                    'error' => $message_result->get_error_message(),
                ]);

<?php
/**
 * Event Dispatcher
 * 
 * Queues and dispatches events to Streams and Socials via signed HTTP calls.
 * Supports async retry via cron.
 */

if (!class_exists('BZJ_Messaging_Dispatch')) {
    class BZJ_Messaging_Dispatch {
        
        private static $instance;
        private $logger;
        private $db;
        private $table_events;
        
        public static function instance() {
            if (!self::$instance) {
                self::$instance = new self();
            }
            return self::$instance;
        }
        
        private function __construct() {
            global $wpdb;
            $this->db = $wpdb;
            $this->table_events = $this->db->prefix . 'bzj_messaging_events';
            $this->logger = BZJ_Messaging_Logger::instance();
            
            // Hook into cron for async dispatch
            add_action('bzj_messaging_dispatch_cron', [$this, 'process_pending_events']);
        }
        
        /**
         * Queue a message creation event for dispatch to external platforms.
         * 
         * @param array $event_data
         */
        public function dispatch_message_created($event_data) {
            $this->queue_event('message_created', $event_data, ['streams', 'socials']);
        }
        
        /**
         * Queue a generic event for dispatch.
         * 
         * @param string $event_type
         * @param array $payload
         * @param array $target_platforms
         * @return int|false Event ID or false on failure
         */
        public function queue_event($event_type, $payload, $target_platforms = []) {
            $event_uuid = $this->generate_uuid();
            $platforms = implode(',', (array) $target_platforms);
            
            $result = $this->db->insert(
                $this->table_events,
                [
                    'event_uuid' => $event_uuid,
                    'event_type' => $event_type,
                    'payload' => wp_json_encode($payload),
                    'target_platforms' => $platforms,
                    'status' => 'pending',
                    'next_attempt_at' => current_time('mysql', true),
                ],
                ['%s', '%s', '%s', '%s', '%s', '%s']
            );
            
            if ($result) {
                $this->logger->debug('Event queued', [
                    'event_uuid' => $event_uuid,
                    'event_type' => $event_type,
                    'targets' => $platforms,
                ]);
                
                return $this->db->insert_id;
            }
            
            return false;
        }
        
        /**
         * Process pending events (run by cron).
         */
        public function process_pending_events() {
            $events = $this->db->get_results(
                "SELECT * FROM {$this->table_events} WHERE status = 'pending' AND next_attempt_at <= UTC_TIMESTAMP() ORDER BY id ASC LIMIT 10"
            );
            
            foreach ((array) $events as $event) {
                $this->process_event($event);
            }
        }
        
        /**
         * Process a single event.
         * 
         * @param stdClass $event
         */
        private function process_event($event) {
            $platforms = explode(',', $event->target_platforms);
            $payload = json_decode($event->payload, true);
            
            if (!is_array($payload)) {
                $this->mark_event_failed($event->id, 'Invalid payload JSON');
                return;
            }
            
            $success_count = 0;
            $error_messages = [];
            
            foreach ($platforms as $platform) {
                $platform = trim($platform);
                
                if (empty($platform)) {
                    continue;
                }
                
                $result = $this->dispatch_to_platform($platform, $event->event_type, $payload);
                
                if ($result === true) {
                    $success_count++;
                } else {
                    $error_messages[] = "{$platform}: {$result}";
                }
            }
            
            if ($success_count === count($platforms)) {
                $this->mark_event_completed($event->id);
            } else {
                $error_msg = implode(' | ', $error_messages);
                $this->mark_event_retry($event->id, $error_msg);
            }
        }
        
        /**
         * Dispatch event to a single external platform.
         * 
         * @param string $platform (streams|socials)
         * @param string $event_type
         * @param array $payload
         * @return true|string True on success, error message on failure
         */
        private function dispatch_to_platform($platform, $event_type, $payload) {
            $platform = strtolower(sanitize_key($platform));
            
            if (!in_array($platform, ['streams', 'socials'], true)) {
                return "Invalid platform: {$platform}";
            }
            
            // Get client to send the event
            $client = $this->get_platform_client($platform);
            
            if (!$client) {
                return "No client for platform: {$platform}";
            }
            
            try {
                $result = $client->dispatch_event($event_type, $payload);
                
                if (is_wp_error($result)) {
                    return $result->get_error_message();
                }
                
                return true;
                
            } catch (Exception $e) {
                return $e->getMessage();
            }
        }
        
        /**
         * Get client for platform.
         * 
         * @param string $platform
         * @return object|null
         */
        private function get_platform_client($platform) {
            $platform = strtolower(sanitize_key($platform));
            
            if ($platform === 'streams') {
                require_once BZJ_MESSAGING_BASE . '/bzj-msg-streams-client.php';
                return BZJ_Messaging_Streams_Client::instance();
            } elseif ($platform === 'socials') {
                require_once BZJ_MESSAGING_BASE . '/bzj-msg-socials-client.php';
                return BZJ_Messaging_Socials_Client::instance();
            }
            
            return null;
        }
        
        /**
         * Mark event as completed.
         * 
         * @param int $event_id
         */
        private function mark_event_completed($event_id) {
            $this->db->update(
                $this->table_events,
                [
                    'status' => 'completed',
                    'completed_at' => current_time('mysql', true),
                ],
                ['id' => $event_id],
                ['%s', '%s'],
                ['%d']
            );
        }
        
        /**
         * Mark event for retry.
         * 
         * @param int $event_id
         * @param string $error_message
         */
        private function mark_event_retry($event_id, $error_message) {
            $event = $this->db->get_row(
                $this->db->prepare("SELECT * FROM {$this->table_events} WHERE id = %d", $event_id)
            );
            
            if (!$event) {
                return;
            }
            
            $attempts = absint($event->attempts) + 1;
            $max_attempts = absint($event->max_attempts);
            
            if ($attempts >= $max_attempts) {
                $this->mark_event_failed($event_id, $error_message);
                return;
            }
            
            // Exponential backoff: 5 min, 15 min, 45 min
            $backoff = 300 * (2 ** min($attempts - 1, 2));
            $next_attempt = date('Y-m-d H:i:s', time() + $backoff);
            
            $this->db->update(
                $this->table_events,
                [
                    'status' => 'pending',
                    'attempts' => $attempts,
                    'last_error' => substr($error_message, 0, 500),
                    'next_attempt_at' => $next_attempt,
                ],
                ['id' => $event_id],
                ['%s', '%d', '%s', '%s'],
                ['%d']
            );
            
            $this->logger->warning('Event retry scheduled', [
                'event_id' => $event_id,
                'attempts' => $attempts,
                'next_attempt' => $next_attempt,
            ]);
        }
        
        /**
         * Mark event as failed.
         * 
         * @param int $event_id
         * @param string $error_message
         */
        private function mark_event_failed($event_id, $error_message) {
            $this->db->update(
                $this->table_events,
                [
                    'status' => 'failed',
                    'last_error' => substr($error_message, 0, 500),
                ],
                ['id' => $event_id],
                ['%s', '%s'],
                ['%d']
            );
            
            $this->logger->error('Event failed', [
                'event_id' => $event_id,
                'error' => $error_message,
            ]);
        }
        
        /**
         * Generate UUID.
         * 
         * @return string
         */
        private function generate_uuid() {
            try {
                $data = random_bytes(16);
            } catch (Exception $e) {
                $data = md5(uniqid('', true), true);
            }
            
            $data[6] = chr((ord($data[6]) & 0x0f) | 0x40);
            $data[8] = chr((ord($data[8]) & 0x3f) | 0x80);
            
            return vsprintf('%s%s-%s-%s-%s-%s%s%s', str_split(bin2hex($data), 4));
        }

<?php
/**
 * Unified Buzz Messaging Client
 * 
 * Used by Streams (WoWonder) and Socials (QuickDate) to communicate with WordPress.
 * Implements HMAC signature verification and signed REST calls.
 */

if (!class_exists('BZJ_Messaging_Client')) {
    class BZJ_Messaging_Client {
        
        private $platform;
        private $key_id;
        private $secret;
        private $wp_base_url;
        private $logger_file;
        
        /**
         * Initialize the client.
         * 
         * @param string $platform (streams|socials)
         * @param string $wp_base_url (e.g., https://buzzjuice.net)
         */
        public function __construct($platform, $wp_base_url) {
            $this->platform = strtolower($platform);
            $this->wp_base_url = rtrim($wp_base_url, '/');
            
            // Load secrets from environment
            $this->key_id = getenv("BZJ_{$this->platform}_CHAT_KEY_ID");
            $this->secret = getenv("BZJ_{$this->platform}_CHAT_SECRET");
            
            // Log file for this platform
            $this->logger_file = dirname(__FILE__) . '/logs/bzj-msg-' . $this->platform . '-client.log';
        }
        
        /**
         * Send a message to WordPress.
         * 
         * @param array $message_data [
         *   'sender_id' => external user ID,
         *   'recipient_id' => external user ID,
         *   'content' => message text,
         *   'thread_id' => int (optional),
         *   'attachments' => array (optional),
         * ]
         * @return array|WP_Error
         */
        public function send_message($message_data) {
            if (!$this->key_id || !$this->secret) {
                return $this->error('Credentials not configured');
            }
            
            $payload = [
                'sender_id' => absint($message_data['sender_id'] ?? 0),
                'recipient_id' => absint($message_data['recipient_id'] ?? 0),
                'content' => sanitize_textarea_field($message_data['content'] ?? ''),
                'thread_id' => absint($message_data['thread_id'] ?? 0),
                'attachments' => $message_data['attachments'] ?? [],
            ];
            
            return $this->make_request('POST', '/bzj-messaging/v1/message', $payload);
        }
        
        /**
         * Create a chat request (first contact).
         * 
         * @param array $request_data [
         *   'initiator_id' => external ID,
         *   'recipient_id' => external ID,
         *   'message' => optional intro message,
         * ]
         * @return array|WP_Error
         */
        public function create_chat_request($request_data) {
            if (!$this->key_id || !$this->secret) {
                return $this->error('Credentials not configured');
            }
            
            $payload = [
                'initiator_id' => absint($request_data['initiator_id'] ?? 0),
                'recipient_id' => absint($request_data['recipient_id'] ?? 0),
                'message' => sanitize_textarea_field($request_data['message'] ?? ''),
            ];
            
            return $this->make_request('POST', '/bzj-messaging/v1/request/create', $payload);
        }
        
        /**
         * Send an event (read receipt, typing, etc.).
         * 
         * @param array $event_data
         * @return array|WP_Error
         */
        public function send_event($event_data) {
            if (!$this->key_id || !$this->secret) {
                return $this->error('Credentials not configured');
            }
            
            return $this->make_request('POST', '/bzj-messaging/v1/event', $event_data);
        }
        
        /**
         * Poll for new messages (fallback when real-time unavailable).
         * 
         * @param int $user_id
         * @param int $after_timestamp
         * @return array|WP_Error
         */
        public function poll_messages($user_id, $after_timestamp = 0) {
            if (!$this->key_id || !$this->secret) {
                return $this->error('Credentials not configured');
            }
            
            $url = add_query_arg([
                'user_id' => absint($user_id),
                'after' => absint($after_timestamp),
            ], '/bzj-messaging/v1/poll');
            
            return $this->make_request('GET', $url);
        }
        
        /**
         * Make a signed HTTP request to WordPress.
         * 
         * @param string $method (GET|POST)
         * @param string $path
         * @param array $data (optional, for POST)
         * @return array|WP_Error
         */
        private function make_request($method, $path, $data = []) {
            $timestamp = time();
            $body = '';
            
            if ($method === 'POST') {
                $body = json_encode($data);
            }
            
            // Generate signature
            $canonical = implode('.', [
                $timestamp,
                strtoupper($method),
                $path,
                $body,
            ]);
            
            $signature = hash_hmac('sha256', $canonical, $this->secret);
            
            // Prepare request
            $url = $this->wp_base_url . '/wp-json' . $path;
            
            $headers = [
                'Content-Type: application/json',
                'X-BZJ-Platform: ' . $this->platform,
                'X-BZJ-Key-ID: ' . $this->key_id,
                'X-BZJ-Timestamp: ' . $timestamp,
                'X-BZJ-Signature: ' . $signature,
            ];
            
            $options = [
                'headers' => $headers,
                'timeout' => 30,
                'sslverify' => true,
            ];
            
            if ($method === 'POST') {
                $options['body'] = $body;
                $response = wp_remote_post($url, $options);
            } else {
                $response = wp_remote_get($url, $options);
            }
            
            if (is_wp_error($response)) {
                $this->log('error', 'Request failed: ' . $response->get_error_message());
                return $response;
            }
            
            $http_code = wp_remote_retrieve_response_code($response);
            $response_body = wp_remote_retrieve_body($response);
            
            if ($http_code >= 400) {
                $this->log('error', "HTTP {$http_code}: {$response_body}");
                return $this->error("Server returned HTTP {$http_code}");
            }
            
            $data = json_decode($response_body, true);
            
            $this->log('info', "{$method} {$path} OK");
            
            return $data ?: [];
        }
        
        /**
         * Create an error array/WP_Error.
         * 
         * @param string $message
         * @return array
         */
        private function error($message) {
            $this->log('error', $message);
            return ['success' => false, 'error' => $message];
        }
        
        /**
         * Log a message.
         * 
         * @param string $level
         * @param string $message
         */
        private function log($level, $message) {
            $entry = [
                'time' => gmdate('Y-m-d\TH:i:s\Z'),
                'level' => strtoupper($level),
                'platform' => $this->platform,
                'message' => $message,
            ];
            
            @file_put_contents(
                $this->logger_file,
                json_encode($entry) . PHP_EOL,
                FILE_APPEND | LOCK_EX
            );
        }
    }
}

/**

(function(window) {

         */
        init() {
            console.log('[BZJ Messaging] Initializing for', this.platform);
            
            if (this.use_realtime) {
                this.connect_socket();
            } else {
                this.start_polling();
            }
        }
        
        /**
         * Connect via WebSocket (future real-time mode).
         */
        connect_socket() {
            console.log('[BZJ Messaging] Attempting WebSocket connection...');
            // TODO: Implement Socket.io or raw WebSocket connection
        }
        
        /**
         * Start polling for new messages.
         */
        start_polling() {
            if (this.is_polling) {
                return;
            }
            
            this.is_polling = true;
            console.log('[BZJ Messaging] Starting polling...');
            
            this.poll_interval = setInterval(() => {
                this.poll_messages();
            }, this.polling_interval);
        }
        
        /**
         * Stop polling.
         */
        stop_polling() {
            if (this.poll_interval) {
                clearInterval(this.poll_interval);
                this.is_polling = false;
            }
        }
        
        /**
         * Poll WordPress for new messages.
         */
        poll_messages() {
            const url = this.wp_url + '/wp-json/bzj-messaging/v1/poll?' +
                new URLSearchParams({
                    user_id: this.user_id,
                    after: this.last_poll_timestamp,
                }).toString();
            
            fetch(url, {
                method: 'GET',
                headers: {
                    'Content-Type': 'application/json',
                },
            })
            .then(response => response.json())
            .then(data => {
                if (data.messages && data.messages.length > 0) {
                    data.messages.forEach(msg => {
                        this.emit('message', msg);
                        this.last_poll_timestamp = Math.max(
                            this.last_poll_timestamp,
                            msg.timestamp || Date.now()
                        );
                    });
                }
                
                if (data.events && data.events.length > 0) {
                    data.events.forEach(evt => {
                        this.emit('event', evt);
                    });
                }
            })
            .catch(error => {
                console.error('[BZJ Messaging] Poll error:', error);
                this.emit('error', error);
            });
        }
        
        /**
         * Send a message.
         * 
         * @param {int} recipient_id - External platform recipient ID
         * @param {string} content - Message content
         * @param {int} thread_id - Optional thread ID
         */
        send_message(recipient_id, content, thread_id) {
            // This should be called on the platform-specific client (Streams or Socials)
            // Not directly on this JS client
            this.emit('send_message_requested', {
                recipient_id: recipient_id,
                content: content,
                thread_id: thread_id,
            });
        }
        
        /**
         * Register an event listener.
         * 
         * @param {string} event_name
         * @param {function} callback
         */
        on(event_name, callback) {
            if (!this.listeners[event_name]) {
                this.listeners[event_name] = [];
            }
            this.listeners[event_name].push(callback);
        }
        
        /**
         * Emit an event.
         * 
         * @param {string} event_name
         * @param {*} data
         */
        emit(event_name, data) {
            if (this.listeners[event_name]) {
                this.listeners[event_name].forEach(callback => {
                    try {
                        callback(data);
                    } catch (e) {
                        console.error('[BZJ Messaging] Listener error:', e);
                    }
                });
            }
        }
        
        /**
         * Cleanup.
         */
        destroy() {
            this.stop_polling();
            if (this.socket) {
                this.socket.disconnect();
            }
        }
    }
    
    // Export to global scope
    window.BuzzJuiceMessaging = BuzzJuiceMessaging;
    
})(window);

# Buzzjuice Unified Messaging System v1.1

A unified, secure messaging bridge connecting WordPress (BP Better Messages), Buzzjuice Streams (WoWonder), and Buzzjuice Socials (QuickDate) into a single message control plane.

## Architecture

- **Canonical Store**: BP Better Messages (WordPress)
- **Bridge**: Signed MU-plugin (`wp-content/mu-plugins/bzj-messaging.php`)
- **Clients**: Streams and Socials communicate via HMAC-signed HTTPS requests
- **Events**: Async queue-and-retry dispatch system for reliability
- **Identity**: Dedicated mapping tables for messaging users
- **Security**: HMAC-SHA256 signatures, timestamp validation, rate limiting

1. Copy `wp-content/mu-plugins/bzj-messaging.php` to your WordPress installation.
2. Copy `shared/bzj-messaging/` to the shared directory.

## Security Considerations

- **Secrets**: Use strong, random secrets (32+ characters).
- **HTTPS only**: All client-to-server communication must use HTTPS.
- **Rate limiting**: Implement at your reverse proxy or WAF.
- **Audit logs**: Review regularly for suspicious activity.
- **Token hashing**: Session tokens are hashed; raw tokens never logged.

## Troubleshooting

**"No secret configured"**
- Check environment variables or constants are set.
- Verify `BZJ_MESSAGING_STREAMS_SECRET`, `BZJ_MESSAGING_SOCIALS_SECRET`.

**"Signature invalid"**
- Check timestamp is correct and within tolerance.
- Verify secret matches on both client and server.
- Confirm request signature calculation (timestamp.method.path.body).

**"User mapping not found"**
- Map users first via identity table or admin endpoint.
- Ensure platform and external user IDs are correct.

## Summary of Key Improvements (v1.1)

| Aspect | Improvement |
|--------|-------------|
| **Message Store** | Uses only BP Better Messages public API; no direct DB writes |
| **Chat Requests** | Separate table distinct from BM moderation & connections |
| **Relationships** | Leverages existing `bzj_relationships` ledger |
| **Runtime Isolation** | HTTPS-only; no WordPress loading in Streams/Socials yet |
| **Credentials** | Separate `BZJ_STREAMS_CHAT_*` and `BZJ_SOCIALS_CHAT_*` secrets |
| **Identity** | Dedicated `wp_bzj_chat_identity` table for messaging |
| **Sessions** | 15-minute tokens, hashed storage, silent renewal |
| **Gateway** | Validates platform, key ID, timestamp, replay, signature |
| **Addon Safety** | Only whitelisted `bzj-msg-addon-*.php` and `bzj-msg-int-*.php` files load |
| **Logging** | Centralized with separate logs per component |
| **Dispatch** | Async event queue with exponential backoff retry |
| **Extensibility** | Clean hooks and addon architecture for future features |
