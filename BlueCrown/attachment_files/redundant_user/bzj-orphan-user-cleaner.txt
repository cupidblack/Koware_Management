This could be done by checking the Wo_Users table for all existing user ids then checking the referenced tables for any existing user data that does not match with any existing user. The identified data could be shown after a dry run then optimally processed to clear the redundant user data.

The db_helpers file contains Wowonder database connection details.

Note the following:
<<START NOTES>>

1. The file should be placed in the root directory at 'buzzjuice.net/streams/bzj-orphan-user-cleaner.php'.

2. When the file is accessed, a ui should display with options to start the dry run, and any other option.

3. The dry run should show results of items the would be removed. The admin can then choose to proceed with the clean.

4. Results of the clean should be shown after the clean.
