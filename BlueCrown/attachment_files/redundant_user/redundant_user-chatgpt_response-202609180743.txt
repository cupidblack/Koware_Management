### Recommended operating sequence

1. Upload the file.
2. Log into Buzzjuice as a WordPress administrator.
3. Open the cleaner URL.
4. **Start dry run**.
5. Review:

   * WoWonder orphan references.
   * QuickDate orphan references.
   * advisory/unmapped tables.
   * WordPress → WoWonder ID anomalies.
   * WordPress → QuickDate ID anomalies.
6. If the orphan findings are correct, enter:
   `DELETE CONFIRMED ORPHANS`
7. Separately review the mapping findings.
8. If the repairable matches are correct, enter:
   `REPAIR CONFIRMED ID MISMATCHES`
9. Review the post-operation verification.

One particularly important design decision is that **schema discovery is intentionally not destructive**. This is consistent with the GitHub review's distinction between confirmed references and advisory discovery. ([GitHub][1])
