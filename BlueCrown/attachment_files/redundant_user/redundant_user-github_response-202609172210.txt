Below is a standalone PHP cleanup script. It performs a **dry run by default**, reports orphaned rows, and only deletes data when explicitly executed.

Save it outside the repository if possible, for example:

```text
tools/cleanup_orphaned_wowonder_users.php
```

Run:

```bash
php cleanup_orphaned_wowonder_users.php
```

Actually delete orphaned rows only after reviewing the dry-run report:

```bash
php cleanup_orphaned_wowonder_users.php --execute --yes
```

```php name=cleanup_orphaned_wowonder_users.php
<?php
/**
 * WoWonder orphaned-user cleanup utility.
 *
 * Dry run:
 *   php cleanup_orphaned_wowonder_users.php
 *
 * Execute deletion:
 *   php cleanup_orphaned_wowonder_users.php --execute --yes
 *
 * Optional:
 *   php cleanup_orphaned_wowonder_users.php --execute --yes --user-id=123
 *
 * This script:
 * - Reads valid user IDs from Wo_Users.
 * - Finds rows in WoWonder tables that reference missing users.
 * - Reports the rows during a dry run.
 * - Deletes them only with --execute --yes.
 *
 * It does not delete media files, S3 objects, WordPress records,
 * QuickDate records, or Palmier records.
 */

declare(strict_types=1);

if (PHP_SAPI !== 'cli') {
    http_response_code(403);
    exit("This script must be executed from the command line.\n");
}

require_once dirname(__DIR__) . '/shared/db_helpers.php';

$conn = get_wowonder_db();

if (!$conn instanceof mysqli) {
    fwrite(STDERR, "Unable to connect to the WoWonder database.\n");
    exit(1);
}

$conn->set_charset('utf8mb4');

$options = getopt('', [
    'execute',
    'yes',
    'user-id:',
    'limit:',
]);

$execute = isset($options['execute']);
$confirmed = isset($options['yes']);
$filterUserId = null;
$reportLimit = 100;

if (isset($options['user-id'])) {
    if (!ctype_digit((string)$options['user-id']) || (int)$options['user-id'] < 1) {
        fwrite(STDERR, "--user-id must be a positive integer.\n");
        exit(1);
    }

    $filterUserId = (int)$options['user-id'];
}

if (isset($options['limit'])) {
    if (!ctype_digit((string)$options['limit']) || (int)$options['limit'] < 1) {
        fwrite(STDERR, "--limit must be a positive integer.\n");
        exit(1);
    }

    $reportLimit = (int)$options['limit'];
}

if ($execute && !$confirmed) {
    fwrite(
        STDERR,
        "Deletion was requested, but confirmation is missing.\n" .
        "Re-run with both --execute and --yes.\n"
    );
    exit(1);
}

echo $execute
    ? "EXECUTION MODE: orphaned rows will be deleted.\n"
    : "DRY-RUN MODE: no rows will be modified.\n";

if ($filterUserId !== null) {
    echo "Filtering orphan checks for user ID: {$filterUserId}\n";
}

echo "\n";

/**
 * Quote a trusted database identifier.
 */
function quoteIdentifier(string $identifier): string
{
    if (!preg_match('/^[A-Za-z0-9_]+$/', $identifier)) {
        throw new RuntimeException("Unsafe database identifier: {$identifier}");
    }

    return '`' . $identifier . '`';
}

/**
 * Execute a query and throw a useful error.
 */
function queryOrFail(mysqli $conn, string $sql): mysqli_result|bool
{
    $result = $conn->query($sql);

    if ($result === false) {
        throw new RuntimeException($conn->error . "\nSQL: " . $sql);
    }

    return $result;
}

/**
 * Return whether a table exists.
 */
function tableExists(mysqli $conn, string $table): bool
{
    $safeTable = $conn->real_escape_string($table);
    $result = $conn->query("SHOW TABLES LIKE '{$safeTable}'");

    return $result !== false && $result->num_rows > 0;
}

/**
 * Return all columns in a table.
 */
function getTableColumns(mysqli $conn, string $table): array
{
    $quotedTable = quoteIdentifier($table);
    $result = queryOrFail($conn, "SHOW COLUMNS FROM {$quotedTable}");

    $columns = [];

    while ($row = $result->fetch_assoc()) {
        $columns[strtolower((string)$row['Field'])] = (string)$row['Field'];
    }

    return $columns;
}

/**
 * Return the number of valid WoWonder users.
 */
function getExistingUserCount(mysqli $conn): int
{
    $result = queryOrFail(
        $conn,
        "SELECT COUNT(*) AS total FROM `Wo_Users`"
    );

    $row = $result->fetch_assoc();

    return (int)($row['total'] ?? 0);
}

/**
 * Build a safe orphan condition.
 *
 * A row is orphaned when its reference column contains a positive user ID
 * that does not exist in Wo_Users.
 */
function orphanCondition(
    string $column,
    ?int $filterUserId = null
): string {
    $quotedColumn = quoteIdentifier($column);

    $condition = "{$quotedColumn} IS NOT NULL
        AND {$quotedColumn} <> 0
        AND NOT EXISTS (
            SELECT 1
            FROM `Wo_Users` AS valid_users
            WHERE valid_users.`user_id` = {$quotedColumn}
        )";

    if ($filterUserId !== null) {
        $condition .= " AND {$quotedColumn} = " . (int)$filterUserId;
    }

    return $condition;
}

/**
 * Include user-dependent rows from Wo_Posts that may have been left behind.
 *
 * This is intentionally handled as a normal reference table. It only deletes
 * posts whose user_id or recipient_id no longer exists in Wo_Users.
 */
if (!tableExists($conn, 'Wo_Users')) {
    fwrite(STDERR, "Required table Wo_Users does not exist.\n");
    exit(1);
}

$existingUserCount = getExistingUserCount();

echo "Existing WoWonder users: {$existingUserCount}\n\n";

$findings = [];
$totalOrphanRows = 0;

foreach ($references as $table => $columns) {
    if (!tableExists($conn, $table)) {
        continue;
    }

    $tableColumns = getTableColumns($conn, $table);
    $availableColumns = [];

    foreach ($columns as $column) {
        $columnKey = strtolower($column);

        if (isset($tableColumns[$columnKey])) {
            $availableColumns[] = $tableColumns[$columnKey];
        }
    }

    if (empty($availableColumns)) {
        continue;
    }

    $quotedTable = quoteIdentifier($table);

    $conditions = [];

    foreach ($availableColumns as $column) {
        $conditions[] = '(' . orphanCondition($column, $filterUserId) . ')';
    }

    $where = implode(' OR ', $conditions);

    $countResult = queryOrFail(
        $conn,
        "SELECT COUNT(*) AS total
         FROM {$quotedTable}
         WHERE {$where}"
    );

    $countRow = $countResult->fetch_assoc();
    $count = (int)($countRow['total'] ?? 0);

    if ($count === 0) {
        continue;
    }

    $totalOrphanRows += $count;

    echo "{$table}: {$count} orphaned row(s)\n";

    foreach ($availableColumns as $column) {
        $columnCondition = orphanCondition($column, $filterUserId);

        $columnCountResult = queryOrFail(
            $conn,
            "SELECT COUNT(*) AS total
             FROM {$quotedTable}
             WHERE {$columnCondition}"
        );

        $columnCountRow = $columnCountResult->fetch_assoc();
        $columnCount = (int)($columnCountRow['total'] ?? 0);

        if ($columnCount === 0) {
            continue;
        }

        echo "  - {$column}: {$columnCount} orphaned reference(s)\n";

        $sampleSql = "
            SELECT DISTINCT {$quotedTable}.{$column} AS orphan_user_id
            FROM {$quotedTable}
            WHERE {$columnCondition}
            ORDER BY {$quotedTable}.{$column}
            LIMIT " . (int)$reportLimit;

        $sampleResult = queryOrFail($conn, $sampleSql);
        $sampleIds = [];

        while ($sampleRow = $sampleResult->fetch_assoc()) {
            $sampleIds[] = (string)$sampleRow['orphan_user_id'];
        }

        if (!empty($sampleIds)) {
            echo "    Sample missing user IDs: " . implode(', ', $sampleIds) . "\n";
        }

        $findings[] = [
            'table' => $table,
            'column' => $column,
            'count' => $columnCount,
            'condition' => $columnCondition,
        ];
    }

    echo "\n";
}

if (empty($findings)) {
    echo "No orphaned user references were found.\n";
    exit(0);
}

echo "Total orphaned reference matches: {$totalOrphanRows}\n";

if (!$execute) {
    echo "\nDry run complete. No database rows were changed.\n";
    echo "Review the report, then execute with:\n";
    echo "  php " . basename(__FILE__) . " --execute --yes\n";
    exit(0);
}

echo "\nBeginning deletion transaction...\n";

if (!$conn->begin_transaction()) {
    fwrite(STDERR, "Unable to start database transaction: {$conn->error}\n");
    exit(1);
}

$deletedRows = 0;

try {
    foreach ($findings as $finding) {
        $table = $finding['table'];
        $column = $finding['column'];
        $condition = $finding['condition'];

        $quotedTable = quoteIdentifier($table);

        $deleteSql = "
            DELETE FROM {$quotedTable}
            WHERE {$condition}
        ";

        queryOrFail($conn, $deleteSql);

        $affected = $conn->affected_rows;
        $deletedRows += $affected;

        echo "Deleted {$affected} row(s) from {$table}.{$column}\n";
    }

    if (!$conn->commit()) {
        throw new RuntimeException("Unable to commit transaction: {$conn->error}");
    }

    echo "\nCleanup completed successfully.\n";
    echo "Deleted rows: {$deletedRows}\n";
} catch (Throwable $exception) {
    $conn->rollback();

    fwrite(
        STDERR,
        "\nCleanup failed. Transaction rolled back.\n" .
        $exception->getMessage() . "\n"
    );

    exit(1);
}
```

### Important notes

1. **Back up the database first.** The execution mode permanently deletes rows.

2. The script only removes database rows whose configured user-reference columns point to an ID missing from `Wo_Users`.

3. It deliberately does not remove:
   - Uploaded files
   - S3 or other object-storage files
   - WordPress user or BuddyPress records
   - QuickDate records
   - Palmier records
   - Rows that contain a valid user ID but are otherwise stale

4. The supplied `Wo_DeleteUser()` function has some naming inconsistencies, such as table constants that may differ between installations. The script checks whether each default WoWonder table and column exists before processing it.

5. The original deletion function contains this apparent typo:

```php
`from_id ` = '{$user_id}'
```

The cleanup script uses the correct column name:

```php
`from_id`
```

6. The script does not invoke `Wo_DeletePost()`, `Wo_DeletePage()`, or `Wo_DeleteGroup()` because those functions may require an active logged-in session and may perform filesystem or object-storage operations. This utility is intended to clean orphaned database references safely and transactionally.
