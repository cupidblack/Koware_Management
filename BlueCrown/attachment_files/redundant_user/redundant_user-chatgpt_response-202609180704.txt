* **WordPress** = integration/source-of-truth layer for the cross-platform IDs.
* **WoWonder Streams** = authoritative source for `wo_user_id`.
* **QuickDate Socials** = authoritative source for `qd_user_id`.

I would also change one important aspect of the previous version: **do not automatically repair an ID merely because a username or email happens to match if the match is ambiguous**. The repair should only be offered when the corresponding WoWonder/QuickDate record is uniquely identifiable. This prevents one user's WordPress metadata from accidentally being assigned another user's platform ID.

The supplied `db_helpers.php` confirms that the site already provides separate WordPress, QuickDate, WoWonder and Palmier connections, including `get_wp_db_conn()`, `get_qd_db_conn()` and `get_wowonder_db_conn()`, with QuickDate's `users` table configured as `users` and WordPress's default prefix as `wp_`. <?php
/**
 * Buzzjuice WoWonder + QuickDate Orphan User Cleaner
 * ==================================================
 *
 * Intended location:
 *   /shared/bzj-wwqd-orphan-user-cleaner.php
 *
 * Purpose:
 *   1. Find database rows in WoWonder that reference users no longer present
 *      in Wo_Users.
 *   2. Find database rows in QuickDate that reference users no longer present
 *      in users.
 *   3. Find WordPress users whose:
 *        - wo_user_id
 *        - qd_user_id
 *      metadata is missing, invalid, stale or points to the wrong platform user.
 *   4. Offer safe repair of uniquely identifiable WordPress platform IDs by
 *      matching WordPress username/email against the authoritative platform
 *      records.
 *
 * IMPORTANT ARCHITECTURE
 * ----------------------
 * WordPress:
 *   Integration/source-of-truth layer for the cross-platform ID mapping.
 *
 * WoWonder:
 *   Authoritative source for wo_user_id.
 *
 * QuickDate:
 *   Authoritative source for qd_user_id.
 *
 * SAFETY
 * ------
 * - Dry-run is non-destructive.
 * - Wo_Users is never modified.
 * - QuickDate users is never modified.
 * - WordPress wp_users is never modified.
 * - Only wp_usermeta values for the explicitly repairable ID fields are changed.
 * - Orphan cleanup is limited to explicitly configured reference columns.
 * - Platform account rows are NEVER deleted by this utility.
 * - Physical media files are NOT deleted.
 * - Ambiguous username/email matches are NEVER repaired automatically.
 * - A fresh scan is performed immediately before destructive operations.
 * - Cleanup and metadata repair have separate confirmations.
 *
 * DEPENDENCY
 * ----------
 * Requires:
 *   /shared/db_helpers.php
 *
 * The helper currently supplies:
 *   get_wp_db_conn()
 *   get_qd_db_conn()
 *   get_wowonder_db()
 *
 * Version:
 *   2026-09-18.1
 */

/* ============================================================
 * SECURITY / HTML HELPERS
 * ========================================================== */

function bzj_wwqd_h(string $value): string
{
    return htmlspecialchars(
        $value,
        ENT_QUOTES | ENT_SUBSTITUTE,
        'UTF-8'
    );
}

function bzj_wwqd_ident(string $identifier): string
{
    if (!preg_match('/^[A-Za-z0-9_]+$/', $identifier)) {
        throw new RuntimeException('Unsafe SQL identifier.');
    }

    return '`' . $identifier . '`';
}

function bzj_wwqd_sql_value(mysqli $db, string $value): string
{
    return "'" . $db->real_escape_string($value) . "'";
}

function bzj_wwqd_query(mysqli $db, string $sql): mysqli_result|bool
{
    $result = $db->query($sql);

    if ($result === false) {
        throw new RuntimeException(
            $db->error . ' | SQL: ' . $sql
        );
    }

    return $result;
}


/* ============================================================
 * DATABASE HELPERS
 * ========================================================== */

function bzj_wwqd_table_exists(mysqli $db, string $table): bool
{
    $tableEscaped = $db->real_escape_string($table);

    $result = bzj_wwqd_query(
        $db,
        "SHOW TABLES LIKE '{$tableEscaped}'"
    );

    return $result instanceof mysqli_result
        && $result->num_rows > 0;
}

function bzj_wwqd_columns(mysqli $db, string $table): array
{
    $result = bzj_wwqd_query(
        $db,
        'SHOW COLUMNS FROM ' . bzj_wwqd_ident($table)
    );

    $columns = [];

    while ($row = $result->fetch_assoc()) {
        if (isset($row['Field'])) {
            $columns[strtolower((string)$row['Field'])] =
                (string)$row['Field'];
        }
    }

    return $columns;
}

function bzj_wwqd_tables(mysqli $db): array
{
    $result = bzj_wwqd_query($db, 'SHOW TABLES');

    $tables = [];

    while ($row = $result->fetch_row()) {
        if (isset($row[0])) {
            $tables[] = (string)$row[0];
        }
    }

    return $tables;
}

function bzj_wwqd_log(array $event): void
{
    $root = dirname(__DIR__);
    $directory = $root . '/data/logs';

    if (!is_dir($directory)) {
        @mkdir($directory, 0750, true);
    }

    $event['timestamp_utc'] = gmdate('c');

    $line = json_encode(
        $event,
        JSON_UNESCAPED_SLASHES |
        JSON_UNESCAPED_UNICODE
    );

    if ($line !== false) {
        @file_put_contents(
            $directory . '/bzj-wwqd-orphan-user-cleaner.log',
            $line . PHP_EOL,
            FILE_APPEND | LOCK_EX
        );
    }
}


/* ============================================================
 * CONNECTIONS

function bzj_wwqd_get_connections(): array
{
    $connections = [];

    $wp = get_wp_db_conn();
    if (!$wp instanceof mysqli || $wp->connect_errno) {
        throw new RuntimeException(
            'Unable to connect to WordPress database.'
        );
    }

    $wp->set_charset('utf8mb4');
    $connections['wp'] = $wp;

    $wo = get_wowonder_db();
    if (!$wo instanceof mysqli || $wo->connect_errno) {
        throw new RuntimeException(
            'Unable to connect to WoWonder database.'
        );
    }

    $wo->set_charset('utf8mb4');
    $connections['wo'] = $wo;

    $qd = get_qd_db_conn();
    if (!$qd instanceof mysqli || $qd->connect_errno) {
        throw new RuntimeException(
            'Unable to connect to QuickDate database.'
        );
    }

    $qd->set_charset('utf8mb4');
    $connections['qd'] = $qd;

    bzj_wwqd_log([
        'event' => 'database_connections',
        'connections' => [
            'wordpress' => defined('WP_DB_NAME')
                ? WP_DB_NAME
                : null,
            'wowonder' => defined('WOWONDER_DB_NAME')
                ? WOWONDER_DB_NAME
                : null,
            'quickdate' => defined('QD_DB_NAME')
                ? QD_DB_NAME
                : null,
        ],
        'tables' => [
            'wordpress_users' =>
                defined('WP_TABLE_PREFIX')
                    ? WP_TABLE_PREFIX . 'users'
                    : 'wp_users',

            'wordpress_usermeta' =>
                defined('WP_TABLE_PREFIX')
                    ? WP_TABLE_PREFIX . 'usermeta'
                    : 'wp_usermeta',

            'wowonder_users' => BZJ_WWQD_WW_USERS,
            'quickdate_users' => BZJ_WWQD_QD_USERS,
        ],
    ]);

    return $connections;
}

function bzj_wwqd_create_wo_snapshot(mysqli $db): void
{
    bzj_wwqd_query(
        $db,
        'DROP TEMPORARY TABLE IF EXISTS `bzj_existing_wo_users`'
    );

    bzj_wwqd_query(
        $db,
        '
        CREATE TEMPORARY TABLE `bzj_existing_wo_users` (
            `user_id` BIGINT UNSIGNED NOT NULL,
            PRIMARY KEY (`user_id`)
        ) ENGINE=InnoDB
        '
    );

    $columns = bzj_wwqd_columns($db, BZJ_WWQD_WW_USERS);

    if (!isset($columns['user_id'])) {
        throw new RuntimeException(
            'Wo_Users.user_id was not found.'
        );
    }

    bzj_wwqd_query(
        $db,
        '
        INSERT INTO `bzj_existing_wo_users` (`user_id`)
        SELECT DISTINCT CAST(`user_id` AS UNSIGNED)
        FROM `Wo_Users`
        WHERE `user_id` IS NOT NULL
          AND TRIM(CAST(`user_id` AS CHAR))
              REGEXP \'^[0-9]+$\'
          AND CAST(`user_id` AS UNSIGNED) > 0
        '
    );
}

function bzj_wwqd_create_qd_snapshot(mysqli $db): void
{
    bzj_wwqd_query(
        $db,
        'DROP TEMPORARY TABLE IF EXISTS `bzj_existing_qd_users`'
    );

    bzj_wwqd_query(
        $db,
        '
        CREATE TEMPORARY TABLE `bzj_existing_qd_users` (
            `user_id` BIGINT UNSIGNED NOT NULL,
            PRIMARY KEY (`user_id`)
        ) ENGINE=InnoDB
        '
    );

    $columns = bzj_wwqd_columns($db, BZJ_WWQD_QD_USERS);

    if (!isset($columns['id'])) {
        throw new RuntimeException(
            'QuickDate users.id was not found.'
        );
    }

    bzj_wwqd_query(
        $db,
        '
        INSERT INTO `bzj_existing_qd_users` (`user_id`)
        SELECT DISTINCT CAST(`id` AS UNSIGNED)
        FROM `users`
        WHERE `id` IS NOT NULL
          AND TRIM(CAST(`id` AS CHAR))
              REGEXP \'^[0-9]+$\'
          AND CAST(`id` AS UNSIGNED) > 0
        '
    );
}

/* ============================================================
 * ORPHAN CONDITION
 * ========================================================== */

function bzj_wwqd_orphan_condition(
    string $column,
    string $snapshotTable
): string {

    $c = bzj_wwqd_ident($column);

    return "
        {$c} IS NOT NULL
        AND TRIM(CAST({$c} AS CHAR))
            REGEXP '^[0-9]+$'
        AND CAST({$c} AS UNSIGNED) > 0
        AND NOT EXISTS (
            SELECT 1
            FROM " . bzj_wwqd_ident($snapshotTable) . " e
            WHERE e.`user_id` = CAST({$c} AS UNSIGNED)
        )
    ";
}


/* ============================================================
 * ORPHAN FINDINGS
 * ========================================================== */

function bzj_wwqd_scan_reference_table(
    mysqli $db,
    string $table,
    array $configuredColumns,
    string $snapshotTable,
    int $sampleLimit
): ?array {

    if (!bzj_wwqd_table_exists($db, $table)) {
        return null;
    }

    $actualColumns = bzj_wwqd_columns($db, $table);

    $columnFindings = [];
    $conditions = [];

    foreach ($configuredColumns as $configuredColumn) {

        $key = strtolower($configuredColumn);

        if (!isset($actualColumns[$key])) {
            continue;
        }

        $column = $actualColumns[$key];

        $condition = bzj_wwqd_orphan_condition(
            $column,
            $snapshotTable
        );

        $result = bzj_wwqd_query(
            $db,
            'SELECT COUNT(*) AS total
             FROM ' . bzj_wwqd_ident($table) . '
             WHERE ' . $condition
        );

        $row = $result->fetch_assoc();

        $count = (int)($row['total'] ?? 0);

        if ($count <= 0) {
            continue;
        }

        $sampleResult = bzj_wwqd_query(
            $db,
            'SELECT DISTINCT ' .
            bzj_wwqd_ident($column) .
            ' AS orphan_user_id
             FROM ' . bzj_wwqd_ident($table) . '
             WHERE ' . $condition .
            ' ORDER BY CAST(' .
            bzj_wwqd_ident($column) .
            ' AS UNSIGNED)
             LIMIT ' . max(
                1,
                min(
                    $sampleLimit,
                    BZJ_WWQD_MAX_SAMPLE_LIMIT
                )
            )
        );

        $samples = [];

        while ($sample = $sampleResult->fetch_assoc()) {
            $samples[] = (string)$sample['orphan_user_id'];
        }

        $columnFindings[] = [
            'column' => $column,
            'count' => $count,
            'sample_user_ids' => $samples,
        ];

        $conditions[] = '(' . $condition . ')';
    }

    if (!$conditions) {
        return null;
    }

    $combined = implode(' OR ', $conditions);

    $result = bzj_wwqd_query(
        $db,
        'SELECT COUNT(*) AS total
         FROM ' . bzj_wwqd_ident($table) . '
         WHERE ' . $combined
    );

    $row = $result->fetch_assoc();

    return [
        'table' => $table,
        'columns' => $columnFindings,
        'condition' => $combined,
        'orphan_row_count' => (int)($row['total'] ?? 0),
    ];
}


/* ============================================================
 * FULL ORPHAN SCAN
 * ========================================================== */

function bzj_wwqd_scan_orphans(
    mysqli $wo,
    mysqli $qd,
    int $sampleLimit
): array {

    bzj_wwqd_create_wo_snapshot($wo);
    bzj_wwqd_create_qd_snapshot($qd);

    $woMap = bzj_wwqd_wowonder_reference_map();
    $woAliases = bzj_wwqd_wowonder_aliases();
    $qdMap = bzj_wwqd_quickdate_reference_map();

    $woFindings = [];

    foreach ($woMap as $configuredTable => $columns) {

        $actualTable = null;

        foreach (
            $woAliases[$configuredTable]
                ?? [$configuredTable]
            as $candidate
        ) {

            if (bzj_wwqd_table_exists($wo, $candidate)) {
                $actualTable = $candidate;
                break;
            }
        }

        if ($actualTable === null) {
            continue;
        }

        $finding = bzj_wwqd_scan_reference_table(
            $wo,
            $actualTable,
            $columns,
            'bzj_existing_wo_users',
            $sampleLimit
        );

        if ($finding !== null) {
            $woFindings[] = $finding;
        }
    }

    $qdFindings = [];

    foreach ($qdMap as $table => $columns) {

        $finding = bzj_wwqd_scan_reference_table(
            $qd,
            $table,
            $columns,
            'bzj_existing_qd_users',
            $sampleLimit
        );

        if ($finding !== null) {
            $qdFindings[] = $finding;
        }
    }

    $woUserCountResult = bzj_wwqd_query(
        $wo,
        'SELECT COUNT(*) AS total FROM `Wo_Users`'
    );

    $woUserCount =
        (int)($woUserCountResult->fetch_assoc()['total'] ?? 0);

    $qdUserCountResult = bzj_wwqd_query(
        $qd,
        'SELECT COUNT(*) AS total FROM `users`'
    );

    $qdUserCount =
        (int)($qdUserCountResult->fetch_assoc()['total'] ?? 0);

    return [
        'wowonder' => [
            'existing_user_count' => $woUserCount,
            'findings' => $woFindings,
        ],

        'quickdate' => [
            'existing_user_count' => $qdUserCount,
            'findings' => $qdFindings,
        ],

        'total_wowonder_rows' =>
            bzj_wwqd_total_finding_rows($woFindings),

        'total_quickdate_rows' =>
            bzj_wwqd_total_finding_rows($qdFindings),
    ];
}

function bzj_wwqd_total_finding_rows(array $findings): int
{
    $total = 0;

    foreach ($findings as $finding) {
        $total += (int)(
            $finding['orphan_row_count'] ?? 0
        );
    }

    return $total;
}

/* ============================================================
 * LOAD WORDPRESS USER / META DATA
 * ========================================================== */

function bzj_wwqd_load_wp_users(
    mysqli $wp
): array {

    $usersTable = bzj_wwqd_wp_users_table();
    $metaTable = bzj_wwqd_wp_usermeta_table();

    if (!bzj_wwqd_table_exists($wp, $usersTable)) {
        throw new RuntimeException(
            'WordPress users table was not found: ' .
            $usersTable
        );
    }

    if (!bzj_wwqd_table_exists($wp, $metaTable)) {
        throw new RuntimeException(
            'WordPress usermeta table was not found: ' .
            $metaTable
        );
    }

    $result = bzj_wwqd_query(
        $wp,
        '
        SELECT
            u.ID,
            u.user_login,
            u.user_email,

            MAX(
                CASE
                    WHEN um.meta_key = ' .
                    bzj_wwqd_sql_value(
                        $wp,
                        BZJ_WWQD_WO_META
                    ) .
                    ' THEN um.meta_value
                    ELSE NULL
                END
            ) AS wo_user_id,

            MAX(
                CASE
                    WHEN um.meta_key = ' .
                    bzj_wwqd_sql_value(
                        $wp,
                        BZJ_WWQD_QD_META
                    ) .
                    ' THEN um.meta_value
                    ELSE NULL
                END
            ) AS qd_user_id

        FROM ' . bzj_wwqd_ident($usersTable) . ' u

        LEFT JOIN ' .
            bzj_wwqd_ident($metaTable) .
            ' um
          ON um.user_id = u.ID
         AND um.meta_key IN (
                ' .
                bzj_wwqd_sql_value(
                    $wp,
                    BZJ_WWQD_WO_META
                ) .
                ',
                ' .
                bzj_wwqd_sql_value(
                    $wp,
                    BZJ_WWQD_QD_META
                ) .
                '
         )

        GROUP BY
            u.ID,
            u.user_login,
            u.user_email

        ORDER BY u.ID
        '
    );

    $users = [];

    while ($row = $result->fetch_assoc()) {
        $users[] = [
            'wp_user_id' => (int)$row['ID'],
            'user_login' => (string)$row['user_login'],
            'user_email' => (string)$row['user_email'],
            'wo_user_id' =>
                trim((string)($row['wo_user_id'] ?? '')),
            'qd_user_id' =>
                trim((string)($row['qd_user_id'] ?? '')),
        ];
    }

    return $users;
}


/* ============================================================
 * PLATFORM USER INDEXES
 * ========================================================== */

function bzj_wwqd_load_platform_index(
    mysqli $db,
    string $table,
    string $idColumn,
    array $identityColumns
): array {

    $select = [
        bzj_wwqd_ident($idColumn) . ' AS platform_id'
    ];

    if ($identityColumns['username']) {
        $select[] =
            bzj_wwqd_ident(
                $identityColumns['username']
            ) . ' AS platform_username';
    } else {
        $select[] = 'NULL AS platform_username';
    }

    if ($identityColumns['email']) {
        $select[] =
            bzj_wwqd_ident(
                $identityColumns['email']
            ) . ' AS platform_email';
    } else {
        $select[] = 'NULL AS platform_email';
    }

    if ($identityColumns['first_name']) {
        $select[] =
            bzj_wwqd_ident(
                $identityColumns['first_name']
            ) . ' AS first_name';
    } else {
        $select[] = 'NULL AS first_name';
    }

    if ($identityColumns['last_name']) {
        $select[] =
            bzj_wwqd_ident(
                $identityColumns['last_name']
            ) . ' AS last_name';
    } else {
        $select[] = 'NULL AS last_name';
    }

    $result = bzj_wwqd_query(
        $db,
        'SELECT ' .
        implode(', ', $select) .
        ' FROM ' .
        bzj_wwqd_ident($table)
    );

    $records = [];

    while ($row = $result->fetch_assoc()) {

        $id = (string)$row['platform_id'];

        $record = [
            'id' => $id,
            'username' =>
                (string)($row['platform_username'] ?? ''),
            'email' =>
                (string)($row['platform_email'] ?? ''),
            'first_name' =>
                (string)($row['first_name'] ?? ''),
            'last_name' =>
                (string)($row['last_name'] ?? ''),
        ];

        $records[] = $record;
    }

    return $records;
}

function bzj_wwqd_build_identity_indexes(
    array $records
): array {

    $byId = [];
    $byEmail = [];
    $byUsername = [];

    foreach ($records as $record) {

        $id = (string)$record['id'];

        $byId[$id] = $record;

        $email =
            bzj_wwqd_normalize_email(
                $record['email']
            );

        if ($email !== '') {
            $byEmail[$email][] = $record;
        }

        $username =
            bzj_wwqd_normalize_username(
                $record['username']
            );

        if ($username !== '') {
            $byUsername[$username][] = $record;
        }
    }

    return [
        'by_id' => $byId,
        'by_email' => $byEmail,
        'by_username' => $byUsername,
    ];
}


/* ============================================================
 * ID MATCHING
 * ========================================================== */

function bzj_wwqd_match_platform_user(
    array $wpUser,
    array $index
): array {

    $email =
        bzj_wwqd_normalize_email(
            $wpUser['user_email']
        );

    $username =
        bzj_wwqd_normalize_username(
            $wpUser['user_login']
        );

    $emailMatches =
        $email !== ''
            ? ($index['by_email'][$email] ?? [])
            : [];

    $usernameMatches =
        $username !== ''
            ? ($index['by_username'][$username] ?? [])
            : [];

    $uniqueEmail =
        count($emailMatches) === 1
            ? $emailMatches[0]
            : null;

    $uniqueUsername =
        count($usernameMatches) === 1
            ? $usernameMatches[0]
            : null;

    $candidate = null;
    $method = null;

    if ($uniqueEmail && $uniqueUsername) {

        if (
            (string)$uniqueEmail['id'] ===
            (string)$uniqueUsername['id']
        ) {
            $candidate = $uniqueEmail;
            $method = 'email+username';
        } else {
            return [
                'status' => 'conflicting_identity_matches',
                'candidate' => null,
                'method' => null,
                'email_matches' => $emailMatches,
                'username_matches' => $usernameMatches,
            ];
        }

    } elseif ($uniqueEmail) {

        $candidate = $uniqueEmail;
        $method = 'email';

    } elseif ($uniqueUsername) {

        $candidate = $uniqueUsername;
        $method = 'username';

    } elseif (
        count($emailMatches) > 1 ||
        count($usernameMatches) > 1
    ) {

        return [
            'status' => 'ambiguous',
            'candidate' => null,
            'method' => null,
            'email_matches' => $emailMatches,
            'username_matches' => $usernameMatches,
        ];

    } else {

        return [
            'status' => 'no_match',
            'candidate' => null,
            'method' => null,
            'email_matches' => [],
            'username_matches' => [],
        ];
    }

    return [
        'status' => 'matched',
        'candidate' => $candidate,
        'method' => $method,
        'email_matches' => $emailMatches,
        'username_matches' => $usernameMatches,
    ];
}


/* ============================================================
 * WORDPRESS ID INTEGRITY SCAN
 * ========================================================== */

function bzj_wwqd_scan_wp_id_integrity(
    mysqli $wp,
    mysqli $wo,
    mysqli $qd
): array {

    $wpUsers = bzj_wwqd_load_wp_users($wp);

    $woIdentityColumns =
        bzj_wwqd_get_wo_identity_columns($wo);

    $qdIdentityColumns =
        bzj_wwqd_get_qd_identity_columns($qd);

    if (
        !$woIdentityColumns['username'] &&
        !$woIdentityColumns['email']
    ) {
        throw new RuntimeException(
            'Wo_Users does not contain a usable username or email column.'
        );
    }

    if (
        !$qdIdentityColumns['username'] &&
        !$qdIdentityColumns['email']
    ) {
        throw new RuntimeException(
            'QuickDate users does not contain a usable username or email column.'
        );
    }

    $woRecords = bzj_wwqd_load_platform_index(
        $wo,
        BZJ_WWQD_WW_USERS,
        'user_id',
        $woIdentityColumns
    );

    $qdRecords = bzj_wwqd_load_platform_index(
        $qd,
        BZJ_WWQD_QD_USERS,
        'id',
        $qdIdentityColumns
    );

    $woIndex = bzj_wwqd_build_identity_indexes(
        $woRecords
    );

    $qdIndex = bzj_wwqd_build_identity_indexes(
        $qdRecords
    );

    $results = [];

    foreach ($wpUsers as $wpUser) {

        $woMatch =
            bzj_wwqd_match_platform_user(
                $wpUser,
                $woIndex
            );

        $qdMatch =
            bzj_wwqd_match_platform_user(
                $wpUser,
                $qdIndex
            );

        $currentWoId =
            trim((string)$wpUser['wo_user_id']);

        $currentQdId =
            trim((string)$wpUser['qd_user_id']);

        $expectedWoId =
            $woMatch['candidate']['id'] ?? null;

        $expectedQdId =
            $qdMatch['candidate']['id'] ?? null;

        $woStatus = 'ok';
        $qdStatus = 'ok';

        if ($woMatch['status'] === 'no_match') {
            $woStatus = 'no_platform_match';
        } elseif ($woMatch['status'] === 'ambiguous') {
            $woStatus = 'ambiguous';
        } elseif (
            $woMatch['status'] ===
            'conflicting_identity_matches'
        ) {
            $woStatus = 'conflicting_identity_matches';
        } elseif ($currentWoId === '') {
            $woStatus = 'missing';
        } elseif (!ctype_digit($currentWoId)) {
            $woStatus = 'invalid';
        } elseif (
            !isset($woIndex['by_id'][$currentWoId])
        ) {
            $woStatus = 'points_to_missing_user';
        } elseif (
            $expectedWoId !== null &&
            $currentWoId !== (string)$expectedWoId
        ) {
            $woStatus = 'mismatch';
        }

        if ($qdMatch['status'] === 'no_match') {
            $qdStatus = 'no_platform_match';
        } elseif ($qdMatch['status'] === 'ambiguous') {
            $qdStatus = 'ambiguous';
        } elseif (
            $qdMatch['status'] ===
            'conflicting_identity_matches'
        ) {
            $qdStatus = 'conflicting_identity_matches';
        } elseif ($currentQdId === '') {
            $qdStatus = 'missing';
        } elseif (!ctype_digit($currentQdId)) {
            $qdStatus = 'invalid';
        } elseif (
            !isset($qdIndex['by_id'][$currentQdId])
        ) {
            $qdStatus = 'points_to_missing_user';
        } elseif (
            $expectedQdId !== null &&
            $currentQdId !== (string)$expectedQdId
        ) {
            $qdStatus = 'mismatch';
        }

        $repairableWo =
            $woMatch['status'] === 'matched'
            && $expectedWoId !== null
            && $currentWoId !== (string)$expectedWoId;

        $repairableQd =
            $qdMatch['status'] === 'matched'
            && $expectedQdId !== null
            && $currentQdId !== (string)$expectedQdId;

        if (
            $woStatus !== 'ok' ||
            $qdStatus !== 'ok'
        ) {

            $results[] = [
                'wp_user_id' =>
                    $wpUser['wp_user_id'],

                'user_login' =>
                    $wpUser['user_login'],

                'user_email' =>
                    $wpUser['user_email'],

                'wo' => [
                    'current_id' => $currentWoId,
                    'status' => $woStatus,
                    'expected_id' => $expectedWoId,
                    'match_method' =>
                        $woMatch['method'],
                    'repairable' =>
                        $repairableWo,
                    'candidate' =>
                        $woMatch['candidate'],
                    'email_matches' =>
                        $woMatch['email_matches'],
                    'username_matches' =>
                        $woMatch['username_matches'],
                ],

                'qd' => [
                    'current_id' => $currentQdId,
                    'status' => $qdStatus,
                    'expected_id' => $expectedQdId,
                    'match_method' =>
                        $qdMatch['method'],
                    'repairable' =>
                        $repairableQd,
                    'candidate' =>
                        $qdMatch['candidate'],
                    'email_matches' =>
                        $qdMatch['email_matches'],
                    'username_matches' =>
                        $qdMatch['username_matches'],
                ],
            ];
        }
    }

    return [
        'wordpress_user_count' => count($wpUsers),

        'wowonder_user_count' =>
            count($woRecords),

        'quickdate_user_count' =>
            count($qdRecords),

        'wowonder_identity_columns' =>
            $woIdentityColumns,

        'quickdate_identity_columns' =>
            $qdIdentityColumns,

        'anomalies' => $results,

        'repairable_count' =>
            count(
                array_filter(
                    $results,
                    static function (array $row): bool {
                        return
                            !empty($row['wo']['repairable']) ||
                            !empty($row['qd']['repairable']);
                    }
                )
            ),
    ];
}


/* ============================================================
 * WORDPRESS USERMETA REPAIR
 * ========================================================== */

function bzj_wwqd_update_usermeta(
    mysqli $wp,
    int $wpUserId,
    string $metaKey,
    string $value
): int {

    $metaTable = bzj_wwqd_wp_usermeta_table();

    /*
     * Update every existing row for this meta key belonging to
     * this WordPress user. If none exists, create one.
     */
    $update = bzj_wwqd_query(
        $wp,
        '
        UPDATE ' . bzj_wwqd_ident($metaTable) . '
        SET meta_value = ' .
            bzj_wwqd_sql_value($wp, $value) . '
        WHERE user_id = ' . (int)$wpUserId . '
          AND meta_key = ' .
            bzj_wwqd_sql_value($wp, $metaKey)
    );

    $affected = $wp->affected_rows;

    $check = bzj_wwqd_query(
        $wp,
        '
        SELECT COUNT(*) AS total
        FROM ' . bzj_wwqd_ident($metaTable) . '
        WHERE user_id = ' . (int)$wpUserId . '
          AND meta_key = ' .
            bzj_wwqd_sql_value($wp, $metaKey)
    );

    $row = $check->fetch_assoc();

    if ((int)($row['total'] ?? 0) === 0) {

        bzj_wwqd_query(
            $wp,
            '
            INSERT INTO ' .
            bzj_wwqd_ident($metaTable) . '
            (
                user_id,
                meta_key,
                meta_value
            )
            VALUES
            (
                ' . (int)$wpUserId . ',
                ' .
                bzj_wwqd_sql_value(
                    $wp,
                    $metaKey
                ) .
                ',
                ' .
                bzj_wwqd_sql_value(
                    $wp,
                    $value
                ) .
                '
            )
            '
        );

        $affected = 1;
    }

    return $affected;
}

function bzj_wwqd_repair_wp_ids(
    mysqli $wp,
    mysqli $wo,
    mysqli $qd,
    array $scan
): array {

    /*
     * Fresh scan is intentionally required before changing anything.
     */
    $fresh = bzj_wwqd_scan_wp_id_integrity(
        $wp,
        $wo,
        $qd
    );

    $repaired = [];
    $skipped = [];
    $errors = [];

    foreach ($fresh['anomalies'] as $row) {

        $wpUserId = (int)$row['wp_user_id'];

        $changes = [];

        if (
            !empty($row['wo']['repairable']) &&
            $row['wo']['expected_id'] !== null
        ) {
            $changes['wo_user_id'] =
                (string)$row['wo']['expected_id'];
        }

        if (
            !empty($row['qd']['repairable']) &&
            $row['qd']['expected_id'] !== null
        ) {
            $changes['qd_user_id'] =
                (string)$row['qd']['expected_id'];
        }

        if (!$changes) {

            $skipped[] = [
                'wp_user_id' => $wpUserId,
                'reason' =>
                    'No unambiguous repairable platform match.',
                'wo_status' =>
                    $row['wo']['status'],
                'qd_status' =>
                    $row['qd']['status'],
            ];

            continue;
        }

        if (!$wp->begin_transaction()) {
            $errors[] = [
                'wp_user_id' => $wpUserId,
                'error' =>
                    'Unable to start WordPress transaction.'
            ];

            continue;
        }

        try {

            foreach ($changes as $metaKey => $value) {

                bzj_wwqd_update_usermeta(
                    $wp,
                    $wpUserId,
                    $metaKey,
                    $value
                );
            }

            if (!$wp->commit()) {
                throw new RuntimeException(
                    'WordPress metadata commit failed: ' .
                    $wp->error
                );
            }

            $repaired[] = [
                'wp_user_id' => $wpUserId,

                'user_login' =>
                    $row['user_login'],

                'user_email' =>
                    $row['user_email'],

                'changes' => $changes,

                'wo_match_method' =>
                    $row['wo']['match_method'],

                'qd_match_method' =>
                    $row['qd']['match_method'],
            ];

        } catch (Throwable $e) {

            $wp->rollback();

            $errors[] = [
                'wp_user_id' => $wpUserId,
                'error' => $e->getMessage(),
            ];
        }
    }

    /*
     * Verify after repair.
     */
    $verification =
        bzj_wwqd_scan_wp_id_integrity(
            $wp,
            $wo,
            $qd
        );

    return [
        'repaired' => $repaired,
        'skipped' => $skipped,
        'errors' => $errors,
        'verification' => $verification,
    ];
}


/* ============================================================
 * ORPHAN CLEANUP
 * ========================================================== */

function bzj_wwqd_clean_reference_findings(
    mysqli $db,
    array $findings,
    string $snapshotTable
): array {

    $deleted = [];
    $errors = [];

    foreach ($findings as $finding) {

        $table = (string)$finding['table'];

        if (!bzj_wwqd_table_exists($db, $table)) {
            continue;
        }

        $actualColumns =
            bzj_wwqd_columns($db, $table);

        $conditions = [];

        foreach ($finding['columns'] as $columnFinding) {

            $key =
                strtolower(
                    (string)$columnFinding['column']
                );

            if (!isset($actualColumns[$key])) {
                continue;
            }

            $conditions[] =
                '(' .
                bzj_wwqd_orphan_condition(
                    $actualColumns[$key],
                    $snapshotTable
                ) .
                ')';
        }

        if (!$conditions) {
            continue;
        }

        $condition =
            implode(' OR ', $conditions);

        if (!$db->begin_transaction()) {
            $errors[] = [
                'table' => $table,
                'error' =>
                    'Unable to begin transaction: ' .
                    $db->error,
            ];

            continue;
        }

        try {

            $beforeResult =
                bzj_wwqd_query(
                    $db,
                    '
                    SELECT COUNT(*) AS total
                    FROM ' .
                    bzj_wwqd_ident($table) .
                    '
                    WHERE ' .
                    $condition
                );

            $before =
                (int)(
                    $beforeResult
                        ->fetch_assoc()['total']
                    ?? 0
                );

            if ($before <= 0) {
                $db->rollback();
                continue;
            }

            bzj_wwqd_query(
                $db,
                '
                DELETE FROM ' .
                bzj_wwqd_ident($table) .
                '
                WHERE ' .
                $condition
            );

            $affected =
                (int)$db->affected_rows;

            if (!$db->commit()) {
                throw new RuntimeException(
                    'Commit failed: ' . $db->error
                );
            }

            $deleted[] = [
                'table' => $table,
                'rows_before_delete' => $before,
                'deleted_rows' => $affected,
                'status' => 'committed',
            ];

        } catch (Throwable $e) {

            $db->rollback();

            $errors[] = [
                'table' => $table,
                'error' => $e->getMessage(),
                'status' => 'rolled_back',
            ];
        }
    }

    return [
        'deleted' => $deleted,
        'errors' => $errors,
    ];
}

function bzj_wwqd_clean_orphans(
    mysqli $wo,
    mysqli $qd
): array {

    /*
     * Never trust an old dry-run.
     * Rebuild both authoritative snapshots and perform a fresh scan.
     */
    $fresh = bzj_wwqd_scan_orphans(
        $wo,
        $qd,
        BZJ_WWQD_SAMPLE_LIMIT
    );

    $woResult =
        bzj_wwqd_clean_reference_findings(
            $wo,
            $fresh['wowonder']['findings'],
            'bzj_existing_wo_users'
        );

    $qdResult =
        bzj_wwqd_clean_reference_findings(
            $qd,
            $fresh['quickdate']['findings'],
            'bzj_existing_qd_users'
        );

    /*
     * Fresh verification.
     */
    $verification =
        bzj_wwqd_scan_orphans(
            $wo,
            $qd,
            BZJ_WWQD_SAMPLE_LIMIT
        );

    return [
        'pre_clean' => $fresh,

        'wowonder' => $woResult,

        'quickdate' => $qdResult,

        'verification' => $verification,
    ];
}


/* ============================================================
 * TOTALS
 * ========================================================== */

function bzj_wwqd_total_deleted(
    array $deleted
): int {

    $total = 0;

    foreach ($deleted as $row) {
        $total += (int)(
            $row['deleted_rows'] ?? 0
        );
    }

    return $total;
}


/* ============================================================
 * REPORT WRITER
 * ========================================================== */

function bzj_wwqd_write_report(
    array $report
): ?string {

    $root = dirname(__DIR__);

    $directory =
        $root .
        '/data/logs/bzj-wwqd-orphan-cleaner';

    if (!is_dir($directory)) {

        if (
            !mkdir(
                $directory,
                0750,
                true
            )
            &&
            !is_dir($directory)
        ) {
            return null;
        }
    }

    $filename =
        'report-' .
        gmdate('Ymd-His') .
        '-' .
        bin2hex(random_bytes(3)) .
        '.json';

    $path =
        $directory .
        '/' .
        $filename;

    $json = json_encode(
        $report,
        JSON_PRETTY_PRINT |
        JSON_UNESCAPED_SLASHES |
        JSON_UNESCAPED_UNICODE
    );

    if (
        $json === false ||
        file_put_contents(
            $path,
            $json . PHP_EOL,
            LOCK_EX
        ) === false
    ) {
        return null;
    }

    return $path;
}

function bzj_wwqd_csrf(): string
{
    if (
        empty(
            $_SESSION[
                BZJ_WWQD_SESSION_KEY
            ]
        )
    ) {
        $_SESSION[
            BZJ_WWQD_SESSION_KEY
        ] = bin2hex(
            random_bytes(32)
        );
    }

    return (string)
        $_SESSION[
            BZJ_WWQD_SESSION_KEY
        ];
}

function bzj_wwqd_verify_csrf(
    string $token
): bool {

    return
        !empty(
            $_SESSION[
                BZJ_WWQD_SESSION_KEY
            ]
        )
        &&
        hash_equals(
            (string)
            $_SESSION[
                BZJ_WWQD_SESSION_KEY
            ],
            $token
        );
}

### Important implementation points

The new version deliberately separates **two different kinds of corruption**.

#### 1. Orphan records

For example, if QuickDate currently has:

```text
users
----
1
2
4
5
```

but a row in `messages` contains:

```text
from = 3
```

then `3` is an orphan because it no longer exists in `users`.

The same principle is applied to WoWonder using:

```text
Wo_Users.user_id
```

as the authoritative set.

The QuickDate reference list is based directly on the `delete_user()` function you supplied: `blocks`, `conversations`, `likes`, `mediafiles`, `messages`, `notifications`, `reports`, `user_gifts`, `views`, `sessions`, `payments`, and `verification_requests`.

#### 2. Cross-platform ID corruption

The new scanner treats a WordPress user approximately like:

```text
wp_users
------------------------------------------------
ID          = 147
user_login  = johnsmith
user_email  = john@example.com

wp_usermeta
------------------------------------------------
wo_user_id  = 832
qd_user_id  = 421
```

It then independently looks for the corresponding authoritative accounts.

For example:

```text
Wo_Users
------------------------------------------------
user_id     = 913
username    = johnsmith
email       = john@example.com
```

and:

```text
QuickDate users
------------------------------------------------
id          = 527
username    = johnsmith
email       = john@example.com
```

The scanner would report:

```text
WordPress user #147

WoWonder
Current: 832
Expected: 913
Status: mismatch
Match: email+username

QuickDate
Current: 421
Expected: 527
Status: mismatch
Match: email+username
```

The repair then changes only:

```text
wo_user_id: 832 → 913
qd_user_id: 421 → 527
```

It **does not change** `Wo_Users.user_id` or QuickDate `users.id`.

### One particularly important safety feature

I intentionally did **not** make the repair logic say:

> "If the ID doesn't work, find something vaguely similar and replace it."

Instead, the repair hierarchy is:

**Email + username agree → repairable**

**Unique email match → repairable**

**Unique username match → repairable**

**Email and username point to different accounts → do not repair**

**Multiple accounts match → do not repair**

**No account matches → do not repair**

That is important because a mistaken ID repair can be considerably more damaging than an orphaned row.

### One issue I would test before putting this into production

The code dynamically detects the actual identity columns in both platform databases. It looks for common names such as:

```text
username
user_name
uname
login
```

and:

```text
email
user_email
mail
```

This is useful because the exact QuickDate/WoWonder schema can vary by version.

The supplied `db_helpers.php` confirms the three database connections and the QuickDate `users` table configuration used by the utility. ([GitHub][1])

I would therefore run **both dry-run scans first**, before authorizing either repair or deletion. The first production run should give you a complete picture of:

* WoWonder orphan rows
* QuickDate orphan rows
* WordPress users whose platform IDs point to deleted users
* WordPress users whose IDs point to the wrong surviving accounts
* missing IDs
* invalid IDs
* ambiguous identities
