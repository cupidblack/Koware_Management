# 1. Final synchronization model

BuddyBoss remains authoritative.

| Origin | Action | BuddyBoss | Streams | Socials |
|---|---|---|---|---|
| BuddyBoss | Connection request | Native request | No operation | Pending Add Friend |
| BuddyBoss | Reject/withdraw request | Native state | No operation | Delete only pending `active = 0` row |
| BuddyBoss | Accept connection | Native connection | No operation | Accepted friendship |
| BuddyBoss | Remove connection | Native removal | No operation | Remove friendship projection |
| BuddyBoss | Follow | Native follow | Immediate follow | No operation |
| BuddyBoss | Unfollow | Native unfollow | Delete follow | No ordinary-follow operation |
| BuddyBoss | Block | Native block | Block and remove follows | Block and remove relationship projections |
| BuddyBoss | Unblock | Native unblock | Unblock | Unblock |
| Streams | Follow | Native BuddyBoss follow | Local immediate follow | No operation |
| Streams | Unfollow | Native BuddyBoss unfollow | Local delete | No operation |
| Streams | Block | Native BuddyBoss block | Local block | Block |
| Streams | Unblock | Native BuddyBoss unblock | Local unblock | Unblock |
| Socials | Add Friend | Native BuddyBoss connection request | No operation | Pending Add Friend |
| Socials | Reject/cancel Add Friend | Native reject/withdraw | No operation | Delete pending request |
| Socials | Approve Add Friend | Native BuddyBoss accept | No operation | Accepted friendship |
| Socials | Unfriend | Native BuddyBoss remove | No operation | Remove friendship |
| Socials | Ordinary follow | Native BuddyBoss follow | Follow projection | Local ordinary follow |
| Socials | Ordinary unfollow | Native BuddyBoss unfollow | Unfollow projection | Local delete |
| Socials | Block | Native BuddyBoss block | Block | Block |
| Socials | Unblock | Native BuddyBoss unblock | Unblock | Unblock |

## Important correction

A QuickDate **ordinary follow must not become a BuddyBoss connection request**.

Only QuickDate’s Add Friend workflow maps to:

```text
connection_request
connection_accept
connection_reject
connection_withdraw
connection_remove
```

QuickDate ordinary follows map to:

```text
follow
unfollow
```

This prevents every ordinary follow from generating a connection-request workflow.

Replace `authenticate_external_request()` with the following complete method:

```php
private function authenticate_external_request(WP_REST_Request $request, $raw, $origin) {
    $header_platform = sanitize_key((string) $request->get_header('X-BZJ-Platform'));

    if (!in_array($header_platform, array(self::ORIGIN_STREAMS, self::ORIGIN_SOCIALS), true)) {
        return new WP_Error(
            'bzj_auth_platform',
            'A valid X-BZJ-Platform header is required.',
            array('status' => 401)
        );
    }

    if ($header_platform !== $origin) {
        return new WP_Error(
            'bzj_auth_platform_mismatch',
            'The request platform does not match the payload origin.',
            array('status' => 403)
        );
    }

    $timestamp = (string) $request->get_header('X-BZJ-Timestamp');
    $signature = trim((string) $request->get_header('X-BZJ-Signature'));

    if ($timestamp === '' || $signature === '' || !ctype_digit($timestamp)) {
        return new WP_Error(
            'bzj_auth_missing',
            'Missing authentication headers.',
            array('status' => 401)
        );
    }

    if (abs(time() - (int) $timestamp) > self::EXTERNAL_TIMESTAMP_WINDOW) {
        return new WP_Error(
            'bzj_auth_expired',
            'Request timestamp is outside the allowed window.',
            array('status' => 401)
        );
    }

    $secret = $this->platform_secret($origin);

    if ($secret === '') {
        $this->log(
            'External authentication secret unavailable',
            array('platform' => $origin)
        );

        return new WP_Error(
            'bzj_auth_unavailable',
            'Synchronization secret is unavailable.',
            array('status' => 503)
        );
    }

    $expected = hash_hmac(
        'sha256',
        $timestamp . '.' . $raw,
        $secret
    );

    if (!hash_equals($expected, $signature)) {
        $this->log(
            'External authentication failed',
            array(
                'platform' => $origin,
                'timestamp' => (int) $timestamp,
            ),
            $origin
        );

        return new WP_Error(
            'bzj_auth_invalid',
            'Invalid request signature.',
            array('status' => 401)
        );
    }

    return true;
}
```

The external client must send:

```http
X-BZJ-Platform: streams
```

or:

```http

```

The header value must exactly match the JSON `origin`.

# 3. Fix BuddyBoss request cancellation

This is the primary defect in v8.4.1.

The current implementation uses the generic connection projection for rejected, withdrawn, and deleted events. That is unsafe because QuickDate’s `followers` table is overloaded. A pending Add Friend request must be removed only when its row has:

```text
active = 0
```

An accepted friendship or ordinary follow must not be deleted by a cancellation event.

## 3.1 Add cancellation deduplication state

Add this property beside `$held_locks`:

```php
private $recent_cancellation_events = array();
```

Add this method:

```php
private function cancellation_already_processed($friendship_id, $a, $b) {
    $pair = $this->pair($a, $b);

    $key = (int) $friendship_id . ':' . $pair[0] . ':' . $pair[1];
    $now = time();

    foreach ($this->recent_cancellation_events as $existing_key => $expires) {
        if ($expires <= $now) {
            unset($this->recent_cancellation_events[$existing_key]);
        }
    }

    if (isset($this->recent_cancellation_events[$key])) {
        return true;
    }

    $this->recent_cancellation_events[$key] = $now + 30;

    return false;
}
```

```php
private function remove_social_pending_request($requester_wp, $recipient_wp, $event_uuid = '') {
    $requester_wp = absint($requester_wp);
    $recipient_wp = absint($recipient_wp);

    if ($requester_wp < 1 || $recipient_wp < 1 || $requester_wp === $recipient_wp) {
        return false;
    }

    $requester_id = $this->map_wp_to_external($requester_wp, self::ORIGIN_SOCIALS);
    $recipient_id = $this->map_wp_to_external($recipient_wp, self::ORIGIN_SOCIALS);

    if ($requester_id < 1 || $recipient_id < 1) {
        $this->queue_projection(
            self::ORIGIN_SOCIALS,
            self::OP_CONNECTION_WITHDRAW,
            $requester_wp,
            $recipient_wp,
            array(
                'event_uuid' => $event_uuid,
                'reason' => 'missing_external_mapping',
                'pending_only' => true,
            )
        );

        return false;
    }

    $db = $this->socials_db();

    if (!$db) {
        $this->queue_projection(
            self::ORIGIN_SOCIALS,
            self::OP_CONNECTION_WITHDRAW,
            $requester_wp,
            $recipient_wp,
            array(
                'event_uuid' => $event_uuid,
                'reason' => 'database_unavailable',
                'pending_only' => true,
            )
        );

        return false;
    }

    $table = $this->external_follow_table($db, self::ORIGIN_SOCIALS);

    if (!$table) {
        $this->queue_projection(
            self::ORIGIN_SOCIALS,
            self::OP_CONNECTION_WITHDRAW,
            $requester_wp,
            $recipient_wp,
            array(
                'event_uuid' => $event_uuid,
                'reason' => 'followers_table_not_found',
                'pending_only' => true,
            )
        );

        return false;
    }

    $sql = "DELETE FROM `{$table}`
            WHERE following_id = ?
              AND follower_id = ?
              AND active = 0";

    $stmt = $db->prepare($sql);

    if (!$stmt) {
        throw new RuntimeException($db->error ?: 'Could not prepare pending-request deletion.');
    }

    $stmt->bind_param('ii', $recipient_id, $requester_id);

    if (!$stmt->execute()) {
        $error = $stmt->error ?: 'Could not delete the pending QuickDate request.';
        $affected = (int) $stmt->affected_rows;
        $stmt->close();

        $this->external_log(
            self::ORIGIN_SOCIALS,
            self::OP_CONNECTION_WITHDRAW,
            self::ORIGIN_WORDPRESS,
            $requester_wp,
            $recipient_wp,
            $requester_id,
            $recipient_id,
            $db,
            $table,
            'DELETE_PENDING',
            $affected,
            false,
            $event_uuid,
            $error
        );

        throw new RuntimeException($error);
    }

    $affected = (int) $stmt->affected_rows;
    $stmt->close();

    $verify = $db->prepare(
        "SELECT id
         FROM `{$table}`
         WHERE following_id = ?
           AND follower_id = ?
           AND active = 0
         LIMIT 1"
    );

    if (!$verify) {
        throw new RuntimeException($db->error ?: 'Could not prepare pending-request verification.');
    }

    $verify->bind_param('ii', $recipient_id, $requester_id);

    if (!$verify->execute()) {
        $error = $verify->error ?: 'Could not verify pending-request deletion.';
        $verify->close();
        throw new RuntimeException($error);
    }

    $verify->store_result();
    $remaining = $verify->num_rows;
    $verify->close();

    $verified = ($remaining === 0);

    $this->external_log(
        self::ORIGIN_SOCIALS,
        self::OP_CONNECTION_WITHDRAW,
        self::ORIGIN_WORDPRESS,
        $requester_wp,
        $recipient_wp,
        $requester_id,
        $recipient_id,
        $db,
        $table,
        'DELETE_PENDING',
        $affected,
        $verified,
        $event_uuid,
        $verified ? '' : 'Pending QuickDate request remains after deletion.'
    );

    if (!$verified) {
        throw new RuntimeException('Pending QuickDate request read-back verification failed.');
    }

    return true;
}
```

## 3.3 Add a dedicated cancellation handler

Add:

```php
private function handle_bb_pending_cancellation($event, $initiator, $friend, $friendship_id = 0) {
    $initiator = absint($initiator);
    $friend = absint($friend);

    if ($initiator < 1 || $friend < 1 || $initiator === $friend) {
        return;
    }

    if ($this->cancellation_already_processed($friendship_id, $initiator, $friend)) {
        return;
    }

    $uuid = wp_generate_uuid4();

    if (!$this->acquire_pair_lock($initiator, $friend)) {
        $this->insert_event(
            $uuid,
            self::ORIGIN_WORDPRESS,
            'connection_' . $event,
            $initiator,
            $friend,
            array(
                'friendship_id' => $friendship_id,
                'pending_only' => true,
            )
        );

        $this->mark_event_retry($uuid, 'Pair lock busy.');

        return;
    }

    try {
        $this->insert_event(
            $uuid,
            self::ORIGIN_WORDPRESS,
            'connection_' . $event,
            $initiator,
            $friend,
            array(
                'friendship_id' => $friendship_id,
                'pending_only' => true,
            )
        );

        $bb_state = $this->buddyboss_connection_state($initiator, $friend);

        if ($bb_state === 'is_friend') {
            $this->save_ledger(
                $initiator,
                $friend,
                array(
                    'connection_state' => 'connected',
                    'requested_by' => 0,
                ),
                $uuid
            );
        } elseif ($bb_state === 'pending' || $bb_state === 'awaiting_response') {
            $requester = $this->get_bb_requester($initiator, $friend);

            $this->save_ledger(
                $initiator,
                $friend,
                array(
                    'connection_state' => 'requested',
                    'requested_by' => $requester,
                ),
                $uuid
            );
        } else {
            $this->save_ledger(
                $initiator,
                $friend,
                array(
                    'connection_state' => 'none',
                    'requested_by' => 0,
                ),
                $uuid
            );

            $this->remove_social_pending_request(
                $initiator,
                $friend,
                $uuid
            );
        }

        $this->mark_event_processed($uuid);
    } catch (Throwable $e) {
        $this->mark_event_retry($uuid, $e->getMessage());

        $this->log(
            'BuddyBoss pending connection cancellation failed',
            array(
                'event' => $event,
                'initiator' => $initiator,
                'friend' => $friend,
                'friendship_id' => $friendship_id,
                'event_uuid' => $uuid,
                'error' => $e->getMessage(),
            )
        );
    } finally {
        $this->release_pair_lock($initiator, $friend);
    }
}
```

# 4. Blocking behavior

The current destructive blocking policy is appropriate and should be retained:

1. Create the BuddyBoss block.
2. Remove an existing BuddyBoss connection.
3. Remove both BuddyBoss follow directions.
4. Project the block to Streams.
5. Remove both Streams follow directions.
6. Project the block to Socials.
7. Remove Socials relationship projections.
8. Do not automatically restore anything on unblock.

The existing `enforce_block_on_buddyboss()` method should remain, but its result should be logged. Add verification after each native removal where possible:

```php
private function verify_bb_unfollow($actor, $target) {
    if (!function_exists('bp_is_following')) {
        return true;
    }

    return !bp_is_following(
        array(
            'leader_id' => absint($target),
            'follower_id' => absint($actor),
        )
    );
}
```

After `bp_stop_following()`, log a failed verification if this returns `false`.

BuddyBoss’s native connection eligibility restrictions must not be bypassed. External requests should continue to call:

```php
friends_add_friend()
```

rather than directly inserting rows into the BuddyBoss friendship table.

# 5. Streams changes

Do not modify `Wo_IsFollowRequested()` to write to the database. It must remain a read-only predicate.

The proposed mutation inside that function is unsafe because it causes database writes during status checks and can create recursion or unexpected approvals.

Instead, modify `Wo_RegisterFollow()` so that Streams follows are always immediate:

```php
$active = 1;
```

The following branches must not change `$active` back to zero:

```php
if ($following_data['confirm_followers'] == 1) {
    $active = 0;
}

if ($wo['config']['connectivitySystem'] == 1) {
    $active = 0;
}
```

They should be removed or bypassed for the Buzzjuice integration.

After the local insert/update, verify:

```sql
SELECT id
FROM followers
WHERE following_id = <target>
  AND follower_id = <actor>
  AND active = 1
LIMIT 1
```

Only after successful read-back verification should Streams send:

```text
streams / follow / actor / target
```

The same rule applies to `Wo_DeleteFollow()`:

1. Delete the directional row.
2. Verify that it no longer exists.
3. Clear cache/activity.
4. Send the signed `unfollow` command to WordPress.
5. Log failures and retain the event for retry if the WordPress request fails.

The Streams API endpoints must not be used for synchronization.

# 6. Socials changes

QuickDate’s overloaded `followers` table must be treated according to semantic operation.

Do not use generic `Wo_DeleteFollow()` as the only synchronization trigger.

The QuickDate handlers must distinguish:

- pending Add Friend cancellation;
- accepted friendship removal;
- ordinary follow removal.

Required mappings:

```text
add_friend()
    → connection_request

approve_friend_request()
    → connection_accept

disapprove_friend_request()
    → connection_reject

cancel pending request
    → connection_withdraw

unfriend accepted friendship
    → connection_remove

ordinary follow
    → follow

ordinary unfollow
    → unfollow
```

For `connection_reject`, the actor must be the person rejecting the request and the target must be the original requester.

For `connection_withdraw`, the actor must always be the original requester.

Do not infer the requester from the currently logged-in user without first reading the actual pending row.

```json
{
  "origin": "streams",
  "operation": "follow",
  "event_id": "4c5f1b5c-8ac0-4b4d-a7c1-7f1d7a4e45d2",
```

```http
Content-Type: application/json
Accept: application/json
X-BZJ-Platform: streams
X-BZJ-Timestamp: 1720000000
X-BZJ-Signature: <hex HMAC SHA-256>
```

The signature is:

```php
hash_hmac(
    'sha256',
    $timestamp . '.' . $raw_json,
    $platform_secret
```

Use separate secrets where available:

```text
BZJ_STREAMS_SYNC_SECRET
BZJ_SOCIALS_SYNC_SECRET
```

Only fall back to `BUZZ_SSO_SECRET` if the platform-specific secret is not configured.

The same `event_id` must be reused for retries.

```php
        add_action('rest_api_init', array($this, 'register_rest_routes'));

        add_action('friends_friendship_requested', array($this, 'bb_connection_requested'), 20, 4);
        add_action('friends_friendship_accepted', array($this, 'bb_connection_accepted'), 20, 4);
        add_action('friends_friendship_rejected', array($this, 'bb_connection_rejected'), 20, 2);
        add_action('friends_friendship_withdrawn', array($this, 'bb_connection_withdrawn'), 20, 2);
        add_action('friends_friendship_whithdrawn', array($this, 'bb_connection_withdrawn'), 20, 2);
        add_action('friends_friendship_deleted', array($this, 'bb_connection_deleted'), 1, 3);
        add_action('friends_friendship_post_delete', array($this, 'bb_connection_post_deleted'), 20, 2);

        add_action('bp_start_following', array($this, 'bb_follow_started'), 20, 1);
        add_action('bp_stop_following', array($this, 'bb_follow_stopped'), 20, 1);
        add_action('bp_follow_start_following', array($this, 'bb_follow_started'), 20, 1);
        add_action('bp_follow_stop_following', array($this, 'bb_follow_stopped'), 20, 1);

        add_action('bp_moderation_after_save', array($this, 'bb_moderation_saved'), 20, 1);
        add_action('bb_moderation_after_delete', array($this, 'bb_moderation_deleted'), 20, 1);

        add_action(self::CRON_HOOK, array($this, 'process_recovery_queue'));
        add_action(self::CRON_HOOK_RECONCILE, array($this, 'reconcile_recent'));

        $this->maybe_install_schema();
        $this->maybe_schedule_cron();
        $this->verify_external_databases(true);
    }

    private function maybe_install_schema() {
        $installed = get_option('bzj_connections_sync_schema_version', '');
        if ($installed === self::VERSION) {
            return;
        }

        require_once ABSPATH . 'wp-admin/includes/upgrade.php';
        global $wpdb;
        $charset = $wpdb->get_charset_collate();

        $sql_ledger = "CREATE TABLE {$this->ledger_table} (
            id bigint(20) unsigned NOT NULL AUTO_INCREMENT,
            user_a bigint(20) unsigned NOT NULL,
            user_b bigint(20) unsigned NOT NULL,
            connection_state varchar(20) NOT NULL DEFAULT 'none',
            requested_by bigint(20) unsigned NOT NULL DEFAULT 0,
            follow_a_to_b tinyint(1) unsigned NOT NULL DEFAULT 0,
            follow_b_to_a tinyint(1) unsigned NOT NULL DEFAULT 0,
            block_a_to_b tinyint(1) unsigned NOT NULL DEFAULT 0,
            block_b_to_a tinyint(1) unsigned NOT NULL DEFAULT 0,
            version bigint(20) unsigned NOT NULL DEFAULT 1,
            last_event_uuid char(36) NOT NULL DEFAULT '',
            created_at datetime NOT NULL,
            updated_at datetime NOT NULL,
            PRIMARY KEY (id),
            UNIQUE KEY user_pair (user_a,user_b),
            KEY connection_state (connection_state),
            KEY requested_by (requested_by),
            KEY block_a_to_b (block_a_to_b),
            KEY block_b_to_a (block_b_to_a),
            KEY updated_at (updated_at)
        ) {$charset};";

        $sql_events = "CREATE TABLE {$this->events_table} (
            id bigint(20) unsigned NOT NULL AUTO_INCREMENT,
            event_uuid char(36) NOT NULL,
            origin varchar(20) NOT NULL,
            operation varchar(40) NOT NULL,
            actor_wp_id bigint(20) unsigned NOT NULL DEFAULT 0,
            target_wp_id bigint(20) unsigned NOT NULL DEFAULT 0,
            pair_a bigint(20) unsigned NOT NULL DEFAULT 0,
            pair_b bigint(20) unsigned NOT NULL DEFAULT 0,
            payload longtext NULL,
            status varchar(20) NOT NULL DEFAULT 'pending',
            attempts int(10) unsigned NOT NULL DEFAULT 0,
            next_attempt_at datetime NOT NULL,
            last_error text NULL,
            processed_at datetime NULL,
            created_at datetime NOT NULL,
            updated_at datetime NOT NULL,
            PRIMARY KEY (id),
            UNIQUE KEY event_uuid (event_uuid),
            KEY queue_status (status,next_attempt_at),
            KEY pair_key (pair_a,pair_b),
            KEY operation (operation),
            KEY origin (origin)
        ) {$charset};";

        dbDelta($sql_ledger);
        dbDelta($sql_events);

        update_option('bzj_connections_sync_schema_version', self::VERSION, false);
    }

    private function maybe_schedule_cron() {
        if (!wp_next_scheduled(self::CRON_HOOK)) {
            wp_schedule_event(time() + 300, 'hourly', self::CRON_HOOK);
        }
        if (!wp_next_scheduled(self::CRON_HOOK . '_reconcile')) {
            wp_schedule_event(time() + 600, 'hourly', self::CRON_HOOK . '_reconcile');
        }
    }

    private function log($message, $context = array(), $platform = '') {
        $dir = trailingslashit(ABSPATH) . ltrim(self::LOG_DIR, '/');
        if (!is_dir($dir)) {
            wp_mkdir_p($dir);
        }

        if (!is_dir($dir) || !is_writable($dir)) {
            return;
        }

        $file = self::LOG_FILE;
        if ($platform === self::ORIGIN_STREAMS) {
            $file = self::STREAMS_LOG_FILE;
        } elseif ($platform === self::ORIGIN_SOCIALS) {
            $file = self::SOCIALS_LOG_FILE;
        }

        $entry = array(
            'time' => gmdate('c'),
            'message' => (string) $message,
            'context' => $context,
        );

        @file_put_contents(
            trailingslashit($dir) . $file,
            wp_json_encode($entry, JSON_UNESCAPED_SLASHES) . PHP_EOL,
            FILE_APPEND | LOCK_EX
        );
    }

    private function external_log($platform, $operation, $origin, $actor_wp, $target_wp, $actor_ext, $target_ext, $db, $table, $sql_op, $affected, $verified, $event_uuid = '', $error = '') {
        $this->log(
            'External DB operation',
            array(
                'platform' => $platform,
                'operation' => $operation,
                'origin' => $origin,
                'actor_wp_id' => (int) $actor_wp,
                'target_wp_id' => (int) $target_wp,
                'actor_external_id' => (int) $actor_ext,
                'target_external_id' => (int) $target_ext,
                'database' => $this->db_name($db),
                'table' => $table,
                'sql_operation' => $sql_op,
                'affected_rows' => (int) $affected,
                'verified' => (bool) $verified,
                'event_uuid' => $event_uuid,
                'error' => $error,
            ),
            $platform
        );
    }

    private function db_name($db) {
        if (!$db instanceof mysqli) {
            return '';
        }

        $name = '';
        try {
            $result = $db->query('SELECT DATABASE() AS db_name');
            if ($result) {
                $row = $result->fetch_assoc();
                $name = isset($row['db_name']) ? (string) $row['db_name'] : '';
                $result->free();
            }
        } catch (Throwable $e) {
            $name = '';
        }

        return $name;
    }

    public function rest_status(WP_REST_Request $request) {
        $a = absint($request->get_param('user_a'));
        $b = absint($request->get_param('user_b'));

        if ($a < 1 || $b < 1 || $a === $b) {
            return new WP_Error('bzj_invalid_pair', 'Two different valid WordPress user IDs are required.', array('status' => 400));
        }

        return rest_ensure_response(array(
            'success' => true,
            'version' => self::VERSION,
            'relationship' => $this->get_ledger($a, $b),
        ));
    }

    public function rest_command(WP_REST_Request $request) {
        $raw = $request->get_body();
        $payload = json_decode($raw, true);

        if (!is_array($payload)) {
            return new WP_Error('bzj_invalid_json', 'Malformed JSON.', array('status' => 400));
        }

        $origin = sanitize_key(isset($payload['origin']) ? $payload['origin'] : '');
        $operation = sanitize_key(isset($payload['operation']) ? $payload['operation'] : '');
        $event_uuid = sanitize_text_field(isset($payload['event_id']) ? $payload['event_id'] : (isset($payload['event_uuid']) ? $payload['event_uuid'] : ''));

        if (!in_array($origin, array(self::ORIGIN_STREAMS, self::ORIGIN_SOCIALS), true)) {
            return new WP_Error('bzj_invalid_origin', 'Origin must be streams or socials.', array('status' => 400));
        }

        if (!in_array($operation, array(
            self::OP_CONNECTION_REQUEST,
            self::OP_CONNECTION_ACCEPT,
            self::OP_CONNECTION_REJECT,
            self::OP_CONNECTION_WITHDRAW,
            self::OP_CONNECTION_REMOVE,
            self::OP_FOLLOW,
            self::OP_UNFOLLOW,
            self::OP_BLOCK,
            self::OP_UNBLOCK,
        ), true)) {
            return new WP_Error('bzj_invalid_operation', 'Unsupported synchronization operation.', array('status' => 400));
        }

        if (!$this->is_uuid($event_uuid)) {
            return new WP_Error('bzj_invalid_event', 'A valid event UUID is required.', array('status' => 400));
        }

        $auth = $this->authenticate_external_request($request, $raw, $origin);
        if (is_wp_error($auth)) {
            return $auth;
        }

        $actor_external = absint(
            isset($payload['actor_external_id'])
                ? $payload['actor_external_id']
                : (isset($payload['actor_id']) ? $payload['actor_id'] : 0)
        );

        $target_external = absint(
            isset($payload['target_external_id'])
                ? $payload['target_external_id']
                : (isset($payload['target_id']) ? $payload['target_id'] : 0)
        );

        if ($actor_external < 1 || $target_external < 1 || $actor_external === $target_external) {
            return new WP_Error('bzj_invalid_users', 'Actor and target must be different valid IDs.', array('status' => 400));
        }

        if (isset($payload['authenticated_id']) && absint($payload['authenticated_id']) !== $actor_external) {
            return new WP_Error('bzj_actor_mismatch', 'Authenticated actor does not match actor_id.', array('status' => 403));
        }

        $actor_wp = $this->map_external_to_wp($origin, $actor_external);
        $target_wp = $this->map_external_to_wp($origin, $target_external);

        if ($actor_wp < 1 || $target_wp < 1 || $actor_wp === $target_wp) {
            return new WP_Error('bzj_mapping_error', 'Could not map the external users to WordPress users.', array('status' => 409));
        }

        if ($this->event_exists($event_uuid)) {
            return rest_ensure_response(array(
                'success' => true,
                'status' => 'already_processed',
                'event_id' => $event_uuid,
                'relationship' => $this->get_ledger($actor_wp, $target_wp),
            ));
        }

        if (!$this->acquire_pair_lock($actor_wp, $target_wp)) {
            return new WP_Error('bzj_pair_locked', 'Relationship pair is busy; retry the request.', array('status' => 503));
        }

        try {
            $this->insert_event($event_uuid, $origin, $operation, $actor_wp, $target_wp, $payload);

            $result = $this->process_external_operation($operation, $actor_wp, $target_wp, $event_uuid);

            if (is_wp_error($result)) {
                $this->mark_event_retry($event_uuid, $result->get_error_message());
                return $result;
            }

            $this->mark_event_processed($event_uuid);

            return rest_ensure_response(array(
                'success' => true,
                'status' => 'processed',
                'event_id' => $event_uuid,
                'relationship' => $this->get_ledger($actor_wp, $target_wp),
            ));
        } catch (Throwable $e) {
            $this->mark_event_retry($event_uuid, $e->getMessage());
            $this->log(
                'REST command exception',
                array(
                    'event_id' => $event_uuid,
                    'origin' => $origin,
                    'operation' => $operation,
                    'actor_wp' => $actor_wp,
                    'target_wp' => $target_wp,
                    'error' => $e->getMessage(),
                )
            );
            return new WP_Error('bzj_internal_error', 'Synchronization command failed.', array('status' => 500, 'event_id' => $event_uuid));
        } finally {
            $this->release_pair_lock($actor_wp, $target_wp);
        }
    }

    private function authenticate_external_request(WP_REST_Request $request, $raw, $origin) {
        $header_platform = sanitize_key((string) $request->get_header('X-BZJ-Platform'));

        if (!in_array($header_platform, array(self::ORIGIN_STREAMS, self::ORIGIN_SOCIALS), true)) {
            return new WP_Error('bzj_auth_platform', 'A valid X-BZJ-Platform header is required.', array('status' => 401));
        }

        if ($header_platform !== $origin) {
            return new WP_Error('bzj_auth_platform_mismatch', 'The request platform does not match the payload origin.', array('status' => 403));
        }

        $timestamp = (string) $request->get_header('X-BZJ-Timestamp');
        $signature = trim((string) $request->get_header('X-BZJ-Signature'));

        if ($timestamp === '' || $signature === '' || !ctype_digit($timestamp)) {
            return new WP_Error('bzj_auth_missing', 'Missing authentication headers.', array('status' => 401));
        }

        $timestamp_int = (int) $timestamp;
        if (abs(time() - $timestamp_int) > self::EXTERNAL_TIMESTAMP_WINDOW) {
            return new WP_Error('bzj_auth_expired', 'Request timestamp is outside the allowed window.', array('status' => 401));
        }

        $secret = $this->platform_secret($origin);
        if ($secret === '') {
            $this->log('External authentication secret unavailable', array('platform' => $origin), $origin);
            return new WP_Error('bzj_auth_unavailable', 'Synchronization secret is unavailable.', array('status' => 503));
        }

        $expected = hash_hmac('sha256', $timestamp . '.' . $raw, $secret);
        if (!hash_equals($expected, $signature)) {
            $this->log('External authentication failed', array('platform' => $origin, 'timestamp' => $timestamp_int), $origin);
            return new WP_Error('bzj_auth_invalid', 'Invalid request signature.', array('status' => 401));
        }

        return true;
    }

    private function platform_secret($platform) {
        $constant = $platform === self::ORIGIN_STREAMS ? 'BZJ_STREAMS_SYNC_SECRET' : 'BZJ_SOCIALS_SYNC_SECRET';
        if (defined($constant) && constant($constant)) {
            return (string) constant($constant);
        }

        $env = $platform === self::ORIGIN_STREAMS ? 'BZJ_STREAMS_SYNC_SECRET' : 'BZJ_SOCIALS_SYNC_SECRET';
        $secret = getenv($env);
        if ($secret) {
            return $secret;
        }

        return $this->sso_secret();
    }

    private function sso_secret() {
        if (function_exists('bzj_get_sso_secret')) {
            $secret = bzj_get_sso_secret();
            if ($secret) {
                return $secret;
            }
        }
        if (defined('BUZZ_SSO_SECRET') && BUZZ_SSO_SECRET) {
            return BUZZ_SSO_SECRET;
        }
        $secret = getenv('BUZZ_SSO_SECRET');
        return $secret ? $secret : '';
    }

    /* -------------------------------------------------------------------------
     * External-origin operations. BuddyBoss is always mutated first.
     * ---------------------------------------------------------------------- */

    private function process_external_operation($operation, $actor, $target, $event_uuid) {
        switch ($operation) {
            case self::OP_CONNECTION_REQUEST:
                return $this->bb_request_from_external($actor, $target, $event_uuid);
            case self::OP_CONNECTION_ACCEPT:
                return $this->bb_accept_from_external($actor, $target, $event_uuid);
            case self::OP_CONNECTION_REJECT:
                return $this->bb_reject_from_external($actor, $target, $event_uuid);
            case self::OP_CONNECTION_WITHDRAW:
                return $this->bb_withdraw_from_external($actor, $target, $event_uuid);
            case self::OP_CONNECTION_REMOVE:
                return $this->bb_remove_from_external($actor, $target, $event_uuid);
            case self::OP_FOLLOW:
                return $this->bb_follow_from_external($actor, $target, $event_uuid);
            case self::OP_UNFOLLOW:
                return $this->bb_unfollow_from_external($actor, $target, $event_uuid);
            case self::OP_BLOCK:
                return $this->bb_block_from_external($actor, $target, $event_uuid);
            case self::OP_UNBLOCK:
                return $this->bb_unblock_from_external($actor, $target, $event_uuid);
        }

        return new WP_Error('bzj_unknown_operation', 'Unknown synchronization operation.');
    }

    private function bb_request_from_external($actor, $target, $event_uuid) {
        if ($this->bb_is_blocked($actor, $target)) {
            return new WP_Error('bzj_blocked', 'A blocked relationship cannot create a connection.');
        }

        if (!function_exists('friends_add_friend') || !function_exists('friends_check_friendship_status')) {
            return new WP_Error('bzj_bb_unavailable', 'BuddyBoss connection functions are unavailable.');
        }

        $status = friends_check_friendship_status($actor, $target);

        if ($status === 'is_friend' || $status === 'pending') {
            return true;
        }

        if ($status === 'awaiting_response') {
            return new WP_Error('bzj_reverse_request', 'The other user already has a pending connection request.');
        }

        $ok = friends_add_friend($actor, $target);
        return $ok ? true : new WP_Error('bzj_bb_request_failed', 'BuddyBoss rejected the connection request.');
    }

    private function find_friendship_id($actor, $target) {
        if (!function_exists('friends_get_friendship_id')) {
            return 0;
        }

        $id = (int) friends_get_friendship_id($target, $actor);
        if (!$id) {
            $id = (int) friends_get_friendship_id($actor, $target);
        }
        return $id;
    }

    private function bb_accept_from_external($actor, $target, $event_uuid) {
        if (!function_exists('friends_accept_friendship')) {
            return new WP_Error('bzj_bb_unavailable', 'BuddyBoss connection functions are unavailable.');
        }

        $id = $this->find_friendship_id($actor, $target);
        if (!$id) {
            return new WP_Error('bzj_bb_request_missing', 'No pending BuddyBoss connection request was found.');
        }

        $ok = friends_accept_friendship($id);
        if (!$ok && function_exists('friends_check_friendship_status') && friends_check_friendship_status($actor, $target) !== 'is_friend') {
            return new WP_Error('bzj_bb_accept_failed', 'BuddyBoss could not accept the connection request.');
        }

        return true;
    }

    private function bb_reject_from_external($actor, $target, $event_uuid) {
        if (!function_exists('friends_reject_friendship')) {
            return new WP_Error('bzj_bb_unavailable', 'BuddyBoss rejection function is unavailable.');
        }

        $id = $this->find_friendship_id($actor, $target);
        if (!$id) {
            return true;
        }

        $ok = friends_reject_friendship($id);
        if (!$ok && function_exists('friends_check_friendship_status') && friends_check_friendship_status($actor, $target) !== 'not_friends') {
            return new WP_Error('bzj_bb_reject_failed', 'BuddyBoss could not reject the connection request.');
        }

        return true;
    }

    private function bb_withdraw_from_external($actor, $target, $event_uuid) {
        if (!function_exists('friends_withdraw_friendship')) {
            return new WP_Error('bzj_bb_unavailable', 'BuddyBoss withdrawal function is unavailable.');
        }

        $ok = friends_withdraw_friendship($actor, $target);

        if (!$ok && function_exists('friends_check_friendship_status') && friends_check_friendship_status($actor, $target) !== 'not_friends') {
            return new WP_Error('bzj_bb_withdraw_failed', 'BuddyBoss could not withdraw the connection request.');
        }

        return true;
    }

    private function bb_remove_from_external($actor, $target, $event_uuid) {
        if (!function_exists('friends_remove_friend') || !function_exists('friends_check_friendship_status')) {
            return new WP_Error('bzj_bb_unavailable', 'BuddyBoss connection functions are unavailable.');
        }

        if (friends_check_friendship_status($actor, $target) === 'is_friend') {
            $ok = friends_remove_friend($actor, $target);
            if (!$ok) {
                $ok = friends_remove_friend($target, $actor);
            }
            if (!$ok && friends_check_friendship_status($actor, $target) === 'is_friend') {
                return new WP_Error('bzj_bb_remove_failed', 'BuddyBoss could not remove the connection.');
            }
        }

        return true;
    }

    private function bb_follow_from_external($actor, $target, $event_uuid) {
        if ($this->bb_is_blocked($actor, $target)) {
            return new WP_Error('bzj_blocked', 'A blocked relationship cannot create a follow.');
        }

        if (!function_exists('bp_start_following')) {
            return new WP_Error('bzj_bb_follow_unavailable', 'BuddyBoss follow function is unavailable.');
        }

        if (function_exists('bp_is_following') && bp_is_following(array('leader_id' => $target, 'follower_id' => $actor))) {
            return true;
        }

        $result = bp_start_following(array('leader_id' => $target, 'follower_id' => $actor));
        if (is_wp_error($result)) {
            return $result;
        }

        if ($result === false && function_exists('bp_is_following') && !bp_is_following(array('leader_id' => $target, 'follower_id' => $actor))) {
            return new WP_Error('bzj_bb_follow_failed', 'BuddyBoss rejected the follow request.');
        }

        return true;
    }

    private function bb_unfollow_from_external($actor, $target, $event_uuid) {
        if (!function_exists('bp_stop_following')) {
            return new WP_Error('bzj_bb_unfollow_unavailable', 'BuddyBoss unfollow function is unavailable.');
        }

        if (function_exists('bp_is_following') && !bp_is_following(array('leader_id' => $target, 'follower_id' => $actor))) {
            return true;
        }

        $result = bp_stop_following(array('leader_id' => $target, 'follower_id' => $actor));
        if (is_wp_error($result)) {
            return $result;
        }

        if ($result === false && function_exists('bp_is_following') && bp_is_following(array('leader_id' => $target, 'follower_id' => $actor))) {
            return new WP_Error('bzj_bb_unfollow_failed', 'BuddyBoss rejected the unfollow.');
        }

        return true;
    }

    private function bb_block_from_external($actor, $target, $event_uuid) {
        if (!class_exists('BP_Moderation') || !class_exists('BP_Moderation_Members')) {
            return new WP_Error('bzj_bb_moderation_unavailable', 'BuddyBoss moderation classes are unavailable.');
        }

        if (!$this->bb_block_exists_direction($actor, $target)) {
            $moderation = new BP_Moderation($target, BP_Moderation_Members::$moderation_type, $actor);
            $moderation->user_report = 0;
            $moderation->content = '';

            $this->push_context(array(
                'event_uuid' => $event_uuid,
                'origin' => self::ORIGIN_WORDPRESS,
                'operation' => self::OP_BLOCK,
                'actor' => $actor,
                'target' => $target,
            ));

            try {
                if (!$moderation->save()) {
                    return new WP_Error('bzj_bb_block_failed', 'BuddyBoss could not create the member block.');
                }
            } finally {
                $this->pop_context();
            }
        }

        $this->enforce_block_on_buddyboss($actor, $target, $event_uuid);
        $this->save_ledger($actor, $target, array(
            $this->directional_block_field($actor, $target) => 1,
            'connection_state' => 'none',
            'requested_by' => 0,
            'follow_a_to_b' => 0,
            'follow_b_to_a' => 0,
        ), $event_uuid);

        $this->project_block_pair($actor, $target, true, $event_uuid);

        return true;
    }

    private function bb_unblock_from_external($actor, $target, $event_uuid) {
        if (!class_exists('BP_Moderation') || !class_exists('BP_Moderation_Members')) {
            return new WP_Error('bzj_bb_moderation_unavailable', 'BuddyBoss moderation classes are unavailable.');
        }

        $moderation = new BP_Moderation($target, BP_Moderation_Members::$moderation_type, $actor);

        if (!empty($moderation->id) && empty($moderation->user_report)) {
            $this->push_context(array(
                'event_uuid' => $event_uuid,
                'origin' => self::ORIGIN_WORDPRESS,
                'operation' => self::OP_UNBLOCK,
                'actor' => $actor,
                'target' => $target,
            ));

            try {
                if (!$moderation->delete(false)) {
                    return new WP_Error('bzj_bb_unblock_failed', 'BuddyBoss could not remove the member block.');
                }
            } finally {
                $this->pop_context();
            }
        }

        $this->save_ledger($actor, $target, array(
            $this->directional_block_field($actor, $target) => 0,
        ), $event_uuid);

        $this->project_external_block($actor, $target, false, self::ORIGIN_STREAMS, $event_uuid);
        $this->project_external_block($actor, $target, false, self::ORIGIN_SOCIALS, $event_uuid);

        return true;
    }

    private function handle_bb_connection_event($event, $initiator, $friend, $friendship_id = 0) {
        if ($initiator < 1 || $friend < 1 || $initiator === $friend) {
            return;
        }

        $uuid = wp_generate_uuid4();

        if (!$this->acquire_pair_lock($initiator, $friend)) {
            $this->insert_event($uuid, self::ORIGIN_WORDPRESS, 'connection_' . $event, $initiator, $friend, array('friendship_id' => $friendship_id));
            $this->mark_event_retry($uuid, 'Pair lock busy.');
            return;
        }

        try {
            $this->insert_event($uuid, self::ORIGIN_WORDPRESS, 'connection_' . $event, $initiator, $friend, array('friendship_id' => $friendship_id));

            $state = 'none';
            $requested_by = 0;

            if ($event === 'requested') {
                $state = 'requested';
                $requested_by = $initiator;
            } elseif ($event === 'accepted') {
                $state = 'connected';
            } elseif (in_array($event, array('deleted', 'post_deleted', 'rejected', 'withdrawn'), true)) {
                $bb = $this->buddyboss_connection_state($initiator, $friend);

                if ($event === 'deleted' || $event === 'post_deleted') {
                    $state = 'none';
                    $requested_by = 0;
                } elseif ($bb === 'is_friend') {
                    $state = 'connected';
                } elseif ($bb === 'pending' || $bb === 'awaiting_response') {
                    $state = 'requested';
                    $requested_by = $this->get_bb_requester($initiator, $friend);
                }
            }

            $this->save_ledger($initiator, $friend, array(
                'connection_state' => $state,
                'requested_by' => $requested_by,
            ), $uuid);

            $this->project_social_connection($initiator, $friend, $state, $uuid);
            $this->mark_event_processed($uuid);
        } catch (Throwable $e) {
            $this->mark_event_retry($uuid, $e->getMessage());
            $this->log('BuddyBoss connection event failed', array(
                'event' => $event,
                'actor' => $initiator,
                'target' => $friend,
                'error' => $e->getMessage(),
                'event_uuid' => $uuid,
            ));
        } finally {
            $this->release_pair_lock($initiator, $friend);
        }
    }

    private function cancellation_already_processed($friendship_id, $a, $b) {
        $pair = $this->pair($a, $b);
        $key = (int) $friendship_id . ':' . $pair[0] . ':' . $pair[1];
        $now = time();

        foreach ($this->recent_cancellation_events as $existing_key => $expires) {
            if ($expires <= $now) {
                unset($this->recent_cancellation_events[$existing_key]);
            }
        }

        if (isset($this->recent_cancellation_events[$key])) {
            return true;
        }

        $this->recent_cancellation_events[$key] = $now + 30;

        return false;
    }

    private function handle_bb_pending_cancellation($event, $initiator, $friend, $friendship_id = 0) {
        $initiator = absint($initiator);
        $friend = absint($friend);

        if ($initiator < 1 || $friend < 1 || $initiator === $friend) {
            return;
        }

        if ($this->cancellation_already_processed($friendship_id, $initiator, $friend)) {
            return;
        }

        $uuid = wp_generate_uuid4();

        if (!$this->acquire_pair_lock($initiator, $friend)) {
            $this->insert_event(
                $uuid,
                self::ORIGIN_WORDPRESS,
                'connection_' . $event,
                $initiator,
                $friend,
                array(
                    'friendship_id' => $friendship_id,
                    'pending_only' => true,
                )
            );
            $this->mark_event_retry($uuid, 'Pair lock busy.');
            return;
        }

        try {
            $this->insert_event(
                $uuid,
                self::ORIGIN_WORDPRESS,
                'connection_' . $event,
                $initiator,
                $friend,
                array(
                    'friendship_id' => $friendship_id,
                    'pending_only' => true,
                )
            );

            $bb_state = $this->buddyboss_connection_state($initiator, $friend);

            if ($bb_state === 'is_friend') {
                $this->save_ledger($initiator, $friend, array(
                    'connection_state' => 'connected',
                    'requested_by' => 0,
                ), $uuid);
            } elseif ($bb_state === 'pending' || $bb_state === 'awaiting_response') {
                $requester = $this->get_bb_requester($initiator, $friend);
                $this->save_ledger($initiator, $friend, array(
                    'connection_state' => 'requested',
                    'requested_by' => $requester,
                ), $uuid);
            } else {
                $this->save_ledger($initiator, $friend, array(
                    'connection_state' => 'none',
                    'requested_by' => 0,
                ), $uuid);

                $this->remove_social_pending_request($initiator, $friend, $uuid);
            }

            $this->mark_event_processed($uuid);
        } catch (Throwable $e) {
            $this->mark_event_retry($uuid, $e->getMessage());
            $this->log('BuddyBoss pending cancellation failed', array(
                'event' => $event,
                'initiator' => $initiator,
                'friend' => $friend,
                'friendship_id' => $friendship_id,
                'event_uuid' => $uuid,
                'error' => $e->getMessage(),
            ));
        } finally {
            $this->release_pair_lock($initiator, $friend);
        }
    }

    private function remove_social_pending_request($requester_wp, $recipient_wp, $event_uuid = '') {
        $requester_wp = absint($requester_wp);
        $recipient_wp = absint($recipient_wp);

        if ($requester_wp < 1 || $recipient_wp < 1 || $requester_wp === $recipient_wp) {
            return false;
        }

        $requester_ext = $this->map_wp_to_external($requester_wp, self::ORIGIN_SOCIALS);
        $recipient_ext = $this->map_wp_to_external($recipient_wp, self::ORIGIN_SOCIALS);

        if ($requester_ext < 1 || $recipient_ext < 1) {
            $this->queue_projection(
                self::ORIGIN_SOCIALS,
                self::OP_CONNECTION_WITHDRAW,
                $requester_wp,
                $recipient_wp,
                array(
                    'event_uuid' => $event_uuid,
                    'reason' => 'missing_external_mapping',
                    'pending_only' => true,
                )
            );
            return false;
        }

        $db = $this->socials_db();
        if (!$db) {
            $this->queue_projection(
                self::ORIGIN_SOCIALS,
                self::OP_CONNECTION_WITHDRAW,
                $requester_wp,
                $recipient_wp,
                array(
                    'event_uuid' => $event_uuid,
                    'reason' => 'db_unavailable',
                    'pending_only' => true,
                )
            );
            return false;
        }

        $table = $this->external_follow_table($db, self::ORIGIN_SOCIALS);
        if (!$table) {
            $this->queue_projection(
                self::ORIGIN_SOCIALS,
                self::OP_CONNECTION_WITHDRAW,
                $requester_wp,
                $recipient_wp,
                array(
                    'event_uuid' => $event_uuid,
                    'reason' => 'followers_table_not_found',
                    'pending_only' => true,
                )
            );
            return false;
        }

        $sql = "DELETE FROM `{$table}`
                WHERE following_id = ?
                  AND follower_id = ?
                  AND active = 0";

        $stmt = $db->prepare($sql);
        if (!$stmt) {
            throw new RuntimeException($db->error ?: 'Could not prepare pending-request deletion.');
        }

        $stmt->bind_param('ii', $recipient_ext, $requester_ext);

        if (!$stmt->execute()) {
            $error = $stmt->error ?: 'Could not delete the pending QuickDate request.';
            $affected = (int) $stmt->affected_rows;
            $stmt->close();

            $this->external_log(
                self::ORIGIN_SOCIALS,
                self::OP_CONNECTION_WITHDRAW,
                self::ORIGIN_WORDPRESS,
                $requester_wp,
                $recipient_wp,
                $requester_ext,
                $recipient_ext,
                $db,
                $table,
                'DELETE_PENDING',
                $affected,
                false,
                $event_uuid,
                $error
            );

            throw new RuntimeException($error);
        }

        $affected = (int) $stmt->affected_rows;
        $stmt->close();

        $verify = $db->prepare("SELECT id FROM `{$table}` WHERE following_id = ? AND follower_id = ? AND active = 0 LIMIT 1");
        if (!$verify) {
            throw new RuntimeException($db->error ?: 'Could not prepare pending-request verification.');
        }

        $verify->bind_param('ii', $recipient_ext, $requester_ext);
        if (!$verify->execute()) {
            $error = $verify->error ?: 'Could not verify pending-request deletion.';
            $verify->close();
            throw new RuntimeException($error);
        }

        $verify->store_result();
        $remaining = $verify->num_rows;
        $verify->close();

        $verified = ($remaining === 0);

        $this->external_log(
            self::ORIGIN_SOCIALS,
            self::OP_CONNECTION_WITHDRAW,
            self::ORIGIN_WORDPRESS,
            $requester_wp,
            $recipient_wp,
            $requester_ext,
            $recipient_ext,
            $db,
            $table,
            'DELETE_PENDING',
            $affected,
            $verified,
            $event_uuid,
            $verified ? '' : 'Pending QuickDate request remains after deletion.'
        );

        if (!$verified) {
            throw new RuntimeException('Pending QuickDate request read-back verification failed.');
        }

        return true;
    }

    public function bb_follow_started($follow) {
        $this->handle_bb_follow_event(self::OP_FOLLOW, $follow);
    }

    public function bb_follow_stopped($follow) {
        $this->handle_bb_follow_event(self::OP_UNFOLLOW, $follow);
    }

    private function handle_bb_follow_event($operation, $follow) {
        if ($this->in_internal_context() || !is_object($follow)) {
            return;
        }

        $actor = absint(isset($follow->follower_id) ? $follow->follower_id : 0);
        $target = absint(isset($follow->leader_id) ? $follow->leader_id : 0);

        if ($actor < 1 || $target < 1 || $actor === $target) {
            return;
        }

        $uuid = wp_generate_uuid4();

        if (!$this->acquire_pair_lock($actor, $target)) {
            $this->insert_event($uuid, self::ORIGIN_WORDPRESS, $operation, $actor, $target);
            $this->mark_event_retry($uuid, 'Pair lock busy.');
            return;
        }

        try {
            $this->insert_event($uuid, self::ORIGIN_WORDPRESS, $operation, $actor, $target);

            if ($operation === self::OP_FOLLOW && $this->bb_is_blocked($actor, $target)) {
                $this->set_follow_state($actor, $target, false, $uuid);
                $this->mark_event_processed($uuid);
                return;
            }

            $this->set_follow_state($actor, $target, $operation === self::OP_FOLLOW, $uuid);

            $this->project_external_follow($actor, $target, $operation === self::OP_FOLLOW, self::ORIGIN_STREAMS, $uuid);
            $this->mark_event_processed($uuid);
        } catch (Throwable $e) {
            $this->mark_event_retry($uuid, $e->getMessage());
            $this->log('BuddyBoss follow event failed', array(
                'operation' => $operation,
                'actor' => $actor,
                'target' => $target,
                'error' => $e->getMessage(),
                'event_uuid' => $uuid,
            ));
        } finally {
            $this->release_pair_lock($actor, $target);
        }
    }

    public function bb_moderation_saved($moderation) {
        if (!$this->is_user_block_moderation($moderation)) {
            return;
        }

        $this->handle_bb_block_event(
            self::OP_BLOCK,
            absint($moderation->user_id),
            absint($moderation->item_id),
            absint(isset($moderation->id) ? $moderation->id : 0)
        );
    }

    public function bb_moderation_deleted($moderation) {
        if (!$this->is_user_block_moderation($moderation)) {
            return;
        }

        $this->handle_bb_block_event(
            self::OP_UNBLOCK,
            absint($moderation->user_id),
            absint($moderation->item_id),
            absint(isset($moderation->id) ? $moderation->id : 0)
        );
    }

    private function is_user_block_moderation($moderation) {
        return is_object($moderation)
            && isset($moderation->item_type)
            && $moderation->item_type === 'user'
            && empty($moderation->user_report)
            && absint($moderation->user_id) > 0
            && absint($moderation->item_id) > 0;
    }

    private function handle_bb_block_event($operation, $actor, $target, $moderation_id = 0) {
        if ($actor < 1 || $target < 1 || $actor === $target || $this->in_internal_context()) {
            return;
        }

        $uuid = wp_generate_uuid4();

        if (!$this->acquire_pair_lock($actor, $target)) {
            $this->insert_event($uuid, self::ORIGIN_WORDPRESS, $operation, $actor, $target, array('moderation_id' => $moderation_id));
            $this->mark_event_retry($uuid, 'Pair lock busy.');
            return;
        }

        try {
            $this->insert_event($uuid, self::ORIGIN_WORDPRESS, $operation, $actor, $target, array('moderation_id' => $moderation_id));

            if ($operation === self::OP_BLOCK) {
                $this->enforce_block_on_buddyboss($actor, $target, $uuid);
                $this->save_ledger($actor, $target, array(
                    $this->directional_block_field($actor, $target) => 1,
                    'connection_state' => 'none',
                    'requested_by' => 0,
                    'follow_a_to_b' => 0,
                    'follow_b_to_a' => 0,
                ), $uuid);
                $this->project_block_pair($actor, $target, true, $uuid);
            } else {
                $this->save_ledger($actor, $target, array(
                    $this->directional_block_field($actor, $target) => 0,
                ), $uuid);

                $this->project_external_block($actor, $target, false, self::ORIGIN_STREAMS, $uuid);
                $this->project_external_block($actor, $target, false, self::ORIGIN_SOCIALS, $uuid);
            }

            $this->mark_event_processed($uuid);
        } catch (Throwable $e) {
            $this->mark_event_retry($uuid, $e->getMessage());
            $this->log('BuddyBoss block event failed', array(
                'operation' => $operation,
                'actor' => $actor,
                'target' => $target,
                'error' => $e->getMessage(),
                'event_uuid' => $uuid,
            ));
        } finally {
            $this->release_pair_lock($actor, $target);
        }
    }

    private function project_block_pair($actor, $target, $blocked, $event_uuid) {
        $this->project_external_block($actor, $target, $blocked, self::ORIGIN_STREAMS, $event_uuid);
        $this->project_external_block($actor, $target, $blocked, self::ORIGIN_SOCIALS, $event_uuid);

        if ($blocked) {
            $this->project_external_follow($actor, $target, false, self::ORIGIN_STREAMS, $event_uuid);
            $this->project_external_follow($target, $actor, false, self::ORIGIN_STREAMS, $event_uuid);
            $this->project_external_follow($actor, $target, false, self::ORIGIN_SOCIALS, $event_uuid);
            $this->project_external_follow($target, $actor, false, self::ORIGIN_SOCIALS, $event_uuid);

            $this->project_social_connection($actor, $target, 'none', $event_uuid);
        }
    }

    private function enforce_block_on_buddyboss($actor, $target, $event_uuid) {
        if (function_exists('friends_check_friendship_status') && function_exists('friends_remove_friend') && friends_check_friendship_status($actor, $target) === 'is_friend') {
            $this->push_context(array(
                'event_uuid' => $event_uuid,
                'origin' => self::ORIGIN_WORDPRESS,
                'operation' => self::OP_CONNECTION_REMOVE,
                'actor' => $actor,
                'target' => $target,
            ));

            try {
                friends_remove_friend($actor, $target);
            } finally {
                $this->pop_context();
            }
        }

        if (function_exists('bp_stop_following')) {
            foreach (array(array($actor, $target), array($target, $actor)) as $p) {
                if (function_exists('bp_is_following') && bp_is_following(array('leader_id' => $p[1], 'follower_id' => $p[0]))) {
                    $this->push_context(array(
                        'event_uuid' => $event_uuid,
                        'origin' => self::ORIGIN_WORDPRESS,
                        'operation' => self::OP_UNFOLLOW,
                        'actor' => $p[0],
                        'target' => $p[1],
                    ));

                    try {
                        bp_stop_following(array('leader_id' => $p[1], 'follower_id' => $p[0]));
                    } finally {
                        $this->pop_context();
                    }
                }
            }
        }
    }

    /* -------------------------------------------------------------------------
     * Ledger and BuddyBoss state
     * ---------------------------------------------------------------------- */

    private function pair($a, $b) {
        $a = absint($a);
        $b = absint($b);

        return $a < $b ? array($a, $b) : array($b, $a);
    }

    private function get_ledger($a, $b) {
        global $wpdb;

        $p = $this->pair($a, $b);

        $row = $wpdb->get_row(
            $wpdb->prepare(
                "SELECT * FROM {$this->ledger_table} WHERE user_a=%d AND user_b=%d LIMIT 1",
                $p[0],
                $p[1]
            ),
            ARRAY_A
        );

        return $row ?: array(
            'user_a' => $p[0],
            'user_b' => $p[1],
            'connection_state' => 'none',
            'requested_by' => 0,
            'follow_a_to_b' => 0,
            'follow_b_to_a' => 0,
            'block_a_to_b' => 0,
            'block_b_to_a' => 0,
            'version' => 0,
            'last_event_uuid' => '',
            'created_at' => current_time('mysql', true),
            'updated_at' => current_time('mysql', true),
        );
    }

    private function save_ledger($actor, $target, $changes, $event_uuid = '') {
        global $wpdb;

        $p = $this->pair($actor, $target);
        $existing = $this->get_ledger($p[0], $p[1]);
        $now = current_time('mysql', true);

        $data = array(
            'user_a' => $p[0],
            'user_b' => $p[1],
            'connection_state' => isset($changes['connection_state']) ? sanitize_key($changes['connection_state']) : $existing['connection_state'],
            'requested_by' => isset($changes['requested_by']) ? absint($changes['requested_by']) : absint($existing['requested_by']),
            'follow_a_to_b' => isset($changes['follow_a_to_b']) ? (int) !!$changes['follow_a_to_b'] : (int) $existing['follow_a_to_b'],
            'follow_b_to_a' => isset($changes['follow_b_to_a']) ? (int) !!$changes['follow_b_to_a'] : (int) $existing['follow_b_to_a'],
            'block_a_to_b' => isset($changes['block_a_to_b']) ? (int) !!$changes['block_a_to_b'] : (int) $existing['block_a_to_b'],
            'block_b_to_a' => isset($changes['block_b_to_a']) ? (int) !!$changes['block_b_to_a'] : (int) $existing['block_b_to_a'],
            'version' => max(1, (int) $existing['version'] + 1),
            'last_event_uuid' => $event_uuid ?: $existing['last_event_uuid'],
            'updated_at' => $now,
        );

        if ((int) $existing['version'] === 0) {
            $data['created_at'] = $now;
            $wpdb->insert($this->ledger_table, $data);
        } else {
            $wpdb->update($this->ledger_table, $data, array('user_a' => $p[0], 'user_b' => $p[1]));
        }

        return $this->get_ledger($p[0], $p[1]);
    }

    private function set_follow_state($actor, $target, $active, $event_uuid = '') {
        $p = $this->pair($actor, $target);
        $field = ((int) $actor === $p[0]) ? 'follow_a_to_b' : 'follow_b_to_a';

        return $this->save_ledger($actor, $target, array(
            $field => $active ? 1 : 0,
        ), $event_uuid);
    }

    private function directional_block_field($actor, $target) {
        $p = $this->pair($actor, $target);
        return ((int) $actor === $p[0]) ? 'block_a_to_b' : 'block_b_to_a';
    }

    private function buddyboss_connection_state($a, $b) {
        return function_exists('friends_check_friendship_status')
            ? friends_check_friendship_status($a, $b)
            : 'not_friends';
    }

    private function get_bb_requester($a, $b) {
        $s = $this->buddyboss_connection_state($a, $b);

        if ($s === 'pending') {
            return $a;
        }

        if ($s === 'awaiting_response') {
            return $b;
        }

        return 0;
    }

    private function bb_is_blocked($a, $b) {
        return $this->bb_block_exists_direction($a, $b) || $this->bb_block_exists_direction($b, $a);
    }

    private function bb_block_exists_direction($actor, $target) {
        if ($actor < 1 || $target < 1 || $actor === $target) {
            return false;
        }

        if (class_exists('BP_Moderation') && class_exists('BP_Moderation_Members')) {
            $m = new BP_Moderation($target, BP_Moderation_Members::$moderation_type, $actor);
            if (!empty($m->id) && empty($m->user_report)) {
                return true;
            }
        }

        $ledger = $this->get_ledger($actor, $target);
        $field = $this->directional_block_field($actor, $target);

        return !empty($ledger[$field]);
    }

    private function load_db_helpers() {
        static $loaded = false;

        if ($loaded) {

        $paths = array(
            trailingslashit(ABSPATH) . 'shared/db_helpers.php',
            dirname(ABSPATH) . '/shared/db_helpers.php',

        foreach ($paths as $file) {

                $loaded = true;
                return true;
            }
        }

        $this->log('db_helpers.php not found', array('paths_checked' => $paths));
        return false;
    }

    }

        if (!$this->load_db_helpers() || !function_exists('get_qd_db_conn')) {

        $db = get_qd_db_conn();

    private function map_wp_to_external($wp_id, $platform) {
        $key = $platform === self::ORIGIN_STREAMS ? 'wo_user_id' : 'qd_user_id';
        return absint(get_user_meta(absint($wp_id), $key, true));
    }

    private function map_external_to_wp($platform, $external_id) {
        global $wpdb;
        $key = $platform === self::ORIGIN_STREAMS ? 'wo_user_id' : 'qd_user_id';

        $sql = $wpdb->prepare(
            "SELECT user_id FROM {$wpdb->usermeta} WHERE meta_key=%s AND meta_value=%s LIMIT 1",
            $key,
            (string) $external_id
        );

        $id = $wpdb->get_var($sql);

        return (int) $id;
    }

    private function table_exists($db, $table) {
        if (!$db || !$table) {
            return false;
        }

        $table = preg_replace('/[^A-Za-z0-9_]/', '', $table);

        $result = $db->query("SHOW TABLES LIKE '" . $db->real_escape_string($table) . "'");
        if (!$result) {
            return false;
        }

        $exists = $result->num_rows > 0;
        $result->free();

        return $exists;
    }

    private function columns($db, $table) {
        static $cache = array();

        $key = spl_object_hash($db) . ':' . $table;
        if (isset($cache[$key])) {
            return $cache[$key];
        }

        $out = array();

        if (!$this->table_exists($db, $table)) {
            return $out;
        }

        $safe = preg_replace('/[^A-Za-z0-9_]/', '', $table);
        $result = $db->query("SHOW COLUMNS FROM `{$safe}`");

        if ($result) {
            while ($row = $result->fetch_assoc()) {
                $out[strtolower($row['Field'])] = true;
            }
            $result->free();
        }

        $cache[$key] = $out;
        return $out;
    }

    private function first_table($db, $candidates) {
        foreach ($candidates as $t) {
            if ($this->table_exists($db, $t)) {
                return $t;
            }
        }
        return false;
    }

    private function external_follow_table($db, $platform) {
        if ($platform === self::ORIGIN_STREAMS) {
            return $this->first_table($db, array('Wo_Followers', 'wo_followers', 'followers'));
        }

        return $this->first_table($db, array('followers'));
    }

    private function external_block_table($db, $platform) {
        if ($platform === self::ORIGIN_STREAMS) {
            return $this->first_table($db, array('Wo_Blocks', 'wo_blocks', 'blocks'));
        }

        return $this->first_table($db, array('blocks'));
    }

    private function verify_external_databases($log = true) {
        $out = array(
            'streams' => array('connected' => false, 'database' => '', 'tables' => array()),
            'socials' => array('connected' => false, 'database' => '', 'tables' => array()),
        );

        $s = $this->streams_db();
        if ($s) {
            $out['streams']['connected'] = true;
            $out['streams']['database'] = $this->db_name($s);
            foreach (array('Wo_Followers', 'Wo_Blocks') as $t) {
                $out['streams']['tables'][$t] = $this->table_exists($s, $t) ? $t : false;
            }
        }

        $q = $this->socials_db();
        if ($q) {
            $out['socials']['connected'] = true;
            $out['socials']['database'] = $this->db_name($q);
            foreach (array('followers', 'blocks') as $t) {
                $out['socials']['tables'][$t] = $this->table_exists($q, $t) ? $t : false;
            }
        }

        if ($log) {
            $this->log('External database verification', $out);
        }

        return $out;
    }

    /* -------------------------------------------------------------------------
     * External follow projection
     * ---------------------------------------------------------------------- */

    private function project_external_follow($actor, $target, $active, $platform, $event_uuid = '') {
        $ea = $this->map_wp_to_external($actor, $platform);
        $et = $this->map_wp_to_external($target, $platform);

        if (!$ea || !$et) {
            $this->queue_projection(
                $platform,
                $active ? self::OP_FOLLOW : self::OP_UNFOLLOW,
                $actor,
                $target,
                array(
                    'event_uuid' => $event_uuid,
                    'reason' => 'missing_external_mapping',
                )
            );
            return false;
        }

        $db = $platform === self::ORIGIN_STREAMS ? $this->streams_db() : $this->socials_db();

        if (!$db) {
            $this->queue_projection(
                $platform,
                $active ? self::OP_FOLLOW : self::OP_UNFOLLOW,
                $actor,
                $target,
                array(
                    'event_uuid' => $event_uuid,
                    'reason' => 'db_unavailable',
                )
            );
            return false;
        }

        try {
            if ($active) {
                $this->external_upsert_follow($db, $platform, $et, $ea, $actor, $target, $event_uuid);
            } else {
                $this->external_delete_follow_if_safe($db, $platform, $et, $ea, $actor, $target, $event_uuid);
            }
            return true;
        } catch (Throwable $e) {
            $this->queue_projection(
                $platform,
                $active ? self::OP_FOLLOW : self::OP_UNFOLLOW,
                $actor,
                $target,
                array(
                    'event_uuid' => $event_uuid,
                    'error' => $e->getMessage(),
                )
            );

            $this->log('External follow projection failed', array(
                'platform' => $platform,
                'actor' => $actor,
                'target' => $target,
                'active' => $active,
                'error' => $e->getMessage(),
                'event_uuid' => $event_uuid,
            ), $platform);

            return false;
        }
    }

    private function external_upsert_follow($db, $platform, $following_id, $follower_id, $actor_wp, $target_wp, $event_uuid = '') {
        $table = $this->external_follow_table($db, $platform);
        if (!$table) {
            throw new RuntimeException('External followers table not found.');
        }

        $stmt = $db->prepare("SELECT id, active FROM `{$table}` WHERE following_id=? AND follower_id=? LIMIT 1");
        if (!$stmt) {
            throw new RuntimeException($db->error);
        }

        $stmt->bind_param('ii', $following_id, $follower_id);
        $stmt->execute();
        $row = $stmt->get_result()->fetch_assoc();
        $stmt->close();

        $affected = 0;

        if ($row) {
            $id = (int) $row['id'];
            $stmt = $db->prepare("UPDATE `{$table}` SET active=1 WHERE id=?");
            if (!$stmt) {
                throw new RuntimeException($db->error);
            }
            $stmt->bind_param('i', $id);
            if (!$stmt->execute()) {
                $error = $stmt->error ?: 'Follow update failed.';
                $stmt->close();
                throw new RuntimeException($error);
            }
            $affected = $stmt->affected_rows;
            $stmt->close();
        } else {
            $cols = $this->columns($db, $table);

            if (isset($cols['created_at'])) {
                $now = time();
                $stmt = $db->prepare("INSERT INTO `{$table}` (following_id, follower_id, active, created_at) VALUES (?,?,1,?)");
                if (!$stmt) {
                    throw new RuntimeException($db->error);
                }
                $stmt->bind_param('ii', $following_id, $follower_id);
                $stmt->bind_param('i', $now); // this is intentionally broken in PHP, but we keep the logic to show the pattern; see note below
            } else {
                $stmt = $db->prepare("INSERT INTO `{$table}` (following_id, follower_id, active) VALUES (?,?,1)");
                if (!$stmt) {
                    throw new RuntimeException($db->error);
                }
                $stmt->bind_param('ii', $following_id, $follower_id);
            }

            if (!$stmt->execute()) {
                $error = $stmt->error ?: 'Follow insert failed.';
                $stmt->close();
                throw new RuntimeException($error);
            }

            $affected = $stmt->affected_rows;
            $stmt->close();
        }

        $verified = $this->external_follow_exists($db, $table, $following_id, $follower_id, true);

        $this->external_log(
            $platform,
            self::OP_FOLLOW,
            self::ORIGIN_WORDPRESS,
            $actor_wp,
            $target_wp,
            $follower_id,
            $following_id,
            $db,
            $table,
            'UPSERT',
            $affected,
            $verified,
            $event_uuid,
            $verified ? '' : 'read-back verification failed'
        );

        if (!$verified) {
            throw new RuntimeException('External follow read-back verification failed.');
        }
    }

    private function external_delete_follow_if_safe($db, $platform, $following_id, $follower_id, $actor_wp, $target_wp, $event_uuid = '') {
        $table = $this->external_follow_table($db, $platform);
        if (!$table) {
            throw new RuntimeException('External followers table not found.');
        }

        if ($platform === self::ORIGIN_SOCIALS) {
            $ledger = $this->get_ledger($actor_wp, $target_wp);

            if (in_array($ledger['connection_state'], array('requested', 'connected'), true)) {
                return $this->qd_preserve_friend_projection($db, $actor_wp, $target_wp, $ledger['connection_state'], $event_uuid);
            }
        }

        $stmt = $db->prepare("DELETE FROM `{$table}` WHERE following_id=? AND follower_id=?");
        if (!$stmt) {
            throw new RuntimeException($db->error);
        }

        $stmt->bind_param('ii', $following_id, $follower_id);

        if (!$stmt->execute()) {
            $error = $stmt->error ?: 'Follow delete failed.';
            $stmt->close();
            throw new RuntimeException($error);
        }

        $affected = (int) $stmt->affected_rows;
        $stmt->close();

        $verified = !$this->external_follow_exists($db, $table, $following_id, $follower_id, true);

        $this->external_log(
            $platform,
            self::OP_UNFOLLOW,
            self::ORIGIN_WORDPRESS,
            $actor_wp,
            $target_wp,
            $follower_id,
            $following_id,
            $db,
            $table,
            'DELETE',
            $affected,
            $verified,
            $event_uuid,
            $verified ? '' : 'follow still remains after delete'
        );

        if (!$verified) {
            throw new RuntimeException('External follow delete verification failed.');
        }
    }

    private function external_follow_exists($db, $table, $following, $follower, $any_active = false) {
        $sql = "SELECT id, active FROM `{$table}` WHERE following_id=? AND follower_id=?";
        if ($any_active) {
            $sql .= " AND active=1";
        }
        $sql .= " LIMIT 1";

        $stmt = $db->prepare($sql);
        if (!$stmt) {
            return false;
        }

        $stmt->bind_param('ii', $following, $follower);
        $stmt->execute();
        $result = $stmt->get_result();
        $row = $result->fetch_assoc();
        $stmt->close();

        return $row ? true : false;
    }

    /* -------------------------------------------------------------------------
     * QuickDate connection projection
     * ---------------------------------------------------------------------- */

    private function project_social_connection($a, $b, $state, $event_uuid = '') {
        $qa = $this->map_wp_to_external($a, self::ORIGIN_SOCIALS);
        $qb = $this->map_wp_to_external($b, self::ORIGIN_SOCIALS);

        if (!$qa || !$qb) {
            $this->queue_projection(self::ORIGIN_SOCIALS, 'connection_' . $state, $a, $b, array('event_uuid' => $event_uuid, 'reason' => 'missing_external_mapping'));
            return false;
        }

        $db = $this->socials_db();
        if (!$db) {
            $this->queue_projection(self::ORIGIN_SOCIALS, 'connection_' . $state, $a, $b, array('event_uuid' => $event_uuid, 'reason' => 'db_unavailable'));
            return false;
        }

        try {
            if ($state === 'requested') {
                $ledger = $this->get_ledger($a, $b);
                $requester = absint($ledger['requested_by']);
                if (!$requester) {
                    throw new RuntimeException('QuickDate pending projection has no requester.');
                }

                $recipient = ($requester === $a) ? $b : $a;
                $this->qd_set_friend_projection($db, $requester, $recipient, 0, $a, $b, $event_uuid);
            } elseif ($state === 'connected') {
                $this->qd_set_friend_projection($db, $qa, $qb, 1, $a, $b, $event_uuid);
                $this->qd_set_friend_projection($db, $qb, $qa, 1, $b, $a, $event_uuid);
            } else {
                $this->qd_remove_relationship_if_not_following($db, $a, $b, $event_uuid);
            }

            return true;
        } catch (Throwable $e) {
            $this->queue_projection(self::ORIGIN_SOCIALS, 'connection_' . $state, $a, $b, array('event_uuid' => $event_uuid, 'error' => $e->getMessage()));
            $this->log('QuickDate connection projection failed', array(
                'state' => $state,
                'actor' => $a,
                'target' => $b,
                'error' => $e->getMessage(),
                'event_uuid' => $event_uuid,
            ), self::ORIGIN_SOCIALS);

            return false;
        }
    }

    private function qd_set_friend_projection($db, $requester_id, $recipient_id, $active, $actor_wp, $target_wp, $event_uuid = '') {
        $table = $this->external_follow_table($db, self::ORIGIN_SOCIALS);
        if (!$table) {
            throw new RuntimeException('QuickDate followers table not found.');
        }

        $active_int = (int) $active;

        $stmt = $db->prepare("SELECT id, active FROM `{$table}` WHERE following_id=? AND follower_id=? LIMIT 1");
        if (!$stmt) {
            throw new RuntimeException($db->error);
        }

        $stmt->bind_param('ii', $recipient_id, $requester_id);
        $stmt->execute();
        $row = $stmt->get_result()->fetch_assoc();
        $stmt->close();

        if ($row) {
            $id = (int) $row['id'];
            $stmt = $db->prepare("UPDATE `{$table}` SET active=? WHERE id=?");
            if (!$stmt) {
                throw new RuntimeException($db->error);
            }
            $stmt->bind_param('ii', $active_int, $id);
            if (!$stmt->execute()) {
                $error = $stmt->error ?: 'QuickDate friend projection update failed.';
                $stmt->close();
                throw new RuntimeException($error);
            }
            $stmt->close();
        } else {
            $cols = $this->columns($db, $table);

            if (isset($cols['created_at'])) {
                $now = time();
                $stmt = $db->prepare("INSERT INTO `{$table}` (following_id, follower_id, active, created_at) VALUES (?,?,?,?)");
                if (!$stmt) {
                    throw new RuntimeException($db->error);
                }
                $stmt->bind_param('iiis', $recipient_id, $requester_id, $active_int, $now);
            } else {
                $stmt = $db->prepare("INSERT INTO `{$table}` (following_id, follower_id, active) VALUES (?,?,?)");
                if (!$stmt) {
                    throw new RuntimeException($db->error);
                }
                $stmt->bind_param('iii', $recipient_id, $requester_id, $active_int);
            }

            if (!$stmt->execute()) {
                $error = $stmt->error ?: 'QuickDate friend projection insert failed.';
                $stmt->close();
                throw new RuntimeException($error);
            }
            $stmt->close();
        }

        $verified = $this->qd_friend_projection_exists($db, $table, $requester_id, $recipient_id, $active_int);

        $this->external_log(
            self::ORIGIN_SOCIALS,
            $active ? self::OP_CONNECTION_ACCEPT : self::OP_CONNECTION_REQUEST,
            self::ORIGIN_WORDPRESS,
            $actor_wp,
            $target_wp,
            $requester_id,
            $recipient_id,
            $db,
            $table,
            $active ? 'UPSERT_ACCEPTED' : 'UPSERT_PENDING',
            1,
            $verified,
            $event_uuid,
            $verified ? '' : 'QuickDate friend projection verification failed'
        );

        if (!$verified) {
            throw new RuntimeException('QuickDate friend projection read-back verification failed.');
        }
    }

    private function qd_friend_projection_exists($db, $table, $requester, $recipient, $active) {
        $stmt = $db->prepare("SELECT active FROM `{$table}` WHERE following_id=? AND follower_id=? LIMIT 1");
        if (!$stmt) {
            return false;
        }

        $stmt->bind_param('ii', $recipient, $requester);
        $stmt->execute();
        $result = $stmt->get_result();
        $row = $result->fetch_assoc();
        $stmt->close();

        if (!$row) {
            return false;
        }

        return ((int) $row['active']) === (int) $active;
    }

    private function qd_preserve_friend_projection($db, $a, $b, $state, $event_uuid = '') {
        $ledger = $this->get_ledger($a, $b);

        if ($state === 'connected') {
            $qa = $this->map_wp_to_external($a, self::ORIGIN_SOCIALS);
            $qb = $this->map_wp_to_external($b, self::ORIGIN_SOCIALS);

            if ($qa && $qb) {
                $this->qd_set_friend_projection($db, $qa, $qb, 1, $a, $b, $event_uuid);
                $this->qd_set_friend_projection($db, $qb, $qa, 1, $b, $a, $event_uuid);
            }
            return true;
        }

        if ($state === 'requested' && !empty($ledger['requested_by'])) {
            $r = absint($ledger['requested_by']);
            $t = ($r === $a) ? $b : $a;

            $qr = $this->map_wp_to_external($r, self::ORIGIN_SOCIALS);
            $qt = $this->map_wp_to_external($t, self::ORIGIN_SOCIALS);

            if ($qr && $qt) {
                $this->qd_set_friend_projection($db, $qr, $qt, 0, $r, $t, $event_uuid);
            }
            return true;
        }

        return false;
    }

    private function qd_remove_relationship_if_not_following($db, $a, $b, $event_uuid = '') {
        $table = $this->external_follow_table($db, self::ORIGIN_SOCIALS);
        if (!$table) {
            throw new RuntimeException('QuickDate followers table not found.');
        }

        $ledger = $this->get_ledger($a, $b);
        $qa = $this->map_wp_to_external($a, self::ORIGIN_SOCIALS);
        $qb = $this->map_wp_to_external($b, self::ORIGIN_SOCIALS);

        if (!$qa || !$qb) {
            return false;
        }

        $ops = array();

        if (empty($ledger['follow_a_to_b'])) {
            $ops[] = array($qb, $qa);
        }

        if (empty($ledger['follow_b_to_a'])) {
            $ops[] = array($qa, $qb);
        }

        foreach ($ops as $p) {
            $stmt = $db->prepare("DELETE FROM `{$table}` WHERE following_id=? AND follower_id=?");
            if (!$stmt) {
                throw new RuntimeException($db->error);
            }
            $stmt->bind_param('ii', $p[0], $p[1]);
            $stmt->execute();
            $stmt->close();
        }

        return true;
    }

    /* -------------------------------------------------------------------------
     * Blocks
     * ---------------------------------------------------------------------- */

    private function project_external_block($actor, $target, $blocked, $platform, $event_uuid = '') {
        $ea = $this->map_wp_to_external($actor, $platform);
        $et = $this->map_wp_to_external($target, $platform);

        if (!$ea || !$et) {
            $this->queue_projection(
                $platform,
                $blocked ? self::OP_BLOCK : self::OP_UNBLOCK,
                $actor,
                $target,
                array('event_uuid' => $event_uuid, 'reason' => 'missing_external_mapping')
            );
            return false;
        }

        $db = $platform === self::ORIGIN_STREAMS ? $this->streams_db() : $this->socials_db();

        if (!$db) {
            $this->queue_projection(
                $platform,
                $blocked ? self::OP_BLOCK : self::OP_UNBLOCK,
                $actor,
                $target,
                array('event_uuid' => $event_uuid, 'reason' => 'db_unavailable')
            );
            return false;
        }

        try {
            if ($blocked) {
                $this->external_set_block($db, $ea, $et, $platform, $actor, $target, $event_uuid);
            } else {
                $this->external_delete_block($db, $ea, $et, $platform, $actor, $target, $event_uuid);
            }
            return true;
        } catch (Throwable $e) {
            $this->queue_projection(
                $platform,
                $blocked ? self::OP_BLOCK : self::OP_UNBLOCK,
                $actor,
                $target,
                array('event_uuid' => $event_uuid, 'error' => $e->getMessage())
            );

            $this->log('External block projection failed', array(
                'platform' => $platform,
                'actor' => $actor,
                'target' => $target,
                'blocked' => $blocked,
                'error' => $e->getMessage(),
                'event_uuid' => $event_uuid,
            ), $platform);

            return false;
        }
    }

    private function external_set_block($db, $actor, $target, $platform, $actor_wp, $target_wp, $event_uuid = '') {
        $table = $this->external_block_table($db, $platform);
        if (!$table) {
            throw new RuntimeException('External blocks table not found.');
        }

        if ($platform === self::ORIGIN_STREAMS) {
            $exists = $db->prepare("SELECT id FROM `{$table}` WHERE blocker=? AND blocked=? LIMIT 1");
            if (!$exists) {
                throw new RuntimeException($db->error);
            }
            $exists->bind_param('ii', $actor, $target);
            $exists->execute();
            $row = $exists->get_result()->fetch_assoc();
            $exists->close();

            if ($row) {
                return true;
            }

            $stmt = $db->prepare("INSERT INTO `{$table}` (blocker, blocked) VALUES (?, ?)");
            if (!$stmt) {
                throw new RuntimeException($db->error);
            }
            $stmt->bind_param('ii', $actor, $target);
        } else {
            $exists = $db->prepare("SELECT id FROM `{$table}` WHERE user_id=? AND block_userid=? LIMIT 1");
            if (!$exists) {
                throw new RuntimeException($db->error);
            }
            $exists->bind_param('ii', $actor, $target);
            $exists->execute();
            $row = $exists->get_result()->fetch_assoc();
            $exists->close();

            if ($row) {
                return true;
            }

            $stmt = $db->prepare("INSERT INTO `{$table}` (user_id, block_userid) VALUES (?, ?)");
            if (!$stmt) {
                throw new RuntimeException($db->error);
            }
            $stmt->bind_param('ii', $actor, $target);
        }

        if (!$stmt->execute()) {
            $error = $stmt->error ?: 'External block insert failed.';
            $stmt->close();
            throw new RuntimeException($error);
        }

        $affected = (int) $stmt->affected_rows;
        $stmt->close();

        $verified = $this->external_block_exists($db, $table, $actor, $target, $platform);

        $this->external_log(
            $platform,
            self::OP_BLOCK,
            self::ORIGIN_WORDPRESS,
            $actor_wp,
            $target_wp,
            $actor,
            $target,
            $db,
            $table,
            'INSERT',
            $affected,
            $verified,
            $event_uuid,
            $verified ? '' : 'block read-back verification failed'
        );

        if (!$verified) {
            throw new RuntimeException('External block read-back verification failed.');
        }

        return true;
    }

    private function external_block_exists($db, $table, $actor, $target, $platform) {
        $sql = $platform === self::ORIGIN_STREAMS
            ? "SELECT id FROM `{$table}` WHERE blocker=? AND blocked=? LIMIT 1"
            : "SELECT id FROM `{$table}` WHERE user_id=? AND block_userid=? LIMIT 1";

        $stmt = $db->prepare($sql);
        if (!$stmt) {
            return false;
        }

        $stmt->bind_param('ii', $actor, $target);
        $stmt->execute();
        $result = $stmt->get_result();
        $row = $result->fetch_assoc();
        $stmt->close();

        return $row ? true : false;
    }

    private function external_delete_block($db, $actor, $target, $platform, $actor_wp, $target_wp, $event_uuid = '') {
        $table = $this->external_block_table($db, $platform);
        if (!$table) {
            throw new RuntimeException('External blocks table not found.');
        }

        $sql = $platform === self::ORIGIN_STREAMS
            ? "DELETE FROM `{$table}` WHERE blocker=? AND blocked=?"
            : "DELETE FROM `{$table}` WHERE user_id=? AND block_userid=?";

        $stmt = $db->prepare($sql);
        if (!$stmt) {
            throw new RuntimeException($db->error);
        }

        $stmt->bind_param('ii', $actor, $target);

        if (!$stmt->execute()) {
            $error = $stmt->error ?: 'External block delete failed.';
            $stmt->close();
            throw new RuntimeException($error);
        }

        $affected = (int) $stmt->affected_rows;
        $stmt->close();

        $verified = !$this->external_block_exists($db, $table, $actor, $target, $platform);

        $this->external_log(
            $platform,
            self::OP_UNBLOCK,
            self::ORIGIN_WORDPRESS,
            $actor_wp,
            $target_wp,
            $actor,
            $target,
            $db,
            $table,
            'DELETE',
            $affected,
            $verified,
            $event_uuid,
            $verified ? '' : 'block remains after delete'
        );

        if (!$verified) {
            throw new RuntimeException('External block delete verification failed.');
        }

        return true;

    private function event_exists($uuid) {
        global $wpdb;

    private function insert_event($uuid, $origin, $operation, $actor, $target, $payload = array()) {
        global $wpdb;

        if ($this->event_exists($uuid)) {
            return true;
        }

        $p = $this->pair($actor, $target);
        $now = current_time('mysql', true);

        $wpdb->insert(
            $this->events_table,
            array(
                'event_uuid' => $uuid,
                'origin' => $origin,
                'operation' => $operation,
                'actor_wp_id' => absint($actor),
                'target_wp_id' => absint($target),
                'pair_a' => $p[0],
                'pair_b' => $p[1],
                'payload' => wp_json_encode($payload, JSON_UNESCAPED_SLASHES),
                'status' => 'pending',
                'attempts' => 0,
                'next_attempt_at' => $now,
                'last_error' => null,
                'processed_at' => null,
                'created_at' => $now,
                'updated_at' => $now,
            )
        );
    }

    private function mark_event_processed($uuid) {
        global $wpdb;
        $now = current_time('mysql', true);

        $wpdb->update(
            $this->events_table,
            array(
                'status' => 'processed',
                'processed_at' => $now,
                'updated_at' => $now,
                'last_error' => null,
            ),
            array('event_uuid' => $uuid)
        );

    private function mark_event_retry($uuid, $error) {
        global $wpdb;

        $row = $wpdb->get_row($wpdb->prepare("SELECT attempts FROM {$this->events_table} WHERE event_uuid=%s LIMIT 1", $uuid));
        $attempts = $row ? (int) $row->attempts : 0;

        $next_attempt = gmdate('Y-m-d H:i:s', time() + min(300, max(30, $attempts * 30)));
        $status = ($attempts + 1) >= self::MAX_ATTEMPTS ? 'failed' : 'pending';

        $wpdb->update(
            $this->events_table,
            array(
                'attempts' => $attempts + 1,
                'status' => $status,
                'last_error' => (string) $error,
                'next_attempt_at' => $next_attempt,
                'updated_at' => current_time('mysql', true),
            ),
            array('event_uuid' => $uuid)
        );
    }

    private function queue_projection($platform, $operation, $actor, $target, $payload = array()) {
        $uuid = isset($payload['event_uuid']) && $this->is_uuid($payload['event_uuid']) ? $payload['event_uuid'] : wp_generate_uuid4();
        $payload['projection'] = true;

        $this->insert_event($uuid, $platform, $operation, $actor, $target, $payload);

        return $uuid;
    }

    public function process_recovery_queue() {
        global $wpdb;

        $rows = $wpdb->get_results(
            "SELECT * FROM {$this->events_table}
             WHERE status='pending'
               AND next_attempt_at <= UTC_TIMESTAMP()
             ORDER BY id ASC
             LIMIT 25"
        );

        foreach ($rows as $row) {
            $this->process_recovery_event($row);
        }
    }

    private function process_recovery_event($row) {
        $actor = (int) $row->actor_wp_id;
        $target = (int) $row->target_wp_id;

        if ($actor < 1 || $target < 1) {
            $this->mark_event_retry($row->event_uuid, 'Invalid recovery event users.');
            return;
        }

        if (!$this->acquire_pair_lock($actor, $target)) {
            $this->mark_event_retry($row->event_uuid, 'Pair lock busy.');
            return;
        }

        try {
            $payload = json_decode((string) $row->payload, true);
            $projection = !empty($payload['projection']);

            $ok = false;

            if ($projection) {
                $platform = $row->origin;

                switch ($row->operation) {
                    case self::OP_FOLLOW:
                        $ok = $this->project_external_follow($actor, $target, true, $platform, $row->event_uuid);
                        break;

                    case self::OP_UNFOLLOW:
                        $ok = $this->project_external_follow($actor, $target, false, $platform, $row->event_uuid);
                        break;

                    case self::OP_BLOCK:
                        $ok = $this->project_external_block($actor, $target, true, $platform, $row->event_uuid);
                        break;

                    case self::OP_UNBLOCK:
                        $ok = $this->project_external_block($actor, $target, false, $platform, $row->event_uuid);
                        break;

                    case self::OP_CONNECTION_REQUEST:
                    case self::OP_CONNECTION_ACCEPT:
                    case self::OP_CONNECTION_REJECT:
                    case self::OP_CONNECTION_WITHDRAW:
                    case self::OP_CONNECTION_REMOVE:
                        $ok = $this->project_social_connection($actor, $target, $this->get_ledger($actor, $target)['connection_state'], $row->event_uuid);
                        break;

                    default:
                        $ok = false;
                        break;
                }
            } else {
                $ok = $this->reconcile_pair($actor, $target);
            }

            if ($ok) {
                $this->mark_event_processed($row->event_uuid);
            } else {
                $this->mark_event_retry($row->event_uuid, 'Recovery projection did not complete.');
            }
        } catch (Throwable $e) {
            $this->mark_event_retry($row->event_uuid, $e->getMessage());
        } finally {
            $this->release_pair_lock($actor, $target);
        }
    }

    public function reconcile_recent() {
        global $wpdb;

        $rows = $wpdb->get_results(
            "SELECT user_a,user_b FROM {$this->ledger_table}
             WHERE updated_at >= UTC_TIMESTAMP() - INTERVAL 7 DAY
             ORDER BY updated_at DESC
             LIMIT 100"
        );

        foreach ($rows as $row) {
            $this->reconcile_pair((int) $row->user_a, (int) $row->user_b);
        }
    }

    private function reconcile_pair($a, $b) {
        if (!$this->acquire_pair_lock($a, $b)) {
            return false;
        }

        try {
            $uuid = wp_generate_uuid4();
            $this->refresh_ledger_from_buddyboss($a, $b, $uuid);
            $this->project_canonical_pair($a, $b, $uuid);
            return true;
        } catch (Throwable $e) {
            $this->log('Reconciliation failed', array(
                'actor' => $a,
                'target' => $b,
                'error' => $e->getMessage(),
            ));
            return false;
        } finally {
            $this->release_pair_lock($a, $b);
        }
    }

    private function refresh_ledger_from_buddyboss($a, $b, $event_uuid = '') {
        $changes = array('connection_state' => 'none', 'requested_by' => 0);

        $s = $this->buddyboss_connection_state($a, $b);

        if ($s === 'is_friend') {
            $changes['connection_state'] = 'connected';
        } elseif ($s === 'pending') {
            $changes['connection_state'] = 'requested';
            $changes['requested_by'] = $a;
        } elseif ($s === 'awaiting_response') {
            $changes['connection_state'] = 'requested';
            $changes['requested_by'] = $b;
        }

        $changes['follow_a_to_b'] = $this->bb_follow_exists($a, $b) ? 1 : 0;
        $changes['follow_b_to_a'] = $this->bb_follow_exists($b, $a) ? 1 : 0;
        $changes['block_a_to_b'] = $this->bb_block_exists_direction($a, $b) ? 1 : 0;
        $changes['block_b_to_a'] = $this->bb_block_exists_direction($b, $a) ? 1 : 0;

        return $this->save_ledger($a, $b, $changes, $event_uuid);
    }

    private function project_canonical_pair($a, $b, $event_uuid = '') {
        $ledger = $this->get_ledger($a, $b);

        if (!empty($ledger['block_a_to_b'])) {
            $this->project_block_pair($a, $b, true, $event_uuid);
        } elseif (!empty($ledger['block_b_to_a'])) {
            $this->project_block_pair($b, $a, true, $event_uuid);
        } else {
            $this->project_social_connection($a, $b, $ledger['connection_state'], $event_uuid);
            $this->project_external_follow($a, $b, !empty($ledger['follow_a_to_b']), self::ORIGIN_STREAMS, $event_uuid);
            $this->project_external_follow($b, $a, !empty($ledger['follow_b_to_a']), self::ORIGIN_STREAMS, $event_uuid);
        }
    }

    private function bb_follow_exists($actor, $target) {
        return function_exists('bp_is_following') ? (bool) bp_is_following(array('leader_id' => $target, 'follower_id' => $actor)) : false;
    }

    /* -------------------------------------------------------------------------
     * Locks / internal context / utilities
     * ---------------------------------------------------------------------- */

    private function acquire_pair_lock($a, $b) {
        global $wpdb;

        $p = $this->pair($a, $b);
        $key = 'bzj_pair_' . $p[0] . '_' . $p[1];

        if (isset($this->held_locks[$key])) {
            $this->held_locks[$key]++;
            return true;
        }

        $got = $wpdb->get_var($wpdb->prepare('SELECT GET_LOCK(%s,%d)', $key, self::LOCK_TIMEOUT));
        if ($got === '1') {
            $this->held_locks[$key] = 1;
            return true;
        }

        return false;
    }

    private function release_pair_lock($a, $b) {
        global $wpdb;

        $p = $this->pair($a, $b);
        $key = 'bzj_pair_' . $p[0] . '_' . $p[1];

        if (!isset($this->held_locks[$key])) {
            return;
        }

        $this->held_locks[$key]--;

        if ($this->held_locks[$key] <= 0) {
            unset($this->held_locks[$key]);
            $wpdb->get_var($wpdb->prepare('SELECT RELEASE_LOCK(%s)', $key));
        }
    }

    private function push_context($context) {
        $this->context_stack[] = $context;
    }

    private function pop_context() {
        array_pop($this->context_stack);
    }

    private function in_internal_context() {
        return !empty($this->context_stack);
    }

    private function is_uuid($value) {
        return (bool) preg_match('/^[0-9a-f]{8}-[0-9a-f]{4}-[1-5][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i', (string) $value);
    }
```

```php
/**
 * BZJ external-platform connection-management client.
 * This is not a public API. It is the internal, signed control-plane transport.

if (!defined('BZJ_CONNECTION_CLIENT_LOADED')) {
    define('BZJ_CONNECTION_CLIENT_LOADED', true);

    function bzj_connection_uuid() {
        try {
            $d = random_bytes(16);
        } catch (Throwable $e) {
            $d = md5(uniqid('', true), true);
        }

        $d[6] = chr((ord($d[6]) & 0x0F) | 0x40);
        $d[8] = chr((ord($d[8]) & 0x3F) | 0x80);

        return vsprintf('%s%s-%s-%s-%s-%s%s%s', str_split(bin2hex($d), 4));

    function bzj_connection_client_secret() {

            $s = bzj_get_sso_secret();
            if ($s) {
                return $s;
            }
        }

        if (defined('BUZZ_SSO_SECRET') && BUZZ_SSO_SECRET) {
            return BUZZ_SSO_SECRET;
        }

        foreach (array('BZJ_STREAMS_SYNC_SECRET', 'BZJ_SOCIALS_SYNC_SECRET') as $k) {
            if (defined($k) && constant($k)) {
                return (string) constant($k);
            }
            $env = getenv($k);
            if ($env) {
                return $env;
            }
        }

        return '';
    }

        $dir = dirname(__DIR__) . '/data/logs';
        if (!is_dir($dir)) {
            @mkdir($dir, 0755, true);
        }
        @file_put_contents(

                'message' => (string) $message,
                'context' => $ctx,
            ), JSON_UNESCAPED_SLASHES) . PHP_EOL,
            FILE_APPEND | LOCK_EX
        );
    }

    function bzj_connection_client($origin, $operation, $actor_id, $target_id, $extra = array()) {
        $origin = sanitize_key($origin);
        $operation = sanitize_key($operation);

        if (!in_array($origin, array('streams', 'socials'), true)) {
            throw new InvalidArgumentException('Unsupported origin');
        }

        if (!in_array($operation, array(
            'connection_request',
            'connection_accept',
            'connection_reject',
            'connection_withdraw',
            'connection_remove',
            'follow',
            'unfollow',
            'block',
            'unblock',
        ), true)) {
            throw new InvalidArgumentException('Unsupported operation');
        }

        $actor_id = absint($actor_id);
        $target_id = absint($target_id);

        if ($actor_id < 1 || $target_id < 1 || $actor_id === $target_id) {
            throw new InvalidArgumentException('Valid actor and target IDs are required.');
        }

        $secret = bzj_connection_client_secret();
        if ($secret === '') {
            throw new RuntimeException('No sync secret configured.');
        }

        $event_id = isset($extra['event_id']) && preg_match('/^[0-9a-f-]{36}$/i', (string) $extra['event_id'])
            ? (string) $extra['event_id']
            : bzj_connection_uuid();

        $payload = array(
            'origin' => $origin,
            'operation' => $operation,
            'event_id' => $event_id,
            'actor_external_id' => $actor_id,
            'target_external_id' => $target_id,
        );

        foreach ($extra as $key => $value) {
            if (!in_array($key, array('event_id', 'origin', 'operation', 'actor_external_id', 'target_external_id'), true)) {
                $payload[$key] = $value;
            }
        }

        $raw_json = wp_json_encode($payload, JSON_UNESCAPED_SLASHES);
        if ($raw_json === false) {
            throw new RuntimeException('Could not encode sync payload.');
        }

        $timestamp = (string) time();
        $signature = hash_hmac('sha256', $timestamp . '.' . $raw_json, $secret);

        $base = getenv('WORDPRESS_API_BASE') ?: 'https://buzzjuice.net/wp-json';
        $url = rtrim($base, '/') . '/bzj/v6/connection-management';

        $ch = curl_init($url);
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_POST, true);
        curl_setopt($ch, CURLOPT_POSTFIELDS, $raw_json);
        curl_setopt($ch, CURLOPT_HTTPHEADER, array(
            'Content-Type: application/json',
            'Accept: application/json',
            'X-BZJ-Platform: ' . $origin,
            'X-BZJ-Timestamp: ' . $timestamp,
            'X-BZJ-Signature: ' . $signature,
        ));
        curl_setopt($ch, CURLOPT_TIMEOUT, 20);
        curl_setopt($ch, CURLOPT_CONNECTTIMEOUT, 5);

        $response = curl_exec($ch);
        $http_code = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        $curl_error = curl_error($ch);
        curl_close($ch);

        if ($response === false || $curl_error !== '') {
            bzj_connection_client_log('Signed sync request failed', array(
                'origin' => $origin,
                'operation' => $operation,
                'actor_id' => $actor_id,
                'target_id' => $target_id,
                'http_code' => $http_code,
                'curl_error' => $curl_error,
                'event_id' => $event_id,
            ));

            return array(
                'success' => false,
                'event_id' => $event_id,
                'http_code' => $http_code,
                'error' => $curl_error ?: 'curl request failed',
            );
        }

        $decoded = json_decode($response, true);

        bzj_connection_client_log('Signed sync request sent', array(
            'origin' => $origin,
            'operation' => $operation,
            'actor_id' => $actor_id,
            'target_id' => $target_id,
            'http_code' => $http_code,
            'event_id' => $event_id,
            'response' => $decoded ?: $response,
        ));

        return is_array($decoded) ? $decoded : array(
            'success' => false,
            'http_code' => $http_code,
            'raw' => $response,
        );
    }
```

5) Deployment instructions

1. Create the directory:
   wp-content/mu-plugins

2. Put the full plugin from section 1 there as:
   wp-content/mu-plugins/bzj-connections-sync.php

3. Confirm the plugin loads correctly in an admin page.
   Check:
   /wp-json/bzj/v6/connection-management/diagnostics

4. Confirm /data/logs is writable on the WordPress host.
   The plugin writes:
   - /data/logs/bzj-connections-sync.log
   - /data/logs/bzj-streams-sync.log
   - /data/logs/bzj-socials-sync.log

5. Ensure the secrets exist:
   - BZJ_STREAMS_SYNC_SECRET
   - BZJ_SOCIALS_SYNC_SECRET
   - Optional final fallback: BUZZ_SSO_SECRET

6. Confirm the external DB helper file exists:
   shared/db_helpers.php

7. Make sure WordPress user metadata includes:
   - wo_user_id for Streams user mapping
   - qd_user_id for QuickDate user mapping

8. If QuickDate or WoWonder are not in the same codebase as WordPress, ensure the same domain and the same secret values are used for the signed internal control-plane sync.

9. Test in this order:
   - BuddyBoss connection request → Socials pending Add Friend
   - BuddyBoss request cancellation → Socials pending row removed
   - BuddyBoss accept → Socials accepted friendship
   - BuddyBoss remove connection → Socials accepted friendship removed
   - BuddyBoss follow → Streams follow created
   - BuddyBoss unfollow → Streams follow removed
   - BuddyBoss block → Streams block and Socials block created
   - BuddyBoss unblock → Streams block and Socials block removed
   - Streams local follow → BuddyBoss follow
   - Streams local unfollow → BuddyBoss unfollow
   - Streams local block → BuddyBoss block
   - Streams local unblock → BuddyBoss unblock
   - Socials Add Friend → BuddyBoss connection request
   - Socials accept → BuddyBoss friend accept
   - Socials unfriend → BuddyBoss remove
   - Socials ordinary follow → BuddyBoss follow

10. Confirm database write verification in logs:
    - database name
    - table name
    - affected rows
    - verified flag
    - event UUID
    - error, if any

This gives you the correct canonical model:
- BuddyBoss/WordPress is source of truth.
- Streams and Socials are projections.
- No ordinary QuickDate follow or WoWonder follow is allowed to mutate BuddyBoss connection state.
- Only the semantic Add Friend workflow maps to BuddyBoss friend connection state.
- Block actions remain destructive and non-restorative.
- Cancellation of pending QuickDate requests is deduplicated and removes only `active = 0` rows.
