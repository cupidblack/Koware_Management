I reviewed the current `buzzjuice.net/streams` repository, the supplied GitHub debugging response, the existing WoWonder session functions, the SSO bridge, and the browser-cookie evidence. The central diagnosis is sound, but I would make **several corrections before deploying the GitHub version**.

## 1. What the evidence establishes

The current WoWonder code still has the original four functions:

* `Wo_CreateSession()` → 40-character SHA-1 `hash_id`
* `Wo_CreateMainSession()` → 20-character SHA-1-derived `main_hash_id`
* `Wo_CheckSession()` → compares request token against `$_SESSION['hash_id']`
* `Wo_CheckMainSession()` → compares request token against `$_SESSION['main_hash_id']`

That is confirmed directly in the repository. 

So the **64-character value you are seeing is not the native `hash_id` or `main_hash_id`**. The debugging implementation uses SHA-256 fingerprints, which are exactly 64 hexadecimal characters. Those fingerprints are deliberately used instead of exposing the actual session/hash secrets. 

Also, the absence of `hash_id` or `main_hash_id` in Chrome DevTools is **not evidence that they don't exist**. They are PHP `$_SESSION` variables stored server-side. The browser normally sees only the session cookie, here:

```text
BUZZSTREAMSESSID
```

Your User-1 and User-2 evidence is actually useful:

```text
BUZZSTREAMSESSID   ...   /streams
PHPSESSID          ...   /
```

That is the arrangement we want. The important thing is ensuring that **Streams always uses `BUZZSTREAMSESSID` and never accidentally starts/continues a `PHPSESSID` session**.

### The important architectural problem

The current `init.php` starts the PHP session here:

```php
if (session_status() !== PHP_SESSION_ACTIVE) @session_start();
```

before explicitly selecting `BUZZSTREAMSESSID`. 

That is the first thing I would correct.

The SSO bridge itself requires `assets/init.php`, so the bridge inherits whatever session configuration `init.php` establishes. 

There is another important point: `ww-sso-bridge.php` still contains this branch:

```php
if (!$wordpress_logged_in) {
    if (session_status() === PHP_SESSION_ACTIVE) {
        $_SESSION = [];
        session_unset();
        @session_destroy();
    }
    ...
}
```

Therefore, if a request reaches the bridge without a detectable WordPress login cookie, it can destroy the **currently active Streams session**, which would remove `hash_id` and `main_hash_id`. 

I would **not remove that security behavior yet**. We should instrument it first so we know whether it is actually responsible.

# 2. One correction to the GitHub implementation

I would **not** blindly use the GitHub version exactly as supplied.

The GitHub implementation is directionally correct, particularly:

* configuring `BUZZSTREAMSESSID` before `session_start()`;

* fingerprinting rather than exposing hashes;

However, I want the diagnostic layer to go one step further.

The objective isn't merely:

> "Does `main_hash_id` exist?"

Therefore the implementation below adds:

6. cookie diagnostics;

16. request correlation IDs;
17. safe logging of relevant SSO state;
18. detection of changes to `$_SESSION['hash_id']` and `$_SESSION['main_hash_id']`.

The raw session IDs, JWTs, SSO tokens and actual hash values remain out of the log.

if (!function_exists('bz_session_request_id')) {

    function bz_session_request_id()
    {
        static $request_id = null;

        if ($request_id !== null) {
            return $request_id;
        }

        try {

            $request_id = bin2hex(random_bytes(8));

        } catch (Throwable $e) {

            $request_id = substr(
                sha1(
                    uniqid('', true) .
                    microtime(true) .
                    mt_rand()
                ),
                0,
                16
            );
        }

        return $request_id;
    }
}

if (!function_exists('bz_session_fingerprint')) {

    function bz_session_fingerprint($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string)$value;

        return array(
            'present' => ($value !== ''),
            'length'  => strlen($value),
            'sha256'  => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format'  => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}

if (!function_exists('bz_session_resolved_save_path')) {

    function bz_session_resolved_save_path()
    {
        $path = function_exists('session_save_path')
            ? (string)session_save_path()
            : '';

        if ($path === '') {
            return '';
        }

        /*
         * PHP may return:
         *
         * N;/path/to/sessions
         * N;MODE;/path/to/sessions
         */

        if (strpos($path, ';') !== false) {

            $parts = explode(';', $path);

            $path = end($parts);
        }

        return rtrim($path, DIRECTORY_SEPARATOR);
    }
}

if (!function_exists('bz_session_storage_diagnostics')) {

    function bz_session_storage_diagnostics()
    {
        $handler = function_exists('ini_get')
            ? (string)ini_get('session.save_handler')
            : '';

        $configured_path = function_exists('session_save_path')
            ? (string)session_save_path()
            : '';

        $resolved_path = bz_session_resolved_save_path();

        $result = array(
            'handler' => $handler,

            'configured_save_path' => $configured_path,

            'resolved_save_path' => $resolved_path,

            'resolved_path_exists' => (
                $resolved_path !== '' &&
                is_dir($resolved_path)
            ),

            'resolved_path_readable' => (
                $resolved_path !== '' &&
                is_readable($resolved_path)
            ),

            'resolved_path_writable' => (
                $resolved_path !== '' &&
                is_writable($resolved_path)
            )
        );

        if (
            $handler === 'files' &&
            $resolved_path !== '' &&
            session_status() === PHP_SESSION_ACTIVE
        ) {

            $id = (string)session_id();

            if ($id !== '') {

                $session_file =
                    $resolved_path .
                    DIRECTORY_SEPARATOR .
                    'sess_' .
                    $id;

                $result['session_file_exists'] =
                    is_file($session_file);

                if (is_file($session_file)) {

                    $result['session_file_size'] =
                        (int)@filesize($session_file);

                    $result['session_file_mtime'] =
                        (int)@filemtime($session_file);
                }
            }
        }

        return $result;
    }
}

    function bz_session_state_snapshot()
    {
        $hash_id = '';

        $main_hash_id = '';

        $request_hash_id = '';

        if (
            isset($_SESSION) &&
            is_array($_SESSION)
        ) {

            if (isset($_SESSION['hash_id'])) {
                $hash_id = $_SESSION['hash_id'];
            }

            if (isset($_SESSION['main_hash_id'])) {
                $main_hash_id = $_SESSION['main_hash_id'];
            }
        }

        if (isset($GLOBALS['hash_id'])) {
            $request_hash_id = $GLOBALS['hash_id'];
        }

        $encoded_session = '';

        if (
            session_status() === PHP_SESSION_ACTIVE &&
            function_exists('session_encode')
        ) {

            $encoded_session = @session_encode();

            if ($encoded_session === false) {
                $encoded_session = '';
            }
        }

        $cookie_params = array();

        if (function_exists('session_get_cookie_params')) {
            $cookie_params = session_get_cookie_params();
        }

        return array(

            'session_status' => function_exists('session_status')
                ? session_status()
                : -1,

            'session_status_name' => (
                function_exists('session_status')
                ? (
                    session_status() === PHP_SESSION_ACTIVE
                        ? 'ACTIVE'
                        : (
                            session_status() === PHP_SESSION_NONE
                                ? 'NONE'
                                : 'DISABLED'
                        )
                )
                : 'UNKNOWN'
            ),

            'session_name' => function_exists('session_name')
                ? session_name()
                : '',

            'session_id' => function_exists('session_id')
                ? bz_session_fingerprint(session_id())
                : array(),

            'session_save_path' => function_exists('session_save_path')
                ? session_save_path()
                : '',

            'session_save_handler' => function_exists('ini_get')
                ? ini_get('session.save_handler')
                : '',

            'cookie_params' => array(
                'path' => isset($cookie_params['path'])
                    ? (string)$cookie_params['path']
                    : '',

                'domain' => isset($cookie_params['domain'])
                    ? (string)$cookie_params['domain']
                    : '',

                'secure' => !empty($cookie_params['secure']),

                'httponly' => !empty($cookie_params['httponly']),

                'samesite' => isset($cookie_params['samesite'])
                    ? (string)$cookie_params['samesite']
                    : ''
            ),

            'cookies' => bz_session_cookie_diagnostics(),

            'hash_id' => bz_session_fingerprint($hash_id),

            'main_hash_id' => bz_session_fingerprint($main_hash_id),

            'request_hash_id' => bz_session_fingerprint($request_hash_id),

            'session_keys' => (
                isset($_SESSION) &&
                is_array($_SESSION)
                    ? array_keys($_SESSION)
                    : array()
            ),

            'session_encoded' => bz_session_fingerprint(

            ),

                isset($_SESSION['wo_user_id'])
                    ? (int)$_SESSION['wo_user_id']
                    : 0
            ),

            'storage' => bz_session_storage_diagnostics()
        );

if (!function_exists('bz_session_snapshot_diff')) {

    function bz_session_snapshot_diff($before, $after)
    {
        $fields = array(
            'session_status',
            'session_status_name',
            'session_name',
            'session_id',
            'session_save_path',
            'session_save_handler',
            'cookie_params',
            'cookies',
            'hash_id',
            'main_hash_id',
            'request_hash_id',
            'session_keys',
            'session_encoded',
            'wo_user_id',
            'storage'
        );

        $changes = array();

        foreach ($fields as $field) {

            $before_value = isset($before[$field])
                ? $before[$field]
                : null;

            $after_value = isset($after[$field])
                ? $after[$field]
                : null;

            if ($before_value !== $after_value) {

                $changes[$field] = array(
                    'before' => $before_value,
                    'after' => $after_value
                );
            }
        }

        return $changes;
    }
}

    function Wo_SessionDiagnosticLog(
        $event,
        $context = array()
    ) {

        $file = bz_stream_session_log_path();

                ? php_sapi_name()
                : '';

                : '';

            bz_session_safe_request_uri();

            isset($_SERVER['SCRIPT_FILENAME'])

                : '';

            isset($_SERVER['HTTP_HOST'])
                ? (string)$_SERVER['HTTP_HOST']
                : '';

        $context['headers'] =
            bz_session_request_headers();

        $context['log_file'] =
            $file;

        $context['log_directory_exists'] =
            is_dir($directory);

        $context['log_directory_writable'] =
            is_writable($directory);

        $context['session_state'] =
            bz_session_state_snapshot();

        $context['trace'] =
            bz_session_trace(30);

            'event' => (string)$event,
            'context' => $context

            $record,
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR

            return false;
        }

        return @file_put_contents(
            $file,
            $json . PHP_EOL,
            FILE_APPEND | LOCK_EX
        ) !== false;
    }
}

if (!function_exists('bz_safe_session_start')) {

    function bz_safe_session_start()
    {
        if (session_status() === PHP_SESSION_ACTIVE) {

            Wo_SessionDiagnosticLog(
                'session_already_active'
            );

            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {

            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' =>
                        'session_not_startable',

                    'session_status' =>
                        session_status()
                )
            );

            return false;
        }

        if (headers_sent($headers_file, $headers_line)) {

            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' =>
                        'headers_already_sent',

                    'headers_file' =>
                        $headers_file,

                    'headers_line' =>
                        (int)$headers_line
                )
            );

            return false;
        }

        try {

            $started = @session_start();

        } catch (Throwable $exception) {

            Wo_SessionDiagnosticLog(
                'session_start_exception',
                array(
                    'exception_class' =>
                        get_class($exception),

                    'exception_message' =>
                        $exception->getMessage()
                )
            );

            return false;
        }

        $active = (
            $started &&
            session_status() === PHP_SESSION_ACTIVE
        );

        Wo_SessionDiagnosticLog(
            $active
                ? 'session_started'
                : 'session_start_failed',
            array(
                'start_return_value' =>
                    (bool)$started,

                'session_name' =>
                    function_exists('session_name')
                        ? session_name()
                        : '',

                'session_id' =>
                    function_exists('session_id')
                        ? bz_session_fingerprint(
                            session_id()
                        )
                        : array()
            )
        );

        return $active;
    }
}

if (!function_exists('Wo_CreateSession')) {

    function Wo_CreateSession()
    {
        if (!Wo_EnsureSessionActive()) {

            Wo_SessionHashLog(
                'create_hash_id_failed',
                array(
                    'session_key' =>
                        'hash_id',

                    'reason' =>
                        'php_session_not_active'
                )
            );

            return '';
        }

        $existing =
            isset($_SESSION['hash_id'])
                ? (string)$_SESSION['hash_id']
                : '';

        /*
         * Native WoWonder hash_id is 40 hexadecimal
         * characters because it is SHA-1.
         */

        if (
            preg_match(
                '/^[a-f0-9]{40}$/i',
                $existing
            )
        ) {

            Wo_SessionHashLog(
                'create_hash_id_reused',
                array(
                    'session_key' =>
                        'hash_id',

                    'value' =>
                        Wo_SessionHashFingerprint(
                            $existing
                        )
                )
            );

            return $existing;
        }

        /*
         * Existing but malformed value.
         */

        if ($existing !== '') {

            Wo_SessionHashLog(
                'create_hash_id_replaced_invalid_value',
                array(
                    'session_key' =>
                        'hash_id',

                    'old_value' =>
                        Wo_SessionHashFingerprint(
                            $existing
                        )
                )
            );
        }

        try {

            $hash = sha1(
                bin2hex(
                    random_bytes(32)
                ) .
                microtime(true) .
                mt_rand()
            );

        } catch (Throwable $exception) {

            $hash = sha1(
                uniqid('', true) .
                microtime(true) .
                mt_rand()
            );

            Wo_SessionHashLog(
                'create_hash_id_random_bytes_failed',
                array(
                    'exception_class' =>
                        get_class(
                            $exception
                        ),

                    'exception_message' =>
                        $exception->getMessage()
                )
            );
        }

        $_SESSION['hash_id'] =
            $hash;

        Wo_SessionHashLog(
            'create_hash_id_created',
            array(
                'session_key' =>
                    'hash_id',

                'value' =>
                    Wo_SessionHashFingerprint(
                        $hash
                    )
            )
        );

        return $hash;
    }

# 9. The 64-character hash issue

This point deserves emphasis.

Your native WoWonder functions currently produce:

```text
hash_id       = 40 hex characters
main_hash_id  = 20 hex characters
```

because:

```php
sha1(...)
```

returns 40 hexadecimal characters, and:

```php
substr(sha1(...), 0, 20)
```

returns 20. 

The debugging system generates:

```php
hash('sha256', $value)
```

which produces:

```text
64 hexadecimal characters
```

So:

```text
64 characters
```

does **not** mean that some hidden `base64_decode()` is producing the WoWonder session hash.

It is almost certainly the **diagnostic fingerprint**.

For example:

```text
Actual main_hash_id
    ↓
abc123.................   20 chars
    ↓
SHA-256 fingerprint
    ↓
8f43c...64 characters...9ab
```

The log intentionally records only the second value.

That is the correct security model.

# 10. Step 5 — Do NOT expect DevTools to show the session variables

This is another misconception we can now eliminate.

Chrome can show:

```text
BUZZSTREAMSESSID
```

because that is a browser cookie.

Chrome cannot directly show:

```php
$_SESSION['hash_id']
$_SESSION['main_hash_id']
```

because those are server-side values.

The relationship is:

```text
Browser
   │
   │ BUZZSTREAMSESSID = random session identifier
   ▼
PHP session storage
   │
   ├── hash_id
   ├── main_hash_id
   ├── wo_user_id
   ├── last_url
   └── other $_SESSION values
```

So our log needs to correlate:

```text
BUZZSTREAMSESSID fingerprint
        +
main_hash_id fingerprint
        +
request hash fingerprint
```

That is much more useful than trying to expose `$_SESSION`.
