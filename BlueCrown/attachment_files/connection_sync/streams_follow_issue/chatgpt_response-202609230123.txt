## Executive diagnosis

I reviewed the current Buzzjuice Streams repository, the previous debug log, and the GitHub recommendations. The evidence now points to a more precise problem than simply “the PHP session is empty.”

There are **two distinct session/token layers** involved:

1. **PHP session continuity**

   * `$_SESSION['hash_id']`
   * `$_SESSION['main_hash_id']`
   * session ID/cookie
   * session save path

2. **The request token supplied to `Wo_CheckMainSession($hash)`**

   * This is **not automatically the same thing** as `$_SESSION['main_hash_id']`.

The current `requests.php` explicitly extracts `$hash_id` from the incoming request, while the session stores `main_hash_id`. GitHub correctly identified that these are separate values. 

More importantly, your existing debug log contains a very significant clue:

* At one point session fingerprint `a259...` had `main_hash_id` fingerprint `25de...`.
* Later session fingerprint `e82e...` had `main_hash_id` fingerprint `653e...`.
* A subsequent request using session `e82e...` supplied request-hash fingerprint `25de...`.

So the request was carrying a token belonging to an **older/different Streams session**, while the active PHP session contained a different `main_hash_id`. 

That is exactly the sort of condition that produces:

> `Requested` → request rejected → reload → `Follow`

while another account/session happens to have matching values and immediately shows `Following`.

There is also evidence that the Streams session itself is generally working: the log shows `BUZZSTREAMSESSID`, `/streams`, `/home/koware/tmp/sessions`, the `files` handler, and persistent hash values across multiple requests.

before setting a Streams-specific session name/cookie configuration.


```php
if (!function_exists('bz_session_value_diagnostic')) {
    function bz_session_value_diagnostic($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length' => strlen($value),
            'fingerprint' => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format' => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}


if (!function_exists('bz_session_safe_scalar')) {
    function bz_session_safe_scalar($value)
    {
        if (is_bool($value)) {
            return $value;
        }

        if (is_int($value) || is_float($value)) {
            return $value;
        }

        if (is_string($value)) {
            return array(
                'type' => 'string',
                'length' => strlen($value),
                'fingerprint' => ($value !== '')
                    ? hash('sha256', $value)
                    : ''
            );
        }

        if (is_array($value)) {
            return array(
                'type' => 'array',
                'keys' => array_keys($value),
                'count' => count($value)
            );
        }

        if (is_object($value)) {
            return array(
                'type' => 'object',
                'class' => get_class($value)
            );
        }

        if ($value === null) {
            return array(
                'type' => 'null'
            );
        }

        return array(
            'type' => gettype($value)
        );
    }
}

if (!function_exists('bz_session_resolved_save_path')) {
    function bz_session_resolved_save_path()
    {
        if (!function_exists('session_save_path')) {
            return '';
        }

        $path = (string) session_save_path();

        if ($path === '') {
            return '';
        }

        /*
         * PHP permits:
         *
         * N;/path/to/sessions
         *
         * N;MODE;/path/to/sessions
         */
        if (strpos($path, ';') !== false) {
            $parts = explode(';', $path);
            $path = end($parts);
        }

        return rtrim($path, DIRECTORY_SEPARATOR);
    }
}

    function bz_session_storage_diagnostics()
    {
        $result = array(
            'handler' => function_exists('ini_get')
                ? (string) ini_get('session.save_handler')

        if (

                $file = $result['resolved_save_path']
                    .DIRECTORY_SEPARATOR
                    .'sess_'.$session_id;

                $result['session_file_expected'] = true;
                $result['session_file_path'] = $file;

                if (file_exists($file)) {
                    $result['session_file_exists'] = true;
                    $result['session_file_size'] = (int) filesize($file);
                    $result['session_file_mtime'] = (int) filemtime($file);
                }
            }
        }

        return $result;
    }
}

if (!function_exists('bz_session_snapshot_diff')) {
    function bz_session_snapshot_diff($before, $after)
    {
        $changes = array();

        $fields = array(
            'session_name',
            'session_id',
            'hash_id',
            'main_hash_id',
            'session_keys',
            'session_encoded',
            'session_save_path',
            'session_save_handler'
        );

        foreach ($fields as $field) {
            $before_value = isset($before[$field])
                ? $before[$field]
                : null;

            $after_value = isset($after[$field])
                ? $after[$field]
                : null;

            if ($before_value !== $after_value) {
                $changes[$field] = array(
                    'before' => $before_value,
                    'after' => $after_value
                );
            }
        }

        return $changes;
    }
}

    function Wo_SessionDiagnosticLog($event, $context = array())
    {
        $file = bz_stream_session_log_path();
        $directory = dirname($file);

        if (!is_dir($directory)) {
            @mkdir($directory, 0750, true);

            );
        }

            : 0;

        $context['sapi'] = function_exists('php_sapi_name')
            ? php_sapi_name()
            : '';

        $context['request_method'] =
            isset($_SERVER['REQUEST_METHOD'])
                ? (string) $_SERVER['REQUEST_METHOD']
                : '';

        $context['request_uri'] =
            bz_session_safe_request_uri();

        $context['script_filename'] =
            isset($_SERVER['SCRIPT_FILENAME'])
                ? (string) $_SERVER['SCRIPT_FILENAME']
                : '';

        $context['http_host'] =
            isset($_SERVER['HTTP_HOST'])
                ? (string) $_SERVER['HTTP_HOST']
                : '';

        $context['log_file'] = $file;
        $context['log_directory_exists'] = is_dir($directory);
        $context['log_directory_writable'] = is_writable($directory);

        $context['session_state'] =
            bz_session_state_snapshot();

        $context['trace'] =
            bz_session_trace(20);

        $record = array(
            'event' => (string) $event,
            'context' => $context
        );

        $json = json_encode(
            $record,
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR
        );

        if ($json === false) {
            return false;
        }

        $written = @file_put_contents(
            $file,
            $json.PHP_EOL,
            FILE_APPEND | LOCK_EX
        );

        return ($written !== false);
    }
}

if (!function_exists('bz_safe_session_start')) {
    function bz_safe_session_start()
    {
        if (!function_exists('session_status')) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'session_status_unavailable'
                )
            );

            return false;
        }

        if (session_status() === PHP_SESSION_ACTIVE) {
            Wo_SessionDiagnosticLog(
                'session_already_active'
            );

            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'session_not_startable',
                    'session_status' => session_status()
                )
            );

            return false;
        }

        if (headers_sent($headers_file, $headers_line)) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'headers_already_sent',
                    'headers_file' => $headers_file,
                    'headers_line' => (int) $headers_line
                )
            );

            return false;
        }

        $before_id = function_exists('session_id')
            ? (string) session_id()
            : '';

        $started = false;

        try {
            $started = session_start();
        } catch (Throwable $exception) {

            Wo_SessionDiagnosticLog(
                'session_start_exception',
                array(
                    'exception_class' => get_class($exception),
                    'exception_message' => $exception->getMessage()
                )
            );

            return false;
        }

        $active = (
            $started &&
            session_status() === PHP_SESSION_ACTIVE
        );

        Wo_SessionDiagnosticLog(
            $active
                ? 'session_started'
                : 'session_start_failed',
            array(
                'start_return_value' => (bool) $started,

                'before_session_id' =>
                    bz_session_value_diagnostic($before_id),

                'after_session_id' =>
                    bz_session_value_diagnostic(
                        function_exists('session_id')
                            ? session_id()
                            : ''
                    ),

                'last_error' => error_get_last()
            )
        );

        return $active;
    }
}
```

```php
if (!function_exists('Wo_EnsureSessionActive')) {
    function Wo_EnsureSessionActive()
    {
        if (!function_exists('session_status')) {

            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' =>
                        'session_status_unavailable'
                )
            );

            return false;
        }

        if (session_status() === PHP_SESSION_ACTIVE) {
            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {

            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' =>
                        'session_not_startable',

                    'session_status' =>
                        session_status()
                )
            );

            return false;
        }

        if (
            headers_sent(
                $headers_file,
                $headers_line
            )
        ) {

            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' =>
                        'headers_already_sent',

                    'headers_file' =>
                        $headers_file,

                    'headers_line' =>
                        (int) $headers_line
                )
            );

            return false;
        }

        try {

            $started =
                session_start();

        } catch (Throwable $exception) {

            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' =>
                        'session_start_exception',

                    'exception_class' =>
                        get_class($exception),

                    'exception_message' =>
                        $exception->getMessage()
                )
            );

            return false;
        }

        $active = (
            $started &&
            session_status() ===
                PHP_SESSION_ACTIVE
        );

        Wo_SessionHashLog(
            $active
                ? 'session_started_by_hash_function'
                : 'session_start_failed_by_hash_function',

            array(
                'start_return_value' =>
                    (bool) $started,

                'session_name' =>
                    function_exists('session_name')
                        ? session_name()
                        : '',

                'session_id' =>
                    function_exists('session_id')
                        ? Wo_SessionHashDiagnostic(

                        )

            )
        );

        return $active;
    }

if (!function_exists('Wo_CreateSession')) {
    function Wo_CreateSession()
    {
        $started_at = microtime(true);

        Wo_SessionHashLog(
            'Wo_CreateSession_enter',
            array(
                'session_key' => 'hash_id'
            )
        );

        if (!Wo_EnsureSessionActive()) {

            Wo_SessionHashLog(
                'create_hash_id_failed',
                array(
                    'session_key' => 'hash_id',
                    'reason' =>
                        'php_session_not_active'
                )
            );

            return '';
        }

        $existing =
            isset($_SESSION['hash_id'])
                ? (string) $_SESSION['hash_id']
                : '';

        if (
            preg_match(
                '/^[a-f0-9]{40}$/i',
                $existing
            )
        ) {

            Wo_SessionHashLog(
                'create_hash_id_reused',
                array(
                    'session_key' => 'hash_id',

                    'existing_value' =>
                        Wo_SessionHashDiagnostic(
                            $existing
                        ),

                    'duration_ms' =>
                        (microtime(true) -
                         $started_at) * 1000
                )
            );

            return $existing;
        }

        if ($existing !== '') {

            Wo_SessionHashLog(
                'create_hash_id_replaced_invalid_value',
                array(
                    'session_key' => 'hash_id',

                    'old_value' =>
                        Wo_SessionHashDiagnostic(
                            $existing
                        )
                )
            );
        }

        try {

            $hash =
                bin2hex(
                    random_bytes(20)
                );

        } catch (Throwable $exception) {

            Wo_SessionHashLog(
                'create_hash_id_random_generation_failed',
                array(
                    'session_key' => 'hash_id',

                    'exception_class' =>
                        get_class($exception),

                    'exception_message' =>
                        $exception->getMessage()
                )
            );

            return '';
        }

        $_SESSION['hash_id'] =
            $hash;

        Wo_SessionHashLog(
            'create_hash_id_created',
            array(
                'session_key' => 'hash_id',

                'old_value' =>
                    Wo_SessionHashDiagnostic(
                        $existing
                    ),

                'new_value' =>
                    Wo_SessionHashDiagnostic(
                        $hash
                    ),

                'session_write_pending' =>
                    true,

                'duration_ms' =>
                    (microtime(true) -
                     $started_at) * 1000
            )
        );

        /*
         * Immediate in-memory readback.
         */
        $readback =
            isset($_SESSION['hash_id'])
                ? (string) $_SESSION['hash_id']
                : '';

        Wo_SessionHashLog(
            'create_hash_id_readback',
            array(
                'session_key' => 'hash_id',

                'readback_value' =>
                    Wo_SessionHashDiagnostic(
                        $readback
                    ),

                'readback_matches' =>
                    hash_equals(
                        $hash,
                        $readback
                    )
            )
        );

        return $hash;
    }
}
```
