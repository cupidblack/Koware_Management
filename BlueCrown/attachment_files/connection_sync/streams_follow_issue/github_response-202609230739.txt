The evidence points to a **Streams-session/token mismatch**, not primarily a QuickDate session collision.

The important distinction is:

- `BUZZSTREAMSESSID` identifies the PHP session used by WoWonder.
- `$_SESSION['main_hash_id']` is the server-side WoWonder token.
- The `$hash_id` passed to `Wo_CheckMainSession($hash_id)` is supplied by the request.
- Those two hash values are only valid when they belong to the same active Streams session.

Your existing `requests.php` extracts `$hash_id` only from the request. If the request contains an old token, no token, or a token generated under another session, `Wo_CheckMainSession()` correctly returns `false`. Forcing it to return `true` only bypasses the protection.

Also, this code is unreachable:

```php
return true;

print_r(...);
```

Anything after `return true` will never execute.

The following implementation keeps session validation enabled, logs the session lifecycle, identifies the configured save path, fingerprints values without logging secrets, records session changes, and logs request/session token mismatches.

# 1. Findings from the supplied code

## Streams currently starts the session too early

The current `streams/assets/init.php` does this:

```php
if (session_status() !== PHP_SESSION_ACTIVE) {
    @session_start();
}
```

before explicitly configuring:

```php
BUZZSTREAMSESSID
/streams
.buzzjuice.net
```

Therefore, the session may inherit:

```text
PHPSESSID
/
```

instead of:

```text
BUZZSTREAMSESSID
/streams
```

The browser evidence shows both cookies:

```text
PHPSESSID         /
BUZZSTREAMSESSID  /streams
```

That is acceptable only if Streams always uses `BUZZSTREAMSESSID` and QuickDate uses `PHPSESSID`.

## QuickDate should not share the Streams session

Do not synchronize the two PHP sessions.

The intended arrangement should be:

```text
WordPress
    ├── PHPSESSID
    │     └── QuickDate / Socials
    │
    └── BUZZSTREAMSESSID
          └── WoWonder / Streams
```

The Streams session must be configured before `session_start()`.

## The SSO bridge can destroy the active session

The Streams bridge contains this logic:

```php
if (!$wordpress_logged_in) {
    if (session_status() === PHP_SESSION_ACTIVE) {
        $_SESSION = [];
        session_unset();
        @session_destroy();
    }
}
```

If the WordPress cookie is temporarily absent from a Streams request, this destroys the active Streams session and removes `hash_id` and `main_hash_id`.

The new logging below will expose this event. Do not remove that security behavior permanently, but the log will show whether it is occurring.

# 3. Replace `streams/assets/init.php`

Use this as the complete `streams/assets/init.php`.

It does the following:

- Configures the Streams session before startup.
- Uses `BUZZSTREAMSESSID`.
- Uses `/streams` as the cookie path.
- Logs `session_save_path()`.
- Logs the session handler.
- Logs the expected session file.
- Logs session ID and hash fingerprints only.
- Never logs raw hashes, cookies, JWTs, or session IDs.
- Records session state before and after application loading.
- Records shutdown changes.
- Does not print debugging information into AJAX responses.

if (!function_exists('bz_session_fingerprint')) {
    function bz_session_fingerprint($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length' => strlen($value),
            'sha256' => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format' => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}

if (!function_exists('bz_session_safe_request_uri')) {
    function bz_session_safe_request_uri()
    {
        $uri = isset($_SERVER['REQUEST_URI'])
            ? (string) $_SERVER['REQUEST_URI']
            : '';

        if ($uri === '') {
            return '';
        }

        return preg_replace(
            '/([?&](?:hash_id|hash|token|sso_token|buzz_access|buzz_refresh|password|secret)=)[^&]*/i',
            '$1[REDACTED]',
            $uri
        );
    }
}

if (!function_exists('bz_session_cookie_diagnostics')) {
    function bz_session_cookie_diagnostics()
    {
        $names = array(
            'BUZZSTREAMSESSID',
            'BUZZSOCIALSESSID',
            'PHPSESSID',
            'buzz_sso',
            'buzz_access',
            'buzz_refresh',
            'user_id',
            'JWT'
        );

        $result = array();

        foreach ($names as $name) {
            $value = isset($_COOKIE[$name])
                ? (string) $_COOKIE[$name]
                : '';

            $result[$name] = array(
                'present' => ($value !== ''),
                'length' => strlen($value),
                'sha256' => ($value !== '')
                    ? hash('sha256', $value)
                    : ''
            );
        }

        return $result;
    }

if (!function_exists('bz_session_trace')) {
    function bz_session_trace($limit = 20)
    {
        $trace = array();

        $frames = debug_backtrace(
            DEBUG_BACKTRACE_IGNORE_ARGS,
            (int) $limit
        );

        foreach ($frames as $frame) {
            $trace[] = array(
                'file' => isset($frame['file'])
                    ? basename((string) $frame['file'])
                    : '',
                'line' => isset($frame['line'])
                    ? (int) $frame['line']
                    : 0,
                'class' => isset($frame['class'])
                    ? (string) $frame['class']
                    : '',
                'type' => isset($frame['type'])
                    ? (string) $frame['type']
                    : '',
                'function' => isset($frame['function'])
                    ? (string) $frame['function']
                    : ''
            );
        }

        return $trace;
    }

if (!function_exists('bz_session_resolved_save_path')) {
    function bz_session_resolved_save_path()
    {
        $path = function_exists('session_save_path')
            ? (string) session_save_path()
            : '';

        if ($path === '') {
            return '';
        }

        /*
         * PHP may return:
         *
         * N;/path/to/sessions
         * N;MODE;/path/to/sessions
         */
        if (strpos($path, ';') !== false) {
            $parts = explode(';', $path);
            $path = end($parts);
        }

        return rtrim($path, DIRECTORY_SEPARATOR);
    }
}

if (!function_exists('bz_session_storage_diagnostics')) {
    function bz_session_storage_diagnostics()
    {
        $handler = function_exists('ini_get')
            ? (string) ini_get('session.save_handler')
            : '';

        $configured_path = function_exists('session_save_path')
            ? (string) session_save_path()
            : '';

        $resolved_path = bz_session_resolved_save_path();

        $result = array(
            'handler' => $handler,
            'configured_save_path' => $configured_path,
            'resolved_save_path' => $resolved_path,
            'resolved_path_exists' => (
                $resolved_path !== '' &&
                is_dir($resolved_path)
            ),
            'resolved_path_readable' => (
                $resolved_path !== '' &&
                is_readable($resolved_path)
            ),
            'resolved_path_writable' => (
                $resolved_path !== '' &&
                is_writable($resolved_path)
            )
        );

        if (
            $handler === 'files' &&
            $resolved_path !== '' &&
            function_exists('session_status') &&
            session_status() === PHP_SESSION_ACTIVE &&
            function_exists('session_id')
        ) {
            $id = (string) session_id();

            if ($id !== '') {
                $session_file = $resolved_path
                    .DIRECTORY_SEPARATOR
                    .'sess_'.$id;

                $result['session_file_exists'] = file_exists($session_file);
                $result['session_file_size'] = file_exists($session_file)
                    ? (int) filesize($session_file)
                    : 0;
                $result['session_file_mtime'] = file_exists($session_file)
                    ? (int) filemtime($session_file)
                    : 0;
            }
        }

        return $result;
    }
}

                                    : 'UNKNOWN'
                            )

if (!function_exists('bz_session_snapshot_diff')) {
    function bz_session_snapshot_diff($before, $after)
    {
        $fields = array(
            'session_status',
            'session_name',
            'session_id',
            'session_save_path',
            'session_save_handler',
            'hash_id',
            'main_hash_id',
            'request_hash_id',
            'session_keys',
            'session_encoded',
            'wo_user_id',
            'storage'
        );

        $changes = array();

        foreach ($fields as $field) {
            $before_value = isset($before[$field])
                ? $before[$field]
                : null;

            $after_value = isset($after[$field])
                ? $after[$field]
                : null;

            if ($before_value !== $after_value) {
                $changes[$field] = array(
                    'before' => $before_value,
                    'after' => $after_value
                );
            }
        }

        return $changes;
    }
}

if (!function_exists('Wo_SessionDiagnosticLog')) {
    function Wo_SessionDiagnosticLog($event, $context = array())
    {
        $file = bz_stream_session_log_path();
        $directory = dirname($file);

        if (!is_dir($directory)) {
            @mkdir($directory, 0750, true);
        }

        if (!is_array($context)) {
            $context = array(
                'value' => $context
            );
        }

        $context['timestamp_utc'] = gmdate('c');
        $context['pid'] = function_exists('getmypid')
            ? (int) getmypid()
            : 0;
        $context['sapi'] = function_exists('php_sapi_name')
            ? php_sapi_name()
            : '';
        $context['request_method'] = isset($_SERVER['REQUEST_METHOD'])
            ? (string) $_SERVER['REQUEST_METHOD']
            : '';
        $context['request_uri'] = bz_session_safe_request_uri();
        $context['script_filename'] = isset($_SERVER['SCRIPT_FILENAME'])
            ? basename((string) $_SERVER['SCRIPT_FILENAME'])
            : '';
        $context['http_host'] = isset($_SERVER['HTTP_HOST'])
            ? (string) $_SERVER['HTTP_HOST']
            : '';
        $context['log_file'] = $file;
        $context['log_directory_exists'] = is_dir($directory);
        $context['log_directory_writable'] = is_writable($directory);
        $context['session_state'] = bz_session_state_snapshot();
        $context['trace'] = bz_session_trace(20);

        $record = array(
            'event' => (string) $event,
            'context' => $context
        );

        $json = json_encode(
            $record,
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR
        );

        if ($json === false) {
            return false;
        }

        return @file_put_contents(
            $file,
            $json.PHP_EOL,
            FILE_APPEND | LOCK_EX
        ) !== false;
    }
}

if (!function_exists('bz_safe_session_start')) {
    function bz_safe_session_start()
    {
        if (session_status() === PHP_SESSION_ACTIVE) {
            Wo_SessionDiagnosticLog('session_already_active');
            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'session_not_startable',
                    'session_status' => session_status()
                )
            );

            return false;
        }

        if (headers_sent($headers_file, $headers_line)) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'headers_already_sent',
                    'headers_file' => $headers_file,
                    'headers_line' => (int) $headers_line
                )
            );

            return false;
        }

        $before_id = function_exists('session_id')
            ? (string) session_id()
            : '';

        try {
            $started = @session_start();
        } catch (Throwable $exception) {
            Wo_SessionDiagnosticLog(
                'session_start_exception',
                array(
                    'exception_class' => get_class($exception),
                    'exception_message' => $exception->getMessage()
                )
            );

            return false;
        }

        $active = (
            $started &&
            session_status() === PHP_SESSION_ACTIVE
        );

        Wo_SessionDiagnosticLog(
            $active
                ? 'session_started'
                : 'session_start_failed',
            array(
                'start_return_value' => (bool) $started,
                'before_session_id' => bz_session_fingerprint($before_id),
                'after_session_id' => bz_session_fingerprint(
                    function_exists('session_id')
                        ? session_id()
                        : ''
                ),
                'last_error' => error_get_last()
            )
        );

        return $active;
    }
}

        }

        $active = (

    function Wo_CreateSession()
    {
        if (!Wo_EnsureSessionActive()) {
            Wo_SessionHashLog(
                'create_hash_id_failed',
                array(
                    'session_key' => 'hash_id',
                    'reason' => 'php_session_not_active'
                )
            );

            return '';
        }

        $existing = isset($_SESSION['hash_id'])
            ? (string) $_SESSION['hash_id']
            : '';

        if (preg_match('/^[a-f0-9]{40}$/i', $existing)) {

                'create_hash_id_reused',

            return $existing;
        }

        if ($existing !== '') {

                array(
                    'session_key' => 'hash_id',
                    'old_value' => Wo_SessionHashFingerprint($existing)
                )
            );
        }

        try {
            $hash = sha1(
                bin2hex(random_bytes(32)) .
                microtime(true) .
                mt_rand()
            );

                uniqid('', true) .
                microtime(true) .
                mt_rand()

                'create_hash_id_random_bytes_failed',
                array(
                    'exception_class' => get_class($exception),
                    'exception_message' => $exception->getMessage()
                )
            );
        }

        $_SESSION['hash_id'] = $hash;

        Wo_SessionHashLog(
            'create_hash_id_created',
            array(
                'session_key' => 'hash_id',
                'value' => Wo_SessionHashFingerprint($hash)
            )
        );

        return $hash;
    }
}

            $stored !== '' &&

                'provided' => Wo_SessionHashFingerprint($provided),
                'stored' => Wo_SessionHashFingerprint($stored),
                'provided_empty' => ($provided === ''),
                'stored_empty' => ($stored === ''),
                'result' => $matches,
                'diagnosis' => (
                    $provided === ''
                        ? 'request_did_not_supply_main_hash_token'
                        : (
                            $stored === ''
                                ? 'active_session_does_not_contain_main_hash_id'
                                : (
                                    $provided !== $stored
                                        ? 'request_token_does_not_match_active_session'
                                        : 'unknown'
                                )
                        )
                )
            )
        );

        return $matches;
    }
}

This implementation uses `hash_equals()` instead of `==`, which is the correct comparison for security tokens.

# 7. What to look for in the new log

Each line is JSON. Search for these events:

```text
streams_bootstrap_before_session_configuration
streams_session_configuration_before_start
session_started
streams_session_started_before_application_includes
create_hash_id_created
create_hash_id_reused
create_main_hash_id_created
create_main_hash_id_reused
check_main_hash_id_success
check_main_hash_id_rejected
request_shutdown_session_state_changed
```

## Successful request

A successful follow-related validation should look conceptually like this:

```json
{
  "event": "check_main_hash_id_success",
  "context": {
    "session_name": "BUZZSTREAMSESSID",
    "provided": {
      "present": true,
      "length": 20,
      "sha256": "..."
    },
    "stored": {
      "present": true,
      "length": 20,
      "sha256": "..."
    },
    "result": true
  }
}
```

The `provided.sha256` and `stored.sha256` values must be identical.

## Missing request token

This indicates that the browser request did not send the token:

```json
{
  "event": "check_main_hash_id_rejected",
  "context": {
    "provided_empty": true,
    "stored_empty": false,
    "diagnosis": "request_did_not_supply_main_hash_token"
  }
}
```

## Session has no main hash

This indicates that the active session is not the same session that created the token:

```json
{
  "event": "check_main_hash_id_rejected",
  "context": {
    "provided_empty": false,
    "stored_empty": true,
    "diagnosis": "active_session_does_not_contain_main_hash_id"
  }
}
```

## Old or foreign token

This is the most likely condition based on the previous log:

```json
{
  "event": "check_main_hash_id_rejected",
  "context": {
    "provided_empty": false,
    "stored_empty": false,
    "diagnosis": "request_token_does_not_match_active_session"
  }
}
```

In that case:

- compare the `session_id.sha256`;
- compare the `main_hash_id.sha256`;
- compare the request URI;
- compare the `pid`;
- compare the timestamps.

If the request fingerprint matches a previous request but the current session fingerprint differs, the browser is sending a stale token.

## Session destroyed

Look for a shutdown change where the session changes from active to empty or where the keys disappear:

```json
{
  "event": "request_shutdown_session_state_changed",
  "context": {
    "changes": {
      "session_keys": {
        "before": ["hash_id", "main_hash_id", "..."],
        "after": []
      }
    }
  }
}
```

If this occurs during `ww-sso-bridge.php`, inspect the no-WordPress-cookie branch.

# 8. How to verify the session save path

The log will record values such as:

```json
"storage": {
  "handler": "files",
  "configured_save_path": "/home/koware/tmp/sessions",
  "resolved_save_path": "/home/koware/tmp/sessions",
  "resolved_path_exists": true,
  "resolved_path_readable": true,
  "resolved_path_writable": true,
  "session_file_exists": true,
  "session_file_size": 1234,
  "session_file_mtime": 1790120000
}
```

For a file-based session handler, the actual session file is normally:

```text
<session_save_path>/sess_<session_id>
```

The implementation records whether that file exists and its size/mtime, but deliberately does not log the raw session ID or full session file path containing it.

If you need to inspect the file directly on the server, use the session ID from the browser only locally and never paste the raw value into a public issue or chat:

```bash
ls -l /home/koware/tmp/sessions/sess_<BUZZSTREAMSESSID>
```

Do not expose the contents of that file publicly because it can contain authenticated session data.

# 10. Most likely result

Based on the old log, the likely sequence is:

1. One request creates `main_hash_id = A`.
2. A later SSO/session transition creates a new Streams session containing `main_hash_id = B`.
3. The browser or cached page submits request token `A`.
4. The active session contains `B`.
5. `Wo_CheckMainSession(A)` rejects the request.
6. The UI changes optimistically to `Requested`.
7. Reloading reads the database and shows `Follow`.

The account that immediately shows `Following` is likely sending a request token that happens to match its active session.

The new log will distinguish this from:

- missing request token;
- missing session cookie;
- session destruction;
- session-save-path failure;
- cookie-path collision;
- SSO bridge interference;
- token mismatch caused by stale cached markup.

Do not leave either validation function permanently bypassed. The correct fix is to ensure that the request token and `$_SESSION['main_hash_id']` are generated and consumed within the same `BUZZSTREAMSESSID` session.
