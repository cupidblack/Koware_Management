The main defect is the client-side state transition: the current `Wo_RegisterFollow()` changes the button to `Requested` before the server responds. The endpoint also treats an inactive/requested row as an unfollow condition, and several failure paths return an undefined `$data`.

Do **not** replace the entire WoWonder follow implementation blindly. Apply the following changes while preserving any existing notification, activity, email, cache, blocking, and privacy logic.

## 1. Add a safe follow logger

Add this once to `streams/assets/includes/functions_one.php`, before the follow-related functions.

```php name=streams/assets/includes/functions_one.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/assets/includes/functions_one.php
/*
 * Buzzjuice Streams follow diagnostics.
 *
 * Log file:
 *     /buzzjuice.net/data.logs/bzj-streams-follow.log
 *
 * Never log passwords, JWTs, cookies, sessions or authorization headers.
 */
if (!function_exists('bzj_streams_follow_log')) {
    function bzj_streams_follow_log($event, $context = array())
    {
        $application_root = dirname(__DIR__, 3);

        if (
            defined('DOCUMENT_ROOT') &&
            DOCUMENT_ROOT !== '' &&
            is_dir(rtrim(DOCUMENT_ROOT, '/') . '/data.logs')
        ) {
            $application_root = rtrim(DOCUMENT_ROOT, '/');
        }

        $log_dir  = rtrim($application_root, '/') . '/data.logs';
        $log_file = $log_dir . '/bzj-streams-follow.log';

        if (!is_dir($log_dir)) {
            @mkdir($log_dir, 0750, true);
        }

        $sensitive_keys = array(
            'password',
            'pass',
            'token',
            'access_token',
            'refresh_token',
            'jwt',
            'cookie',
            'cookies',
            'session',
            'session_id',
            'authorization',
            'hash_id'
        );

        foreach ($sensitive_keys as $key) {
            if (array_key_exists($key, $context)) {
                unset($context[$key]);
            }
        }

        $current_user_id = 0;

        if (
            isset($GLOBALS['wo']) &&
            is_array($GLOBALS['wo']) &&
            !empty($GLOBALS['wo']['user']['user_id'])
        ) {
            $current_user_id = (int) $GLOBALS['wo']['user']['user_id'];
        }

        $payload = array(
            'time'       => gmdate('c'),
            'event'      => (string) $event,
            'user_id'    => $current_user_id,
            'request_id' => sha1(uniqid('', true)),
            'method'     => isset($_SERVER['REQUEST_METHOD'])
                ? (string) $_SERVER['REQUEST_METHOD']
                : '',
            'uri'        => isset($_SERVER['REQUEST_URI'])
                ? substr((string) $_SERVER['REQUEST_URI'], 0, 500)
                : '',
            'ip'         => isset($_SERVER['REMOTE_ADDR'])
                ? (string) $_SERVER['REMOTE_ADDR']
                : '',
            'context'    => $context
        );

        $json = json_encode(
            $payload,
            JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE
        );

        if ($json !== false) {
            @file_put_contents(
                $log_file,
                $json . PHP_EOL,
                FILE_APPEND | LOCK_EX
            );
        }
    }
}
```

```bash

chown <php-user>:<php-group> /path/to/buzzjuice.net/data.logs
chmod 750 /path/to/buzzjuice.net/data.logs
```

Do not make `data.logs` world-writable.

## 2. Correct `Wo_IsFollowing()`

If the current function determines following by checking whether `COUNT(id) == 1`, duplicate rows can make an active relationship appear inactive.

The function should return true when **at least one** active row exists:

```php name=streams/assets/includes/functions_one.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/assets/includes/functions_one.php
function Wo_IsFollowing($following_id, $user_id = 0)
{
    global $sqlConnect, $wo;

    if (empty($wo['loggedin']) || $wo['loggedin'] !== true) {
        return false;
    }

    if (
        empty($following_id) ||
        !is_numeric($following_id) ||
        (int) $following_id < 1
    ) {
        return false;
    }

    if (
        empty($user_id) ||
        !is_numeric($user_id) ||
        (int) $user_id < 1
    ) {
        $user_id = !empty($wo['user']['user_id'])
            ? $wo['user']['user_id']
            : 0;
    }

    $following_id = (int) $following_id;
    $user_id      = (int) $user_id;

    if ($user_id < 1) {
        return false;
    }

    $query = mysqli_query(
        $sqlConnect,
        "SELECT `id`
         FROM " . T_FOLLOWERS . "
         WHERE `following_id` = {$following_id}
           AND `follower_id` = {$user_id}
           AND `active` = '1'
         LIMIT 1"
    );

    if (!$query) {
        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'IS_FOLLOWING_QUERY_FAILED',
                array(
                    'following_id' => $following_id,
                    'follower_id'   => $user_id,
                    'mysql_error'   => mysqli_error($sqlConnect)
                )
            );
        }

        return false;
    }

    return mysqli_num_rows($query) > 0;
}
```

## 3. Refactor the relationship transition inside `Wo_RegisterFollow()`

Do not discard the existing `Wo_RegisterFollow()` side effects. Replace only the part that inserts the follower row.

The relationship transition should follow this state machine:

```text
active row exists       => already Following; do not insert another row
inactive row exists     => promote one row to active=1
no row exists            => insert active=1
```

## 4. Replace `follow_user.php`

This endpoint must only delete an **active** relationship. It must not delete a pending/inactive row before attempting to promote it.

```php name=streams/xhr/follow_user.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/xhr/follow_user.php
<?php

if (
    $f === 'follow_user' &&
    !empty($wo['loggedin']) &&
    $wo['loggedin'] === true
) {
    $data = array(
        'status'        => 400,
        'can_send'      => 0,
        'following'     => false,
        'requested'     => false,
        'follow_status' => 'follow',
        'message'       => ''
    );

    $follower_id = !empty($wo['user']['user_id'])
        ? (int) $wo['user']['user_id']
        : 0;

    $following_id = 0;

    if (
        !isset($_GET['following_id']) ||
        !is_numeric($_GET['following_id']) ||
        (int) $_GET['following_id'] < 1
    ) {
        $data['message'] = 'Invalid follow target.';

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'XHR_INVALID_TARGET',
                array(
                    'follower_id' => $follower_id,
                    'target'      => isset($_GET['following_id'])
                        ? $_GET['following_id']
                        : null
                )
            );
        }
    } elseif (
        !isset($hash_id) ||
        Wo_CheckMainSession($hash_id) !== true
    ) {
        $data['message'] = 'Invalid session.';

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'XHR_INVALID_SESSION',
                array(
                    'follower_id' => $follower_id
                )
            );
        }
    } else {
        $following_id = (int) $_GET['following_id'];

        if ($following_id === $follower_id) {
            $data['message'] = 'You cannot follow yourself.';
        } elseif (
            Wo_IsFollowing($following_id, $follower_id) === true
        ) {
            /*
             * Following -> Follow.
             */
            $deleted = Wo_DeleteFollow(
                $following_id,
                $follower_id
            );

            if ($deleted === true) {
                $data['status']        = 200;
                $data['following']     = false;
                $data['requested']     = false;
                $data['follow_status'] = 'follow';
                $data['message']       = 'Follow removed.';

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'XHR_UNFOLLOW_SUCCESS',
                        array(
                            'follower_id'  => $follower_id,
                            'following_id' => $following_id
                        )
                    );
                }
            } else {
                $data['message'] = 'Unable to remove the follow.';

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'XHR_UNFOLLOW_FAILED',
                        array(
                            'follower_id'  => $follower_id,
                            'following_id' => $following_id
                        )
                    );
                }
            }
        } else {
            /*
             * Follow or promote an existing inactive relationship.
             */
            $user_followers = Wo_CountFollowing(
                $follower_id,
                true
            );

            $friends_limit = isset(
                $wo['config']['connectivitySystemLimit']
            )
                ? (int) $wo['config']['connectivitySystemLimit']
                : 0;

            $limit_reached =
                isset($wo['config']['connectivitySystem']) &&
                (int) $wo['config']['connectivitySystem'] === 1 &&
                $friends_limit > 0 &&
                $user_followers >= $friends_limit;

            if ($limit_reached) {
                $data['message'] =
                    'You have reached the maximum number of follows.';
            } else {
                $registered = Wo_RegisterFollow(
                    $following_id,
                    $follower_id
                );

                if ($registered === true) {
                    /*
                     * The database is authoritative.
                     */
                    $is_following = Wo_IsFollowing(
                        $following_id,
                        $follower_id
                    );

                    if ($is_following === true) {
                        $data['status']        = 200;
                        $data['following']     = true;
                        $data['requested']     = false;
                        $data['follow_status'] = 'following';
                        $data['message']       = 'Following.';

                        if (
                            function_exists('Wo_CanSenEmails') &&
                            Wo_CanSenEmails()
                        ) {
                            $data['can_send'] = 1;
                        }

                        if (function_exists('bzj_streams_follow_log')) {
                            bzj_streams_follow_log(
                                'XHR_FOLLOW_SUCCESS',
                                array(
                                    'follower_id'  => $follower_id,
                                    'following_id' => $following_id
                                )
                            );
                        }
                    } else {
                        $data['message'] =
                            'The follow was not persisted.';

                        if (function_exists('bzj_streams_follow_log')) {
                            bzj_streams_follow_log(
                                'XHR_FOLLOW_VERIFY_FAILED',
                                array(
                                    'follower_id'  => $follower_id,
                                    'following_id' => $following_id
                                )
                            );
                        }
                    }
                } else {
                    $data['message'] =
                        'This account cannot be followed at this time.';

                    if (function_exists('bzj_streams_follow_log')) {
                        bzj_streams_follow_log(
                            'XHR_REGISTER_FOLLOW_FAILED',
                            array(
                                'follower_id'  => $follower_id,
                                'following_id' => $following_id
                            )
                        );
                    }
                }
            }
        }
    }

    if (
        $data['status'] === 200 &&
        function_exists('Wo_CleanCache')
    ) {
        Wo_CleanCache();
    }

    /*
     * Always return the final database state.
     */
    if ($following_id > 0 && $follower_id > 0) {
        $final_following = Wo_IsFollowing(
            $following_id,
            $follower_id
        );

        $final_requested = Wo_IsFollowRequested(
            $following_id,
            $follower_id
        );

        if ($final_following === true) {
            $data['following']     = true;
            $data['requested']     = false;
            $data['follow_status'] = 'following';
        } elseif ($final_requested === true) {
            $data['following']     = false;
            $data['requested']     = true;
            $data['follow_status'] = 'requested';
        } else {
            $data['following']     = false;
            $data['requested']     = false;
            $data['follow_status'] = 'follow';
        }

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'XHR_FINAL_STATE',
                array(
                    'follower_id'  => $follower_id,
                    'following_id' => $following_id,
                    'status'       => $data['status'],
                    'following'    => $data['following'],
                    'requested'   => $data['requested'],
                    'follow_status'=> $data['follow_status']
                )
            );
        }
    }

    header('Content-Type: application/json; charset=utf-8');
    echo json_encode($data);
    exit();
}
```

## 7. Fix the bulk endpoint

```php name=streams/xhr/follow_users.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/xhr/follow_users.php
<?php

if (
    $f === 'follow_users' &&
    !empty($wo['loggedin']) &&
    $wo['loggedin'] === true
) {

        'status'  => 400,
        'followed' => 0,

        ? (int) $wo['user']['user_id']

        }

    }

    header('Content-Type: application/json; charset=utf-8');
```

## 10. SSO and auto-registration

The SSO bridge is unlikely to be the direct cause of the button changing to `Requested`; that happens in the browser before the AJAX response. However, malformed or partially registered accounts can cause follow validation to fail.

The current bridge contains this helper:

```php
$username = preg_replace('/[^a-zA-Z0-9_]/', '', $username);
```

That silently transforms usernames. Do not rename existing users or quarantine accounts automatically. Replace it with a validation-only helper:

```php name=streams/ww-sso-bridge.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/ww-sso-bridge.php#L390-L410
if (!function_exists('bz_clean_username')) {
    function bz_clean_username($username)
    {
        $username = trim((string) $username);

        if ($username === '') {
            return '';
        }

        return function_exists('mb_substr')
            ? mb_substr($username, 0, 32, 'UTF-8')
            : substr($username, 0, 32);
    }
}
```

Before calling `Wo_RegisterUser()`, log and validate:

```php name=streams/ww-sso-bridge.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/ww-sso-bridge.php#L671-L718
$final_username = bz_clean_username($wp_username);
$wp_email       = trim((string) $wp_email);

if ($final_username === '' || $wp_email === '') {
    bz_bridge_log(
        'SSO auto-registration rejected: incomplete identity',
        array(
            'wp_user_id' => $wp_user_id,
            'has_username'=> $final_username !== '',
            'has_email'   => $wp_email !== ''
        )
    );

    $fatal_error = 'Your Streams account is missing required identity information.';
} else {
    $registration = Wo_RegisterUser(array(
        'username' => $final_username,
        'email'    => $wp_email,
        'password' => bin2hex(random_bytes(16)),
        'active'   => 1
    ));

    bz_bridge_log(
        'SSO auto-registration returned',
        array(
            'wp_user_id'  => $wp_user_id,
            'username'    => $final_username,
            'registration'=> is_array($registration)
                ? array(
                    'success' => !empty($registration['user_id']),
                    'user_id' => !empty($registration['user_id'])
                        ? (int) $registration['user_id']
                        : 0
                )
                : array(
                    'success' => (bool) $registration
                )
        )
    );
}
```

Do not log the generated password, JWT, cookies, or session data.

After registration, verify the created row exists and has:

```text
user_id > 0
active = 1
username not empty
email not empty
```

Do not copy user 66's account values to SSO-created users unless those values are proven to be required by the application.
