Yes. I reviewed the **current live repository versions**, the previous ChatGPT response, and the GitHub response, and there is a more fundamental issue than simply “some accounts are corrupt.”

The current implementation has **three interacting state problems**:

1. `Wo_RegisterFollow()` forces `active=1`, but the AJAX endpoint still treats an inactive/requested row as an instruction to **unfollow** before `Wo_RegisterFollow()` is even called. 
2. The browser currently changes the button **before the server response arrives**, including creating `Requested` state from `is_confirm`. 
3. `Wo_IsFollowing()` uses `COUNT(id) == 1`, so duplicate active rows can make a valid relationship appear not to exist. 

There is also an important **account-level issue**: the current `Wo_RegisterFollow()` still checks the target's `follow_privacy` and can return `false`. Therefore two otherwise valid accounts can behave differently depending on that user's database attributes. 

For Buzzjuice's intended model, I would make the architecture authoritative:

> **Follow click → server writes `active=1` → server verifies DB → server returns authoritative state → browser renders `Following`.**

No client-side `Requested` decision. No `confirm_followers` decision. No `connectivitySystem` conversion. No reliance on account-specific follow settings.

The GitHub recommendation to preserve the existing privacy restriction is therefore the one recommendation I would **not** carry over unchanged, because it conflicts with your stated Buzzjuice requirement that follows are immediately accepted.

# 2. Replace `Wo_IsFollowing()`

The existing implementation is:

```php
SELECT COUNT(id) ...
return COUNT == 1;
```

That is unnecessarily fragile if duplicate rows exist. 

Replace it with:

```php
function Wo_IsFollowing($following_id, $user_id = 0)
{
    global $sqlConnect, $wo;

    if (empty($wo['loggedin']) || $wo['loggedin'] !== true) {
        return false;
    }

    if (
        empty($following_id) ||
        !is_numeric($following_id) ||
        (int)$following_id < 1
    ) {
        return false;
    }

    if (
        empty($user_id) ||
        !is_numeric($user_id) ||
        (int)$user_id < 1
    ) {
        $user_id = !empty($wo['user']['user_id'])
            ? (int)$wo['user']['user_id']
            : 0;
    }

    $following_id = (int)$following_id;
    $user_id      = (int)$user_id;

    if ($user_id < 1) {
        return false;
    }

    $query = mysqli_query(
        $sqlConnect,
        "SELECT `id`
         FROM " . T_FOLLOWERS . "
         WHERE `following_id` = {$following_id}
           AND `follower_id` = {$user_id}
           AND `active` = '1'
         LIMIT 1"
    );

    if (!$query) {
        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'IS_FOLLOWING_QUERY_FAILED',
                array(
                    'following_id' => $following_id,
                    'follower_id'   => $user_id,
                    'mysql_error'   => mysqli_error($sqlConnect)
                )
            );
        }

        return false;
    }

    return mysqli_num_rows($query) > 0;
}
```

This means:

* one active row = Following
* two active rows = Following
* five active rows = Following
* zero active rows = not Following

That is the correct semantic interpretation.

# 4. Replace `Wo_DeleteFollow()`

The existing function is actually close, but we should make the deletion authoritative and remove **all duplicate rows**. GitHub correctly identified this as important. 

Replace the active implementation with:

```php
function Wo_DeleteFollow($following_id = 0, $follower_id = 0)
{
    global $wo, $sqlConnect;

    if (empty($wo['loggedin']) || $wo['loggedin'] !== true) {
        return false;
    }

    if (
        empty($following_id) ||
        !is_numeric($following_id) ||
        (int)$following_id < 1
    ) {
        return false;
    }

    if (
        empty($follower_id) ||
        !is_numeric($follower_id) ||
        (int)$follower_id < 1
    ) {
        return false;
    }

    $following_id = (int)$following_id;
    $follower_id  = (int)$follower_id;

    /*
     * Delete the complete relationship regardless of whether
     * duplicate active/inactive rows exist.
     */
    $delete_query = mysqli_query(
        $sqlConnect,
        "DELETE FROM " . T_FOLLOWERS . "
         WHERE `following_id` = {$following_id}
           AND `follower_id` = {$follower_id}"
    );

    if (!$delete_query) {

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'DELETE_FOLLOW_FAILED',
                array(
                    'following_id' => $following_id,
                    'follower_id'  => $follower_id,
                    'mysql_error'  => mysqli_error($sqlConnect)
                )
            );
        }

        return false;
    }

    $deleted_rows = mysqli_affected_rows($sqlConnect);

    /*
     * Preserve existing activity cleanup.
     */
    if ($wo['config']['connectivitySystem'] == 1) {

        mysqli_query(
            $sqlConnect,
            "DELETE FROM " . T_FOLLOWERS . "
             WHERE `follower_id` = {$following_id}
               AND `following_id` = {$follower_id}"
        );

        Wo_DeleteSelectedActivity(
            $follower_id,
            'friend',
            $following_id
        );

        Wo_DeleteSelectedActivity(
            $following_id,
            'friend',
            $follower_id
        );

    } else {

        Wo_DeleteSelectedActivity(
            $follower_id,
            'following',
            $following_id
        );
    }

    cache($following_id, 'users', 'delete');
    cache($follower_id, 'users', 'delete');

    if (function_exists('bzj_streams_follow_log')) {
        bzj_streams_follow_log(
            'DELETE_FOLLOW_SUCCESS',
            array(
                'following_id' => $following_id,
                'follower_id'  => $follower_id,
                'deleted_rows' => $deleted_rows
            )
        );
    }

    return true;
}

                }

            } else {

                $data['message'] = 'Unable to remove the follow.';

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'XHR_UNFOLLOW_FAILED',
                        array(
                            'follower_id'  => $follower_id,
                            'following_id' => $following_id
                        )
                    );
                }
            }

        /*
         * -----------------------------------------------------------
         * Not currently active -> FOLLOW
         *
         * Wo_RegisterFollow() handles:
         *   - no row
         *   - inactive row
         *   - duplicate rows
         *   - authoritative active=1
         * -----------------------------------------------------------
         */
        } else {

            /*
             * Preserve the existing follower limit.
             */
            $user_followers = Wo_CountFollowing(
                $follower_id,
                true
            );

            $friends_limit = $wo['config']['connectivitySystemLimit'];

            if (
                $wo['config']['connectivitySystem'] == 1 &&
                $user_followers >= $friends_limit
            ) {

                $data['status'] = 400;
                $data['message'] = 'Follow limit reached.';

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'XHR_FOLLOW_LIMIT_REACHED',
                        array(
                            'follower_id'  => $follower_id,
                            'following_id' => $following_id,
                            'followers'    => $user_followers,
                            'limit'        => $friends_limit
                        )
                    );
                }

            } else {

                $registered = Wo_RegisterFollow(
                    $following_id,
                    $follower_id
                );

                if ($registered === true) {

                    /*
                     * Authoritative DB verification.
                     */
                    $final_following = Wo_IsFollowing(
                        $following_id,
                        $follower_id
                    );

                    $final_requested = Wo_IsFollowRequested(
                        $following_id,
                        $follower_id
                    );

                    if ($final_following === true) {

                        $data['status']        = 200;
                        $data['following']     = true;
                        $data['requested']     = false;
                        $data['follow_status'] = 'following';
                        $data['message']       = 'Following.';

                        if (Wo_CanSenEmails()) {
                            $data['can_send'] = 1;
                        }

                        if (function_exists('bzj_streams_follow_log')) {
                            bzj_streams_follow_log(
                                'XHR_FOLLOW_SUCCESS',
                                array(
                                    'follower_id'  => $follower_id,
                                    'following_id' => $following_id,
                                    'following'    => true,
                                    'requested'    => $final_requested
                                )
                            );
                        }

                    } elseif ($final_requested === true) {

                        /*
                         * This should now be exceptional because Buzzjuice
                         * uses immediate follow.
                         *
                         * We report it rather than pretending success.
                         */
                        $data['status']        = 409;
                        $data['following']     = false;
                        $data['requested']     = true;
                        $data['follow_status'] = 'requested';
                        $data['message']       =
                            'The follow was saved as pending unexpectedly.';

                        if (function_exists('bzj_streams_follow_log')) {
                            bzj_streams_follow_log(
                                'XHR_UNEXPECTED_REQUESTED_STATE',
                                array(
                                    'follower_id'  => $follower_id,
                                    'following_id' => $following_id
                                )
                            );
                        }

                    } else {

                        $data['status'] = 500;
                        $data['message'] =
                            'The follow operation did not persist.';

                        if (function_exists('bzj_streams_follow_log')) {
                            bzj_streams_follow_log(
                                'XHR_FOLLOW_POST_WRITE_VERIFICATION_FAILED',
                                array(
                                    'follower_id'  => $follower_id,
                                    'following_id' => $following_id
                                )
                            );
                        }
                    }

                } else {

                    $data['status'] = 500;
                    $data['message'] =
                        'Unable to create the follow.';

                    if (function_exists('bzj_streams_follow_log')) {
                        bzj_streams_follow_log(
                            'XHR_REGISTER_FOLLOW_FAILED',
                            array(
                                'follower_id'  => $follower_id,
                                'following_id' => $following_id
                            )
                        );
                    }
                }
            }
        }
    }

    if (function_exists('Wo_CleanCache')) {
        Wo_CleanCache();
    }

    if (function_exists('bzj_streams_follow_log')) {
        bzj_streams_follow_log(
            'XHR_FINAL_STATE',
            array(
                'follower_id'   => $follower_id,
                'following_id'  => $following_id,
                'status'        => $data['status'],
                'following'     => $data['following'],
                'requested'     => $data['requested'],
                'follow_status' => $data['follow_status'],
                'message'       => $data['message']
            )
        );
    }

    header('Content-Type: application/json; charset=utf-8');

    echo json_encode($data);

    exit();
}
```

This implements the state machine GitHub proposed, but with the Buzzjuice immediate-follow policy made authoritative.

# 6. Replace the JavaScript `Wo_RegisterFollow()`

This is equally important.

The current browser code changes the UI before the AJAX request completes and can explicitly construct:

```text
Requested
```

when `is_confirm_f == 1`. 

That is exactly the wrong architecture for Buzzjuice.

The browser should **never decide the relationship state**.

Replace only the existing JavaScript function around lines 283–372 with:

```javascript
function Wo_RegisterFollow(id, is_confirm, show_modal) {

    var followContainer = $('[id="Follow-' + id + '"]');
    var button = followContainer.find('button').first();

    /*
     * Preserve the existing confirmation modal mechanism.
     *
     * IMPORTANT:
     * is_confirm is intentionally NOT used to create a Requested state.
     * Buzzjuice Streams uses immediate follows.
     */
    if (show_modal === true) {
        $('#unfriend_btn').attr(
            'onclick',
            'Wo_RegisterFollow(' + id + ')'
        );

        $('#un_friend_modal').modal('show');

        return false;
    }

    $('#un_friend_modal').modal('hide');

    if (!button.length || button.prop('disabled')) {
        return false;
    }

    /*
     * Capture the current state only for socket notification handling.
     */
    var wasFollowing =
        button.hasClass('btn-active') ||
        button.hasClass('wo_following_btn');

    var originalHtml = followContainer.html();

    /*
     * Prevent double-click/race conditions while the server
     * processes the relationship.
     */
    button.prop('disabled', true);

    if (typeof bzj_streams_follow_log_client === 'function') {
        bzj_streams_follow_log_client(
            'CLICK',
            {
                following_id: id,
                was_following: wasFollowing
            }
        );
    }

    $.ajax({
        url: Wo_Ajax_Requests_File(),
        type: 'GET',
        dataType: 'json',

        data: {
            f: 'follow_user',
            following_id: id
        }

    }).done(function(data) {

        /*
         * Never change the UI based on the click itself.
         *
         * The server response is authoritative.
         */
        if (!data || data.status != 200) {

            followContainer.html(originalHtml);

            followContainer
                .find('button')
                .prop('disabled', false);

            console.error(
                'Buzzjuice Streams follow request failed.',
                data
            );

            return;
        }

        var currentButton =
            followContainer.find('button').first();

        /*
         * -----------------------------------------------------------
         * AUTHORITATIVE FOLLOWING STATE
         * -----------------------------------------------------------
         */
        if (
            data.following === true ||
            data.follow_status === 'following'
        ) {

            currentButton
                .removeClass(
                    'wo_follow_btn wo_request_btn btn-requested'
                )
                .addClass(
                    'btn-active wo_following_btn'
                )
                .prop('disabled', false);

            currentButton
                .find('.button-text')
                .text(
                    ' <?php echo $wo["lang"]["following_btn"]; ?>'
                );

            /*
             * Socket notification only when a new follow was created.
             */
            if (
                typeof node_socket_flow !== 'undefined' &&
                node_socket_flow == '1' &&
                !wasFollowing &&
                typeof socket !== 'undefined'
            ) {

                socket.emit(
                    'user_notification',
                    {
                        to_id: id,
                        user_id: _getCookie('user_id'),
                        type: 'added'
                    }
                );
            }

            if (
                typeof data.can_send !== 'undefined' &&
                data.can_send == 1
            ) {
                Wo_SendMessages();
            }

            return;
        }

        /*
         * -----------------------------------------------------------
         * REQUESTED STATE
         * -----------------------------------------------------------
         *
         * This is retained as defensive compatibility with existing
         * WoWonder data, but Buzzjuice should not normally reach it.
         */
        if (
            data.requested === true ||
            data.follow_status === 'requested'
        ) {

            currentButton
                .removeClass(
                    'wo_follow_btn btn-active wo_following_btn'
                )
                .addClass(
                    'btn-requested wo_request_btn'
                )
                .prop('disabled', false);

            currentButton
                .find('.button-text')
                .text(
                    ' <?php echo $wo["lang"]["requested"]; ?>'
                );

            console.warn(
                'Buzzjuice Streams returned an unexpected requested state.',
                data
            );

            return;
        }

        /*
         * -----------------------------------------------------------
         * FOLLOW STATE
         * -----------------------------------------------------------
         */
        currentButton
            .removeClass(
                'btn-active wo_following_btn ' +
                'btn-requested wo_request_btn'
            )
            .addClass(
                'wo_follow_btn'
            )
            .prop('disabled', false);

        currentButton
            .find('.button-text')
            .text(
                ' <?php echo $wo["lang"]["follow"]; ?>'
            );

        if (
            typeof node_socket_flow !== 'undefined' &&
            node_socket_flow == '1' &&
            wasFollowing &&
            typeof socket !== 'undefined'
        ) {

            socket.emit(
                'user_notification',
                {
                    to_id: id,
                    user_id: _getCookie('user_id'),
                    type: 'removed'
                }
            );
        }

    }).fail(function(xhr, status, error) {

        /*
         * Restore the original button when the HTTP request itself fails.
         */
        followContainer.html(originalHtml);

        followContainer
            .find('button')
            .prop('disabled', false);

        console.error(
            'Buzzjuice Streams follow AJAX failure.',
            {
                status: status,
                error: error,
                http_status: xhr.status
            }
        );

    });

    return false;
}
```

This directly implements the key GitHub correction: **the browser doesn't change to `Following` or `Requested` until the server has answered.**

# 11. The account-registration issue

I also reviewed the current `Wo_RegisterUser()` and SSO bridge.

There is something worth correcting conceptually.

The current `Wo_RegisterUser()` inserts whatever fields are supplied in `$registration_data`, then creates a `T_USERS_FIELDS` row. It does **not explicitly normalize all account-behaviour fields such as follow/privacy settings**. 

The SSO bridge currently does:

```php
$registration = Wo_RegisterUser([
    'username' => $final_username,
    'email'    => $wp_email,
    'password' => bin2hex(random_bytes(16)),
    'active'   => 1
]);
```

and then expects:

```php
$registration['user_id']
```

even though the current `Wo_RegisterUser()` returns `true` rather than a user array. The bridge has a fallback DB lookup, which is why this can still work, but the contract is inconsistent. 

I would **not rewrite the entire registration system right now**, because that introduces unnecessary risk.

Instead, the follow system should no longer depend on those account attributes.

# 18. Final architecture after these changes

The resulting flow becomes deterministic:

```text
                    BUZZJUICE STREAMS
                           │
                           ▼
                   User taps Follow
                           │
                           ▼
                Wo_RegisterFollow()
                           │
             ┌─────────────┼──────────────┐
             │             │              │
       active row?     inactive row?    no row?
             │             │              │
             ▼             ▼              ▼
        keep one       promote it      INSERT
         active           active        active=1
             │             │              │
             └─────────────┼──────────────┘
                           ▼
                  Verify Wo_Followers
                           │
                           ▼
                   active row exists
                           │
                           ▼
                 JSON: following=true
                           │
                           ▼
                   Browser → Following
```

And unfollow:

```text
Following
    │
    ▼
click
    │
    ▼
Wo_IsFollowing() = true
    │
    ▼
Wo_DeleteFollow()
    │
    ▼
DELETE all matching rows
    │
    ▼
verify / invalidate cache
    │
    ▼
JSON: following=false
    │
    ▼
Browser → Follow
```

There is **no normal Requested state in this model**.

`Requested` remains only as defensive compatibility for old/corrupt data. The server will log it if it unexpectedly survives the new state machine.

4. Replace `Wo_RegisterFollow()`.
