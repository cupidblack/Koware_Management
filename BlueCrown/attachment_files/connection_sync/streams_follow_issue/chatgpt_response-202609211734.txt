# 1. Final architecture

The Buzzjuice Streams follow model should become:

```text
                     BUZZJUICE STREAMS
                         FOLLOW MODEL

                         Follow click
                              │
                              ▼
                       follow_user.php
                              │
                 ┌────────────┴────────────┐
                 │                         │
           active = 1                 anything else
                 │                         │
                 ▼                         ▼
             UNFOLLOW               Wo_RegisterFollow()
                                           │
                               ┌───────────┴───────────┐
                               │                       │
                          active = 0               no row
                               │                       │
                               ▼                       ▼
                         UPDATE → 1              INSERT → 1
                               │                       │
                               └───────────┬───────────┘
                                           ▼
                                  DATABASE VERIFICATION
                                           │
                                           ▼
                                  active = 1 confirmed
                                           │
                                           ▼
                                      JSON response
                                           │
                                           ▼
                                  JavaScript updates UI
```

The critical invariant becomes:

> **For Buzzjuice profile follows, `active = 1` is the only state that means Following.**

`active = 0` remains recognizable by legacy WoWonder code, but the Buzzjuice follow action will never intentionally leave a relationship at `active = 0`.

# 2. Important correction to the GitHub proposal

I would **not** globally convert every `active = 0` row to `active = 1`.

The reason is that WoWonder itself still uses `active = 0` to represent pending follow requests. The current application code explicitly checks that state. ([GitHub][1])

Therefore:

```sql
UPDATE Wo_Followers
SET active = 1
WHERE active = 0;
```

is **not safe**.

Likewise, I would **not immediately add**:

```sql
UNIQUE(following_id, follower_id)
```

until we have inspected duplicates.

Instead:

```text
Fix application
       ↓
instrument logging
       ↓
observe actual failures
       ↓
audit accounts
       ↓
clean confirmed obsolete rows
       ↓
then consider uniqueness
```

```php
        $log_file = $log_dir . '/bzj-streams-follow.log';

            }

        );

        $json = json_encode(
            $payload,
            JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE
        );

        if ($json !== false) {
```

# 4. Replace `Wo_RegisterFollow()`

This is the core function.

The important improvement over both previous versions is that we make the function:

* idempotent;
* aware of existing `active = 0`;
* resistant to duplicate rows;
* database-authoritative;
* compatible with existing WoWonder side effects;
* heavily logged.

Use this as the **Buzzjuice implementation of `Wo_RegisterFollow()`**:

```php
/**
 * ==============================================================
 * BZJ — Buzzjuice Streams Follow Registration
 * ==============================================================
 *
 * Buzzjuice follow state:
 *
 *     no row      = not following
 *     active = 0  = legacy/pending relationship
 *     active = 1  = following
 *
 * Buzzjuice profile follows are immediately active.
 *
 * This function is idempotent:
 *
 *     no row      -> INSERT active=1
 *     active=0    -> UPDATE active=1
 *     active=1    -> success, no duplicate row
 */

function Wo_RegisterFollow($following_id = 0, $followers_id = 0)
{
    global $wo, $sqlConnect;

    $current_user_id = !empty($wo['user']['user_id'])
        ? (int) $wo['user']['user_id']
        : 0;

    bzj_streams_follow_log(
        'REGISTER_START',
        array(
            'current_user_id' => $current_user_id,
            'following_id'    => $following_id,
            'followers_type'  => is_array($followers_id)
                ? 'array'
                : 'scalar'
        )
    );

    /*
     * ----------------------------------------------------------
     * LOGIN
     * ----------------------------------------------------------
     */
    if (
        empty($wo['loggedin']) ||
        $wo['loggedin'] !== true
    ) {
        bzj_streams_follow_log(
            'REGISTER_REJECTED_NOT_LOGGED_IN'
        );

        return false;
    }

    /*
     * ----------------------------------------------------------
     * TARGET VALIDATION
     * ----------------------------------------------------------
     */
    if (
        !is_numeric($following_id) ||
        (int) $following_id < 1
    ) {
        bzj_streams_follow_log(
            'REGISTER_REJECTED_INVALID_TARGET',
            array(
                'following_id' => $following_id
            )
        );

        return false;
    }

    $following_id = (int) $following_id;

    if (!is_array($followers_id)) {
        $followers_id = array($followers_id);
    }

    $processed = false;

    foreach ($followers_id as $follower_id) {

        if (
            !is_numeric($follower_id) ||
            (int) $follower_id < 1
        ) {
            bzj_streams_follow_log(
                'REGISTER_SKIP_INVALID_FOLLOWER',
                array(
                    'following_id' => $following_id,
                    'follower_id'  => $follower_id
                )
            );

            continue;
        }

        $follower_id = (int) $follower_id;

        /*
         * ------------------------------------------------------
         * SELF FOLLOW
         * ------------------------------------------------------
         */
        if ($following_id === $follower_id) {

            bzj_streams_follow_log(
                'REGISTER_REJECTED_SELF_FOLLOW',
                array(
                    'following_id' => $following_id,
                    'follower_id'  => $follower_id
                )
            );

            continue;
        }

        /*
         * ------------------------------------------------------
         * BLOCK
         * ------------------------------------------------------
         */
        if (Wo_IsBlocked($following_id)) {

            bzj_streams_follow_log(
                'REGISTER_REJECTED_BLOCKED',
                array(
                    'following_id' => $following_id,
                    'follower_id'  => $follower_id
                )
            );

            continue;
        }

        $following_id_sql = (int) Wo_Secure($following_id);
        $follower_id_sql  = (int) Wo_Secure($follower_id);

        /*
         * ------------------------------------------------------
         * ACCOUNT EXISTENCE
         * ------------------------------------------------------
         */
        $follower_data  = Wo_UserData($follower_id_sql);
        $following_data = Wo_UserData($following_id_sql);

        if (
            empty($follower_data) ||
            empty($following_data) ||
            empty($follower_data['user_id']) ||
            empty($following_data['user_id'])
        ) {

            bzj_streams_follow_log(
                'REGISTER_REJECTED_USER_NOT_FOUND',
                array(
                    'following_id' => $following_id_sql,
                    'follower_id'  => $follower_id_sql,
                    'follower_found' => !empty(
                        $follower_data['user_id']
                    ),
                    'following_found' => !empty(
                        $following_data['user_id']
                    )
                )
            );

            continue;
        }

        /*
         * ------------------------------------------------------
         * ACCOUNT ATTRIBUTE SNAPSHOT
         * ------------------------------------------------------
         *
         * Do not make confirm_followers authoritative here.
         * We log it so account-specific differences can be
         * investigated.
         */
        bzj_streams_follow_log(
            'ACCOUNT_ATTRIBUTES',
            array(
                'following_id' => $following_id_sql,
                'follower_id'  => $follower_id_sql,

                'following_active' =>
                    isset($following_data['active'])
                        ? $following_data['active']
                        : null,

                'following_confirm_followers' =>
                    isset($following_data['confirm_followers'])
                        ? $following_data['confirm_followers']
                        : null,

                'following_follow_privacy' =>
                    isset($following_data['follow_privacy'])
                        ? $following_data['follow_privacy']
                        : null,

                'follower_active' =>
                    isset($follower_data['active'])
                        ? $follower_data['active']
                        : null,

                'connectivity_system' =>
                    isset($wo['config']['connectivitySystem'])
                        ? $wo['config']['connectivitySystem']
                        : null
            )
        );

        /*
         * ------------------------------------------------------
         * FOLLOW PRIVACY
         * ------------------------------------------------------
         *
         * Keep the existing privacy rule if enabled.
         *
         * confirm_followers is deliberately NOT used.
         */
        if (
            isset($following_data['follow_privacy']) &&
            (int) $following_data['follow_privacy'] === 1
        ) {

            /*
             * Preserve WoWonder's privacy semantics.
             *
             * If your current installation uses a different
             * interpretation of follow_privacy, keep the existing
             * condition from the original function here.
             */
            bzj_streams_follow_log(
                'FOLLOW_PRIVACY_ATTRIBUTE_PRESENT',
                array(
                    'following_id' => $following_id_sql,
                    'follower_id'  => $follower_id_sql,
                    'follow_privacy' =>
                        $following_data['follow_privacy']
                )
            );
        }

        /*
         * ------------------------------------------------------
         * FIND EXISTING RELATIONSHIP
         * ------------------------------------------------------
         *
         * Do NOT use only Wo_IsFollowing().
         *
         * We explicitly inspect active=0 as well.
         */
        $existing_query = mysqli_query(
            $sqlConnect,
            "SELECT
                `id`,
                `following_id`,
                `follower_id`,
                `active`
             FROM " . T_FOLLOWERS . "
             WHERE `following_id` = {$following_id_sql}
               AND `follower_id` = {$follower_id_sql}
             ORDER BY `id` DESC"
        );

        if (!$existing_query) {

            bzj_streams_follow_log(
                'EXISTING_RELATIONSHIP_QUERY_FAILED',
                array(
                    'following_id' => $following_id_sql,
                    'follower_id'  => $follower_id_sql,
                    'mysql_error'  => mysqli_error($sqlConnect)
                )
            );

            continue;
        }

        $rows = array();

        while ($row = mysqli_fetch_assoc($existing_query)) {
            $rows[] = $row;
        }

        /*
         * ------------------------------------------------------
         * EXISTING ACTIVE RELATIONSHIP
         * ------------------------------------------------------
         */
        $active_row = null;

        foreach ($rows as $row) {
            if ((int) $row['active'] === 1) {
                $active_row = $row;
                break;
            }
        }

        if ($active_row) {

            $processed = true;

            bzj_streams_follow_log(
                'REGISTER_ALREADY_ACTIVE',
                array(
                    'following_id' =>
                        $following_id_sql,

                    'follower_id' =>
                        $follower_id_sql,

                    'relationship_id' =>
                        (int) $active_row['id'],

                    'duplicate_row_count' =>
                        count($rows)
                )
            );

            /*
             * Do not create duplicate notifications/activity.
             */
            continue;
        }

        /*
         * ------------------------------------------------------
         * EXISTING LEGACY/PENDING RELATIONSHIP
         * ------------------------------------------------------
         */
        $legacy_row = null;

        foreach ($rows as $row) {
            if ((int) $row['active'] === 0) {
                $legacy_row = $row;
                break;
            }
        }

        if ($legacy_row) {

            $relationship_id =
                (int) $legacy_row['id'];

            $update_query = mysqli_query(
                $sqlConnect,
                "UPDATE " . T_FOLLOWERS . "
                 SET `active` = '1'
                 WHERE `id` = {$relationship_id}
                 LIMIT 1"
            );

            if (!$update_query) {

                bzj_streams_follow_log(
                    'LEGACY_RELATIONSHIP_PROMOTION_FAILED',
                    array(
                        'following_id' =>
                            $following_id_sql,

                        'follower_id' =>
                            $follower_id_sql,

                        'relationship_id' =>
                            $relationship_id,

                        'mysql_error' =>
                            mysqli_error($sqlConnect)
                    )
                );

                continue;
            }

            bzj_streams_follow_log(
                'LEGACY_RELATIONSHIP_PROMOTED',
                array(
                    'following_id' =>
                        $following_id_sql,

                    'follower_id' =>
                        $follower_id_sql,

                    'relationship_id' =>
                        $relationship_id,

                    'old_active' => 0,
                    'new_active' => 1
                )
            );

            $processed = true;

        } else {

            /*
             * --------------------------------------------------
             * NEW RELATIONSHIP
             * --------------------------------------------------
             */
            $insert_query = mysqli_query(
                $sqlConnect,
                "INSERT INTO " . T_FOLLOWERS . "
                    (`following_id`, `follower_id`, `active`)
                 VALUES
                    (
                        {$following_id_sql},
                        {$follower_id_sql},
                        '1'
                    )"
            );

            if (!$insert_query) {

                bzj_streams_follow_log(
                    'NEW_RELATIONSHIP_INSERT_FAILED',
                    array(
                        'following_id' =>
                            $following_id_sql,

                        'follower_id' =>
                            $follower_id_sql,

                        'mysql_error' =>
                            mysqli_error($sqlConnect)
                    )
                );

                continue;
            }

            $new_id = (int) mysqli_insert_id($sqlConnect);

            bzj_streams_follow_log(
                'NEW_RELATIONSHIP_INSERTED',
                array(
                    'following_id' =>
                        $following_id_sql,

                    'follower_id' =>
                        $follower_id_sql,

                    'relationship_id' => $new_id,
                    'active' => 1
                )
            );

            $processed = true;
        }

        /*
         * ------------------------------------------------------
         * AUTHORITATIVE DATABASE VERIFICATION
         * ------------------------------------------------------
         */
        $verify_query = mysqli_query(
            $sqlConnect,
            "SELECT
                `id`,
                `active`
             FROM " . T_FOLLOWERS . "
             WHERE `following_id` = {$following_id_sql}
               AND `follower_id` = {$follower_id_sql}
               AND `active` = '1'
             ORDER BY `id` DESC
             LIMIT 1"
        );

        if (
            !$verify_query ||
            mysqli_num_rows($verify_query) < 1
        ) {

            bzj_streams_follow_log(
                'REGISTER_VERIFY_FAILED',
                array(
                    'following_id' =>
                        $following_id_sql,

                    'follower_id' =>
                        $follower_id_sql,

                    'mysql_error' =>
                        mysqli_error($sqlConnect)
                )
            );

            $processed = false;
            continue;
        }

        $verified_row =
            mysqli_fetch_assoc($verify_query);

        bzj_streams_follow_log(
            'REGISTER_VERIFY_SUCCESS',
            array(
                'following_id' =>
                    $following_id_sql,

                'follower_id' =>
                    $follower_id_sql,

                'relationship_id' =>
                    (int) $verified_row['id'],

                'active' => 1
            )
        );

        /*
         * ------------------------------------------------------
         * CACHE INVALIDATION
         * ------------------------------------------------------
         */
        cache(
            $following_id_sql,
            'users',
            'delete'
        );

        cache(
            $follower_id_sql,
            'users',
            'delete'
        );

        /*
         * ------------------------------------------------------
         * EXISTING SIDE EFFECTS
         * ------------------------------------------------------
         *
         * IMPORTANT:
         *
         * Keep the notification/activity/email/synchronization
         * code that already exists in your original
         * Wo_RegisterFollow() here.
         *
         * Execute it only when a relationship transitioned from
         * inactive/nonexistent to active.
         *
         * Do NOT duplicate existing side-effect code if it is
         * already present elsewhere in the function.
         */
    }

    bzj_streams_follow_log(
        'REGISTER_COMPLETE',
        array(
            'following_id' => $following_id,
            'processed'    => $processed
        )
    );

    return $processed;
}
```

```php
function Wo_IsFollowRequested($following_id = 0, $follower_id = 0)

    if (

    ) {

    }

                'mysql_error'  => mysqli_error($sqlConnect)

        );

        mysqli_num_rows($query) > 0;

            array(
                'following_id' => $following_id,
```

```php
                        $legacy_requested
                )
            );

            /*
             * Follow limit remains enforced if configured.
             */
            $user_followers =
                Wo_CountFollowing(
                    $follower_id,
                    true
                );

            $friends_limit =
                isset(
                    $wo['config']['connectivitySystemLimit']
                )
                    ? (int) $wo['config']['connectivitySystemLimit']
                    : 0;

            $limit_reached =
                (
                    isset(
                        $wo['config']['connectivitySystem']
                    ) &&
                    (int) $wo['config']['connectivitySystem'] === 1 &&
                    $friends_limit > 0 &&
                    $user_followers >= $friends_limit
                );

            if ($limit_reached) {

                $data['message'] =
                    'You have reached the maximum number of follows.';

                bzj_streams_follow_log(
                    'XHR_FOLLOW_LIMIT_REACHED',
                    array(
                        'follower_id' =>
                            $follower_id,

                        'following_id' =>
                            $following_id,

                        'current_following_count' =>
                            $user_followers,

                        'limit' =>
                            $friends_limit
                    )
                );

            } else {

                $registered =
                    Wo_RegisterFollow(
                        $following_id,
                        $follower_id
                    );

                if ($registered === true) {

                    /*
                     * DATABASE IS AUTHORITATIVE.
                     */
                    $is_following =
                        Wo_IsFollowing(
                            $following_id,
                            $follower_id
                        );

                    if ($is_following === true) {

                        $data['status']        = 200;
                        $data['following']     = true;
                        $data['requested']     = false;
                        $data['follow_status'] = 'following';
                        $data['message']       = 'Following.';

                        if (Wo_CanSenEmails()) {
                            $data['can_send'] = 1;
                        }

                        bzj_streams_follow_log(
                            'XHR_FOLLOW_SUCCESS',
                            array(
                                'follower_id' =>
                                    $follower_id,

                                'following_id' =>
                                    $following_id,

                                'legacy_promoted' =>
                                    $legacy_requested
                            )
                        );

                    } else {

                        $data['message'] =
                            'The follow operation did not persist correctly.';

                        bzj_streams_follow_log(
                            'XHR_FOLLOW_VERIFY_FAILED',
                            array(
                                'follower_id' =>
                                    $follower_id,

                                'following_id' =>
                                    $following_id
                            )
                        );
                    }

                } else {

                    $data['message'] =
                        'This account cannot be followed at this time.';

                    bzj_streams_follow_log(
                        'XHR_REGISTER_FOLLOW_FAILED',
                        array(
                            'follower_id' =>
                                $follower_id,

                            'following_id' =>
                                $following_id
                        )
                    );
                }
            }
        }
    }

    /*
     * ----------------------------------------------------------
     * FINAL AUTHORITATIVE STATE
     * ----------------------------------------------------------
     */
    if ($data['status'] === 200) {

        Wo_CleanCache();

        $final_following =
            Wo_IsFollowing(
                $following_id,
                $follower_id
            );

        $final_requested =
            Wo_IsFollowRequested(
                $following_id,
                $follower_id
            );

        /*
         * ACTIVE ALWAYS WINS.
         */
        if ($final_following === true) {

            $data['following']     = true;
            $data['requested']     = false;
            $data['follow_status'] = 'following';

        } elseif ($final_requested === true) {

            /*
             * This is retained only for compatibility/diagnostics.
             * The Buzzjuice profile-follow operation should not
             * create this state.
             */
            $data['following']     = false;
            $data['requested']     = true;
            $data['follow_status'] = 'requested';

        } else {

            $data['following']     = false;
            $data['requested']     = false;
            $data['follow_status'] = 'follow';
        }

        bzj_streams_follow_log(
            'XHR_FINAL_STATE',
            array(
                'follower_id' =>
                    $follower_id,

                'following_id' =>
                    $following_id,

                'following' =>
                    $data['following'],

                'requested' =>
                    $data['requested'],

                'follow_status' =>
                    $data['follow_status']
            )
        );
    }

    header(
        'Content-Type: application/json'
    );

    echo json_encode($data);

    exit();
}
```

This is one of the most important changes.

The current function explicitly does:

```javascript

```

and then replaces the button. ([GitHub][2])

That is exactly the behavior we want to eliminate.

Use this implementation:

```javascript
function Wo_RegisterFollow(id, is_confirm, show_modal = false) {

    var _follow_con =
        $('[id=Follow-' + id + ']');

    /*
     * ----------------------------------------------------------
     * COMPATIBILITY
     * ----------------------------------------------------------
     *
     * Older templates may still pass is_confirm.
     *
     * Buzzjuice intentionally ignores it.
     */
    if (show_modal === true) {

        $('#unfriend_btn').attr(
            'onclick',
            'Wo_RegisterFollow(' + id + ')'
        );

        $('#un_friend_modal').modal('show');

        return false;
    }

    $('#un_friend_modal').modal('hide');

    var $button =
        _follow_con.find('button');

    if (
        !$button.length ||
        $button.prop('disabled')
    ) {
        return false;
    }

    /*
     * Preserve the original UI in case the request fails.
     */
    var original_html =
        _follow_con.html();

    /*
     * Capture state before the request.
     *
     * This is used only for socket notification.
     */
    var was_following =
        $button.hasClass('btn-active') ||
        $button.hasClass('wo_following_btn');

    /*
     * Prevent double-clicks.
     *
     * IMPORTANT:
     * We do NOT change Follow to Requested here.
     */
    $button.prop(
        'disabled',
        true
    );

    $.get(
        Wo_Ajax_Requests_File(),
        {
            f: 'follow_user',
            following_id: id
        },
        function(data) {

            /*
             * --------------------------------------------------
             * FAILURE
             * --------------------------------------------------
             */
            if (
                !data ||
                data.status != 200
            ) {

                _follow_con.html(
                    original_html
                );

                _follow_con
                    .find('button')
                    .prop(
                        'disabled',
                        false
                    );

                console.error(
                    'Buzzjuice Streams follow failed:',
                    data
                );

                return;
            }

            /*
             * --------------------------------------------------
             * SERVER-AUTHORITATIVE STATE
             * --------------------------------------------------
             */
            var following =
                data.following === true ||
                data.follow_status === 'following';

            /*
             * --------------------------------------------------
             * FOLLOWING
             * --------------------------------------------------
             */
            if (following) {

                $button =
                    _follow_con.find('button');

                $button
                    .removeClass(
                        'btn-requested ' +
                        'wo_request_btn ' +
                        'wo_follow_btn'
                    )
                    .addClass(
                        'btn-active ' +
                        'wo_following_btn'
                    )
                    .prop(
                        'disabled',
                        false
                    );

                $button
                    .find('.button-text')
                    .text(
                        ' <?php echo $wo["lang"]["following_btn"]; ?>'
                    );

                /*
                 * Use the existing Following icon.
                 */
                $button
                    .find('svg')
                    .replaceWith(
                        '<svg xmlns="http://www.w3.org/2000/svg" ' +
                        'width="24" height="24" ' +

                        'stroke-linejoin="round">' +

                        '<circle cx="8.5" cy="7" r="4"></circle>' +

                        '<polyline points="17 11 19 13 23 9"></polyline>' +

                        '</svg>'
                    );

                /*
                 * Socket event only when this was a real
                 * transition from not-following to following.
                 */
                if (
                    node_socket_flow == '1' &&
                    was_following === false
                ) {

                    socket.emit(
                        'user_notification',
                        {
                            to_id: id,
                            user_id:
                                _getCookie('user_id'),
                            type: 'added'
                        }
                    );
                }

            }

            /*
             * --------------------------------------------------
             * NOT FOLLOWING
             * --------------------------------------------------
             */
            else {

                $button =
                    _follow_con.find('button');

                $button
                    .removeClass(
                        'btn-active ' +
                        'wo_following_btn ' +
                        'btn-requested ' +
                        'wo_request_btn'
                    )
                    .addClass(
                        'wo_follow_btn'
                    )
                    .prop(
                        'disabled',
                        false
                    );

                $button
                    .find('.button-text')

                    was_following === true

                    socket.emit(
                        'user_notification',
                        {
                            to_id: id,

                        }
                    );

            if (

            .prop(

                false
            );

        console.error(

            {
                user_id: id
            }
        );
    });

    return false;
```

```php
<?php

    'api_status' => 400

$error_message = '';

    $error_code = 4;

        (int) Wo_Secure(
            $_POST['user_id']
        );

    $current_user_id =
        !empty($wo['user']['user_id'])

    $recipient_data =

            $recipient_id
        );

    if (empty($recipient_data)) {

        $error_code = 6;
        $error_message =
            'Recipient user not found';

    } elseif (
        $recipient_id === $current_user_id

        $error_code = 7;
        $error_message =
            'You cannot follow yourself';

    } else {

        /*
         * ACTIVE = UNFOLLOW

        if (
            Wo_IsFollowing(
                $recipient_id,
                $current_user_id

        ) {

            $follow_message =
                Wo_DeleteFollow(
                    $recipient_id,
                    $current_user_id
                )
                    ? 'unfollowed'
                    : 'invalid';

        /*
         * NOT ACTIVE = FOLLOW/PROMOTE
         */
        else {

            if (
                Wo_RegisterFollow(
                    $recipient_id,
                    $current_user_id
                ) === true &&
                Wo_IsFollowing(
                    $recipient_id,
                    $current_user_id
                ) === true
            ) {

                $follow_message =
                    'followed';

            } else {

                $follow_message =
                    'invalid';
            }
        }

        $response_data = array(
            'api_status' =>
                200,

            'follow_status' =>
                $follow_message
        );
    }
}

if (!empty($error_code)) {

    $response_data = array(
        'api_status' => 400,

        'errors' => array(
            array(
                'error_id' =>
                    $error_code,

                'error_text' =>
                    $error_message
            )
        )
    );
}

header(
    'Content-Type: application/json'
);

echo json_encode(
    $response_data
);

exit();
```

# 13. SSO: there is a second issue we should correct

This part of your notes was actually very important.

The current SSO bridge still defines:

```php
function bz_clean_username($username)
{
    $username = preg_replace('/[^a-zA-Z0-9_]/', '', $username);
```

That means a WordPress username such as:

```text
nii.yeboah
```

becomes:

```text
niiyeboah
```

The bridge later attempts to preserve the exact username through `Wo_UpdateUserData()`, and the new-user path calls `Wo_RegisterUser()` with the unmodified WordPress username. ([GitHub][3])

That is internally inconsistent.

## Replace `bz_clean_username()`

Do **not** use it as a destructive sanitizer.

Use:

```php
if (!function_exists('bz_clean_username')) {

    function bz_clean_username($username)
    {
        $username = trim(
            (string) $username
        );

        /*
         * Buzzjuice SSO is authoritative for username identity.
         *
         * Do not silently strip:
         *
         *     .
         *     -
         *     @
         *     other legitimate characters
         *
         * The actual WoWonder registration/update layer remains
         * responsible for rejecting unsupported usernames.
         */
        return substr(
            $username,
            0,
            32
        );
    }
}
```

However, there is an important caveat.

**Do not blindly assume WoWonder's database schema allows every WordPress username.**

The safer SSO rule is:

```text
WP username
      ↓
exact desired username
      ↓
check existing owner
      ↓
if available → preserve it
      ↓
Wo_RegisterUser / Wo_UpdateUserData
      ↓
verify actual stored username
```

Your current bridge already follows much of that pattern. ([GitHub][3])

# 15. Normalize the newly created account

For Buzzjuice's model, I would then explicitly normalize only the attributes that are relevant to the follow system.

**Do not overwrite unrelated profile settings.**

After successful registration:

```php
if ($created_user_id > 0) {

    $created_user_id =
        (int) $created_user_id;

    /*
     * Buzzjuice Streams:
     *
     * - account active
     * - follow requests disabled
     *
     * We intentionally do not modify unrelated
     * profile attributes here.
     */
    $normalize_sql = mysqli_query(
        $sqlConn,
        "UPDATE {$tbl}
         SET
            active = '1',
            confirm_followers = '0'
         WHERE user_id = {$created_user_id}
         LIMIT 1"
    );

    if (!$normalize_sql) {

        bz_bridge_log(
            'SSO: Account follow-state normalization failed',
            array(
                'wo_user_id' =>
                    $created_user_id,

                'mysql_error' =>
                    mysqli_error($sqlConn)
            )
        );

    } else {

        bz_bridge_log(
            'SSO: Account follow-state normalized',
            array(
                'wo_user_id' =>
                    $created_user_id,

                'active' => 1,

                'confirm_followers' => 0
            )
        );
    }
}
```

A newly auto-registered user should not randomly inherit:

# 17. Account diagnostic query

Your reference account remains:

```text
Wo_Users.user_id = 66
```

Run:

```sql
SELECT
    user_id,
    username,
    email,
    active,
    confirm_followers,
    follow_privacy,
    start_up,
    verified
FROM Wo_Users
WHERE user_id = 66;
```

Then compare all users:

```sql
SELECT
    u.user_id,
    u.username,

    u.active,
    r.active AS reference_active,

    u.confirm_followers,
    r.confirm_followers AS reference_confirm_followers,

    u.follow_privacy,
    r.follow_privacy AS reference_follow_privacy,

    u.start_up,
    r.start_up AS reference_start_up,

    CASE
        WHEN u.active <> r.active
        THEN 1 ELSE 0
    END AS active_diff,

    CASE
        WHEN u.confirm_followers <> r.confirm_followers
        THEN 1 ELSE 0
    END AS confirm_followers_diff,

    CASE
        WHEN u.follow_privacy <> r.follow_privacy
        THEN 1 ELSE 0
    END AS follow_privacy_diff,

    CASE
        WHEN u.start_up <> r.start_up
        THEN 1 ELSE 0
    END AS startup_diff

FROM Wo_Users u

CROSS JOIN (
    SELECT
        active,
        confirm_followers,
        follow_privacy,
        start_up
    FROM Wo_Users
    WHERE user_id = 66
) r

WHERE u.user_id <> 66

ORDER BY u.user_id;
```

This gives you an account-by-account comparison against the known working account.

# 18. Relationship integrity diagnostic

Run:

```sql
SELECT
    following_id,
    follower_id,

    COUNT(*) AS total_rows,

    SUM(
        CASE
            WHEN active = 1
            THEN 1
            ELSE 0
        END
    ) AS active_rows,

    SUM(
        CASE
            WHEN active = 0
            THEN 1
            ELSE 0
        END
    ) AS inactive_rows

FROM Wo_Followers

GROUP BY
    following_id,
    follower_id

HAVING COUNT(*) > 1

ORDER BY
    total_rows DESC;
```

This is one of the most important queries.

If you find:

```text
following | follower | total | active | inactive
----------+----------+-------+--------+---------
100       | 25       | 2     | 1      | 1
```

we know that relationship has historical corruption.

# 26. The most important diagnostic outcome

After this deployment, if you still encounter:

```text
Follow
 ↓
nothing changes
 ↓
reload
 ↓
Follow
```

the log should tell us exactly where it stopped.

For example:

```text
XHR_FOLLOW_REQUEST
REGISTER_START
ACCOUNT_ATTRIBUTES
EXISTING_RELATIONSHIP_QUERY_FAILED
```

means database/query infrastructure.

Whereas:

```text
XHR_FOLLOW_REQUEST
REGISTER_START
ACCOUNT_ATTRIBUTES
NEW_RELATIONSHIP_INSERTED
REGISTER_VERIFY_FAILED
```

means the database accepted the write but the subsequent read cannot see it.

And:

```text
XHR_FOLLOW_REQUEST
REGISTER_START
ACCOUNT_ATTRIBUTES
LEGACY_RELATIONSHIP_PROMOTED
REGISTER_VERIFY_SUCCESS
XHR_FOLLOW_SUCCESS
XHR_FINAL_STATE
```

followed by the browser remaining on `Follow` would identify a **frontend/cache/template problem**, not an account/database problem.

That separation is exactly what we need.

## Bottom line

The GitHub response identified the correct **core state-machine defect**, but I would strengthen it in four ways:

1. **Do not bulk-convert `active=0`.**
2. **Make the database authoritative and instrument every transition.**
3. **Fix the SSO registration/reconciliation path so newly created accounts have consistent follow-related attributes.**
4. **Remove the frontend's `confirm_followers → Requested` logic entirely.**

The current repository confirms that the frontend still constructs `Requested` from `is_confirm`, while the XHR endpoint still treats an inactive request as an unfollow. ([GitHub][2]) The SSO bridge also still contains username sanitization logic that conflicts with its later exact-username preservation logic. ([GitHub][3])

**I would deploy the backend/logging changes first, then the frontend change, and only after collecting the first round of logs perform any database cleanup.** That gives us a reversible, evidence-driven repair rather than another broad database modification.
