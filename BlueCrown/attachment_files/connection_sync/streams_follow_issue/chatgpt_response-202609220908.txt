## Diagnosis

I reviewed the current repository versions, the 1,357-line diagnostic log, the previous ChatGPT proposal, and the GitHub review. The GitHub diagnosis is essentially correct, but there is one important refinement:

**The primary failure is not that `Wo_CheckMainSession()` is inherently broken. The immediate failure is that the browser's `Wo_RegisterFollow()` currently does not send `hash_id` at all.** The current function calls:

```javascript
$.get(Wo_Ajax_Requests_File(), {f: 'follow_user', following_id: id}, ...)
```

while `follow_user.php` passes the resulting `$hash_id` to `Wo_CheckMainSession()`. 

At the same time, the SSO bridge creates the normal WoWonder login session but currently only sets:

```php
$_SESSION['user_id']
$_SESSION['wo_user_id']
$_SESSION['wp_Wo_SSO_Login']
```

It does **not** initialize `hash_id` and `main_hash_id`. 

There is also a second architectural issue: the existing WoWonder implementations generate `hash_id` and `main_hash_id` using weak `sha1(rand(...))` values. `hash_id` is 40 characters, while `main_hash_id` is 20 characters. 

The good news is that your diagnostic log actually demonstrates that the PHP session mechanism itself **can** create and retain a 20-character `main_hash_id`. For example, the log shows `create_main_session_created`, followed immediately by `create_main_session_reused` with the same PHP session fingerprint. 

So I would **not remove `Wo_CheckMainSession()`**. We should repair the entire session chain:

```text
WP/BuddyBoss authentication
        ↓
ww-sso-bridge.php
        ↓
PHPSESSID
        ↓
$_SESSION['hash_id']       40 chars
$_SESSION['main_hash_id']  20 chars
        ↓
page renders .main_session
        ↓
Wo_RegisterFollow()
        ↓
hash_id=<main_hash_id>
        ↓
requests.php
        ↓
follow_user.php
        ↓
Wo_CheckMainSession()
        ↓
Wo_RegisterFollow()
```

This preserves the existing security boundary instead of weakening it.

# 1. What the existing evidence tells us

### A. The current session functions are weak but structurally correct

The current repository has:

```php
function Wo_CreateSession() {
    $hash = sha1(rand(1111, 9999));
    ...
}

function Wo_CreateMainSession() {
    $hash = substr(sha1(rand(1111, 9999)), 0, 20);
    ...
}
```

and corresponding equality checks. 

They aren't the source of the follow failure by themselves.

### B. `requests.php` already passes the supplied hash into the XHR environment

It currently looks for:

```php
$_POST['hash_id']
$_GET['hash_id']
$_GET['hash']
$_POST['hash']
```

in that order. 

So the router doesn't need a major redesign.

### C. `follow_user.php` correctly protects the endpoint

The current endpoint performs:

```php
Wo_CheckMainSession($hash_id)
```

before allowing the follow operation. 

That check should stay.

### D. The browser currently doesn't provide the required token

This is the critical defect:

```javascript
$.get(Wo_Ajax_Requests_File(), {f: 'follow_user', following_id: id}, ...)
```

There is no `hash_id`. 

Therefore the server effectively receives:

```text
provided hash = ""
stored main_hash_id = 20-character value
```

and correctly rejects it.

That explains your log:

```json
{
  "event":"endpoint_rejected",
  "context":{
    "reason":"invalid_main_session"
  }
}
```

The reason some accounts appeared to work is therefore important: **those cases aren't proof that the session architecture is correct.** They indicate that those requests reached a different execution state/path or that the follow was already represented differently in WoWonder.

```php
/**
 * -------------------------------------------------------------------------
 * Buzzjuice / WoWonder request-session diagnostics
 * -------------------------------------------------------------------------
 *
 * hash_id:
 *   40 hexadecimal characters.
 *
 * main_hash_id:
 *   20 hexadecimal characters.
 *
 * SECURITY:
 *   Raw session credentials are NEVER written to the diagnostic log.
 *
 * The diagnostic representation contains:
 *   - presence
 *   - length
 *   - SHA-256 fingerprint
 *   - first four characters
 *   - last four characters
 *   - hexadecimal-format validity
 * -------------------------------------------------------------------------
 */

if (!function_exists('Wo_SessionDiagnosticRequestId')) {
    function Wo_SessionDiagnosticRequestId()
    {
        static $request_id = null;

        if ($request_id !== null) {
            return $request_id;
        }

        $request_id = '';

        if (!empty($_SERVER['HTTP_X_REQUEST_ID'])) {
            $request_id = preg_replace(
                '/[^a-zA-Z0-9._-]/',
                '',
                (string) $_SERVER['HTTP_X_REQUEST_ID']
            );
        }

        if (
            $request_id === '' &&
            !empty($_SERVER['UNIQUE_ID'])
        ) {
            $request_id = preg_replace(
                '/[^a-zA-Z0-9._-]/',
                '',
                (string) $_SERVER['UNIQUE_ID']
            );
        }

        if ($request_id === '') {
            try {
                $request_id = bin2hex(random_bytes(8));
            } catch (Throwable $e) {
                $request_id = substr(
                    hash(
                        'sha256',
                        microtime(true) . mt_rand()
                    ),
                    0,
                    16
                );
            }
        }

        return $request_id;
    }
}

if (!function_exists('Wo_SessionValueDiagnostics')) {
    function Wo_SessionValueDiagnostics($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length' => strlen($value),
            'fingerprint' => (
                $value !== ''
                    ? hash('sha256', $value)
                    : ''
            ),
            'first_4_chars' => (
                $value !== ''
                    ? substr($value, 0, 4)
                    : ''
            ),
            'last_4_chars' => (
                $value !== ''
                    ? substr($value, -4)
                    : ''
            ),
            'hex_format' => (
                $value !== ''
                    ? (bool) preg_match(
                        '/^[a-f0-9]+$/i',
                        $value
                    )
                    : false
            )
        );
    }
}

if (!function_exists('Wo_SessionDiagnosticLog')) {
    function Wo_SessionDiagnosticLog(
        $event,
        $context = array()
    ) {
        $log_directory =
            dirname(__DIR__, 3) . '/data/logs';

        if (!is_dir($log_directory)) {
            @mkdir(

            );
        }

        if (!is_array($context)) {
            $context = array(
                'value' => (string) $context
            );
        }

        $session_status =
            function_exists('session_status')

                : -1;

            Wo_SessionDiagnosticRequestId();

        $context['timestamp_utc'] =

        $context['method'] =

        $context['request_uri'] =
            isset($_SERVER['REQUEST_URI'])
                ? (string) $_SERVER['REQUEST_URI']
                : '';

        $context['remote_addr'] =
            isset($_SERVER['REMOTE_ADDR'])

            function_exists('session_name')
                ? session_name()
                : '';

            function_exists('session_name')

                : false;

        $context['php_session_id'] =
            Wo_SessionValueDiagnostics(

            );

        $line = json_encode(

            ),
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR
        );

        if ($line === false) {
            $line = json_encode(
                array(
                    'event' =>
                        'diagnostic_json_encode_failed',
                    'context' => array(
                        'request_id' =>
                            Wo_SessionDiagnosticRequestId(),
                        'timestamp_utc' =>
                            gmdate('c')
                    )
                )
            );
        }

        if ($line !== false) {
            @file_put_contents(
                $log_directory .
                '/session-' .
                gmdate('Y-m-d') .
                '.log',
                $line . PHP_EOL,
                FILE_APPEND | LOCK_EX
            );
        }

if (!function_exists('Wo_EnsurePhpSession')) {
    function Wo_EnsurePhpSession()
    {
        if (
            !function_exists('session_status') ||
            !function_exists('session_start')
        ) {
            Wo_SessionDiagnosticLog(
                'php_session_unavailable',
                array(
                    'session_status_available' =>
                        function_exists('session_status'),
                    'session_start_available' =>
                        function_exists('session_start')
                )
            );

            return false;
        }

        if (
            session_status() === PHP_SESSION_ACTIVE
        ) {
            return true;
        }

        if (
            session_status() !== PHP_SESSION_NONE
        ) {
            Wo_SessionDiagnosticLog(
                'php_session_not_startable',
                array(
                    'session_status' =>
                        session_status()
                )
            );

            return false;
        }

        if (
            headers_sent(
                $headers_file,
                $headers_line
            )
        ) {
            Wo_SessionDiagnosticLog(
                'php_session_start_blocked_headers_sent',
                array(
                    'headers_file' =>
                        $headers_file,
                    'headers_line' =>
                        $headers_line
                )
            );

            return false;
        }

        try {
            $started = @session_start();
        } catch (Throwable $e) {
            Wo_SessionDiagnosticLog(
                'php_session_start_exception',
                array(
                    'error_class' =>
                        get_class($e),
                    'error_message' =>
                        $e->getMessage()
                )
            );

            return false;
        }

        $active =
            $started &&
            session_status() === PHP_SESSION_ACTIVE;

        Wo_SessionDiagnosticLog(
            $active
                ? 'php_session_started'
                : 'php_session_start_failed',
            array(
                'start_return_value' =>
                    $started,
                'session_status_after_start' =>
                    session_status(),
                'session_name' =>
                    session_name(),
                'last_php_error' =>
                    error_get_last()
            )
        );

        return $active;
    }
}

    function Wo_CreateSession()
    {
        if (!Wo_EnsurePhpSession()) {
            Wo_SessionDiagnosticLog(
                'create_session_failed',
                array(
                    'session_key' =>
                        'hash_id',
                    'reason' =>
                        'php_session_not_active'
                )
            );

            return '';
        }

        $existing =
            isset($_SESSION['hash_id'])
                ? (string) $_SESSION['hash_id']
                : '';

        if (
            $existing !== '' &&
            preg_match(

                $existing
            )
        ) {
            Wo_SessionDiagnosticLog(

                )
            );

            return $existing;
        }

        try {
            $hash = bin2hex(

        } catch (Throwable $e) {
            Wo_SessionDiagnosticLog(

                    'session_key' =>
                        'hash_id',
                    'error_class' =>
                        get_class($e),
                    'error_message' =>
                        $e->getMessage()
                )

            'create_session_created',

                'old_value' =>
                    Wo_SessionValueDiagnostics(
                        $old_value
                    ),
                'new_value' =>
                    Wo_SessionValueDiagnostics(
                        $hash
                    ),
                'session_write_pending' =>
                    true
            )
        );

        return $hash;
    }
}

if (!function_exists('Wo_CheckSession')) {
    function Wo_CheckSession($hash = '')
    {
        $provided_hash =
            is_scalar($hash)
                ? (string) $hash
                : '';

        if (!Wo_EnsurePhpSession()) {
            Wo_SessionDiagnosticLog(
                'check_session_failed',
                array(
                    'session_key' =>
                        'hash_id',
                    'reason' =>
                        'php_session_not_active',
                    'provided' =>
                        Wo_SessionValueDiagnostics(
                            $provided_hash
                        )
                )
            );

            return false;
        }

        $stored_hash =
            isset($_SESSION['hash_id'])
                ? (string) $_SESSION['hash_id']
                : '';

        $provided_valid =
            (bool) preg_match(
                '/^[a-f0-9]{40}$/i',
                $provided_hash
            );

        $stored_valid =
            (bool) preg_match(
                '/^[a-f0-9]{40}$/i',
                $stored_hash
            );

        $matches =
            $provided_valid &&
            $stored_valid &&
            hash_equals(
                $stored_hash,
                $provided_hash
            );

        Wo_SessionDiagnosticLog(
            $matches
                ? 'check_session_passed'
                : 'check_session_failed',
            array(
                'session_key' =>
                    'hash_id',
                'provided' =>
                    Wo_SessionValueDiagnostics(
                        $provided_hash
                    ),
                'stored' =>
                    Wo_SessionValueDiagnostics(
                        $stored_hash
                    ),
                'provided_format_valid' =>
                    $provided_valid,
                'stored_format_valid' =>
                    $stored_valid,
                'match' =>
                    $matches,
                'reason' =>
                    $matches
                        ? 'match'
                        : (
                            $provided_hash === ''
                                ? 'empty_provided_hash'
                                : (
                                    $stored_hash === ''
                                        ? 'empty_stored_hash'
                                        : (
                                            !$provided_valid
                                                ? 'invalid_provided_format'
                                                : (
                                                    !$stored_valid
                                                        ? 'invalid_stored_format'
                                                        : 'fingerprints_differ'
                                                )
                                        )
                                )
                        )
            )
        );

        return $matches;
    }
}
```

### Why this version

There are three important improvements over the original:

1. `random_bytes()` instead of `sha1(rand(...))`.
2. `hash_equals()` instead of loose `==`.
3. Full diagnostic fingerprints without logging the actual credential.

And importantly, **we do not close/reopen the PHP session inside these functions**. Your `init.php` already starts the PHP session before `functions_two.php` is loaded.

```php
    $data['status'] = 401;

    $data['error'] =
        'The current user session is invalid.';

    if (
        function_exists(
            'Wo_SessionDiagnosticLog'
        )
    ) {
        Wo_SessionDiagnosticLog(
            'follow_endpoint_rejected',
            array(
                'reason' =>
                    'invalid_current_user',

                'following_id' =>
                    $following_id
            )
        );
    }

    echo json_encode($data);

    exit();
}

/*
 * -------------------------------------------------------------------------
 * Self-follow protection
 * -------------------------------------------------------------------------
 */

if (
    $following_id ===
    $current_user_id
) {

    $data['status'] = 400;

    $data['error'] =
        'You cannot follow yourself.';

    if (
        function_exists(
            'Wo_SessionDiagnosticLog'
        )
    ) {
        Wo_SessionDiagnosticLog(
            'follow_endpoint_rejected',
            array(
                'reason' =>
                    'self_follow',

                'following_id' =>
                    $following_id,

                'current_user_id' =>
                    $current_user_id
            )
        );
    }

    echo json_encode($data);

    exit();
}

/*
 * -------------------------------------------------------------------------
 * Follow operation
 * -------------------------------------------------------------------------
 */

try {

    $user_followers =
        Wo_CountFollowing(
            $current_user_id,
            true
        );

    $friends_limit =
        isset(
            $wo['config']
                ['connectivitySystemLimit']
        )
            ? (int)
                $wo['config']
                    ['connectivitySystemLimit']
            : 0;

    $is_following =
        Wo_IsFollowing(
            $following_id,
            $current_user_id
        ) === true;

    $is_requested =
        Wo_IsFollowRequested(
            $following_id,
            $current_user_id
        ) === true;

    /*
     * Existing relationship/request:
     * remove it.
     */

    if (
        $is_following ||
        $is_requested
    ) {

        $success =
            Wo_DeleteFollow(
                $following_id,
                $current_user_id
            );

        if ($success) {

            $data = array(
                'status' => 200,
                'can_send' => 0,
                'action' => 'removed',
                'following_id' =>
                    $following_id
            );

            if (
                function_exists(
                    'Wo_SessionDiagnosticLog'
                )
            ) {
                Wo_SessionDiagnosticLog(
                    'follow_endpoint_completed',
                    array(
                        'action' =>
                            'removed',

                        'following_id' =>
                            $following_id,

                        'current_user_id' =>
                            $current_user_id
                    )
                );
            }

        } else {

            $data['status'] = 500;

            $data['error'] =
                'Unable to remove the follow relationship.';
        }

    /*
     * Follow limit.
     */

    } elseif (
        isset(
            $wo['config']
                ['connectivitySystem']
        ) &&
        (int)
            $wo['config']
                ['connectivitySystem'] === 1 &&
        $friends_limit > 0 &&
        $user_followers >=
            $friends_limit
    ) {

        $data = array(
            'status' => 400,
            'can_send' => 0,
            'error' =>
                'You have reached the follow limit.'
        );

        if (
            function_exists(
                'Wo_SessionDiagnosticLog'
            )
        ) {
            Wo_SessionDiagnosticLog(
                'follow_endpoint_rejected',
                array(
                    'reason' =>
                        'follow_limit_reached',

                    'following_id' =>
                        $following_id,

                    'current_user_id' =>
                        $current_user_id,

                    'user_followers' =>
                        $user_followers,

                    'friends_limit' =>
                        $friends_limit
                )
            );
        }

    /*
     * New follow.
     */

    } else {

        $success =
            Wo_RegisterFollow(
                $following_id,
                $current_user_id
            );

        if ($success) {

            $can_send = 0;

            if (
                function_exists(
                    'Wo_CanSenEmails'
                ) &&
                Wo_CanSenEmails()
            ) {
                $can_send = 1;
            }

            $data = array(
                'status' => 200,
                'can_send' => $can_send,
                'action' => 'added',
                'following_id' =>
                    $following_id
            );

            if (
                function_exists(
                    'Wo_SessionDiagnosticLog'
                )
            ) {
                Wo_SessionDiagnosticLog(
                    'follow_endpoint_completed',
                    array(
                        'action' =>
                            'added',

                        'following_id' =>
                            $following_id,

                        'current_user_id' =>
                            $current_user_id,

                        'can_send' =>
                            $can_send
                    )
                );
            }

        } else {

            $data['status'] = 500;

            $data['error'] =
                'Unable to create the follow relationship.';

            if (
                function_exists(
                    'Wo_SessionDiagnosticLog'
                )
            ) {
                Wo_SessionDiagnosticLog(
                    'follow_endpoint_failed',
                    array(
                        'reason' =>
                            'register_follow_failed',

                        'following_id' =>
                            $following_id,

                        'current_user_id' =>
                            $current_user_id
                    )
                );
            }
        }
    }

} catch (Throwable $e) {

    $data = array(
        'status' => 500,
        'can_send' => 0,
        'error' =>
            'An internal error occurred while processing the follow request.'
    );

    if (
        function_exists(
            'Wo_SessionDiagnosticLog'
        )
    ) {
        Wo_SessionDiagnosticLog(
            'follow_endpoint_exception',
            array(
                'following_id' =>
                    $following_id,

                'current_user_id' =>
                    $current_user_id,

                'error_class' =>
                    get_class($e),

                'error_message' =>
                    $e->getMessage()
            )
        );
    }
}

if (!empty($wo['loggedin'])) {
    Wo_CleanCache();
}

echo json_encode($data);

exit();
```

This version retains the security check while making every failure explicit. The GitHub proposal follows the same principle.

# 12. What we should NOT change

There are several tempting changes I specifically do **not** recommend.

### Do not remove:

```php
Wo_CheckMainSession($hash_id)
```

from `follow_user.php`.

That merely hides the defect and weakens the endpoint.

### Do not make `Wo_CheckMainSession()` automatically create a session

For example, don't do:

```php
if (!$stored) {
    Wo_CreateMainSession();
}
```

inside the checker.

That would make an invalid/missing request token potentially become valid merely because the server generated a new one.

The proper sequence is:

```text
Create → render → submit → validate
```

not:

```text
Validate → silently create → accept
```

### Do not put the full hash in logs

The fingerprint is sufficient to establish:

```text
A == B
```

without putting the credential itself into your logs.

### Do not modify `sso-session-sync.php` yet

There is currently no evidence that it is destroying or replacing the Streams PHP session. Its source doesn't call `session_start()` or `session_name()`.

# 18. One important correction to the previous implementation

The previous diagnostic implementation appears to have been successful enough to prove that the session functions were running, but it exposed an architectural mistake in the client/server contract.

The server expects:

```text
main_hash_id
```

but the client wasn't actually sending it.

The distinction is:

| Value               |       Length | Purpose                           |
| ------------------- | -----------: | --------------------------------- |
| `hash_id`           |           40 | WoWonder request/session token    |
| `main_hash_id`      |           20 | Main request-security token       |
| PHP session ID      | typically 32 | Identifies the PHP session itself |
| SHA-256 fingerprint |           64 | **Diagnostic only**               |

The **64-character fingerprint must never be mistaken for the token**.

This is particularly important because the earlier diagnostic log makes the fingerprints visible and therefore it would be easy for a later patch to accidentally use one as the actual request credential.

# 19. Expected end state

Once this patch is deployed, the normal Follow operation should become:

```text
1. SSO login
       ↓
2. PHP session established
       ↓
3. Wo_CreateSession()
       ↓
4. Wo_CreateMainSession()
       ↓
5. values stored in $_SESSION
       ↓
6. main_hash_id rendered into .main_session
       ↓
7. JavaScript reads .main_session
       ↓
8. AJAX sends hash_id=<main_hash_id>
       ↓
9. requests.php receives it
       ↓
10. follow_user.php receives it
       ↓
11. Wo_CheckMainSession()
       ↓
12. fingerprint matches
       ↓
13. Wo_RegisterFollow()
       ↓
14. database changes
       ↓
15. HTTP 200
       ↓
16. UI remains consistent
       ↓
17. reload reads actual database state
```

That is the architecture I would use going forward.

### Most important implementation order

**Deploy in this order:**

1. `functions_two.php` — session functions + diagnostics.
2. `ww-sso-bridge.php` — initialize both hashes during SSO + repair fast path.
3. Active Sunshine container/layout — render `.main_session`.
4. `content.phtml` — send `hash_id`.
5. `requests.php` — add router diagnostics.
6. `follow_user.php` — use the hardened endpoint.
7. **Do not touch `sso-session-sync.php` yet.**
8. Log out → clear session → log in → perform the four tests above.

The key success criterion before we investigate anything else is:

```text
PAGE main_hash fingerprint
            =
AJAX supplied hash fingerprint
            =
$_SESSION['main_hash_id'] fingerprint
```

Once that is true, `Wo_CheckMainSession()` should stop being the blocker, and we can cleanly determine whether your **automatic acceptance modification to `Wo_RegisterFollow()`** is behaving correctly.
