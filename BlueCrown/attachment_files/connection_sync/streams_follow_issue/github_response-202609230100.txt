The evidence points to **two separate problems**:

1. `streams/assets/init.php` currently starts the default PHP session before configuring the Streams session.
2. `streams/requests.php` accepts `hash_id` only from the request. If the follow request does not send `hash_id`, then `Wo_CheckMainSession($hash_id)` receives an empty value even when `$_SESSION['main_hash_id']` exists.

Therefore, forcing `Wo_CheckMainSession()` to return `true` masks both the session-continuity problem and the missing-request-token problem. Do not leave it permanently bypassed.

The browser data shows that the intended separation is already possible:

```text
BUZZSTREAMSESSID  Path=/streams
PHPSESSID         Path=/
```

Streams should use `BUZZSTREAMSESSID`; QuickDate should continue using its own session. The two applications should not share or synchronize the same PHP session.

Also remove all `print_r()` calls from session functions. They can corrupt JSON responses from AJAX requests.

```text
/buzzjuice.net/streams/data/logs
```

```php name=streams/assets/init.php
if (!function_exists('bz_session_value_diagnostic')) {
    function bz_session_value_diagnostic($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length' => strlen($value),
            'fingerprint' => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format' => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}

if (!function_exists('bz_session_safe_scalar')) {
    function bz_session_safe_scalar($value)
    {
        if (is_bool($value)) {
            return $value;
        }

        if (is_int($value) || is_float($value)) {
            return $value;
        }

        if (is_string($value)) {
            return array(
                'type' => 'string',
                'length' => strlen($value),
                'fingerprint' => $value !== ''
                    ? hash('sha256', $value)
                    : ''
            );
        }

        if (is_array($value)) {
            return array(
                'type' => 'array',
                'keys' => array_keys($value),
                'count' => count($value)
            );
        }

        if (is_object($value)) {
            return array(
                'type' => 'object',
                'class' => get_class($value)
            );
        }

        if ($value === null) {
            return array(
                'type' => 'null'
            );
        }

        return array(
            'type' => gettype($value)
        );
    }
}

if (!function_exists('bz_session_cookie_diagnostics')) {
    function bz_session_cookie_diagnostics()
    {
        $names = array(
            'BUZZSTREAMSESSID',
            'BUZZSOCIALSESSID',
            'PHPSESSID',
            'buzz_sso',
            'buzz_access',
            'buzz_refresh',
            'user_id',
            'JWT'
        );

        $result = array();

        foreach ($names as $name) {
            $present = isset($_COOKIE[$name]);
            $value = $present ? (string) $_COOKIE[$name] : '';

            $result[$name] = array(
                'present' => $present,
                'length' => strlen($value),
                'fingerprint' => $value !== ''
                    ? hash('sha256', $value)
                    : ''
            );
        }

        return $result;
    }
}

if (!function_exists('bz_session_safe_request_uri')) {
    function bz_session_safe_request_uri()
    {
        $uri = isset($_SERVER['REQUEST_URI'])
            ? (string) $_SERVER['REQUEST_URI']
            : '';

        if ($uri === '') {
            return '';
        }

        return preg_replace(
            '/([?&](?:hash_id|hash|sso_token|buzz_access|buzz_refresh|token|password|secret)=)[^&]*/i',
            '$1[REDACTED]',
            $uri
        );
    }
}

if (!function_exists('bz_session_trace')) {
    function bz_session_trace($limit = 15)
    {
        $trace = array();

        $frames = debug_backtrace(
            DEBUG_BACKTRACE_IGNORE_ARGS,
            (int) $limit
        );

        foreach ($frames as $frame) {
            $trace[] = array(
                'file' => isset($frame['file'])
                    ? basename((string) $frame['file'])
                    : '',
                'line' => isset($frame['line'])
                    ? (int) $frame['line']
                    : 0,
                'class' => isset($frame['class'])
                    ? (string) $frame['class']
                    : '',
                'type' => isset($frame['type'])
                    ? (string) $frame['type']
                    : '',
                'function' => isset($frame['function'])
                    ? (string) $frame['function']
                    : ''
            );
        }

        return $trace;
    }
}

if (!function_exists('bz_session_state_snapshot')) {
    function bz_session_state_snapshot()
    {
        $status = function_exists('session_status')
            ? session_status()
            : -1;

        $session_id = '';

        if (
            $status === PHP_SESSION_ACTIVE &&
            function_exists('session_id')
        ) {
            $session_id = (string) session_id();
        }

        $session_name = function_exists('session_name')
            ? (string) session_name()
            : '';

        $cookie_params = function_exists('session_get_cookie_params')
            ? session_get_cookie_params()
            : array();

        $hash_id = '';
        $main_hash_id = '';

        if (isset($_SESSION) && is_array($_SESSION)) {
            if (isset($_SESSION['hash_id'])) {
                $hash_id = $_SESSION['hash_id'];
            }

            if (isset($_SESSION['main_hash_id'])) {
                $main_hash_id = $_SESSION['main_hash_id'];
            }
        }

        return array(
            'session_status' => $status,
            'session_status_name' =>
                ($status === PHP_SESSION_DISABLED)
                    ? 'PHP_SESSION_DISABLED'
                    : (
                        ($status === PHP_SESSION_NONE)
                            ? 'PHP_SESSION_NONE'
                            : (
                                ($status === PHP_SESSION_ACTIVE)
                                    ? 'PHP_SESSION_ACTIVE'
                                    : 'UNKNOWN'
                            )
                    ),

            'session_name' => $session_name,

            'session_cookie_present' =>
                ($session_name !== '' &&
                 isset($_COOKIE[$session_name])),

            'session_id' =>
                bz_session_value_diagnostic($session_id),

            'session_save_path' =>
                function_exists('session_save_path')
                    ? (string) session_save_path()
                    : '',

            'session_save_handler' =>
                function_exists('ini_get')
                    ? (string) ini_get('session.save_handler')
                    : '',

            'session_serialize_handler' =>
                function_exists('ini_get')
                    ? (string) ini_get('session.serialize_handler')
                    : '',

            'session_use_cookies' =>
                function_exists('ini_get')
                    ? (string) ini_get('session.use_cookies')
                    : '',

            'session_use_only_cookies' =>
                function_exists('ini_get')
                    ? (string) ini_get('session.use_only_cookies')
                    : '',

            'session_use_strict_mode' =>
                function_exists('ini_get')
                    ? (string) ini_get('session.use_strict_mode')
                    : '',

            'session_cookie_params' => array(
                'lifetime' => isset($cookie_params['lifetime'])
                    ? (int) $cookie_params['lifetime']
                    : 0,

                'path' => isset($cookie_params['path'])
                    ? (string) $cookie_params['path']
                    : '',

                'domain' => isset($cookie_params['domain'])
                    ? (string) $cookie_params['domain']
                    : '',

                'secure' => !empty($cookie_params['secure']),
                'httponly' => !empty($cookie_params['httponly']),

                'samesite' => isset($cookie_params['samesite'])
                    ? (string) $cookie_params['samesite']
                    : ''
            ),

            'incoming_cookies' =>
                bz_session_cookie_diagnostics(),

            'hash_id' =>
                bz_session_value_diagnostic($hash_id),

            'main_hash_id' =>
                bz_session_value_diagnostic($main_hash_id),

            'request_hash_id' =>
                bz_session_value_diagnostic(
                    isset($GLOBALS['hash_id'])
                        ? $GLOBALS['hash_id']
                        : ''
                ),

            'session_keys' =>
                bz_session_sanitized_session_keys(),

            'wo_user_id' =>
                isset($_SESSION['wo_user_id'])
                    ? (int) $_SESSION['wo_user_id']
                    : 0
        );
    }
}

if (!function_exists('Wo_SessionDiagnosticLog')) {
    function Wo_SessionDiagnosticLog($event, $context = array())
    {
        $file = bz_stream_session_log_path();
        $directory = dirname($file);

        if (!is_dir($directory)) {
            @mkdir($directory, 0750, true);
        }

        if (!is_array($context)) {
            $context = array(
                'value' => bz_session_safe_scalar($context)
            );
        }

        $context['timestamp_utc'] = gmdate('c');
        $context['pid'] = function_exists('getmypid')
            ? (int) getmypid()
            : 0;

        $context['sapi'] = function_exists('php_sapi_name')
            ? php_sapi_name()
            : '';

        $context['request_method'] =
            isset($_SERVER['REQUEST_METHOD'])
                ? (string) $_SERVER['REQUEST_METHOD']
                : '';

        $context['request_uri'] =
            bz_session_safe_request_uri();

        $context['script_filename'] =
            isset($_SERVER['SCRIPT_FILENAME'])
                ? basename((string) $_SERVER['SCRIPT_FILENAME'])
                : '';

        $context['http_host'] =
            isset($_SERVER['HTTP_HOST'])
                ? (string) $_SERVER['HTTP_HOST']
                : '';

        $context['log_file'] = $file;
        $context['log_directory_exists'] = is_dir($directory);
        $context['log_directory_writable'] = is_writable($directory);

        $context['session_state'] =
            bz_session_state_snapshot();

        $context['trace'] =
            bz_session_trace(15);

        $record = array(
            'event' => (string) $event,
            'context' => $context
        );

        $json = json_encode(
            $record,
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR
        );

        if ($json === false) {
            return false;
        }

        $written = @file_put_contents(
            $file,
            $json.PHP_EOL,
            FILE_APPEND | LOCK_EX
        );

        return ($written !== false);
    }
}

if (!function_exists('bz_safe_session_start')) {
    function bz_safe_session_start()
    {
        if (!function_exists('session_status')) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'session_status_unavailable'
                )
            );

            return false;
        }

        if (session_status() === PHP_SESSION_ACTIVE) {
            Wo_SessionDiagnosticLog(
                'session_already_active'
            );

            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'session_not_startable',
                    'session_status' => session_status()
                )
            );

            return false;
        }

        if (headers_sent($headers_file, $headers_line)) {
            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' => 'headers_already_sent',
                    'headers_file' => $headers_file,
                    'headers_line' => (int) $headers_line
                )
            );

            return false;
        }

        $before_id = function_exists('session_id')
            ? (string) session_id()
            : '';

        $started = false;

        try {
            $started = session_start();
        } catch (Throwable $exception) {
            Wo_SessionDiagnosticLog(
                'session_start_exception',
                array(
                    'exception_class' => get_class($exception),
                    'exception_message' => $exception->getMessage()
                )
            );

            return false;
        }

        $active = (
            $started &&
            session_status() === PHP_SESSION_ACTIVE
        );

        Wo_SessionDiagnosticLog(
            $active
                ? 'session_started'
                : 'session_start_failed',
            array(
                'start_return_value' => (bool) $started,
                'before_session_id' =>
                    bz_session_value_diagnostic($before_id),
                'after_session_id' =>
                    bz_session_value_diagnostic(
                        function_exists('session_id')
                            ? session_id()
                            : ''
                    ),
                'last_error' => error_get_last()
            )
        );

        return $active;
    }
}
```

```php name=streams/assets/includes/functions_two.php
if (!function_exists('Wo_CreateSession')) {
    function Wo_CreateSession()
    {
        if (!Wo_EnsureSessionActive()) {
            Wo_SessionHashLog(
                'create_hash_id_failed',
                array(
                    'session_key' => 'hash_id',
                    'reason' => 'php_session_not_active'
                )
            );

            return '';
        }

        $existing = isset($_SESSION['hash_id'])
            ? (string) $_SESSION['hash_id']
            : '';

        if (preg_match('/^[a-f0-9]{40}$/i', $existing)) {
            Wo_SessionHashLog(
                'create_hash_id_reused',
                array(
                    'session_key' => 'hash_id',
                    'value' => Wo_SessionHashDiagnostic($existing)
                )
            );

            return $existing;
        }

        if ($existing !== '') {
            Wo_SessionHashLog(
                'create_hash_id_replaced_invalid_value',
                array(
                    'session_key' => 'hash_id',
                    'old_value' => Wo_SessionHashDiagnostic($existing)
                )
            );
        }

        try {
            $hash = bin2hex(random_bytes(20));
        } catch (Throwable $exception) {
            Wo_SessionHashLog(
                'create_hash_id_random_generation_failed',
                array(
                    'session_key' => 'hash_id',
                    'exception_class' => get_class($exception),
                    'exception_message' => $exception->getMessage()
                )
            );

            return '';
        }

        $_SESSION['hash_id'] = $hash;

        Wo_SessionHashLog(

    function Wo_CheckSession($hash = '')
    {
        $provided = is_scalar($hash)
            ? trim((string) $hash)
            : '';

        if (!Wo_EnsureSessionActive()) {
            Wo_SessionHashLog(
                'check_hash_id_failed',
                array(
                    'session_key' => 'hash_id',
                    'reason' => 'php_session_not_active',
                    'provided' => Wo_SessionHashDiagnostic($provided)
                )
            );

            return false;
        }

        $stored = isset($_SESSION['hash_id'])
            ? (string) $_SESSION['hash_id']
            : '';

        $provided_valid = (bool) preg_match(
            '/^[a-f0-9]{40}$/i',
            $provided
        );

        $stored_valid = (bool) preg_match(
            '/^[a-f0-9]{40}$/i',
            $stored
        );

        $matched = (
            $provided_valid &&
            $stored_valid &&
            hash_equals($stored, $provided)
        );

        Wo_SessionHashLog(
            $matched
                ? 'check_hash_id_passed'
                : 'check_hash_id_failed',
            array(
                'session_key' => 'hash_id',
                'reason' => $matched
                    ? 'hash_match'
                    : 'missing_invalid_or_mismatched_hash',
                'provided' => Wo_SessionHashDiagnostic($provided),
                'stored' => Wo_SessionHashDiagnostic($stored),
                'provided_valid' => $provided_valid,
                'stored_valid' => $stored_valid,
                'matched' => $matched
            )
        );

        return $matched;
    }
}

            'create_main_hash_id_created',

                'session_key' => 'main_hash_id',

                'new_value' => Wo_SessionHashDiagnostic($hash),
```

# 4. Important correction regarding `hash_id`

The logging will prove whether the session is continuous, but it will not make a missing AJAX parameter appear.

`streams/requests.php` currently resolves the request token like this:

```php
$hash_id = '';

if (!empty($_POST['hash_id'])) {
    $hash_id = $_POST['hash_id'];
} else if (!empty($_GET['hash_id'])) {
    $hash_id = $_GET['hash_id'];
} else if (!empty($_GET['hash'])) {
    $hash_id = $_GET['hash'];
} else if (!empty($_POST['hash'])) {
    $hash_id = $_POST['hash'];
}
```

The session value and the request value are separate:

```text
$_SESSION['main_hash_id']     = stored session token
$_POST['hash_id']              = client-supplied token
```

`Wo_CheckMainSession()` correctly rejects an empty request token. If the follow request does not submit `hash_id`, the log should show something similar to:

```json
{
  "event": "check_main_hash_id_failed",
  "context": {
    "reason": "missing_invalid_or_mismatched_hash",
    "provided": {
      "present": false,
      "length": 0
    },
    "stored": {
      "present": true,
      "length": 20
    },
    "provided_valid": false,
    "stored_valid": true,
    "matched": false
  }
}
```

That result means the PHP session is working, but the request is missing the token.

The requested constraint says not to modify `follow_user.php` or theme files. That is acceptable for this investigation, but the final fix may still require the existing client-side request to include the correct token. The new logging will distinguish this from session loss.

# 6. How to interpret the generated log

## Healthy session continuity

A healthy request sequence should show:

```text
streams_session_configuration_before_start
session_started
create_hash_id_created
create_main_hash_id_created
create_hash_id_reused
create_main_hash_id_reused
check_main_hash_id_passed
request_shutdown_session_state
```

Across requests, the following should remain consistent:

- `session_name` is `BUZZSTREAMSESSID`.
- `session_cookie_present` is `true`.
- The session ID fingerprint remains the same.
- `session_save_path` remains the same.
- `hash_id` fingerprint remains the same.
- `main_hash_id` fingerprint remains the same.
- `session_keys` continue to include both hash keys.

## Session replacement or loss

These events indicate session continuity problems:

```text
session_start_failed
session_start_exception
create_hash_id_created
create_main_hash_id_created
```

appearing repeatedly on normal page loads.

If a new hash is created with a different session ID fingerprint, investigate:

- Cookie path mismatch.
- Cookie domain mismatch.
- HTTPS or `Secure` mismatch.
- PHP-FPM workers using different session storage.
- Different `session.save_path` values.
- Session garbage collection.
- A second `session_start()` using another session name.
- Code calling `session_destroy()`.
- SSO code clearing `$_SESSION`.

## Hash present but request missing

This is the likely explanation for the follow behavior:

```text
stored main_hash_id: present
provided request hash: absent
check_main_hash_id_failed
```

In that case, the session is not necessarily broken. The request simply does not contain the token expected by the validation function.

## Hash changes within the same session

If the same session ID fingerprint shows:

```text
create_main_hash_id_replaced_invalid_value
```

or a new hash fingerprint, then some code is modifying or clearing:

```php
$_SESSION['main_hash_id']
```

The trace associated with the event shows the code path that reached the session function. Direct writes elsewhere will be visible through the before/after snapshots, but PHP cannot automatically intercept every direct assignment to `$_SESSION`. If the shutdown snapshot shows a change without a corresponding hash-function event, search the repository for:

```text
$_SESSION['hash_id']
$_SESSION['main_hash_id']
unset($_SESSION
session_unset
session_destroy
$_SESSION =
session_regenerate_id
```

The QuickDate code is especially important because it contains legacy session-clearing logic, including:

```php
$_SESSION = [];
session_unset();
session_destroy();
```

That code should not run against the Streams session. The cookie separation prevents normal `/social` requests from using the Streams session, but any bridge or shared bootstrap that starts the wrong session before Streams initialization can still cause interference.

# 7. Expected conclusion from the investigation

The final diagnosis will probably be one of these:

### Case A — Session continuity is correct, request token is missing

The log will show:

```text
BUZZSTREAMSESSID remains stable
main_hash_id remains stable
provided request hash is empty
```

This means the follow request is not submitting the required token. The session functions are working correctly.

### Case B — Streams is receiving a new session

The log will show:

```text
BUZZSTREAMSESSID changes between requests
session ID fingerprint changes
hashes are recreated
```

This indicates a cookie, path, domain, HTTPS, save-path or session-handler problem.

### Case C — QuickDate or SSO clears the Streams session

The log will show:

```text
hashes exist earlier in the request
hashes disappear by shutdown
```

or a new session appears immediately after a bridge request. In that case, inspect bridge calls and session-destruction code.

The most important immediate correction is to restore real validation, configure the Streams session before startup, and use the new log to determine whether the failure is caused by **session loss** or by an **empty `hash_id` request parameter**.
