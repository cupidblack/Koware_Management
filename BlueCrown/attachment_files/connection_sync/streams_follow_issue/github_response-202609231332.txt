The strongest evidence points to **session separation and session lifecycle interference**, not to the follow implementation itself.

## Findings

1. `hash_id` and `main_hash_id` are stored in `$_SESSION`; they will not appear as separate browser cookies.
2. `BUZZSTREAMSESSID` is the relevant browser cookie for Streams. `PHPSESSID` belongs to another application/session context.
3. The 64-character values are almost certainly SHA-256 fingerprints produced by the diagnostic code. Native WoWonder values are:
   - `hash_id`: 40-character SHA-1 value
   - `main_hash_id`: 20-character SHA-1-derived value
4. The existing `init.php` starts the session before explicitly selecting the Streams session name. That allows Streams to accidentally start using `PHPSESSID`.
5. `ww-sso-bridge.php` destroys the active session when it does not detect a WordPress login cookie. If the wrong session is active, this can remove `hash_id` and `main_hash_id`.
6. QuickDate must not use or destroy the Streams session.
7. This debug statement is unreachable:

```php
return true;
print_r(...);
```

8. The current creation functions do not modify an existing hash. These assignments are redundant:

```php
$_SESSION['hash_id'] = $_SESSION['hash_id'];
$_SESSION['main_hash_id'] = $_SESSION['main_hash_id'];
```

9. The repository-wide code search is limited to the first ten matches per search, so the search output is not necessarily complete. Continue checking the full results in GitHub’s code-search interface:

```php name=streams/assets/init.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/assets/init.php
if (!function_exists('bz_session_request_id')) {
    function bz_session_request_id()
    {
        static $request_id = null;

        if ($request_id !== null) {
            return $request_id;
        }

        try {
            $request_id = bin2hex(random_bytes(12));
        } catch (Throwable $exception) {
            $request_id = substr(
                sha1(uniqid('', true).microtime(true).mt_rand()),
                0,
                24
            );
        }

        return $request_id;
    }
}

if (!function_exists('bz_session_fingerprint')) {
    function bz_session_fingerprint($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string)$value;

        return array(
            'present' => ($value !== ''),
            'length'  => strlen($value),
            'sha256'  => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format'  => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}

if (!function_exists('bz_session_safe_uri')) {
    function bz_session_safe_uri()
    {
        $uri = isset($_SERVER['REQUEST_URI'])
            ? (string)$_SERVER['REQUEST_URI']
            : '';

        if ($uri === '') {
            return '';
        }

        return preg_replace(
            '/([?&](?:hash|hash_id|token|sso_token|buzz_sso|buzz_access|buzz_refresh|password|secret)=)[^&]*/i',
            '$1[REDACTED]',
            $uri
        );
    }
}

if (!function_exists('bz_session_resolved_save_path')) {
    function bz_session_resolved_save_path()
    {
        $path = function_exists('session_save_path')
            ? (string)session_save_path()
            : '';

        if ($path === '') {
            return '';
        }

        /*
         * PHP may return:
         *
         *     N;/path/to/sessions
         *     N;MODE;/path/to/sessions
         */
        if (strpos($path, ';') !== false) {
            $parts = explode(';', $path);
            $path = end($parts);
        }

        return rtrim($path, DIRECTORY_SEPARATOR);
    }
}

                : 0;
            $result['session_file_mtime'] = is_file($session_file)

if (!function_exists('bz_session_state_snapshot')) {
    function bz_session_state_snapshot()
    {
        $status = function_exists('session_status')
            ? session_status()
            : -1;

        $hash_id = '';
        $main_hash_id = '';
        $request_hash_id = '';

        if (isset($_SESSION) && is_array($_SESSION)) {
            if (isset($_SESSION['hash_id'])) {
                $hash_id = $_SESSION['hash_id'];
            }

            if (isset($_SESSION['main_hash_id'])) {
                $main_hash_id = $_SESSION['main_hash_id'];
            }
        }

        if (isset($GLOBALS['hash_id'])) {
            $request_hash_id = $GLOBALS['hash_id'];
        }

        $cookie_params = function_exists('session_get_cookie_params')
            ? session_get_cookie_params()
            : array();

        $encoded_session = '';

        if ($status === PHP_SESSION_ACTIVE) {
            $encoded_session = @session_encode();

            if ($encoded_session === false) {
                $encoded_session = '';
            }

        return array(
            'session_status' => $status,
            'session_name' => function_exists('session_name')
                ? (string)session_name()
                : '',
            'session_id' => bz_session_fingerprint(
                function_exists('session_id')
                    ? session_id()
                    : ''
            ),
            'session_cookie_present' => (
                function_exists('session_name') &&
                isset($_COOKIE[session_name()])
            ),
            'cookie_params' => array(
                'path' => isset($cookie_params['path'])
                    ? (string)$cookie_params['path']
                    : '',
                'domain' => isset($cookie_params['domain'])
                    ? (string)$cookie_params['domain']
                    : '',
                'secure' => !empty($cookie_params['secure']),
                'httponly' => !empty($cookie_params['httponly']),
                'samesite' => isset($cookie_params['samesite'])
                    ? (string)$cookie_params['samesite']
                    : ''
            ),
            'session_save_handler' => function_exists('ini_get')
                ? (string)ini_get('session.save_handler')
                : '',
            'session_save_path' => function_exists('session_save_path')
                ? (string)session_save_path()
                : '',

            'request_hash_id' => bz_session_fingerprint($request_hash_id),

if (!function_exists('bz_session_snapshot_diff')) {
    function bz_session_snapshot_diff($before, $after)
    {
        $fields = array(
            'session_status',
            'session_name',
            'session_id',
            'cookie_params',
            'session_save_handler',
            'session_save_path',
            'hash_id',
            'main_hash_id',
            'request_hash_id',
            'session_keys',
            'session_encoded',
            'wo_user_id',
            'storage'
        );

        $changes = array();

        foreach ($fields as $field) {
            $before_value = isset($before[$field])
                ? $before[$field]
                : null;

            $after_value = isset($after[$field])
                ? $after[$field]
                : null;

            if ($before_value !== $after_value) {
                $changes[$field] = array(
                    'before' => $before_value,
                    'after' => $after_value
                );
            }
        }

        return $changes;
    }
}

if (!function_exists('Wo_SessionDiagnosticLog')) {
    function Wo_SessionDiagnosticLog($event, $context = array())
    {
        $file = bz_stream_session_log_path();
        $directory = dirname($file);

        if (!is_dir($directory)) {
            @mkdir($directory, 0750, true);
        }

        if (!is_array($context)) {
            $context = array('value' => $context);
        }

        $context['timestamp_utc'] = gmdate('c');
        $context['request_id'] = bz_session_request_id();
        $context['pid'] = function_exists('getmypid')
            ? (int)getmypid()
            : 0;
        $context['method'] = isset($_SERVER['REQUEST_METHOD'])
            ? (string)$_SERVER['REQUEST_METHOD']
            : '';
        $context['uri'] = bz_session_safe_uri();
        $context['script'] = isset($_SERVER['SCRIPT_FILENAME'])
            ? (string)$_SERVER['SCRIPT_FILENAME']
            : '';
        $context['host'] = isset($_SERVER['HTTP_HOST'])
            ? (string)$_SERVER['HTTP_HOST']
            : '';
        $context['session_state'] = bz_session_state_snapshot();
        $context['trace'] = bz_session_trace();

        $record = array(
            'event' => (string)$event,
            'context' => $context
        );

        $json = json_encode(
            $record,
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR
        );

        if ($json === false) {
            return false;
        }

        return @file_put_contents(
            $file,
            $json.PHP_EOL,
            FILE_APPEND | LOCK_EX
        ) !== false;
    }
}

    {

                )

            Wo_SessionDiagnosticLog(
                'session_start_exception',
                array(
                    'exception_class' => get_class($exception),
                    'exception_message' => $exception->getMessage()
                )

            return false;

        $active = (
            $started &&
            session_status() === PHP_SESSION_ACTIVE
        );

        Wo_SessionDiagnosticLog(
            $active
                ? 'session_started'
                : 'session_start_failed',
            array(
                'return_value' => (bool)$started,
                'last_error' => error_get_last()
            )
        );

        return $active;
    }
```

```php name=streams/assets/includes/functions_two.php url=https://github.com/cupidblack/buzzjuice.net/blob/main/streams/assets/includes/functions_two.php#L5581-L5671
function Wo_CreateSession()
{
    if (!Wo_EnsureSessionActive()) {
        Wo_SessionHashLog(
            'hash_create_failed',
            array(
                'hash_name' => 'hash_id'
            )
        );

        return '';
    }

    if (
        isset($_SESSION['hash_id']) &&
        is_string($_SESSION['hash_id']) &&
        preg_match('/^[a-f0-9]{40}$/i', $_SESSION['hash_id'])
    ) {
        Wo_SessionHashLog(
            'hash_reused',
            array(
                'hash_name' => 'hash_id',
                'value' => Wo_SessionHashFingerprint(
                    $_SESSION['hash_id']
                )
            )
        );

        return $_SESSION['hash_id'];
    }

    $old_value = isset($_SESSION['hash_id'])
        ? $_SESSION['hash_id']
        : '';

    try {
        $hash = sha1(random_bytes(32));
    } catch (Throwable $exception) {
        $hash = sha1(
            uniqid('', true).
            microtime(true).
            mt_rand()
        );
    }

    $_SESSION['hash_id'] = $hash;

    Wo_SessionHashLog(
        $old_value === ''
            ? 'hash_created'
            : 'hash_replaced_invalid_value',
        array(
            'hash_name' => 'hash_id',
            'old_value' => Wo_SessionHashFingerprint($old_value),
            'new_value' => Wo_SessionHashFingerprint($hash)
        )
    );

    return $hash;
}

function Wo_CheckSession($hash = '')
{
    if (!Wo_EnsureSessionActive()) {
        Wo_SessionHashLog(
            'hash_check_failed',
            array(
                'hash_name' => 'hash_id',
                'reason' => 'session_not_active',
                'request_value' => Wo_SessionHashFingerprint($hash)
            )
        );

        return false;
    }

    $stored = isset($_SESSION['hash_id'])
        ? $_SESSION['hash_id']
        : '';

    $valid = (
        is_string($hash) &&
        is_string($stored) &&
        $hash !== '' &&
        $stored !== '' &&
        hash_equals($stored, $hash)
    );

    Wo_SessionHashLog(
        $valid
            ? 'hash_check_passed'
            : 'hash_check_failed',
        array(
            'hash_name' => 'hash_id',
            'request_value' => Wo_SessionHashFingerprint($hash),
            'stored_value' => Wo_SessionHashFingerprint($stored),
            'reason' => $valid
                ? 'match'
                : (
                    $stored === ''
                        ? 'stored_value_missing'
                        : (
                            $hash === ''
                                ? 'request_value_missing'
                                : 'mismatch'
                        )
                )
        )
    );

    return $valid;
}

function Wo_CreateMainSession()
{
    if (!Wo_EnsureSessionActive()) {
        Wo_SessionHashLog(
            'hash_create_failed',
            array(
                'hash_name' => 'main_hash_id'
            )
        );

        return '';
    }

    if (
        isset($_SESSION['main_hash_id']) &&
        is_string($_SESSION['main_hash_id']) &&
        preg_match('/^[a-f0-9]{20}$/i', $_SESSION['main_hash_id'])
    ) {
        Wo_SessionHashLog(
            'hash_reused',
            array(
                'hash_name' => 'main_hash_id',
                'value' => Wo_SessionHashFingerprint(
                    $_SESSION['main_hash_id']
                )
            )
        );

        return $_SESSION['main_hash_id'];
    }

    $old_value = isset($_SESSION['main_hash_id'])
        ? $_SESSION['main_hash_id']
        : '';

    try {
        $hash = substr(
            hash('sha1', random_bytes(32)),
            0,
            20
        );
    } catch (Throwable $exception) {
        $hash = substr(
            sha1(
                uniqid('', true).
                microtime(true).
                mt_rand()
            ),
            0,
            20
        );
    }

    $_SESSION['main_hash_id'] = $hash;

    Wo_SessionHashLog(
        $old_value === ''
            ? 'hash_created'
            : 'hash_replaced_invalid_value',
        array(
            'hash_name' => 'main_hash_id',
            'old_value' => Wo_SessionHashFingerprint($old_value),
            'new_value' => Wo_SessionHashFingerprint($hash)
        )
    );

    return $hash;
}

function Wo_CheckMainSession($hash = '')
{
    if (!Wo_EnsureSessionActive()) {
        Wo_SessionHashLog(
            'hash_check_failed',
            array(
                'hash_name' => 'main_hash_id',
                'reason' => 'session_not_active',
                'request_value' => Wo_SessionHashFingerprint($hash)
            )
        );

        return false;
    }

    $stored = isset($_SESSION['main_hash_id'])
        ? $_SESSION['main_hash_id']
        : '';

    $valid = (
        is_string($hash) &&
        is_string($stored) &&
        $hash !== '' &&
        $stored !== '' &&
        hash_equals($stored, $hash)
    );

    Wo_SessionHashLog(
        $valid
            ? 'hash_check_passed'
            : 'hash_check_failed',
        array(
            'hash_name' => 'main_hash_id',
            'request_value' => Wo_SessionHashFingerprint($hash),
            'stored_value' => Wo_SessionHashFingerprint($stored),
            'reason' => $valid
                ? 'match'
                : (
                    $stored === ''
                        ? 'stored_value_missing'
                        : (
                            $hash === ''
                                ? 'request_value_missing'
                                : 'mismatch'
                        )
                )
        )
    );

    return $valid;
}
```

The validation remains enabled. Do not leave either check permanently set to:

```php
return true;
```

That would bypass CSRF/session protection for many unrelated endpoints.

# Step 6 — Important correction for QuickDate

The QuickDate bridge must never share the Streams session.

The following arrangement is recommended:

```text
Streams:
    session name: BUZZSTREAMSESSID
    cookie path: /streams

QuickDate:
    session name: BUZZSOCIALSESSID
    cookie path: /social

WordPress:
    WordPress cookies
```

The current browser evidence shows:

```text
BUZZSTREAMSESSID  path /streams
PHPSESSID         path /
```

That is not necessarily wrong, but it is unsafe if QuickDate and Streams both use the same `PHPSESSID`.

Before `SessionStart()` is called by QuickDate, configure the Socials session separately in `social/bootstrap.php` or in the earliest file loaded by QuickDate:

```php
<?php

if (session_status() === PHP_SESSION_NONE) {
    @ini_set('session.name', 'BUZZSOCIALSESSID');
    @ini_set('session.cookie_path', '/social');
    @ini_set('session.cookie_domain', '.buzzjuice.net');
    @ini_set('session.cookie_secure', '1');
    @ini_set('session.cookie_httponly', '1');
    @ini_set('session.cookie_samesite', 'Lax');
    @ini_set('session.use_only_cookies', '1');
    @ini_set('session.use_trans_sid', '0');

    @session_name('BUZZSOCIALSESSID');
}
```

This must execute before:

```php
SessionStart();
session_start();
```

Do not make QuickDate call:

```php
session_destroy();
```

against the Streams session. QuickDate should only destroy `BUZZSOCIALSESSID`.

Also, do not use this in QuickDate:

```php
setcookie('PHPSESSID', '', -1, '/');
```

unless QuickDate is explicitly the owner of that cookie. In your current architecture, that cookie may be used by WordPress or another application.

The log is newline-delimited JSON. Each line represents one event.

Useful events include:


For a failed follow request, compare these values across requests:

```text

main_hash_id.length

storage.session_file
```

## Expected healthy sequence

A healthy Streams page should look conceptually like this:

```text
Request 1:
    session_name = BUZZSTREAMSESSID
    session_cookie_present = true
    hash_id.length = 40
    main_hash_id.length = 20
    hash_created / hash_reused

Request 2:
    session_name = BUZZSTREAMSESSID
    same session_id fingerprint
    same hash_id fingerprint
    same main_hash_id fingerprint
    hash_check_passed
```

The actual hashes are intentionally not logged.

## Failure patterns

### Pattern A — Session name is `PHPSESSID`

Example:

```text
session_name = PHPSESSID
cookie_params.path = /
```

This proves Streams started the wrong session.

### Pattern B — Session name is correct but session ID changes

Example:

```text
session_name = BUZZSTREAMSESSID
session_id.sha256 changes
```

This indicates one of:

- `session_regenerate_id()`
- `session_destroy()`
- a cookie collision
- a different cookie path/domain
- the request did not send `BUZZSTREAMSESSID`
- multiple application entry points use different session configuration

### Pattern C — Session ID remains constant but hash disappears

Example:

```text
same session_id.sha256
hash_id.length: 40 -> 0
main_hash_id.length: 20 -> 0
```

This indicates code unset or replaced the values inside the same session.

Search especially for:

```php
$_SESSION = array();
$_SESSION = [];
session_unset();
unset($_SESSION['hash_id']);
unset($_SESSION['main_hash_id']);
session_destroy();
```

### Pattern D — Profile page gets new hashes every refresh

If the profile page creates a new `hash_id` and `main_hash_id` but the session fingerprint also changes, the profile request is not using the same Streams session.

If the session fingerprint remains constant while the hashes change, some code is explicitly replacing the session values.

### Pattern E — Request token differs from stored token

Example:

```text
stored main_hash_id: length 20, fingerprint A
request_hash_id: length 20, fingerprint B
```

This means the browser page contains a token from a different request/session than the AJAX request.

That is the most likely explanation for:

```text
Follow -> Requested
reload -> Follow
```

The follow request is then rejected by the session guard, so the database state is not updated.

# Step 8 — Correct interpretation of the page-source values

Your page-source observations are significant:

```text
Main page:
hash_id      = 40 characters
main_session = 20 characters
```

Those values remain constant after reload, which is expected when the same session is used.

The profile page produces new values:

```text
Profile refresh 1:
hash_id      = different 40-character value
main_session = different 20-character value
```

That should not happen if:

1. `BUZZSTREAMSESSID` is unchanged;
2. `Wo_CreateSession()` reuses the existing session value;
3. `Wo_CreateMainSession()` reuses the existing session value.

Therefore, the new profile values indicate one of these conditions:

- the profile request uses a different PHP session;
- the profile request does not receive `BUZZSTREAMSESSID`;
- the profile request starts with `PHPSESSID`;
- code destroys or regenerates the session before the hash functions run;
- code explicitly unsets either hash;
- the profile template calls a different initialization path;
- the HTML is generated from a different request than the AJAX request.

The new logging will distinguish these cases.

# Step 9 — Do not interpret the 64-character hash as a session hash

A 64-character hexadecimal value is:

```text
SHA-256 output
```

The diagnostic code creates it with:

```php
hash('sha256', $value)
```

It is only a fingerprint of the original value.

It is not:

```text
$_SESSION['hash_id']
$_SESSION['main_hash_id']
PHPSESSID
BUZZSTREAMSESSID
```

Do not copy the fingerprint into a cookie or hidden field.
