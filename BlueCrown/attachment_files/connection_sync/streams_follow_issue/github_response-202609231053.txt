## Diagnosis

The primary fault is the Streams PHP session being started **before** Streams selects its own session cookie:

```php
if (session_status() !== PHP_SESSION_ACTIVE) {
    @session_start();
}
```

The current `streams/assets/init.php` therefore may start the session using the default configuration, normally:

```text
Cookie: PHPSESSID
Path: /
```

Only afterward does the browser also receive:

```text
Cookie: BUZZSTREAMSESSID
Path: /streams
```

Your browser evidence shows both cookies:

```text
PHPSESSID
BUZZSTREAMSESSID
```

That is safe only if QuickDate uses `PHPSESSID` and Streams consistently uses `BUZZSTREAMSESSID`. At present, the Streams bootstrap does not guarantee that.

There are also several independent problems:

1. `hash_id` and `main_hash_id` are server-side `$_SESSION` values. They will not appear as individual browser cookies.
2. The 64-character values are almost certainly SHA-256 fingerprints generated by the previous diagnostic code, not native WoWonder hashes.
3. Native WoWonder values are:
   - `hash_id`: 40-character SHA-1 value
   - `main_hash_id`: 20-character SHA-1-derived value
4. This code is unreachable:

```php
return true;

print_r(...);
```

5. `ww-sso-bridge.php` can destroy the active Streams session when the WordPress login cookie is temporarily unavailable.
6. `streams/sources/logout.new` explicitly destroys the active session.
7. `streams/sources/switch-account.php` explicitly destroys the active session.
8. The obsolete `streams/xhr/login.php` also destroys the session when switching accounts.
9. The QuickDate session and Streams session should not be synchronized or shared.
10. Replacing `$_SESSION` with `$_COOKIE` for `main_hash_id` would be a security regression and should not be done.

The relevant files are:

- [`streams/assets/init.php`](https://github.com/cupidblack/buzzjuice.net/blob/main/streams/assets/init.php)
- [`streams/assets/includes/functions_two.php`](https://github.com/cupidblack/buzzjuice.net/blob/main/streams/assets/includes/functions_two.php)
- [`streams/assets/includes/functions_one.php`](https://github.com/cupidblack/buzzjuice.net/blob/main/streams/assets/includes/functions_one.php)

# 1. Do not use cookies for `main_hash_id`

Do **not** change the functions to use:

```php
$_COOKIE['main_hash_id']
```

A cookie is controlled by the browser. A user could modify it before sending the request. The correct design is:

```text
Browser:
    BUZZSTREAMSESSID

Server:
    session file or session backend
        hash_id
        main_hash_id
```

The browser must send the session identifier. The actual security values must remain server-side.

Also do not log the raw values. The diagnostic logger below logs:

- whether a value exists;
- its length;
- its type/format;
- a SHA-256 fingerprint;
- the session ID fingerprint;
- the active session name;
- the save handler;
- the save path;
- the expected session file;
- request URI and script;
- a stack trace;
- before/after changes.

# 2. Identify the actual session save path

The definitive PHP setting is:

```php
session_save_path()
```

The session name and current session ID determine the session file when the handler is `files`:

```text
<session_save_path>/sess_<session_id>
```

For example:

```text
/var/lib/php/sessions/sess_95a960ffc45503d8feed61b87e97cf40
```

Do not assume that this is the path. The code below records the actual configured and resolved paths in:

```text
/buzzjuice.net/data/logs/buzzjuice-session-debug.log
```

The PHP process must be able to write to:

```text
/buzzjuice.net/data/logs
```

Example server preparation:

```bash
cd /home/koware/public_html/buzzjuice.net

mkdir -p data/logs
chmod 0750 data/logs

# Replace the account with the actual PHP-FPM/Apache account.
chown -R www-data:www-data data/logs
```

Do not make the diagnostic log publicly downloadable.

if (!function_exists('bz_session_request_id')) {
    function bz_session_request_id()
    {
        static $request_id = null;

        if ($request_id !== null) {
            return $request_id;
        }

        try {
            $request_id = bin2hex(random_bytes(12));
        } catch (Throwable $exception) {
            $request_id = substr(
                sha1(uniqid('', true).microtime(true).mt_rand()),
                0,
                24
            );
        }

        return $request_id;
    }
}

if (!function_exists('bz_session_fingerprint')) {
    function bz_session_fingerprint($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length'  => strlen($value),
            'sha256'  => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format'  => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}

if (!function_exists('bz_session_safe_request_uri')) {
    function bz_session_safe_request_uri()
    {
        $uri = isset($_SERVER['REQUEST_URI'])
            ? (string) $_SERVER['REQUEST_URI']
            : '';

        if ($uri === '') {
            return '';
        }

        return preg_replace(
            '/([?&](?:hash_id|hash|token|sso_token|buzz_sso|buzz_access|buzz_refresh|password|secret)=)[^&]*/i',
            '$1[REDACTED]',
            $uri
        );
    }
}

    function bz_session_cookie_diagnostics()
    {
        $names = array(
            'BUZZSTREAMSESSID',
            'BUZZSOCIALSESSID',
            'PHPSESSID',

            'buzz_refresh',

                'present' => ($value !== ''),
                'length'  => strlen($value),
                'sha256'  => ($value !== '')
                    ? hash('sha256', $value)
                    : ''
            );
        }

        return $result;
    }
}

if (!function_exists('bz_session_resolved_save_path')) {
    function bz_session_resolved_save_path()
    {
        $path = function_exists('session_save_path')
            ? (string) session_save_path()
            : '';

        if ($path === '') {
            return '';
        }

        /*
         * PHP may return:
         *
         *     N;/path/to/sessions
         *     N;MODE;/path/to/sessions
         */
        if (strpos($path, ';') !== false) {
            $parts = explode(';', $path);
            $path = end($parts);
        }

        return rtrim($path, DIRECTORY_SEPARATOR);
    }
}

if (!function_exists('bz_session_storage_diagnostics')) {
    function bz_session_storage_diagnostics()
    {
        $handler = function_exists('ini_get')
            ? (string) ini_get('session.save_handler')
            : '';

        $configured_path = function_exists('session_save_path')
            ? (string) session_save_path()
            : '';

        $resolved_path = bz_session_resolved_save_path();

        $result = array(
            'handler' => $handler,
            'configured_save_path' => $configured_path,
            'resolved_save_path' => $resolved_path,
            'resolved_path_exists' => (
                $resolved_path !== '' &&
                is_dir($resolved_path)
            ),
            'resolved_path_readable' => (
                $resolved_path !== '' &&
                is_readable($resolved_path)
            ),
            'resolved_path_writable' => (
                $resolved_path !== '' &&
                is_writable($resolved_path)
            )
        );

        if (
            $handler === 'files' &&
            $resolved_path !== '' &&
            session_status() === PHP_SESSION_ACTIVE
        ) {
            $id = function_exists('session_id')
                ? (string) session_id()
                : '';

            if ($id !== '') {
                $session_file = $resolved_path
                    .DIRECTORY_SEPARATOR
                    .'sess_'.$id;

                $exists = is_file($session_file);

                $result['session_file_exists'] = $exists;
                $result['session_file_fingerprint'] =
                    bz_session_fingerprint($session_file);
                $result['session_file_size'] = $exists
                    ? (int) @filesize($session_file)
                    : 0;
                $result['session_file_mtime'] = $exists
                    ? (int) @filemtime($session_file)
                    : 0;
            }
        }

        return $result;
    }
}

if (!function_exists('bz_session_snapshot_diff')) {
    function bz_session_snapshot_diff($before, $after)
    {
        $fields = array(
            'session_status',
            'session_status_name',
            'session_name',
            'session_id',
            'session_save_path',
            'session_save_handler',
            'session_cookie_params',
            'hash_id',
            'main_hash_id',
            'request_hash_id',
            'session_keys',
            'session_encoded',
            'wo_user_id',
            'storage'
        );

        $changes = array();

        foreach ($fields as $field) {
            $before_value = isset($before[$field])
                ? $before[$field]
                : null;

            $after_value = isset($after[$field])
                ? $after[$field]
                : null;

            if ($before_value !== $after_value) {
                $changes[$field] = array(
                    'before' => $before_value,
                    'after' => $after_value
                );
            }
        }

        return $changes;
    }
}

                    'exception_class' => get_class($exception),

            $started &&
            session_status() === PHP_SESSION_ACTIVE

            $active

                : 'session_start_failed',
            array(
                'start_return_value' => (bool) $started,
                'last_error' => error_get_last()
            )
        );

        return $active;
    }
}

## Important correction to this replacement

The code above must be loaded before anything calls `session_start()`. If another included file starts the session earlier, the problem remains.

Therefore, search the entire application for:

```text
session_start(
SessionStart(
session_name(
ini_set('session.name'
session_set_cookie_params(
```

The first session operation on a Streams request must be the configuration in `init.php`.

if (!function_exists('Wo_SessionHashFingerprint')) {
    function Wo_SessionHashFingerprint($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length'  => strlen($value),
            'sha256'  => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format'  => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}

            return Wo_SessionDiagnosticLog($event, $context);

        return false;
    }

if (!function_exists('Wo_EnsureSessionActive')) {
    function Wo_EnsureSessionActive()
    {
        if (!function_exists('session_status')) {
            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' => 'session_status_unavailable'
                )
            );

            return false;
        }

        if (session_status() === PHP_SESSION_ACTIVE) {
            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {
            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' => 'session_not_startable',
                    'session_status' => session_status()
                )
            );

            return false;
        }

        if (headers_sent($headers_file, $headers_line)) {
            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' => 'headers_already_sent',
                    'headers_file' => $headers_file,
                    'headers_line' => (int) $headers_line
                )
            );

            return false;
        }

        try {
            $started = @session_start();
        } catch (Throwable $exception) {
            Wo_SessionHashLog(
                'hash_operation_failed',
                array(
                    'reason' => 'session_start_exception',
                    'exception_class' => get_class($exception),
                    'exception_message' => $exception->getMessage()
                )
            );

            return false;
        }

        $active = (
            $started &&
            session_status() === PHP_SESSION_ACTIVE
        );

        Wo_SessionHashLog(
            $active
                ? 'session_started_by_hash_function'
                : 'session_start_failed_by_hash_function',
            array(
                'start_return_value' => (bool) $started,
                'session_name' => function_exists('session_name')
                    ? session_name()
                    : ''
            )
        );

        return $active;
    }
}

if (!function_exists('Wo_CreateSession')) {
    function Wo_CreateSession()
    {
        if (!Wo_EnsureSessionActive()) {
            Wo_SessionHashLog(
                'create_hash_id_failed',
                array(
                    'session_key' => 'hash_id',
                    'reason' => 'php_session_not_active'
                )
            );

            return '';
        }

        $existing = isset($_SESSION['hash_id'])
            ? (string) $_SESSION['hash_id']
            : '';

        if (preg_match('/^[a-f0-9]{40}$/i', $existing)) {
            Wo_SessionHashLog(
                'hash_id_reused',
                array(
                    'session_key' => 'hash_id',
                    'value' => Wo_SessionHashFingerprint($existing)
                )
            );

            return $existing;
        }

        if ($existing !== '') {
            Wo_SessionHashLog(
                'hash_id_replaced_invalid_existing_value',
                array(
                    'session_key' => 'hash_id',
                    'old_value' => Wo_SessionHashFingerprint($existing)
                )
            );
        }

        try {
            $hash = sha1(random_bytes(32));
        } catch (Throwable $exception) {
            $hash = sha1(
                uniqid('', true).
                microtime(true).
                mt_rand()
            );
        }

        $_SESSION['hash_id'] = $hash;

        Wo_SessionHashLog(
            'hash_id_created',
            array(
                'session_key' => 'hash_id',
                'new_value' => Wo_SessionHashFingerprint($hash)
            )
        );

        return $hash;
    }
}

if (!function_exists('Wo_CheckSession')) {
    function Wo_CheckSession($hash = '')
    {
        $provided = is_scalar($hash)
            ? (string) $hash
            : '';

        $stored = (
            isset($_SESSION) &&
            is_array($_SESSION) &&
            isset($_SESSION['hash_id'])
        )
            ? (string) $_SESSION['hash_id']
            : '';

        $valid = (
            $provided !== '' &&
            $stored !== '' &&
            hash_equals($stored, $provided)
        );

        Wo_SessionHashLog(
            $valid
                ? 'hash_id_check_passed'
                : 'hash_id_check_failed',
            array(
                'session_key' => 'hash_id',
                'provided_value' => Wo_SessionHashFingerprint($provided),
                'stored_value' => Wo_SessionHashFingerprint($stored),
                'provided_empty' => ($provided === ''),
                'stored_empty' => ($stored === ''),
                'reason' => (
                    $provided === ''
                        ? 'request_hash_empty'
                        : (
                            $stored === ''
                                ? 'session_hash_missing'
                                : 'hash_mismatch'
                        )
                )
            )
        );

        return $valid;
    }
}

## Why `hash_equals()` is used

The previous code used:

```php
if ($hash == $_SESSION["main_hash_id"]) {
```

The comparison should be:

```php
hash_equals($stored, $provided)
```

The session value is the trusted value, and the request value is the untrusted value.

# 5. Ensure the hash values are created during page rendering

The functions above only create values when called. They do not automatically create `hash_id` or `main_hash_id` on every request.

The normal WoWonder theme code creates them while rendering hidden fields such as:

```php
<input type="hidden" name="hash_id" value="<?php echo Wo_CreateSession(); ?>">
```

and:

```php
<input type="hidden" class="main_session" value="<?php echo Wo_CreateMainSession(); ?>">
```

Because you do not want theme changes, first inspect the generated HTML in the browser:

```text
View source → search for:
hash_id
main_session
main_hash_id
```

Then inspect the request that fails:

```text
Developer Tools → Network → failing request → Payload
```

Confirm whether the request contains:

```text
hash_id=<20-character main_hash_id>
```

If the request contains no hash at all, the problem is not only session storage. The client page is not rendering or sending the required token.

For the follow operation, the critical log event should look like:

```text
main_hash_id_check_failed
```

with one of these reasons:

```text
request_hash_empty
session_main_hash_missing
main_hash_mismatch
```

# 8. Fix the QuickDate/Streams session architecture

The intended architecture should be:

```text
WordPress
├── PHPSESSID
│   └── QuickDate / Socials
│
└── BUZZSTREAMSESSID
    └── WoWonder / Streams
```

The browser evidence is consistent with that design:

```text
PHPSESSID          Path /
BUZZSTREAMSESSID   Path /streams
```

However, `social/qd-sso-bridge.php` currently contains logic that can clear or destroy its active session when the WordPress cookie is unavailable. It also uses a shared domain and relies on framework-level session startup.

The most important rule is:

```text
QuickDate must not call session_destroy() on BUZZSTREAMSESSID.
Streams must not use PHPSESSID.
```

Because session cookies are selected by cookie name, path and domain, verify the following in the log:

```json
{
    "session_name": "BUZZSTREAMSESSID",
    "session_cookie_params": {
        "path": "/streams",
        "domain": ".buzzjuice.net"
    }
}
```

If a Streams request logs:

```json
{
    "session_name": "PHPSESSID",
    "session_cookie_params": {
        "path": "/"
    }
}
```

then the request is using the wrong PHP session before WoWonder has a chance to validate anything.

# 9. Do not log raw session or SSO values

The existing SSO helper contains debug paths that can log complete cookies and sessions when debugging is enabled. In particular, avoid logging structures such as:

```php
'cookies' => $_COOKIE,
'session' => $_SESSION
```

Do not log:

- `buzz_sso`;
- `buzz_access`;
- `buzz_refresh`;
- `wordpress_logged_in_*`;
- `PHPSESSID`;
- `BUZZSTREAMSESSID`;
- `user_id`;
- `JWT`;
- passwords;
- complete `$_SESSION`.

The diagnostic logger above records only fingerprints and safe metadata.

The 64-character value from the prior implementation is explained by:

```php
hash('sha256', $value)
```

A SHA-256 hexadecimal digest is exactly 64 hexadecimal characters. It is not evidence that WoWonder created a 64-character `main_hash_id`.

Perform the following in a private browser window.

## Test A — Fresh Streams session

1. Delete site cookies for `buzzjuice.net`.
2. Log into WordPress.
3. Open `/streams`.
4. Inspect cookies.
5. Confirm that Streams creates:

6. Confirm that the diagnostic log contains:

```text

streams_application_bootstrap_complete
```

7. Confirm that the logged session name is:

```text
BUZZSTREAMSESSID
```

## Test B — Rendered token

1. Open a profile page.
2. View the HTML source.
3. Find the main session field.
4. Confirm that its length is 20 characters.
5. Open the follow request in Developer Tools.
6. Confirm that the same request token is transmitted.

The log should show:

```text
main_hash_id_created
main_hash_id_reused
main_hash_id_check_passed
```

## Test C — Failed follow

Reproduce the failure and locate the corresponding request using `request_id`.

The important sequence is:

```text
streams_request_hash_extracted
main_hash_id_check_failed
request_shutdown_session_state_unchanged
```

Interpretation:

- `request_hash_empty`: the browser did not send the token;
- `session_main_hash_missing`: the server session did not contain it;
- `main_hash_mismatch`: the request used a token from another session;
- changed `session_id`: session regeneration or a new session occurred;
- changed `session_name`: another bootstrap changed the session configuration;
- changed `main_hash_id` to empty: application code removed it;
- `streams_sso_session_destroyed`: the SSO bridge destroyed the session.

## Test D — Reload

After the failed follow, reload the page and compare:

```text
session_id fingerprint
main_hash_id fingerprint
BUZZSTREAMSESSID cookie fingerprint
```

If the browser sends the same `BUZZSTREAMSESSID` but the server logs a different session ID, inspect:

- PHP session save path;
- load balancing;
- multiple PHP servers;
- missing shared session storage;
- container or worker-local `/tmp`;
- PHP session garbage collection;
- session cookie domain/path;
- session regeneration.

If requests are handled by multiple servers, all servers must share the same session backend. A local filesystem session directory on each server will produce intermittent behavior exactly like the behavior described.

# 12. What the final diagnosis should look like

After applying the diagnostics, the likely outcomes are:

## Case 1 — Wrong session cookie

```text
session_name = PHPSESSID
cookie path = /
```

Fix the order of session configuration in `init.php`.

## Case 2 — SSO bridge destroys the session

```text
streams_sso_about_to_destroy_session_no_wordpress_cookie
streams_sso_session_before_destroy
streams_sso_session_destroyed
```

The bridge is clearing the Streams session. Investigate why the WordPress cookie is absent on that request.

## Case 3 — Request does not contain a main hash

```text
streams_request_hash_extracted
hash_source = none
main_hash_id_check_failed
reason = request_hash_empty
```

The browser-side page is not sending the required token. This is a rendering/request-construction issue, not a session-save-path issue.

## Case 4 — Token belongs to another session

```text
main_hash_id_check_failed
reason = main_hash_mismatch
```

Compare:

```text
provided_value.sha256
stored_value.sha256
session_id.sha256
```

This indicates a stale token, a session-cookie mismatch, a cached page, or a request handled by a different session backend.

## Case 5 — Server session storage is not persistent

```text
session_file_exists = false
```

or the session file path/mtime changes unexpectedly between requests.

Check PHP-FPM configuration, `session.save_path`, permissions and load-balancer affinity.

# 13. Cleanup after debugging

After the issue is identified:

1. Remove or disable verbose request tracing.
2. Keep the session configuration fix.
3. Keep `hash_equals()`.
4. Keep the separation between `PHPSESSID` and `BUZZSTREAMSESSID`.
5. Remove any `print_r()` calls from production code.
6. Ensure the log is outside the public web root or blocked by the web server.
7. Rotate/delete the diagnostic log because it may contain user IDs, URLs and request metadata.
8. Never keep raw cookie/token logging enabled.

The correct production design is:

```text
Wo_CreateSession()
    stores hash_id in $_SESSION

Wo_CreateMainSession()
    stores main_hash_id in $_SESSION

Wo_CheckSession()
    validates against $_SESSION['hash_id']

Wo_CheckMainSession()
    validates against $_SESSION['main_hash_id']

BUZZSTREAMSESSID
    identifies the server-side Streams session

PHPSESSID
    identifies the separate QuickDate/Socials session
```

The immediate changes should therefore be limited to the Streams bootstrap, the four diagnostic session functions, request logging, and explicit instrumentation around known session destruction points—not `follow_user.php`, the theme, or a replacement of server-side session values with cookies.
