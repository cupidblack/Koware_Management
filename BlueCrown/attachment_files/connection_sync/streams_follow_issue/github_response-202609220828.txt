The failure is a **session continuity problem**, not primarily a follow-button problem.

The evidence points to three separate issues:

1. `Wo_CreateSession()` and `Wo_CreateMainSession()` currently use different token contracts:
   - `hash_id`: 40 hexadecimal characters.
   - `main_hash_id`: 20 hexadecimal characters.
2. `ww-sso-bridge.php` establishes the WoWonder login session but does not initialize `$_SESSION['hash_id']` or `$_SESSION['main_hash_id']`.
3. The follow request must submit the **20-character `main_hash_id`**, but the current flow either submits no hash or submits an incompatible 64-character value.

The existing `streams/assets/init.php` does start a PHP session before loading the functions, so the four functions belong in `functions_two.php`, not `functions_one.php`. # 1. Preserve the security model

Do **not** remove `Wo_CheckMainSession()` from `follow_user.php`.

Do not log complete session values. A session hash is a credential. The diagnostic code below logs:

- whether a value exists;
- its length;
- SHA-256 fingerprint;
- first and last four characters;
- hexadecimal-format validity;
- whether the supplied and stored values match.

Do not use this pattern inside session functions:

```php
session_write_close();
session_start();
```

The application already starts the session in `streams/assets/init.php`. Closing and reopening it can cause stale-session and race-condition problems.

/**
 * -------------------------------------------------------------------------
 * Buzzjuice / WoWonder request-session diagnostics
 * -------------------------------------------------------------------------
 *
 * hash_id:
 *   40 hexadecimal characters.
 *
 * main_hash_id:
 *   20 hexadecimal characters.
 *
 * Raw session credentials are never written to the log.
 */

if (!function_exists('Wo_SessionDiagnosticRequestId')) {
    function Wo_SessionDiagnosticRequestId()
    {
        static $request_id = null;

        if ($request_id !== null) {
            return $request_id;
        }

        $request_id = '';

        if (!empty($_SERVER['HTTP_X_REQUEST_ID'])) {
            $request_id = preg_replace(
                '/[^a-zA-Z0-9._-]/',
                '',
                (string) $_SERVER['HTTP_X_REQUEST_ID']
            );
        }

        if ($request_id === '' && !empty($_SERVER['UNIQUE_ID'])) {
            $request_id = preg_replace(
                '/[^a-zA-Z0-9._-]/',
                '',
                (string) $_SERVER['UNIQUE_ID']
            );
        }

        if ($request_id === '') {
            try {
                $request_id = bin2hex(random_bytes(8));
            } catch (Throwable $e) {
                $request_id = substr(
                    hash('sha256', microtime(true) . mt_rand()),
                    0,
                    16
                );
            }
        }

        return $request_id;
    }
}

if (!function_exists('Wo_SessionValueDiagnostics')) {
    function Wo_SessionValueDiagnostics($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length' => strlen($value),
            'fingerprint' => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'first_4_chars' => ($value !== '')
                ? substr($value, 0, 4)
                : '',
            'last_4_chars' => ($value !== '')
                ? substr($value, -4)
                : '',
            'hex_format' => ($value !== '')
                ? (bool) preg_match('/^[a-f0-9]+$/i', $value)
                : false
        );
    }
}

if (!function_exists('Wo_SessionDiagnosticLog')) {
    function Wo_SessionDiagnosticLog($event, $context = array())
    {
        $log_directory = dirname(__DIR__, 3) . '/data/logs';

        if (!is_dir($log_directory)) {
            @mkdir($log_directory, 0750, true);
        }

        if (!is_array($context)) {
            $context = array(
                'value' => (string) $context
            );
        }

        $session_status = function_exists('session_status')
            ? session_status()
            : -1;

        $php_session_id = '';

        if (
            $session_status === PHP_SESSION_ACTIVE &&
            function_exists('session_id')
        ) {
            $php_session_id = (string) session_id();
        }

        $context['request_id'] =
            Wo_SessionDiagnosticRequestId();

        $context['timestamp_utc'] =
            gmdate('c');

        $context['method'] =
            isset($_SERVER['REQUEST_METHOD'])
                ? (string) $_SERVER['REQUEST_METHOD']
                : '';

        $context['request_uri'] =
            isset($_SERVER['REQUEST_URI'])
                ? (string) $_SERVER['REQUEST_URI']
                : '';

        $context['remote_addr'] =
            isset($_SERVER['REMOTE_ADDR'])
                ? (string) $_SERVER['REMOTE_ADDR']
                : '';

        $context['session_status'] =
            $session_status;

        $context['session_name'] =
            function_exists('session_name')
                ? session_name()
                : '';

        $context['session_cookie_present'] =
            function_exists('session_name')
                ? !empty($_COOKIE[session_name()])
                : false;

        $context['php_session_id'] =
            Wo_SessionValueDiagnostics($php_session_id);

        $line = json_encode(
            array(
                'event' => (string) $event,
                'context' => $context
            ),
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR
        );

        if ($line === false) {
            $line = json_encode(
                array(
                    'event' => 'diagnostic_json_encode_failed',
                    'context' => array(
                        'request_id' =>
                            Wo_SessionDiagnosticRequestId(),
                        'timestamp_utc' => gmdate('c')
                    )
                )
            );
        }

        if ($line !== false) {
            @file_put_contents(
                $log_directory .
                '/session-' .
                gmdate('Y-m-d') .
                '.log',
                $line . PHP_EOL,
                FILE_APPEND | LOCK_EX
            );
        }
    }
}

if (!function_exists('Wo_EnsurePhpSession')) {
    function Wo_EnsurePhpSession()
    {
        if (
            !function_exists('session_status') ||
            !function_exists('session_start')
        ) {
            Wo_SessionDiagnosticLog(
                'php_session_unavailable',
                array(
                    'session_status_available' =>
                        function_exists('session_status'),
                    'session_start_available' =>
                        function_exists('session_start')
                )
            );

            return false;
        }

        if (session_status() === PHP_SESSION_ACTIVE) {
            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {
            Wo_SessionDiagnosticLog(
                'php_session_not_startable',
                array(
                    'session_status' => session_status()
                )
            );

            return false;
        }

        if (headers_sent($headers_file, $headers_line)) {
            Wo_SessionDiagnosticLog(
                'php_session_start_blocked_headers_sent',
                array(
                    'headers_file' => $headers_file,
                    'headers_line' => $headers_line
                )
            );

            return false;
        }

        try {
            $started = @session_start();
        } catch (Throwable $e) {
            Wo_SessionDiagnosticLog(
                'php_session_start_exception',
                array(
                    'error_class' => get_class($e),
                    'error_message' => $e->getMessage()
                )
            );

            return false;
        }

        $active =
            $started &&
            session_status() === PHP_SESSION_ACTIVE;

        Wo_SessionDiagnosticLog(
            $active
                ? 'php_session_started'
                : 'php_session_start_failed',
            array(
                'start_return_value' => $started,
                'session_status_after_start' =>
                    session_status(),
                'session_name' => session_name(),
                'last_php_error' => error_get_last()
            )
        );

        return $active;
    }
}

if (!function_exists('Wo_CreateSession')) {
    function Wo_CreateSession()
    {
        if (!Wo_EnsurePhpSession()) {
            Wo_SessionDiagnosticLog(
                'create_session_failed',
                array(
                    'session_key' => 'hash_id',
                    'reason' => 'php_session_not_active'
                )
            );

            return '';
        }

        $existing = isset($_SESSION['hash_id'])
            ? (string) $_SESSION['hash_id']
            : '';

        if (
            $existing !== '' &&
            preg_match('/^[a-f0-9]{40}$/i', $existing)
        ) {
            Wo_SessionDiagnosticLog(
                'create_session_reused',
                array(
                    'session_key' => 'hash_id',
                    'value' =>
                        Wo_SessionValueDiagnostics($existing)
                )
            );

            return $existing;
        }

        $old_value = $existing;

        try {
            $hash = bin2hex(random_bytes(20));
        } catch (Throwable $e) {
            Wo_SessionDiagnosticLog(
                'create_session_random_generation_failed',
                array(
                    'session_key' => 'hash_id',
                    'error_class' => get_class($e),
                    'error_message' => $e->getMessage()
                )
            );

            return '';
        }

        $_SESSION['hash_id'] = $hash;

        Wo_SessionDiagnosticLog(
            'create_session_created',
            array(
                'session_key' => 'hash_id',
                'old_value' =>
                    Wo_SessionValueDiagnostics($old_value),
                'new_value' =>
                    Wo_SessionValueDiagnostics($hash)
            )
        );

        return $hash;
    }
}

if (!function_exists('Wo_CheckSession')) {
    function Wo_CheckSession($hash = '')
    {
        $provided_hash = is_scalar($hash)
            ? (string) $hash
            : '';

        if (!Wo_EnsurePhpSession()) {
            Wo_SessionDiagnosticLog(
                'check_session_failed',
                array(
                    'session_key' => 'hash_id',
                    'reason' => 'php_session_not_active',
                    'provided' =>
                        Wo_SessionValueDiagnostics($provided_hash)
                )
            );

            return false;
        }

        $stored_hash = isset($_SESSION['hash_id'])
            ? (string) $_SESSION['hash_id']
            : '';

        $provided_valid =
            (bool) preg_match(
                '/^[a-f0-9]{40}$/i',
                $provided_hash
            );

        $stored_valid =
            (bool) preg_match(
                '/^[a-f0-9]{40}$/i',
                $stored_hash
            );

        $matches =
            $provided_valid &&
            $stored_valid &&
            hash_equals($stored_hash, $provided_hash);

        Wo_SessionDiagnosticLog(
            $matches
                ? 'check_session_passed'
                : 'check_session_failed',
            array(
                'session_key' => 'hash_id',
                'provided' =>
                    Wo_SessionValueDiagnostics($provided_hash),
                'stored' =>
                    Wo_SessionValueDiagnostics($stored_hash),
                'provided_format_valid' => $provided_valid,
                'stored_format_valid' => $stored_valid,
                'match' => $matches,
                'reason' => $matches
                    ? 'match'
                    : (
                        $provided_hash === ''
                            ? 'empty_provided_hash'
                            : (
                                $stored_hash === ''
                                    ? 'empty_stored_hash'
                                    : (
                                        !$provided_valid
                                            ? 'invalid_provided_format'
                                            : (
                                                !$stored_valid
                                                    ? 'invalid_stored_format'
                                                    : 'fingerprints_differ'
                                            )
                                    )
                            )
                    )
            )
        );

        return $matches;
    }
}

- `/streams/requests.php` reuses that Streams PHP session.

# 13. How to interpret the resulting logs

## Case 1 — Supplied token is empty

```text
provided.length = 0
stored.length = 20
reason = empty_provided_hash
```

The client did not submit `hash_id`. Check:

- `.main_session` exists;
- the follow JavaScript reads it;
- the AJAX request includes `hash_id`.

## Case 2 — Supplied token is 64 characters

```text
provided.length = 64
stored.length = 20
reason = invalid_provided_format
```

A previous patch or another JavaScript component is supplying a SHA-256-style value. Search the complete repository for:

```text
hash_id
main_session
Wo_CreateMainSession
```

The correct follow token is the 20-character `main_hash_id`.

## Case 3 — Both values are 20 characters but fingerprints differ

```text
provided.length = 20
stored.length = 20
reason = fingerprints_differ
```

This indicates that the browser page and AJAX request are using different PHP sessions. Check:

- PHP session cookie name;
- cookie domain;
- cookie path;
- HTTPS/secure cookie behavior;
- session save path;
- load balancer/session storage;
- whether a bridge or logout request regenerates/destroys the session;
- whether the browser is sending multiple PHP session cookies.

## Case 4 — Both values match but follow still fails

```text
check_main_session_passed
follow_endpoint_failed
```

The session problem is solved. Investigate:

- `Wo_RegisterFollow()`;
- connectivity-system configuration;
- follow-request database rows;
- whether an existing requested/following row is being toggled;
- database errors;
- automatic acceptance logic.

# 14. Important conclusion about the current symptom

The visible behavior is explained by the current optimistic client-side update:

1. The button is immediately replaced with `Requested`.
2. The AJAX request reaches `follow_user.php`.
3. `Wo_CheckMainSession($hash_id)` rejects the request.
4. The response does not reliably reset the button.
5. Reloading reads the unchanged database state and shows `Follow` again.

The accounts where the action appears to work immediately are likely accounts with a valid shared session or a different request path. That explains the inconsistent behavior without requiring different follow logic per account.

The correct order of repair is:

1. Fix session initialization and consistency.
2. Initialize both hashes during SSO login.
3. Render the canonical 20-character main hash.
4. Send it explicitly from `Wo_RegisterFollow()`.
5. Keep server-side validation.
6. Add clear error responses and logging.
7. Only then investigate automatic acceptance behavior.

Do not begin by changing all follow buttons or removing the security check. That would hide the shared session defect and leave other WoWonder operations such as reactions, event actions, forum operations, payments, and administrative requests vulnerable to the same failure.
