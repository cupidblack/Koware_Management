# 3. Recommended architecture

I recommend **not** putting the entire diagnostic subsystem into `functions_two.php`.

Instead:

### `init.php`

Owns:

* session configuration
* diagnostic logger
* session bootstrap
* shutdown diagnostic

### `functions_two.php`

Owns:

* `Wo_CreateSession()`
* `Wo_CheckSession()`
* `Wo_CreateMainSession()`
* `Wo_CheckMainSession()`

Those four functions call the diagnostic logger.

This gives us a much cleaner separation:

```text
Streams request
     │
     ▼
init.php
     │
     ├── configure BUZZSTREAMSESSID
     ├── configure /streams cookie
     ├── configure session storage
     ├── start session
     ├── diagnostic snapshot
     │
     ▼
functions_two.php
     │
     ├── Wo_CreateSession()
     ├── Wo_CheckSession()
     ├── Wo_CreateMainSession()
     └── Wo_CheckMainSession()
     │
     ▼
WoWonder application
     │
     ▼
shutdown diagnostic
```

This also means we don't have to touch `follow_user.php` or the theme files.

```php
    function bz_session_value_diagnostic($value)
    {
        if (!is_scalar($value)) {
            $value = '';
        }

        $value = (string) $value;

        return array(
            'present' => ($value !== ''),
            'length' => strlen($value),
            'fingerprint' => ($value !== '')
                ? hash('sha256', $value)
                : '',
            'format' => ($value === '')
                ? 'empty'
                : (
                    preg_match('/^[a-f0-9]+$/i', $value)
                        ? 'hexadecimal'
                        : 'non_hexadecimal'
                )
        );
    }
}

    function bz_session_cookie_diagnostics()
    {
        $names = array(
            'BUZZSTREAMSESSID',
            'BUZZSOCIALSESSID',
            'PHPSESSID',
            'buzz_sso',
            'buzz_access',
            'buzz_refresh',
            'user_id',
            'JWT'
        );

        $result = array();

        foreach ($names as $name) {

            $present = isset($_COOKIE[$name]);

            $result[$name] = array(
                'present' => $present,
                'length' => $present
                    ? strlen((string) $_COOKIE[$name])
                    : 0,
                'fingerprint' => $present
                    ? hash('sha256', (string) $_COOKIE[$name])
                    : ''
            );
        }

        return $result;
    }
}

        $uri = isset($_SERVER['REQUEST_URI'])

        return preg_replace(
            '/([?&](?:hash_id|hash|sso_token|buzz_access|buzz_refresh|token|password)=)[^&]*/i',
            '$1[REDACTED]',
            $uri
        );
    }

if (!function_exists('Wo_SessionDiagnosticLog')) {
    function Wo_SessionDiagnosticLog($event, $context = array())
    {
        $file = bz_stream_session_log_path();
        $directory = dirname($file);

        /*
         * Ensure the directory exists.
         */
        if (!is_dir($directory)) {

            @mkdir($directory, 0750, true);
        }

        /*
         * Determine whether the directory is actually writable.
         */
        $directory_exists = is_dir($directory);
        $directory_writable = $directory_exists && is_writable($directory);

        /*
         * Add standard request/session information.
         */
        if (!is_array($context)) {
            $context = array(
                'value' => (string) $context
            );
        }

        $context['timestamp_utc'] = gmdate('c');

        $context['pid'] = function_exists('getmypid')
            ? (int) getmypid()
            : 0;

        $context['sapi'] = function_exists('php_sapi_name')
            ? php_sapi_name()
            : '';

        $context['request_method'] =
            isset($_SERVER['REQUEST_METHOD'])
                ? (string) $_SERVER['REQUEST_METHOD']
                : '';

        $context['request_uri'] =
            bz_session_safe_request_uri();

        $context['script_filename'] =
            isset($_SERVER['SCRIPT_FILENAME'])
                ? (string) $_SERVER['SCRIPT_FILENAME']
                : '';

        $context['http_host'] =
            isset($_SERVER['HTTP_HOST'])
                ? (string) $_SERVER['HTTP_HOST']
                : '';

        $context['log_file'] = $file;

        $context['log_directory_exists'] =
            $directory_exists;

        $context['log_directory_writable'] =
            $directory_writable;

        $context['session_state'] =
            bz_session_state_snapshot();

        $context['trace'] =
            bz_session_trace(15);

        $record = array(
            'event' => (string) $event,
            'context' => $context
        );

        $json = json_encode(
            $record,
            JSON_UNESCAPED_SLASHES |
            JSON_UNESCAPED_UNICODE |
            JSON_PARTIAL_OUTPUT_ON_ERROR
        );

        if ($json === false) {
            return false;
        }

        /*
         * Write atomically with a lock.
         */
        $written = @file_put_contents(
            $file,
            $json . PHP_EOL,
            FILE_APPEND | LOCK_EX
        );

        return ($written !== false);
    }
}

if (!function_exists('bz_safe_session_start')) {
    function bz_safe_session_start()
    {
        if (!function_exists('session_status')) {

            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' =>
                        'session_status_unavailable'
                )
            );

            return false;
        }

        if (session_status() === PHP_SESSION_ACTIVE) {

            Wo_SessionDiagnosticLog(
                'session_already_active',
                array(
                    'session_id' =>
                        bz_session_value_diagnostic(
                            session_id()
                        )
                )
            );

            return true;
        }

        if (session_status() !== PHP_SESSION_NONE) {

            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' =>
                        'session_not_startable',

                    'session_status' =>
                        session_status()
                )
            );

            return false;
        }

        if (headers_sent($headers_file, $headers_line)) {

            Wo_SessionDiagnosticLog(
                'session_start_failed',
                array(
                    'reason' =>
                        'headers_already_sent',

                    'headers_file' =>
                        $headers_file,

                    'headers_line' =>
                        (int) $headers_line
                )
            );

            return false;
        }

        $before_id = function_exists('session_id')
            ? (string) session_id()
            : '';

        try {

            $started = session_start();

        } catch (Throwable $exception) {

            Wo_SessionDiagnosticLog(
                'session_start_exception',
                array(
                    'exception_class' =>
                        get_class($exception),

                    'exception_message' =>
                        $exception->getMessage()
                )
            );

            return false;
        }

        $active =
            ($started &&
             session_status() === PHP_SESSION_ACTIVE);

        Wo_SessionDiagnosticLog(
            $active
                ? 'session_started'
                : 'session_start_failed',
            array(
                'start_return_value' =>
                    (bool) $started,

                'before_session_id' =>
                    bz_session_value_diagnostic(
                        $before_id
                    ),

                'after_session_id' =>
                    bz_session_value_diagnostic(
                        function_exists('session_id')
                            ? session_id()
                            : ''
                    ),

                'last_error' =>
                    error_get_last()
            )
        );

        return $active;
    }
}
```

```php
        if ($existing !== '') {

            Wo_SessionDiagnosticLog(
                'Wo_CreateSession_invalid_existing_value',
                array(
                    'session_key' => 'hash_id',

                    'existing_value' =>
                        Wo_SessionValueDiagnostic(
                            $existing
                        )
                )
            );
        }

        try {

            $hash = bin2hex(
                random_bytes(20)
            );

        } catch (Throwable $exception) {

            Wo_SessionDiagnosticLog(
                'Wo_CreateSession_random_generation_failed',
                array(
                    'session_key' => 'hash_id',

                    'exception_class' =>
                        get_class($exception),

                    'exception_message' =>
                        $exception->getMessage()
                )
            );

            return '';
        }

        $_SESSION['hash_id'] = $hash;

        Wo_SessionDiagnosticLog(
            'Wo_CreateSession_created',
            array(
                'session_key' => 'hash_id',

                'old_value' =>
                    Wo_SessionValueDiagnostic(
                        $existing
                    ),

                'new_value' =>
                    Wo_SessionValueDiagnostic(
                        $hash
                    ),

                'session_write_pending' => true,

                'duration_ms' =>
                    round(
                        (microtime(true) - $function_start) * 1000,
                        3
                    )
            )
        );

        /*
         * Immediately read it back from $_SESSION.
         *
         * This confirms that PHP accepted the assignment
         * during the current request.
         */
        $read_back = isset($_SESSION['hash_id'])
            ? (string) $_SESSION['hash_id']
            : '';

        Wo_SessionDiagnosticLog(
            'Wo_CreateSession_readback',
            array(
                'session_key' => 'hash_id',

                'readback_value' =>
                    Wo_SessionValueDiagnostic(
                        $read_back
                    ),

                'readback_matches' =>
                    hash_equals(
                        $hash,
                        $read_back
                    )
            )
        );

        return $hash;
    }
```

# 7. Why this version is better than the previous implementation

There are several important changes.

### A. We no longer use `rand()`

The original:

```php
sha1(rand(1111, 9999))
```

has a very small random space.

The new implementation uses:

```php
random_bytes(20)
```

and:

```php
bin2hex()
```

This gives us cryptographically strong random session hash values.

---

### B. `Wo_CheckMainSession()` no longer contains unreachable debugging code

Your previous version had:

```php
if ($hash == $_SESSION["main_hash_id"]) {
    return true;

    print_r(...);
}
```

Anything after:

```php
return true;
```

is unreachable.

That has been corrected.

---

### C. We distinguish four different failure classes

For example:

```text
provided_hash_empty
stored_hash_empty
provided_hash_invalid_format
stored_hash_invalid_format
```

This is important.

If the log says:

```text
stored_hash_empty
```

then the problem is session persistence.

If it says:

```text
provided_hash_empty
```

then the session may be perfectly healthy and the problem is the code that calls:

```php
Wo_CheckMainSession($hash)
```

with an empty argument.

Those are completely different problems.

---

# 8. The most important diagnostic addition: session storage

Every relevant log entry now records:

```text
session_name
session_id
session_save_path
session_save_handler
session_serialize_handler
session_use_cookies
session_use_only_cookies
session_use_strict_mode
session_cookie_params
```

The actual session ID is **not exposed**; only its fingerprint is logged.

So we should be able to see something similar to:

```json
"session_name":"BUZZSTREAMSESSID",
"session_save_path":"/some/php/session/path",
"session_save_handler":"files",
"session_cookie_params":{
    "path":"/streams",
    "domain":".buzzjuice.net",
    "secure":true,
    "httponly":true,
    "samesite":"Lax"
}
```

That directly answers your first requirement.

---

# 9. Why `BUZZSTREAMSESSID` matters

Your developer tools currently show:

```text
BUZZSTREAMSESSID
/streams
```

and separately:

```text
PHPSESSID
/
```

This is exactly the separation we want.

Streams should effectively have:

```text
BUZZSTREAMSESSID
Path: /streams
Domain: .buzzjuice.net
```

while QuickDate can retain its own session mechanism.

We should **not** attempt to make:

```text
BUZZSTREAMSESSID
```

and:

```text
PHPSESSID
```

share a session.

Instead:

```text
WordPress
   │
   └── SSO/JWT
          │
          ├── Streams
          │      └── BUZZSTREAMSESSID
          │             ├── hash_id
          │             └── main_hash_id
          │
          └── QuickDate
                 └── its own session
```

That is much safer.

The QuickDate SSO bridge itself describes its modern SSO trust as JWT-based rather than relying on PHP session persistence. ([GitHub][3])

# 10. One subtle but important point about the earlier logs

The earlier log showed:

```text
session_started
```

followed by:

```text
hash_id absent
main_hash_id absent
```

and then:

```text
hash_created: true
main_hash_created: true
```

That is **not itself an error**.

It simply means:

```text
request begins
       ↓
session exists
       ↓
Wo_CreateSession()
       ↓
hash_id created
       ↓
Wo_CreateMainSession()
       ↓
main_hash_id created
```

The problem becomes significant if a **subsequent request** shows:

```text
same session ID
```

but:

```text
hash_id absent
main_hash_id absent
```

or if the session ID itself changes unexpectedly.

The new logging will let us distinguish those cases.

### Request A — profile load

```text

Wo_CreateSession_created
Wo_CreateMainSession_created
```

### Request B — same profile reload

We want:


with the **same session ID fingerprint** and the same hash fingerprints.

### Request C — Follow

We want:



depending on which function the follow operation actually invokes.

### Request D — reload

If reload gives:

```text
new session ID
```

then the cookie/session continuity is broken.

If it gives:

```text
same session ID
different hash
```

then something regenerated/overwrote the hash.

If it gives:

```text

same hash
```



then we have a caller/value mismatch.

That distinction is exactly what we were missing previously.

## Bigger-picture recommendation

I would **not leave `Wo_CheckMainSession()` forced to `true` in production**.

The fact that forcing it to `true` makes Follow work is valuable evidence: it strongly indicates the Follow operation is being stopped by session validation rather than the Follow database operation itself.

The correct end state should be:

```text
WordPress
   ↓
SSO authentication
   ↓
Streams isolated PHP session
   ↓
stable BUZZSTREAMSESSID
   ↓
stable hash_id
   ↓
stable main_hash_id
   ↓
Wo_CheckSession()
Wo_CheckMainSession()
   ↓
normal WoWonder security
   ↓
Follow
```

The previous diagnostic work already established that WoWonder can create both hashes. ([GitHub][1]) The next DEBUG LOG-1 should tell us **whether they survive across requests and whether the caller is actually supplying the expected value**.
