Yes. I reviewed the **current Buzzjuice Streams repository code**, the previous ChatGPT proposal, and the GitHub review. The GitHub review correctly identified an important weakness in the previous proposal: the problem should not be treated as simply `confirm_followers`. The current implementation has several independent state-handling issues that can explain why account 66 works while other accounts behave differently. 

Most importantly, the current `Wo_IsFollowing()` returns `true` only when the count is **exactly 1**. If an account has duplicate active `Wo_Followers` rows, `COUNT(id)` becomes 2+, causing the function to report **not following even though an active relationship exists**. That is a particularly important account-corruption scenario to eliminate. 

I would therefore implement this as a **state-machine repair**, rather than simply forcing `active=1`.

## Recommended final architecture

The resulting flow will be:

```text
                ┌──────────────────────┐
                │ User taps Follow     │
                └──────────┬───────────┘
                           │
                           ▼
                  follow_user.php
                           │
                           ▼
                 Wo_RegisterFollow()
                           │
              ┌────────────┼────────────┐
              │            │            │
        active row     inactive row    no row
              │            │            │
              ▼            ▼            ▼
          already       promote       INSERT
          following     to active     active=1
              │            │            │
              └────────────┼────────────┘
                           ▼
                    verify database
                           │
                           ▼
                  authoritative JSON
                           │
                           ▼
                 JavaScript renders
                           │
                     ┌─────┴─────┐
                     ▼           ▼
                 Following     Follow
```

`Requested` is no longer generated optimistically by JavaScript. It can only appear if the server explicitly reports an actual `active=0` relationship. This is consistent with the GitHub review.

# 1. `functions_one.php`

There are **four changes** I recommend here:

1. Add the diagnostic logger.
2. Fix `Wo_IsFollowing()`.
3. Refactor `Wo_RegisterFollow()`.
4. Make `Wo_DeleteFollow()` reliably remove the complete relationship.

The existing customized `Wo_RegisterFollow()` already forces `$active = 1`, but it still blindly inserts a new row. It also does not account for an existing `active=0` row. 

### 1A. Add the diagnostic logger

Place this before the follow-related functions in:

`streams/assets/includes/functions_one.php`

```php
/*
 * ========================================================================
 * BUZZJUICE STREAMS FOLLOW DIAGNOSTICS
 * ========================================================================
 *
 * Log:
 *   /buzzjuice.net/data.logs/bzj-streams-follow.log
 *
 * Never log passwords, JWTs, cookies, sessions, authorization headers,
 * or other authentication secrets.
 */

if (!function_exists('bzj_streams_follow_log')) {
    function bzj_streams_follow_log($event, $context = array())
    {
        $application_root = dirname(__DIR__, 3);

        if (
            defined('DOCUMENT_ROOT') &&
            DOCUMENT_ROOT !== '' &&
            is_dir(rtrim(DOCUMENT_ROOT, '/') . '/data.logs')
        ) {
            $application_root = rtrim(DOCUMENT_ROOT, '/');
        }

        $log_dir  = rtrim($application_root, '/') . '/data.logs';
        $log_file = $log_dir . '/bzj-streams-follow.log';

        if (!is_dir($log_dir)) {
            @mkdir($log_dir, 0750, true);
        }

        $sensitive_keys = array(
            'password',
            'pass',
            'token',
            'access_token',
            'refresh_token',
            'jwt',
            'cookie',
            'cookies',
            'session',
            'session_id',
            'authorization',
            'hash_id'
        );

        foreach ($sensitive_keys as $key) {
            if (array_key_exists($key, $context)) {
                unset($context[$key]);
            }
        }

        $current_user_id = 0;

        if (
            isset($GLOBALS['wo']) &&
            is_array($GLOBALS['wo']) &&
            !empty($GLOBALS['wo']['user']['user_id'])
        ) {
            $current_user_id = (int) $GLOBALS['wo']['user']['user_id'];
        }

        $payload = array(
            'time'       => gmdate('c'),
            'event'      => (string) $event,
            'user_id'    => $current_user_id,
            'request_id' => function_exists('wp_generate_uuid4')
                ? wp_generate_uuid4()
                : sha1(uniqid('', true)),
            'method'     => isset($_SERVER['REQUEST_METHOD'])
                ? (string) $_SERVER['REQUEST_METHOD']
                : '',
            'uri'        => isset($_SERVER['REQUEST_URI'])
                ? substr((string) $_SERVER['REQUEST_URI'], 0, 500)
                : '',
            'context'    => $context
        );

        $json = json_encode(
            $payload,
            JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE
        );

        if ($json !== false) {
            @file_put_contents(
                $log_file,
                $json . PHP_EOL,
                FILE_APPEND | LOCK_EX
            );
        }
    }
}
```

This follows the GitHub recommendation and gives us a persistent diagnostic trail without putting credentials into the log.

# 2. Fix `Wo_IsFollowing()`

This is one of the most important corrections.

Your current implementation effectively does:

```php
COUNT(id) == 1
```

rather than:

```php
COUNT(id) > 0
```

That means duplicate active rows can make a genuinely active relationship appear to be inactive. 

Replace the current function with:

```php
function Wo_IsFollowing($following_id, $user_id = 0)
{
    global $sqlConnect, $wo;

    if ($wo['loggedin'] == false) {
        return false;
    }

    if (
        empty($following_id) ||
        !is_numeric($following_id) ||
        $following_id < 1
    ) {
        return false;
    }

    if (
        empty($user_id) ||
        !is_numeric($user_id) ||
        $user_id < 1
    ) {
        $user_id = $wo['user']['user_id'];
    }

    $following_id = (int) Wo_Secure($following_id);
    $user_id      = (int) Wo_Secure($user_id);

    $query = mysqli_query(
        $sqlConnect,
        "SELECT `id`
         FROM " . T_FOLLOWERS . "
         WHERE `following_id` = {$following_id}
           AND `follower_id` = {$user_id}
           AND `active` = '1'
         LIMIT 1"
    );

    if (!$query) {
        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'IS_FOLLOWING_QUERY_FAILED',
                array(
                    'following_id' => $following_id,
                    'follower_id'   => $user_id,
                    'mysql_error'   => mysqli_error($sqlConnect)
                )
            );
        }

        return false;
    }

    return mysqli_num_rows($query) > 0;
}
```

### Why this matters

Now:

```text
0 active rows → false
1 active row  → true
2 active rows → true
10 active rows → true
```

The duplicate itself remains a database-cleanup issue, but it can no longer make the application incorrectly believe that the user is not following.

# 3. Replace `Wo_RegisterFollow()`

This is the core repair.

The current implementation correctly forces `active=1`, but it doesn't handle an existing inactive relationship and doesn't guard against duplicate relationships. 

Replace the current customized `Wo_RegisterFollow()` with:

```php
//BCR&D
function Wo_RegisterFollow($following_id = 0, $followers_id = 0)
{
    global $wo, $sqlConnect;

    if ($wo['loggedin'] == false) {
        return false;
    }

    if (
        !isset($following_id) ||
        empty($following_id) ||
        !is_numeric($following_id) ||
        $following_id < 1
    ) {
        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'REGISTER_INVALID_FOLLOWING_ID',
                array(
                    'following_id' => $following_id
                )
            );
        }

        return false;
    }

    if (!is_array($followers_id)) {
        $followers_id = array($followers_id);
    }

    $overall_success = true;

    foreach ($followers_id as $follower_id) {

        if (
            !isset($follower_id) ||
            empty($follower_id) ||
            !is_numeric($follower_id) ||
            $follower_id < 1
        ) {
            $overall_success = false;

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_INVALID_FOLLOWER_ID',
                    array(
                        'following_id' => $following_id,
                        'follower_id'   => $follower_id
                    )
                );
            }

            continue;
        }

        $following_id_safe = (int) Wo_Secure($following_id);
        $follower_id_safe  = (int) Wo_Secure($follower_id);

        if ($following_id_safe === $follower_id_safe) {
            $overall_success = false;

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_SELF_FOLLOW_BLOCKED',
                    array(
                        'following_id' => $following_id_safe,
                        'follower_id'   => $follower_id_safe
                    )
                );
            }

            continue;
        }

        /*
         * Blocked users must never be able to establish a follow.
         */
        if (Wo_IsBlocked($following_id_safe)) {
            $overall_success = false;

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_BLOCKED',
                    array(
                        'following_id' => $following_id_safe,
                        'follower_id'   => $follower_id_safe
                    )
                );
            }

            continue;
        }

        /*
         * Load both users.
         */
        $follower_data  = Wo_UserData($follower_id_safe);
        $following_data = Wo_UserData($following_id_safe);

        if (
            empty($follower_data['user_id']) ||
            empty($following_data['user_id'])
        ) {
            $overall_success = false;

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_USER_LOOKUP_FAILED',
                    array(
                        'following_id' => $following_id_safe,
                        'follower_id'   => $follower_id_safe,
                        'follower_found' => !empty($follower_data['user_id']),
                        'following_found' => !empty($following_data['user_id'])
                    )
                );
            }

            continue;
        }

        /*
         * Preserve the existing WoWonder privacy restriction.
         *
         * IMPORTANT:
         * This restriction must not create active=0.
         * It either permits the follow or rejects it.
         */
        if (
            isset($following_data['follow_privacy']) &&
            (int) $following_data['follow_privacy'] === 1
        ) {
            if (
                Wo_IsFollowing(
                    $follower_id_safe,
                    $following_id_safe
                ) === false
            ) {
                $overall_success = false;

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'REGISTER_PRIVACY_REJECTED',
                        array(
                            'following_id' => $following_id_safe,
                            'follower_id'   => $follower_id_safe
                        )
                    );
                }

                continue;
            }
        }

        /*
         * Inspect ALL existing rows for this relationship.
         *
         * We deliberately do not use Wo_IsFollowing() here because
         * this diagnostic/state-transition operation needs to know
         * whether duplicate rows exist.
         */
        $existing_query = mysqli_query(
            $sqlConnect,
            "SELECT `id`, `active`
             FROM " . T_FOLLOWERS . "
             WHERE `following_id` = {$following_id_safe}
               AND `follower_id` = {$follower_id_safe}
             ORDER BY `id` DESC"
        );

        if (!$existing_query) {
            $overall_success = false;

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_EXISTING_QUERY_FAILED',
                    array(
                        'following_id' => $following_id_safe,
                        'follower_id'   => $follower_id_safe,
                        'mysql_error'   => mysqli_error($sqlConnect)
                    )
                );
            }

            continue;
        }

        $rows = array();

        while ($row = mysqli_fetch_assoc($existing_query)) {
            $rows[] = array(
                'id'     => (int) $row['id'],
                'active' => (int) $row['active']
            );
        }

        $active_rows   = array();
        $inactive_rows = array();

        foreach ($rows as $row) {
            if ($row['active'] === 1) {
                $active_rows[] = $row;
            } else {
                $inactive_rows[] = $row;
            }
        }

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'REGISTER_EXISTING_STATE',
                array(
                    'following_id' => $following_id_safe,
                    'follower_id'   => $follower_id_safe,
                    'total_rows'    => count($rows),
                    'active_rows'   => count($active_rows),
                    'inactive_rows' => count($inactive_rows)
                )
            );
        }

        /*
         * ---------------------------------------------------------------
         * CASE 1:
         * Already actively following.
         *
         * Do NOT insert another row.
         * ---------------------------------------------------------------
         */
        if (count($active_rows) > 0) {

            cache($following_id_safe, 'users', 'delete');
            cache($follower_id_safe, 'users', 'delete');

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_ALREADY_ACTIVE',
                    array(
                        'following_id' => $following_id_safe,
                        'follower_id'   => $follower_id_safe,
                        'active_rows'   => count($active_rows),
                        'inactive_rows' => count($inactive_rows)
                    )
                );
            }

            continue;
        }

        /*
         * ---------------------------------------------------------------
         * CASE 2:
         * Existing inactive/requested relationship.
         *
         * Promote ONE existing row to active.
         *
         * Do not create another row.
         * ---------------------------------------------------------------
         */
        if (count($inactive_rows) > 0) {

            $relationship_id = (int) $inactive_rows[0]['id'];

            $promote_query = mysqli_query(
                $sqlConnect,
                "UPDATE " . T_FOLLOWERS . "
                 SET `active` = '1'
                 WHERE `id` = {$relationship_id}
                 LIMIT 1"
            );

            if (!$promote_query) {
                $overall_success = false;

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'REGISTER_PROMOTION_FAILED',
                        array(
                            'following_id' => $following_id_safe,
                            'follower_id'   => $follower_id_safe,
                            'relationship_id' => $relationship_id,
                            'mysql_error'   => mysqli_error($sqlConnect)
                        )
                    );
                }

                continue;
            }

            /*
             * Remove duplicate inactive rows belonging to the same
             * relationship. We only do this after one row has been
             * successfully promoted.
             *
             * This prevents an old requested relationship from remaining
             * alongside the new active relationship.
             */
            if (count($inactive_rows) > 1) {

                $keep_id = $relationship_id;

                $cleanup_query = mysqli_query(
                    $sqlConnect,
                    "DELETE FROM " . T_FOLLOWERS . "
                     WHERE `following_id` = {$following_id_safe}
                       AND `follower_id` = {$follower_id_safe}
                       AND `active` = '0'
                       AND `id` <> {$keep_id}"
                );

                if (!$cleanup_query) {
                    if (function_exists('bzj_streams_follow_log')) {
                        bzj_streams_follow_log(
                            'REGISTER_INACTIVE_DUPLICATE_CLEANUP_FAILED',
                            array(
                                'following_id' => $following_id_safe,
                                'follower_id'   => $follower_id_safe,
                                'mysql_error'   => mysqli_error($sqlConnect)
                            )
                        );
                    }
                }
            }

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_LEGACY_PROMOTED',
                    array(
                        'following_id'   => $following_id_safe,
                        'follower_id'    => $follower_id_safe,
                        'relationship_id' => $relationship_id,
                        'old_active'     => 0,
                        'new_active'     => 1
                    )
                );
            }

        } else {

            /*
             * -----------------------------------------------------------
             * CASE 3:
             * No relationship exists.
             *
             * Buzzjuice Streams uses immediate following:
             * active = 1.
             * -----------------------------------------------------------
             */
            $insert_query = mysqli_query(
                $sqlConnect,
                "INSERT INTO " . T_FOLLOWERS . "
                 (`following_id`, `follower_id`, `active`)
                 VALUES
                 ({$following_id_safe}, {$follower_id_safe}, '1')"
            );

            if (!$insert_query) {
                $overall_success = false;

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'REGISTER_INSERT_FAILED',
                        array(
                            'following_id' => $following_id_safe,
                            'follower_id'   => $follower_id_safe,
                            'mysql_error'   => mysqli_error($sqlConnect)
                        )
                    );
                }

                continue;
            }

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_INSERTED',
                    array(
                        'following_id'    => $following_id_safe,
                        'follower_id'     => $follower_id_safe,
                        'relationship_id' => (int) mysqli_insert_id($sqlConnect),
                        'active'          => 1
                    )
                );
            }
        }

        /*
         * ---------------------------------------------------------------
         * AUTHORITATIVE DATABASE VERIFICATION
         * ---------------------------------------------------------------
         */
        $verify_query = mysqli_query(
            $sqlConnect,
            "SELECT COUNT(`id`) AS `active_count`
             FROM " . T_FOLLOWERS . "
             WHERE `following_id` = {$following_id_safe}
               AND `follower_id` = {$follower_id_safe}
               AND `active` = '1'"
        );

        if (!$verify_query) {
            $overall_success = false;

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_VERIFY_QUERY_FAILED',
                    array(
                        'following_id' => $following_id_safe,
                        'follower_id'   => $follower_id_safe,
                        'mysql_error'   => mysqli_error($sqlConnect)
                    )
                );
            }

            continue;
        }

        $verify_row = mysqli_fetch_assoc($verify_query);
        $active_count = isset($verify_row['active_count'])
            ? (int) $verify_row['active_count']
            : 0;

        if ($active_count < 1) {
            $overall_success = false;

            if (function_exists('bzj_streams_follow_log')) {
                bzj_streams_follow_log(
                    'REGISTER_VERIFY_FAILED',
                    array(
                        'following_id' => $following_id_safe,
                        'follower_id'   => $follower_id_safe,
                        'active_count'  => $active_count
                    )
                );
            }

            continue;
        }

        /*
         * Clear user caches after the database transition.
         */
        cache($following_id_safe, 'users', 'delete');
        cache($follower_id_safe, 'users', 'delete');

        /*
         * Only register notification/activity for an actual transition.
         *
         * Existing active relationship was handled above and therefore
         * does not create duplicate notifications.
         */
        $notification_data = array(
            'recipient_id' => $following_id_safe,
            'notifier_id'  => $follower_id_safe,
            'type'         => 'following',
            'url'          => 'index.php?link1=timeline&u=' .
                              $follower_data['username']
        );

        Wo_RegisterNotification($notification_data);

        $activity_data = array(
            'user_id'       => $follower_id_safe,
            'follow_id'     => $following_id_safe,
            'activity_type' => 'following'
        );

        Wo_RegisterActivity($activity_data);

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'REGISTER_VERIFY_SUCCESS',
                array(
                    'following_id' => $following_id_safe,
                    'follower_id'   => $follower_id_safe,
                    'active_count'  => $active_count
                )
            );
        }
    }

    return $overall_success;
}
```

This retains the important WoWonder notification/activity behavior rather than discarding it, which was one of the concerns correctly raised by GitHub.

# 4. `follow_user.php`

The existing endpoint is particularly problematic because its current decision logic can treat an existing requested relationship as something to delete. 

Replace the entire file with:

```php
<?php

if (
    $f === 'follow_user' &&
    !empty($wo['loggedin']) &&
    $wo['loggedin'] === true
) {

    $data = array(
        'status'        => 400,
        'can_send'      => 0,
        'following'     => false,
        'requested'     => false,
        'follow_status' => 'follow',
        'message'       => ''
    );

    $follower_id = !empty($wo['user']['user_id'])
        ? (int) $wo['user']['user_id']
        : 0;

    $following_id = 0;

    /*
     * Validate target.
     */
    if (
        !isset($_GET['following_id']) ||
        !is_numeric($_GET['following_id']) ||
        (int) $_GET['following_id'] < 1
    ) {

        $data['message'] = 'Invalid follow target.';

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'XHR_INVALID_TARGET',
                array(
                    'follower_id' => $follower_id,
                    'target'      => isset($_GET['following_id'])
                        ? $_GET['following_id']
                        : null
                )
            );
        }

    } elseif (
        !isset($hash_id) ||
        Wo_CheckMainSession($hash_id) !== true
    ) {

        $data['message'] = 'Invalid session.';

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'XHR_INVALID_SESSION',
                array(
                    'follower_id' => $follower_id
                )
            );
        }

    } else {

        $following_id = (int) $_GET['following_id'];

        /*
         * Self-follow protection.
         */
        if ($following_id === $follower_id) {

            $data['message'] = 'You cannot follow yourself.';

        }

        /*
         * ---------------------------------------------------------------
         * ACTIVE RELATIONSHIP
         *
         * Clicking Following means UNFOLLOW.
         * ---------------------------------------------------------------
         */
        elseif (
            Wo_IsFollowing(
                $following_id,
                $follower_id
            ) === true
        ) {

            $deleted = Wo_DeleteFollow(
                $following_id,
                $follower_id
            );

            if ($deleted === true) {

                $data['status']        = 200;
                $data['following']     = false;
                $data['requested']     = false;
                $data['follow_status'] = 'follow';
                $data['message']       = 'Follow removed.';

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'XHR_UNFOLLOW_SUCCESS',
                        array(
                            'follower_id'  => $follower_id,
                            'following_id' => $following_id
                        )
                    );
                }

            } else {

                $data['message'] = 'Unable to remove the follow.';

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'XHR_UNFOLLOW_FAILED',
                        array(
                            'follower_id'  => $follower_id,
                            'following_id' => $following_id
                        )
                    );
                }
            }

        }

        /*
         * ---------------------------------------------------------------
         * NOT CURRENTLY ACTIVE
         *
         * This includes:
         *
         *   no row
         *   active=0 row
         *
         * Wo_RegisterFollow() is responsible for turning this into
         * active=1.
         * ---------------------------------------------------------------
         */
        else {

            $user_followers = Wo_CountFollowing(
                $follower_id,
                true
            );

            $friends_limit = isset(
                $wo['config']['connectivitySystemLimit']
            )
                ? (int) $wo['config']['connectivitySystemLimit']
                : 0;

            $limit_reached =
                isset($wo['config']['connectivitySystem']) &&
                (int) $wo['config']['connectivitySystem'] === 1 &&
                $friends_limit > 0 &&
                $user_followers >= $friends_limit;

            if ($limit_reached) {

                $data['message'] =
                    'You have reached the maximum number of follows.';

                if (function_exists('bzj_streams_follow_log')) {
                    bzj_streams_follow_log(
                        'XHR_FOLLOW_LIMIT_REACHED',
                        array(
                            'follower_id'  => $follower_id,
                            'following_id' => $following_id,
                            'current_count' => $user_followers,
                            'limit'         => $friends_limit
                        )
                    );
                }

            } else {

                $registered = Wo_RegisterFollow(
                    $following_id,
                    $follower_id
                );

                if ($registered === true) {

                    $is_following = Wo_IsFollowing(
                        $following_id,
                        $follower_id
                    );

                    if ($is_following === true) {

                        $data['status']        = 200;
                        $data['following']     = true;
                        $data['requested']     = false;
                        $data['follow_status'] = 'following';
                        $data['message']       = 'Following.';

                        if (
                            function_exists('Wo_CanSenEmails') &&
                            Wo_CanSenEmails()
                        ) {
                            $data['can_send'] = 1;
                        }

                        if (function_exists('bzj_streams_follow_log')) {
                            bzj_streams_follow_log(
                                'XHR_FOLLOW_SUCCESS',
                                array(
                                    'follower_id'  => $follower_id,
                                    'following_id' => $following_id
                                )
                            );
                        }

                    } else {

                        $data['message'] =
                            'The follow was not persisted.';

                        if (function_exists('bzj_streams_follow_log')) {
                            bzj_streams_follow_log(
                                'XHR_FOLLOW_VERIFY_FAILED',
                                array(
                                    'follower_id'  => $follower_id,
                                    'following_id' => $following_id
                                )
                            );
                        }
                    }

                } else {

                    $data['message'] =
                        'This account cannot be followed at this time.';

                    if (function_exists('bzj_streams_follow_log')) {
                        bzj_streams_follow_log(
                            'XHR_REGISTER_FOLLOW_FAILED',
                            array(
                                'follower_id'  => $follower_id,
                                'following_id' => $following_id
                            )
                        );
                    }
                }
            }
        }
    }

    /*
     * Clear cache after a successful state transition.
     */
    if (
        $data['status'] === 200 &&
        function_exists('Wo_CleanCache')
    ) {
        Wo_CleanCache();
    }

    /*
     * ---------------------------------------------------------------
     * SERVER-AUTHORITATIVE FINAL STATE
     * ---------------------------------------------------------------
     */
    if (
        $following_id > 0 &&
        $follower_id > 0
    ) {

        $final_following = Wo_IsFollowing(
            $following_id,
            $follower_id
        );

        $final_requested = Wo_IsFollowRequested(
            $following_id,
            $follower_id
        );

        if ($final_following === true) {

            $data['following']     = true;
            $data['requested']     = false;
            $data['follow_status'] = 'following';

        } elseif ($final_requested === true) {

            $data['following']     = false;
            $data['requested']     = true;
            $data['follow_status'] = 'requested';

        } else {

            $data['following']     = false;
            $data['requested']     = false;
            $data['follow_status'] = 'follow';
        }

        if (function_exists('bzj_streams_follow_log')) {
            bzj_streams_follow_log(
                'XHR_FINAL_STATE',
                array(
                    'follower_id'  => $follower_id,
                    'following_id' => $following_id,
                    'status'       => $data['status'],
                    'following'    => $data['following'],
                    'requested'    => $data['requested'],
                    'follow_status'=> $data['follow_status']
                )
            );
        }
    }

    header('Content-Type: application/json; charset=utf-8');

    echo json_encode($data);

    exit();
}
```

The important difference is that **the browser no longer decides whether a click means "follow", "requested", or "unfollow". The database state does.**

# 6. Fix the frontend race condition

This is another major part of the problem.

The current JavaScript immediately changes the button to `Following`/`Requested` **before the AJAX response comes back**. The current function does exactly that at lines 297–320, and then separately performs the AJAX request. 

That means the browser can temporarily display a state that the database never accepted.

Replace the existing `Wo_RegisterFollow()` JavaScript function in:

`streams/themes/sunshine/layout/extra_js/content.phtml`

with:

```javascript
function Wo_RegisterFollow(id, is_confirm, show_modal) {

    var followContainer = $('[id="Follow-' + id + '"]');

    /*
     * Compatibility with existing callers.
     *
     * The server is authoritative.
     * is_confirm is deliberately ignored.
     */
    if (show_modal === true) {

        $('#unfriend_btn').attr(
            'onclick',
            'Wo_RegisterFollow(' + id + ')'
        );

        $('#un_friend_modal').modal('show');

        return false;
    }

    $('#un_friend_modal').modal('hide');

    var button = followContainer.find('button').first();

    if (
        !button.length ||
        button.prop('disabled')
    ) {
        return false;
    }

    var originalHtml = followContainer.html();

    var wasFollowing =
        button.hasClass('btn-active') ||
        button.hasClass('wo_following_btn');

    /*
     * Prevent double-clicks while the server is processing the request.
     */
    button.prop('disabled', true);

    $.ajax({
        url: Wo_Ajax_Requests_File(),
        type: 'GET',
        dataType: 'json',

        data: {
            f: 'follow_user',
            following_id: id
        }

    }).done(function(data) {

        /*
         * The server did not accept the operation.
         *
         * Restore the exact previous markup.
         */
        if (
            !data ||
            parseInt(data.status, 10) !== 200
        ) {

            followContainer.html(originalHtml);

            followContainer
                .find('button')
                .prop('disabled', false);

            console.error(
                'Buzzjuice follow request failed.',
                data
            );

            if ($('#modal-alert').length) {

                $('#modal-alert').modal('show');

                if (typeof Wo_Delay === 'function') {

                    Wo_Delay(
                        function() {
                            $('#modal-alert').modal('hide');
                        },
                        3000
                    );
                }
            }

            return;
        }

        /*
         * -------------------------------------------------------------
         * SERVER-AUTHORITATIVE STATE
         * -------------------------------------------------------------
         */

        var isFollowing =
            data.following === true ||
            data.follow_status === 'following';

        var isRequested =
            data.requested === true ||
            data.follow_status === 'requested';

        var currentButton =
            followContainer.find('button').first();

        /*
         * -------------------------------------------------------------
         * FOLLOWING
         * -------------------------------------------------------------
         */
        if (isFollowing) {

            currentButton
                .removeClass(
                    'wo_follow_btn ' +
                    'wo_request_btn ' +
                    'btn-requested'
                )
                .addClass(
                    'btn-active wo_following_btn'
                )
                .prop('disabled', false);

            currentButton
                .find('.button-text')
                .text(
                    ' <?php echo $wo["lang"]["following_btn"]; ?>'
                );

            if (
                typeof node_socket_flow !== 'undefined' &&
                node_socket_flow == '1' &&
                !wasFollowing &&
                typeof socket !== 'undefined'
            ) {

                socket.emit(
                    'user_notification',
                    {
                        to_id: id,
                        user_id: _getCookie('user_id'),
                        type: 'added'
                    }
                );
            }

        }

        /*
         * -------------------------------------------------------------
         * REQUESTED
         *
         * This is now only possible when the SERVER explicitly
         * reports an inactive relationship.
         * -------------------------------------------------------------
         */
        else if (isRequested) {

            currentButton
                .removeClass(
                    'wo_follow_btn ' +
                    'btn-active ' +
                    'wo_following_btn'
                )
                .addClass(
                    'btn-requested wo_request_btn'
                )
                .prop('disabled', false);

            currentButton
                .find('.button-text')
                .text(
                    ' <?php echo $wo["lang"]["requested"]; ?>'
                );

        }

        /*
         * -------------------------------------------------------------
         * FOLLOW
         * -------------------------------------------------------------
         */
        else {

            currentButton
                .removeClass(
                    'btn-active ' +
                    'wo_following_btn ' +
                    'btn-requested ' +
                    'wo_request_btn'
                )
                .addClass('wo_follow_btn')
                .prop('disabled', false);

            currentButton
                .find('.button-text')
                .text(
                    ' <?php echo $wo["lang"]["follow"]; ?>'
                );

            if (
                typeof node_socket_flow !== 'undefined' &&
                node_socket_flow == '1' &&
                wasFollowing &&
                typeof socket !== 'undefined'
            ) {

                socket.emit(
                    'user_notification',
                    {
                        to_id: id,
                        user_id: _getCookie('user_id'),

                    }

            .find('button')
```

# 8. Important SSO correction

I agree with GitHub that the SSO registration deserves attention, but **I would not use SSO as the first explanation for the current follow problem**.

Your current `bz_clean_username()` still does:

```php
preg_replace('/[^a-zA-Z0-9_]/', '', $username);
```

so a WordPress username such as:

```text
nii.yeboah
```

can become:

```text
niiyeboah
```

That is undesirable because the Buzzjuice WordPress identity should remain authoritative. 

Replace it with:

```php
if (!function_exists('bz_clean_username')) {
    function bz_clean_username($username)
    {
        /*
         * Do not silently strip punctuation.
         *
         * Username availability, reserved names and database
         * constraints are checked separately.
         */
        $username = trim((string) $username);

        if ($username === '') {
            return '';
        }

        return function_exists('mb_substr')
            ? mb_substr($username, 0, 32, 'UTF-8')
            : substr($username, 0, 32);
    }
}
```

This follows the GitHub recommendation. 

### One thing I would NOT retain from the old bridge

I would not allow this type of automatic conflict resolution:

```php
UPDATE Wo_Users
SET username = 'legacy_...'
```

against an existing account simply because a new WordPress username conflicts.

The safer hierarchy is:

```text
Existing wo_user_id
        ↓
verify account
        ↓
Exact email match
        ↓
Exact username match
        ↓
Conflict = stop and log
        ↓
Only then auto-register
```

That prevents SSO from silently modifying an unrelated user's identity.

# 15. Why the symptoms now make sense

With the current code, several different users can experience apparently random behavior even though the same button is being pressed.

### User A — works immediately

```text
No existing relationship
       ↓
Wo_RegisterFollow()
       ↓
INSERT active=1
       ↓
Wo_IsFollowing() = true
       ↓
Following
```

### User B — Requested

Potentially:

```text
Existing active=0 row
       ↓
Frontend uses confirm_followers
       ↓
Requested
```

or another old WoWonder path may have created `active=0`.

The current JavaScript explicitly generates the Requested state based on `confirm_followers`, before the AJAX request completes. 

### User C — stays Follow

Possible sequence:

```text
Wo_RegisterFollow()
       ↓
operation fails
       ↓
no reliable response state
       ↓
frontend reconstructs Follow
```

### User D — has active relationship but appears not to follow

This is the particularly interesting one:

```text
Wo_Followers:

id  | following | follower | active
----+-----------+----------+-------
101 | 200       | 300      | 1
102 | 200       | 300      | 1
```

Current:

```php
COUNT(id) == 1
```

returns false.

So the application effectively says:

> "You aren't following."

even though two active relationships exist.

The new implementation fixes this.

# 16. One further improvement I recommend

There is an architectural distinction worth preserving:

### `Wo_Users` attributes

These describe the **account**:

```text
active
verified
confirm_followers
follow_privacy
start_up
```

### `Wo_Followers`

This describes the **relationship**:

```text
following_id
follower_id
active
```

The relationship should therefore be the ultimate authority for:

```text
Follow
Following
Requested
```

rather than allowing:

```text
Wo_Users.confirm_followers
```

to override the actual relationship state.

That's the fundamental reason the new architecture is more reliable.
