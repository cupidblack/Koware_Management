## UPDATED INTEGRATION PROPOSAL

### Core Architecture Principle

**BuddyBoss is the authoritative source of truth.** The synchronization system acts as a state mirror and projection engine, not as an independent authority. All external platforms (Streams and Socials) sync *to* BuddyBoss, never *from* it independently.

### Revised Relationship Matrix

#### 1. CONNECTION/FRIENDSHIP MANAGEMENT

**Critical Finding:** The WoWonder Friends System is **disabled** in Buzzjuice Streams. Therefore, BuddyBoss connections do NOT create Streams friendships—only Socials friendships.

| Origin | BuddyBoss State | Streams State | Socials State |
|--------|-----------------|---------------|---------------|
| BuddyBoss connection request | Pending | — | Pending friend request |
| BuddyBoss connection accept | Connected | — | Confirmed friend |
| BuddyBoss connection reject | None | — | Remove pending |
| BuddyBoss connection withdraw | None | — | Remove pending |
| BuddyBoss unfriend | None | — | Remove friend |
| Socials friend request | Creates BB request | — | Pending |
| Socials accept friend | Creates BB connection | — | Connected |
| Socials reject/decline | Removes BB request | — | Removed |
| Socials unfriend | Removes BB connection | — | Removed |

**1.i - Connection Request Initiation (BuddyBoss)**
- When user A sends a connection request to user B on BuddyBoss, the `friends_friendship_requested` hook fires
- The sync plugin intercepts this and creates a pending "Add Friend" request in Socials (QuickDate)
- BuddyBoss connection restrictions (role, profile type, gender, etc.) remain authoritative and are NOT bypassed

**1.ii - Connection Request Cancellation (BuddyBoss)**
- When a connection request is withdrawn or rejected, the `friends_friendship_withdrawn` or `friends_friendship_rejected` hook fires
- The sync plugin removes the corresponding pending friend request from Socials

**2.i - Connection Acceptance (BuddyBoss)**
- When user B accepts user A's connection request, the `friends_friendship_accepted` hook fires
- The sync plugin creates a confirmed friendship in Socials (sets `active = 1` in the followers table)
- Both users are now connected on BuddyBoss and friends on Socials

**2.ii - Connection Removal (BuddyBoss)**
- When either user removes the connection, the `friends_friendship_deleted` hook fires
- The sync plugin removes the friendship from Socials
- No automatic re-connection occurs

#### 2. FOLLOW MANAGEMENT

| Origin | BuddyBoss | Streams | Socials |
|--------|-----------|---------|---------|
| BuddyBoss follow | Follow | Follow | Follow |
| BuddyBoss unfollow | None | Unfollow | Unfollow |
| Streams follow | Follow | Follow | Follow |
| Streams unfollow | Unfollow | None | Unfollow |
| Socials follow | Follow | Follow | Follow |
| Socials unfollow | Unfollow | Unfollow | None |

**Important:** Follow is independent from connection/friendship.

**4.i - Follow Creation (BuddyBoss)**
- When user A follows user B, the `bp_follow_start_following` hook fires
- The sync plugin creates follow records in both Streams and Socials
- User B receives a follower notification on all three platforms

**4.ii - Follow Removal (BuddyBoss)**
- When user A unfollows user B, the `bp_follow_stop_following` hook fires
- The sync plugin removes the follow from Streams and Socials

#### 3. BLOCK MANAGEMENT (Authoritative & Destructive)

**Critical Implementation:** Blocking is a **dominant state** that automatically terminates connections and follows.

| Origin | BuddyBoss | Streams | Socials |
|--------|-----------|---------|---------|
| BuddyBoss block | Block + remove connection + remove all follows | Block + remove follows | Block + remove friend + remove follows |
| BuddyBoss unblock | Unblock only (no auto-reconnect) | Unblock | Unblock |
| Streams block | Block BB | Block | Block Socials |
| Streams unblock | Unblock BB | Unblock | Unblock Socials |
| Socials block | Block BB | Block Streams | Block |
| Socials unblock | Unblock BB | Unblock Streams | Unblock |

**3.i - Block Creation (BuddyBoss)**
- When user A blocks user B, the `bp_moderation_block_created` hook fires
- The sync plugin executes this sequence:
  1. Check if they are connected; if yes, call `friends_remove_friend()`
  2. Remove any follows between them in both directions using `bp_stop_following()`
  3. Create block records in Streams (Wo_Blocks table) and Socials (blocks table)
  4. Remove any follows from Streams and Socials in both directions
  5. Log the operation with event tracking

**3.ii - Block Removal (BuddyBoss)**
- When user A unblocks user B, the `bp_moderation_unblock_created` hook fires
- The sync plugin removes the block from Streams and Socials
- **Critical:** Do NOT recreate the connection or follows—those must be re-established intentionally
- This prevents the undesirable situation where unblocking automatically reconnects users

#### 4. STREAMS (WoWonder) INITIATED ACTIONS

**6.ii - Block Removal (Streams)**
- When user A unblocks user B, the `Wo_RemoveBlock()` function is called
- A signed request to the endpoint removes the block from BuddyBoss and Socials

**7.ii - Reject/Cancel Friend Request (Socials)**

**8.ii - Unfriend (Socials)**

**9.i - Block (Socials)**

- The cascade removes connection and follows from all platforms

**9.ii - Unblock (Socials)**
- When user A unblocks user B, the `unblock()` function is called
- A signed request removes the block from BuddyBoss and Streams

**10.i - Follow (Socials)**
- When user A follows user B, the `Wo_RegisterFollow()` function is called (from QuickDate context)
- A signed request creates the follow on BuddyBoss
- All three platforms now reflect the follow

**10.ii - Unfollow (Socials)**
- When user A unfollows, `Wo_DeleteFollow()` is called

## CRITICAL IMPLEMENTATION NOTES

### 1. Loop Prevention Strategy

**Three-layer approach:**

- **Layer 1 — Context Marker:** When the sync plugin calls BuddyBoss functions (`friends_remove_friend()`, `bp_stop_following()`, etc.), a flag is set to mark the operation as internally generated.

- **Layer 2 — Event UUID:** Every operation receives a unique UUID. When the BuddyBoss hook fires from an internal operation, the hook handler checks if the event UUID matches an in-flight internal operation.

- **Layer 3 — Pair Lock:** Only one synchronization operation can execute for a given user pair (`wp_user_id_1`, `wp_user_id_2`) at a time. This is enforced using MySQL's `GET_LOCK()`.

### 2. Pair-Level Locking (Critical for Race Conditions)

```
Operation 1: User A blocks User B
  ├─ Acquire lock on (A, B)
  ├─ Check if connected → remove connection
  ├─ Remove follows → both directions
  ├─ Create block in all platforms
  └─ Release lock

Operation 2: Simultaneous request "User A follow User B"
  ├─ Wait for lock on (A, B)
  ├─ ... (waits until Operation 1 completes)
  ├─ Check current state → user is blocked
  ├─ Reject operation (already blocked)
  └─ Release lock
```

### 3. BuddyBoss Restrictions Remain Authoritative

The sync plugin does **not** bypass existing BuddyBoss connection restrictions. When an external platform calls the endpoint to create a connection, the plugin calls:

```php
friends_add_friend( $wp_user_1, $wp_user_2 )
```

This native BuddyBoss function applies all existing restrictions (role, profile type, gender, other custom logic). If the restriction denies the operation, `friends_add_friend()` returns false, and the endpoint responds with an error.

### 4. Handling Missing User Meta

If a Streams or Socials user doesn't have a corresponding WordPress user ID in their platform's meta fields (`wo_user_id`, `qd_user_id`), the operation fails with a descriptive error.

### 5. Database Connection Resilience

- All external database operations (Streams, Socials) use try/catch blocks
- Failed projections are queued in `wp_bzj_relationship_events` for retry
- WordPress cron (`bzj_process_relationship_events_cron`) runs every 5 minutes to retry failed projections
- Maximum 3 retry attempts per event before flagging as permanently failed

### 6. Timestamp & Signature Validation

- Timestamp must be within 5 minutes of current server time (prevents replay attacks)
- Signature is verified using HMAC-SHA256 with `BUZZ_SSO_SECRET`
- Request body must be raw JSON (not form-encoded) to match signature calculation

### 7. User Metadata Storage (No API Calls)

WordPress stores Streams and Socials user IDs in usermeta:
```
wp_usermeta.meta_key = 'wo_user_id' → WoWonder/Streams ID
wp_usermeta.meta_key = 'qd_user_id' → QuickDate/Socials ID
```

The sync plugin queries this during initialization and caches it to avoid repeated lookups.

## RECONCILIATION LOGIC

The plugin provides a reconciliation function (`bzj_reconcile_relationships()`) that:

1. Reads the authoritative state from BuddyBoss (WordPress native tables)
2. Compares it against the sync ledger (`wp_bzj_relationships`)
3. Identifies discrepancies
4. Refreshes the ledger based on BuddyBoss reality
5. Queues any necessary Streams and Socials projections

This is called:
- On plugin activation
- Manually via WP-CLI: `wp bzj reconcile-relationships`
- Periodically via cron (can be configured)

	/**
	 * Bootstrap: Install schema and schedule crons

	public function bootstrap() {
		$version = get_option('bzj_sync_schema_version', '');
		if ($version !== BZJ_SYNC_VERSION) {
			$this->install_schema();
		}
		
		// Schedule event processing
		if (!wp_next_scheduled('bzj_sync_process_events')) {
			wp_schedule_event(time() + 30, 'bzj_minute', 'bzj_sync_process_events');
		}
		
		// Schedule reconciliation
		if (!wp_next_scheduled('bzj_sync_reconcile')) {
			wp_schedule_event(time() + 300, 'hourly', 'bzj_sync_reconcile');
		}
	}

	/**
	 * Handle REST command from external platform
	 */
	public function handle_rest_command(WP_REST_Request $request) {
		try {
			$raw_body = $request->get_body();
			$payload = json_decode($raw_body, true);
			
			if (!is_array($payload)) {
				return new WP_Error(
					'bzj_invalid_json',
					'Request body must contain valid JSON',
					array('status' => 400)
				);
			}
			
			// Authenticate request
			$auth_error = $this->authenticate_request($request, $raw_body);
			if (is_wp_error($auth_error)) {
				return $auth_error;
			}
			
			// Extract and validate payload
			$origin = sanitize_key($payload['origin'] ?? '');
			$operation = sanitize_key($payload['operation'] ?? '');
			$event_uuid = sanitize_text_field($payload['event_id'] ?? '');
			$actor_external_id = absint($payload['actor_id'] ?? 0);
			$target_external_id = absint($payload['target_id'] ?? 0);
			
			// Validate
			if (!in_array($origin, array('streams', 'socials'), true)) {
				return new WP_Error(
					'bzj_invalid_origin',
					'Origin must be "streams" or "socials"',
					array('status' => 400)
				);
			}
			
			$allowed_ops = array(
				'connection_request', 'connection_accept', 'connection_reject',
				'connection_withdraw', 'connection_remove',
				'follow', 'unfollow', 'block', 'unblock'
			);
			
			if (!in_array($operation, $allowed_ops, true)) {
				return new WP_Error(
					'bzj_invalid_operation',
					'Invalid operation',
					array('status' => 400)
				);
			}
			
			if (!$this->is_uuid($event_uuid)) {
				return new WP_Error(
					'bzj_invalid_uuid',
					'Invalid event UUID',
					array('status' => 400)
				);
			}
			
			if ($actor_external_id < 1 || $target_external_id < 1 || $actor_external_id === $target_external_id) {
				return new WP_Error(
					'bzj_invalid_users',
					'Actor and target must be different valid user IDs',
					array('status' => 400)
				);
			}
			
			// Map external IDs to WordPress IDs
			$actor_wp_id = $this->map_external_to_wp($origin, $actor_external_id);
			$target_wp_id = $this->map_external_to_wp($origin, $target_external_id);
			
			if (!$actor_wp_id || !$target_wp_id || $actor_wp_id === $target_wp_id) {
				return new WP_Error(
					'bzj_mapping_error',
					'Could not map external IDs to WordPress users',
					array('status' => 409)
				);
			}
			
			// Check if event already processed
			if ($this->event_exists($event_uuid)) {
				$ledger = $this->get_ledger($actor_wp_id, $target_wp_id);
				return rest_ensure_response(array(
					'success' => true,
					'status' => 'already_processed',
					'event_id' => $event_uuid,
					'relationship' => $ledger,
				));
			}
			
			// Acquire pair lock to prevent race conditions
			if (!$this->acquire_pair_lock($actor_wp_id, $target_wp_id)) {
				return new WP_Error(
					'bzj_pair_locked',
					'Another operation is in progress for this pair. Please retry.',
					array('status' => 429)
				);
			}
			
			try {
				// Record the event
				$this->insert_event(
					$event_uuid,
					$origin,
					$operation,
					$actor_wp_id,
					$target_wp_id,
					$payload
				);
				
				// Process the command
				$result = $this->process_external_command(
					$operation,
					$actor_wp_id,
					$target_wp_id,
					$event_uuid,
					$origin
				);
				
				if (is_wp_error($result)) {
					$this->mark_event_retry($event_uuid, $result->get_error_message());
					return new WP_Error(
						'bzj_operation_failed',
						$result->get_error_message(),
						array('status' => 409, 'event_id' => $event_uuid)
					);
				}
				
				$this->mark_event_processed($event_uuid);
				$ledger = $this->get_ledger($actor_wp_id, $target_wp_id);
				
				return rest_ensure_response(array(
					'success' => true,
					'status' => 'processed',
					'event_id' => $event_uuid,
					'relationship' => $ledger,
				));
				
			} catch (Throwable $e) {
				$this->mark_event_retry($event_uuid, $e->getMessage());
				$this->log('REST command exception', array(
					'event_id' => $event_uuid,
					'error' => $e->getMessage(),
					'trace' => $e->getTraceAsString(),
				));
				
				return new WP_Error(
					'bzj_internal_error',
					'Internal synchronization error',
					array('status' => 500, 'event_id' => $event_uuid)
				);
			} finally {
				$this->release_pair_lock($actor_wp_id, $target_wp_id);
			}
			
		} catch (Throwable $e) {
			$this->log('REST command fatal error', array(
				'error' => $e->getMessage(),
				'trace' => $e->getTraceAsString(),
			));
			
			return new WP_Error(
				'bzj_fatal_error',
				'Synchronization service error',
				array('status' => 500)
			);
		}
	}
	
	/**
	 * Handle REST status query
	 */
	public function handle_rest_status(WP_REST_Request $request) {
		$user_a = absint($request->get_param('user_a'));
		$user_b = absint($request->get_param('user_b'));
		
		if ($user_a < 1 || $user_b < 1 || $user_a === $user_b) {
			return new WP_Error(
				'bzj_invalid_params',
				'Two different valid user IDs required',
				array('status' => 400)
			);
		}
		
		$ledger = $this->get_ledger($user_a, $user_b);
		$queue = $this->get_event_queue($user_a, $user_b);
		
		return rest_ensure_response(array(
			'success' => true,
			'version' => BZJ_SYNC_VERSION,
			'relationship' => $ledger,
			'queue' => $queue,
		));
	}
	
	/**
	 * Authenticate incoming REST request
	 */
	private function authenticate_request(WP_REST_Request $request, $raw_body) {
		$timestamp = $request->get_header('X-BZJ-Timestamp');
		$signature = $request->get_header('X-BZJ-Signature');
		
		if (!$timestamp || !$signature) {
			return new WP_Error(
				'bzj_missing_auth',
				'Missing authentication headers',
				array('status' => 401)
			);
		}
		
		if (!ctype_digit((string) $timestamp)) {
			return new WP_Error(
				'bzj_invalid_timestamp',
				'Invalid timestamp format',
				array('status' => 401)
			);
		}
		
		$timestamp = (int) $timestamp;
		
		// Check timestamp is within window
		if (abs(time() - $timestamp) > BZJ_SYNC_TIMESTAMP_WINDOW) {
			return new WP_Error(
				'bzj_expired_request',
				'Request timestamp outside allowed window',
				array('status' => 401)
			);
		}
		
		// Get shared secret
		$secret = $this->get_shared_secret();
		if (!$secret) {
			return new WP_Error(
				'bzj_no_secret',
				'Shared secret not configured',
				array('status' => 503)
			);
		}
		
		// Calculate expected signature
		$expected = hash_hmac('sha256', $timestamp . '.' . $raw_body, $secret);
		
		// Compare signatures (constant time to prevent timing attacks)
		if (!hash_equals($expected, trim($signature))) {
			return new WP_Error(
				'bzj_invalid_signature',
				'Invalid request signature',
				array('status' => 401)
			);
		}
		
		return true;
	}
	
	/**
	 * Get shared secret for authentication
	 */
	private function get_shared_secret() {
		// Try function first
		if (function_exists('bzj_get_sso_secret')) {
			$secret = bzj_get_sso_secret();
			if ($secret) {
				return $secret;
			}
		}
		
		// Try environment variable
		$secret = getenv('BUZZ_SSO_SECRET');
		if ($secret) {
			return $secret;
		}
		
		// Try constant
		if (defined('BUZZ_SSO_SECRET')) {
			return BUZZ_SSO_SECRET;
		}
		
		// Try option
		return get_option('bzj_shared_secret', '');
	}
	
	/**
	 * Process command from external platform
	 */
	private function process_external_command($operation, $actor_wp_id, $target_wp_id, $event_uuid, $origin) {
		$this->push_context(array(
			'event_uuid' => $event_uuid,
			'origin' => $origin,
			'operation' => $operation,
			'actor' => $actor_wp_id,
			'target' => $target_wp_id,
		));
		
		try {
			switch ($operation) {
				case 'connection_request':
					return $this->process_connection_request($actor_wp_id, $target_wp_id, $event_uuid);
				case 'connection_accept':
					return $this->process_connection_accept($actor_wp_id, $target_wp_id, $event_uuid);
				case 'connection_reject':
					return $this->process_connection_reject($actor_wp_id, $target_wp_id, $event_uuid);
				case 'connection_withdraw':
					return $this->process_connection_withdraw($actor_wp_id, $target_wp_id, $event_uuid);
				case 'connection_remove':
					return $this->process_connection_remove($actor_wp_id, $target_wp_id, $event_uuid);
				case 'follow':
					return $this->process_follow($actor_wp_id, $target_wp_id, true, $event_uuid);
				case 'unfollow':
					return $this->process_follow($actor_wp_id, $target_wp_id, false, $event_uuid);
				case 'block':
					return $this->process_block($actor_wp_id, $target_wp_id, true, $event_uuid);
				case 'unblock':
					return $this->process_block($actor_wp_id, $target_wp_id, false, $event_uuid);
				default:
					return new WP_Error('bzj_unknown_op', 'Unknown operation');
			}
		} finally {
			$this->pop_context();
		}
	}
	
	/**
	 * Process connection request from external platform
	 */
	private function process_connection_request($actor_wp_id, $target_wp_id, $event_uuid) {
		if (!function_exists('friends_add_friend')) {
			return new WP_Error('bzj_bb_unavailable', 'BuddyBoss friendship functions unavailable');
		}
		
		// Check if blocked
		if ($this->is_blocked($actor_wp_id, $target_wp_id)) {
			return new WP_Error('bzj_blocked', 'Users are blocked; connection rejected');
		}
		
		// Check current status
		$status = function_exists('friends_check_friendship_status')
			? friends_check_friendship_status($actor_wp_id, $target_wp_id)
			: 'not_friends';
		
		// Already friends - just sync state
		if ($status === 'is_friend') {
			$this->save_ledger($actor_wp_id, $target_wp_id, array(
				'bb_connection_state' => 'is_friend',
				'bb_connection_requested_by' => 0,
			), $event_uuid);
			$this->project_connection_to_socials($actor_wp_id, $target_wp_id, 'is_friend');
			return true;
		}
		
		// Already pending - no action needed
		if (in_array($status, array('pending', 'awaiting_response'), true)) {
			return true;
		}
		
		// Send connection request
		if (!friends_add_friend($actor_wp_id, $target_wp_id, false)) {
			return new WP_Error(
				'bzj_bb_request_failed',
				'BuddyBoss rejected connection request'
			);
		}
		
		// Ensure ledger is updated
		$this->save_ledger($actor_wp_id, $target_wp_id, array(
			'bb_connection_state' => 'pending',
			'bb_connection_requested_by' => $actor_wp_id,
		), $event_uuid);
		
		// Project to Socials
		$this->project_connection_to_socials($actor_wp_id, $target_wp_id, 'pending');
		
		$this->log('Connection request processed', array(
			'actor' => $actor_wp_id,
			'target' => $target_wp_id,
			'event_uuid' => $event_uuid,
		));
		
		return true;
	}
	
	/**
	 * Process connection accept from external platform
	 */
	private function process_connection_accept($actor_wp_id, $target_wp_id, $event_uuid) {
		if (!function_exists('friends_get_friendship_id') || !function_exists('friends_accept_friendship')) {
			return new WP_Error('bzj_bb_unavailable', 'BuddyBoss friendship functions unavailable');
		}
		
		// Find friendship request
		$friendship_id = friends_get_friendship_id($target_wp_id, $actor_wp_id);
		if (!$friendship_id) {
			$friendship_id = friends_get_friendship_id($actor_wp_id, $target_wp_id);
		}
		
		// If no request exists but already friends, just sync
		if (!$friendship_id) {
			if (function_exists('friends_check_friendship_status')) {
				$status = friends_check_friendship_status($actor_wp_id, $target_wp_id);
				if ($status === 'is_friend') {
					$this->save_ledger($actor_wp_id, $target_wp_id, array(
						'bb_connection_state' => 'is_friend',
						'bb_connection_requested_by' => 0,
					), $event_uuid);
					$this->project_connection_to_socials($actor_wp_id, $target_wp_id, 'is_friend');
					return true;
				}
			}
			return new WP_Error('bzj_no_request', 'No pending connection request found');
		}
		
		// Check if already accepted
		if (function_exists('friends_check_friendship_status')) {
			$status = friends_check_friendship_status($actor_wp_id, $target_wp_id);
			if ($status === 'is_friend') {
				$this->save_ledger($actor_wp_id, $target_wp_id, array(
					'bb_connection_state' => 'is_friend',
					'bb_connection_requested_by' => 0,
				), $event_uuid);
				$this->project_connection_to_socials($actor_wp_id, $target_wp_id, 'is_friend');
				return true;
			}
		}
		
		// Accept friendship
		if (!friends_accept_friendship($friendship_id)) {
			return new WP_Error('bzj_accept_failed', 'Failed to accept friendship');
		}
		
		// Update ledger
		$this->save_ledger($actor_wp_id, $target_wp_id, array(
			'bb_connection_state' => 'is_friend',
			'bb_connection_requested_by' => 0,
		), $event_uuid);
		
		// Project to Socials
		$this->project_connection_to_socials($actor_wp_id, $target_wp_id, 'is_friend');
		
		$this->log('Connection accepted', array(
			'actor' => $actor_wp_id,
			'target' => $target_wp_id,
			'event_uuid' => $event_uuid,
		));
		
		return true;
	}
	
	/**

	/**
	 * Process follow/unfollow from external platform
	 */
	private function process_follow($actor_wp_id, $target_wp_id, $follow, $event_uuid) {
		if (!function_exists('bp_start_following') || !function_exists('bp_stop_following')) {
			return new WP_Error('bzj_bb_unavailable', 'BuddyBoss follow functions unavailable');
		}
		
		// Check block status
		if ($follow && $this->is_blocked($actor_wp_id, $target_wp_id)) {
			return new WP_Error('bzj_blocked', 'Cannot follow blocked user');
		}
		
		if ($follow) {
			// Follow
			$result = bp_start_following(array(
				'leader_id' => $target_wp_id,
				'follower_id' => $actor_wp_id,
			));
			
			if (is_wp_error($result)) {
				return $result;
			}
			
			// Verify follow was created
			if ($result === false && function_exists('bp_is_following')) {
				if (!bp_is_following(array('leader_id' => $target_wp_id, 'follower_id' => $actor_wp_id))) {
					return new WP_Error('bzj_follow_failed', 'Failed to create follow');
				}
			}
		} else {
			// Unfollow
			$result = bp_stop_following(array(
				'leader_id' => $target_wp_id,
				'follower_id' => $actor_wp_id,
			));
			
			if (is_wp_error($result)) {
				return $result;
			}
		}
		
		// Update ledger
		$pair = $this->normalize_pair($actor_wp_id, $target_wp_id);
		$field = ($actor_wp_id === $pair[0]) ? 'bb_follow_a_to_b' : 'bb_follow_b_to_a';
		
		$this->save_ledger($actor_wp_id, $target_wp_id, array(
			$field => $follow ? 1 : 0,
		), $event_uuid);
		
		// Project to external platforms
		$this->project_follow_to_streams($actor_wp_id, $target_wp_id, $follow);
		$this->project_follow_to_socials($actor_wp_id, $target_wp_id, $follow);
		
		$this->log('Follow operation', array(
			'actor' => $actor_wp_id,
			'target' => $target_wp_id,
			'follow' => $follow,
			'event_uuid' => $event_uuid,
		));
		
		return true;
	}
	
	/**
	 * Process block/unblock from external platform
	 */
	private function process_block($actor_wp_id, $target_wp_id, $block, $event_uuid) {
		if ($block) {
			// Blocking - apply cascade
			if (!class_exists('BP_Moderation') || !class_exists('BP_Moderation_Members')) {
				return new WP_Error('bzj_bb_unavailable', 'BuddyBoss moderation unavailable');
			}
			
			// Check if already blocked
			if ($this->is_blocked($actor_wp_id, $target_wp_id, $actor_wp_id)) {
				return true; // Already blocked, nothing to do
			}
			
			// Create block in BuddyBoss
			$moderation = new BP_Moderation(
				$target_wp_id,
				BP_Moderation_Members::$moderation_type,
				$actor_wp_id
			);
			$moderation->user_report = 0;
			$moderation->content = '';
			
			if (!$moderation->save()) {
				return new WP_Error('bzj_block_failed', 'Failed to create block');
			}
			
			// Cascade: remove connection and follows
			$this->enforce_block_cascade($actor_wp_id, $target_wp_id, $event_uuid);
			
			// Update ledger
			$pair = $this->normalize_pair($actor_wp_id, $target_wp_id);
			$field = ($actor_wp_id === $pair[0]) ? 'bb_block_a_to_b' : 'bb_block_b_to_a';
			
			$this->save_ledger($actor_wp_id, $target_wp_id, array(
				$field => 1,
				'bb_connection_state' => 'none',
				'bb_connection_requested_by' => 0,
				'bb_follow_a_to_b' => 0,
				'bb_follow_b_to_a' => 0,
			), $event_uuid);
			
			// Project block to external platforms
			$this->project_block_to_streams($actor_wp_id, $target_wp_id, true);
			$this->project_block_to_socials($actor_wp_id, $target_wp_id, true);
			
		} else {
			// Unblocking
			if (!class_exists('BP_Moderation') || !class_exists('BP_Moderation_Members')) {
				return new WP_Error('bzj_bb_unavailable', 'BuddyBoss moderation unavailable');
			}
			
			$moderation = new BP_Moderation(
				$target_wp_id,
				BP_Moderation_Members::$moderation_type,
				$actor_wp_id
			);
			
			if (!empty($moderation->id) && empty($moderation->user_report)) {
				if (!$moderation->delete(false)) {
					return new WP_Error('bzj_unblock_failed', 'Failed to remove block');
				}
			}
			
			// Update ledger (do NOT restore connection or follows - intentional)
			$pair = $this->normalize_pair($actor_wp_id, $target_wp_id);
			$field = ($actor_wp_id === $pair[0]) ? 'bb_block_a_to_b' : 'bb_block_b_to_a';
			
			$this->save_ledger($actor_wp_id, $target_wp_id, array(
				$field => 0,
			), $event_uuid);
			
			// Project unblock to external platforms
			$this->project_block_to_streams($actor_wp_id, $target_wp_id, false);
			$this->project_block_to_socials($actor_wp_id, $target_wp_id, false);
		}
		
		$this->log('Block operation', array(
			'actor' => $actor_wp_id,
			'target' => $target_wp_id,
			'block' => $block,
			'event_uuid' => $event_uuid,
		));
		
		return true;
	}
	
	/**
	 * Enforce block cascade - remove connections and follows
	 */
	private function enforce_block_cascade($actor_wp_id, $target_wp_id, $event_uuid) {
		// Push context to prevent recursive hook handling
		$this->push_context(array(
			'event_uuid' => $event_uuid,
			'origin' => 'wordpress',
			'operation' => 'block_cascade',
			'actor' => $actor_wp_id,
			'target' => $target_wp_id,
		));
		
		try {
			// Remove connection if exists
			if (function_exists('friends_check_friendship_status') && function_exists('friends_remove_friend')) {
				$status = friends_check_friendship_status($actor_wp_id, $target_wp_id);
				if ($status === 'is_friend') {
					friends_remove_friend($actor_wp_id, $target_wp_id);
				}
			}
			
			// Remove follows in both directions
			if (function_exists('bp_stop_following')) {
				foreach (array(array($actor_wp_id, $target_wp_id), array($target_wp_id, $actor_wp_id)) as $pair) {
					try {
						bp_stop_following(array(
							'leader_id' => $pair[1],
							'follower_id' => $pair[0],
						));
					} catch (Throwable $e) {
						$this->log('Block cascade - follow removal failed', array(
							'pair' => $pair,
							'error' => $e->getMessage(),
						));
					}
				}
			}
		} finally {
			$this->pop_context();
		}
	}

			absint($friendship->friend_user_id)
		);
	}
	
	/**
	 * Handle BuddyBoss connection deleted hook
	 */
	public function handle_bb_connection_deleted($id, $initiator, $friend) {
		$a = absint($initiator);
		$b = absint($friend);
		
		// Detect if this is a contextual duplicate (to prevent loops)
		if ($this->is_contextual_duplicate('connection_remove', $a, $b) ||
		    $this->is_contextual_duplicate('connection_remove', $b, $a)) {
			return;
		}
		
		// Determine if this was a withdrawal or a removal
		$ledger = $this->get_ledger($a, $b);
		$operation = ($ledger['bb_connection_state'] === 'pending')
			? 'connection_withdraw'
			: 'connection_remove';
		
		$this->handle_bb_connection_event($operation, $a, $b);
	}
	
	/**
	 * Generic BuddyBoss connection event handler
	 */
	private function handle_bb_connection_event($operation, $actor, $target) {
		if ($actor < 1 || $target < 1 || $actor === $target) {
			return;
		}
		
		// Check for contextual duplicate to prevent loops
		if ($this->is_contextual_duplicate($operation, $actor, $target)) {
			return;
		}
		
		$event_uuid = wp_generate_uuid4();
		
		// Try to acquire lock
		if (!$this->acquire_pair_lock($actor, $target)) {
			// Queue for later processing
			$this->insert_event($event_uuid, 'wordpress', $operation, $actor, $target);
			$this->mark_event_retry($event_uuid, 'Pair lock busy during BuddyBoss event');
			return;
		}
		
		try {
			$this->insert_event($event_uuid, 'wordpress', $operation, $actor, $target);
			
			switch ($operation) {
				case 'connection_request':
					$this->save_ledger($actor, $target, array(
						'bb_connection_state' => 'pending',
						'bb_connection_requested_by' => $actor,
					), $event_uuid);
					$this->project_connection_to_socials($actor, $target, 'pending');
					break;
					
				case 'connection_accept':
					$this->save_ledger($actor, $target, array(
						'bb_connection_state' => 'is_friend',
						'bb_connection_requested_by' => 0,
					), $event_uuid);
					$this->project_connection_to_socials($actor, $target, 'is_friend');
					break;
					
				case 'connection_reject':
				case 'connection_withdraw':
				case 'connection_remove':
					$this->save_ledger($actor, $target, array(
						'bb_connection_state' => 'none',
						'bb_connection_requested_by' => 0,
					), $event_uuid);
					$this->project_connection_to_socials($actor, $target, 'none');
					break;
			}
			
			$this->mark_event_processed($event_uuid);
			
		} catch (Throwable $e) {
			$this->mark_event_retry($event_uuid, $e->getMessage());
			$this->log('BuddyBoss connection event error', array(
				'operation' => $operation,
				'actor' => $actor,
				'target' => $target,
				'error' => $e->getMessage(),
			));
		} finally {
			$this->release_pair_lock($actor, $target);
		}
	}

	/**
	 * Generic BuddyBoss follow event handler
	 */
	private function handle_bb_follow_event($operation, $actor, $target) {
		if ($actor < 1 || $target < 1 || $actor === $target) {
			return;
		}
		
		// Check for contextual duplicate
		if ($this->is_contextual_duplicate($operation, $actor, $target)) {
			return;
		}
		
		$event_uuid = wp_generate_uuid4();
		
		// Try to acquire lock
		if (!$this->acquire_pair_lock($actor, $target)) {
			$this->insert_event($event_uuid, 'wordpress', $operation, $actor, $target);
			$this->mark_event_retry($event_uuid, 'Pair lock busy during BuddyBoss follow event');
			return;
		}
		
		try {
			$this->insert_event($event_uuid, 'wordpress', $operation, $actor, $target);
			
			$following = ($operation === 'follow');
			
			// Update ledger
			$pair = $this->normalize_pair($actor, $target);
			$field = ($actor === $pair[0]) ? 'bb_follow_a_to_b' : 'bb_follow_b_to_a';
			
			$this->save_ledger($actor, $target, array(
				$field => $following ? 1 : 0,
			), $event_uuid);
			
			// Check if blocked - if so, don't sync to external
			if ($following && $this->is_blocked($actor, $target)) {
				// Revert the follow
				$this->save_ledger($actor, $target, array(
					$field => 0,
				), $event_uuid);
				$this->mark_event_processed($event_uuid);
				return;
			}
			
			// Project to external platforms
			$this->project_follow_to_streams($actor, $target, $following);
			$this->project_follow_to_socials($actor, $target, $following);
			
			$this->mark_event_processed($event_uuid);
			
		} catch (Throwable $e) {
			$this->mark_event_retry($event_uuid, $e->getMessage());
			$this->log('BuddyBoss follow event error', array(
				'operation' => $operation,
				'actor' => $actor,
				'target' => $target,
				'error' => $e->getMessage(),
			));
		} finally {
			$this->release_pair_lock($actor, $target);
		}
	}
	
	/**
	 * Handle BuddyBoss moderation saved hook (block created)

	public function handle_bb_moderation_saved($moderation) {
		if (!is_object($moderation)) {

			return;

		$this->handle_bb_block_event(
			'block',

			absint($moderation->item_id)
		);
	}

			return;
		}
		
		if (!isset($moderation->item_type) || $moderation->item_type !== 'user' || !empty($moderation->user_report)) {
			return;
		}

			'unblock',
			absint($moderation->user_id),
			absint($moderation->item_id)
		);
	}
	
	/**
	 * Generic BuddyBoss block event handler
	 */
	private function handle_bb_block_event($operation, $actor, $target) {
		if ($actor < 1 || $target < 1 || $actor === $target) {
			return;
		}
		
		// Check for contextual duplicate
		if ($this->is_contextual_duplicate($operation, $actor, $target)) {
			return;
		}
		
		$event_uuid = wp_generate_uuid4();
		
		// Try to acquire lock
		if (!$this->acquire_pair_lock($actor, $target)) {
			$this->insert_event($event_uuid, 'wordpress', $operation, $actor, $target);
			$this->mark_event_retry($event_uuid, 'Pair lock busy during BuddyBoss block event');
			return;
		}
		
		try {
			$this->insert_event($event_uuid, 'wordpress', $operation, $actor, $target);
			
			if ($operation === 'block') {
				// Cascade: remove connection and follows
				$this->enforce_block_cascade($actor, $target, $event_uuid);
				
				$pair = $this->normalize_pair($actor, $target);
				$field = ($actor === $pair[0]) ? 'bb_block_a_to_b' : 'bb_block_b_to_a';
				
				$this->save_ledger($actor, $target, array(
					$field => 1,
					'bb_connection_state' => 'none',
					'bb_connection_requested_by' => 0,
					'bb_follow_a_to_b' => 0,
					'bb_follow_b_to_a' => 0,
				), $event_uuid);
				
				$this->project_block_to_streams($actor, $target, true);
				$this->project_block_to_socials($actor, $target, true);
				
			} else {
				// Unblock
				$pair = $this->normalize_pair($actor, $target);
				$field = ($actor === $pair[0]) ? 'bb_block_a_to_b' : 'bb_block_b_to_a';
				
				$this->save_ledger($actor, $target, array(
					$field => 0,
				), $event_uuid);
				
				// Do NOT restore connection or follows
				$this->project_block_to_streams($actor, $target, false);
				$this->project_block_to_socials($actor, $target, false);
			}
			
			$this->mark_event_processed($event_uuid);
			
		} catch (Throwable $e) {
			$this->mark_event_retry($event_uuid, $e->getMessage());
			$this->log('BuddyBoss block event error', array(
				'operation' => $operation,
				'actor' => $actor,
				'target' => $target,
				'error' => $e->getMessage(),
			));
		} finally {
			$this->release_pair_lock($actor, $target);
		}
	}
	
	// ===== PROJECTION METHODS =====
	
	/**
	 * Project connection state to Socials
	 */
	private function project_connection_to_socials($actor_wp_id, $target_wp_id, $state) {
		try {
			$actor_socials_id = $this->get_external_id($actor_wp_id, 'socials');
			$target_socials_id = $this->get_external_id($target_wp_id, 'socials');
			
			if (!$actor_socials_id || !$target_socials_id) {
				$this->log('Socials connection projection - user mapping failed', array(
					'actor_wp' => $actor_wp_id,
					'target_wp' => $target_wp_id,
				));
				return false;
			}
			
			// Get Socials database connection
			$socials_db = $this->get_socials_db();
			if (!$socials_db) {
				$this->log('Socials connection projection - database unavailable', array(
					'actor_wp' => $actor_wp_id,
					'target_wp' => $target_wp_id,
				));
				return false;
			}
			
			// QuickDate friend states are represented in followers table
			// active=1: confirmed friend
			// active=0: pending friend request
			// not in table: no relationship
			
			if ($state === 'is_friend') {
				// Create/update as confirmed friend (active=1)
				$this->socials_set_active_friend($socials_db, $target_socials_id, $actor_socials_id);
			} elseif ($state === 'pending') {
				// Create as pending friend request (active=0)
				$this->socials_set_pending_friend($socials_db, $target_socials_id, $actor_socials_id);
			} else {
				// Remove the relationship
				$this->socials_remove_friend($socials_db, $actor_socials_id, $target_socials_id);
			}
			
			return true;
			
		} catch (Throwable $e) {
			$this->log('Socials connection projection error', array(
				'actor_wp' => $actor_wp_id,
				'target_wp' => $target_wp_id,
				'state' => $state,
				'error' => $e->getMessage(),
			));
			return false;
		}
	}

	/**
	 * Add follow to Streams
	 */
	private function streams_add_follow($db, $following_id, $follower_id) {
		// Streams followers table: Wo_Followers or followers
		$table_name = $this->streams_get_followers_table($db);
		
		$stmt = $db->prepare(
			"SELECT id FROM `{$table_name}` WHERE following_id = ? AND follower_id = ? LIMIT 1"
		);
		if (!$stmt) {
			throw new Exception('Prepare failed: ' . $db->error);
		}
		
		$stmt->bind_param('ii', $following_id, $follower_id);
		$stmt->execute();
		$result = $stmt->get_result();
		$row = $result->fetch_assoc();
		$stmt->close();
		
		if ($row) {
			// Update to active
			$stmt = $db->prepare("UPDATE `{$table_name}` SET active = 1 WHERE id = ?");
			if (!$stmt) {
				throw new Exception('Prepare failed: ' . $db->error);
			}
			$stmt->bind_param('i', $row['id']);
			$ok = $stmt->execute();
			$stmt->close();
			
			if (!$ok) {
				throw new Exception('Follow update failed');
			}
		} else {
			// Insert new follow
			$created_at = time();
			$stmt = $db->prepare(
				"INSERT INTO `{$table_name}` (following_id, follower_id, active, created_at) VALUES (?, ?, 1, ?)"
			);
			if (!$stmt) {
				throw new Exception('Prepare failed: ' . $db->error);
			}
			
			$stmt->bind_param('iii', $following_id, $follower_id, $created_at);
			$ok = $stmt->execute();
			$stmt->close();
			
			if (!$ok) {
				throw new Exception('Follow insert failed');
			}
		}
	}

	/**
	 * Set pending friend request in Socials (QuickDate)
	 */
	private function socials_set_pending_friend($db, $requester_id, $recipient_id) {
		// In QuickDate, pending friend requests are followers rows with active=0
		$table_name = $this->socials_get_followers_table($db);
		
		// Remove any opposite direction active follows
		$stmt = $db->prepare("DELETE FROM `{$table_name}` WHERE following_id = ? AND follower_id = ? AND active = 1");
		if (!$stmt) {
			throw new Exception('Prepare failed: ' . $db->error);
		}
		
		$stmt->bind_param('ii', $recipient_id, $requester_id);
		$stmt->execute();
		$stmt->close();
		
		// Check if request already exists
		$stmt = $db->prepare("SELECT id FROM `{$table_name}` WHERE following_id = ? AND follower_id = ? LIMIT 1");
		if (!$stmt) {
			throw new Exception('Prepare failed: ' . $db->error);
		}
		
		$stmt->bind_param('ii', $requester_id, $recipient_id);
		$stmt->execute();
		$result = $stmt->get_result();
		$row = $result->fetch_assoc();
		$stmt->close();
		
		if ($row) {
			// Update to pending
			$stmt = $db->prepare("UPDATE `{$table_name}` SET active = 0 WHERE id = ?");
			if (!$stmt) {
				throw new Exception('Prepare failed: ' . $db->error);
			}
			$stmt->bind_param('i', $row['id']);
			$ok = $stmt->execute();
			$stmt->close();
			
			if (!$ok) {
				throw new Exception('Pending friend update failed');
			}
		} else {
			// Insert pending request
			$now = time();
			$stmt = $db->prepare(
				"INSERT INTO `{$table_name}` (following_id, follower_id, active, created_at) VALUES (?, ?, 0, ?)"
			);
			if (!$stmt) {
				throw new Exception('Prepare failed: ' . $db->error);
			}
			
			$stmt->bind_param('iii', $requester_id, $recipient_id, $now);
			$ok = $stmt->execute();
			$stmt->close();
			
			if (!$ok) {
				throw new Exception('Pending friend insert failed');
			}
		}
	}

			if ($result instanceof mysqli_result && $result->num_rows > 0) {
				return $table;
			}
		}
		throw new Exception('Socials blocks table not found');
	}

	/**
	 * Normalize pair (ensure smaller ID first)
	 */
	private function normalize_pair($a, $b) {
		$a = absint($a);
		$b = absint($b);
		return ($a < $b) ? array($a, $b) : array($b, $a);
	}
	
	/**
	 * Get ledger entry
	 */
	private function get_ledger($user_a, $user_b) {
		$pair = $this->normalize_pair($user_a, $user_b);

				'bb_block_b_to_a' => 0,
				'streams_block_a_to_b' => 0,
				'streams_block_b_to_a' => 0,
				'socials_block_a_to_b' => 0,
				'socials_block_b_to_a' => 0,
				'version' => 0,
			);
		}
		
		// Ensure integers
		$int_fields = array(
			'wp_user_a', 'wp_user_b', 'bb_connection_requested_by',

		foreach ($int_fields as $field) {

	/**
	 * Save ledger entry
	 */
	private function save_ledger($user_a, $user_b, $changes, $event_uuid = '') {
		$pair = $this->normalize_pair($user_a, $user_b);
		$existing = $this->get_ledger($pair[0], $pair[1]);
		$now = gmdate('Y-m-d H:i:s');
		
		// Build state from existing
		$state = array(
			'bb_connection_state' => $existing['bb_connection_state'],
			'bb_connection_requested_by' => $existing['bb_connection_requested_by'],
			'bb_follow_a_to_b' => $existing['bb_follow_a_to_b'],
			'bb_follow_b_to_a' => $existing['bb_follow_b_to_a'],
			'streams_follow_a_to_b' => $existing['streams_follow_a_to_b'],
			'streams_follow_b_to_a' => $existing['streams_follow_b_to_a'],
			'socials_follow_a_to_b' => $existing['socials_follow_a_to_b'],
			'socials_follow_b_to_a' => $existing['socials_follow_b_to_a'],
			'bb_block_a_to_b' => $existing['bb_block_a_to_b'],
			'bb_block_b_to_a' => $existing['bb_block_b_to_a'],
			'streams_block_a_to_b' => $existing['streams_block_a_to_b'],
			'streams_block_b_to_a' => $existing['streams_block_b_to_a'],
			'socials_block_a_to_b' => $existing['socials_block_a_to_b'],
			'socials_block_b_to_a' => $existing['socials_block_b_to_a'],
		);
		
		// Apply changes
		foreach ($changes as $key => $value) {
			if (array_key_exists($key, $state)) {
				$state[$key] = $value;
			}
		}
		
		// If blocked in any direction, clear connection and follows
		if ($state['bb_block_a_to_b'] || $state['bb_block_b_to_a']) {
			$state['bb_connection_state'] = 'none';
			$state['bb_connection_requested_by'] = 0;
			$state['bb_follow_a_to_b'] = 0;
			$state['bb_follow_b_to_a'] = 0;
		}
		
		$data = array(
			'wp_user_a' => $pair[0],
			'wp_user_b' => $pair[1],
			'bb_connection_state' => $state['bb_connection_state'],
			'bb_connection_requested_by' => (int) $state['bb_connection_requested_by'],
			'bb_follow_a_to_b' => (int) $state['bb_follow_a_to_b'],
			'bb_follow_b_to_a' => (int) $state['bb_follow_b_to_a'],
			'streams_follow_a_to_b' => (int) $state['streams_follow_a_to_b'],
			'streams_follow_b_to_a' => (int) $state['streams_follow_b_to_a'],
			'socials_follow_a_to_b' => (int) $state['socials_follow_a_to_b'],
			'socials_follow_b_to_a' => (int) $state['socials_follow_b_to_a'],
			'bb_block_a_to_b' => (int) $state['bb_block_a_to_b'],
			'bb_block_b_to_a' => (int) $state['bb_block_b_to_a'],
			'streams_block_a_to_b' => (int) $state['streams_block_a_to_b'],
			'streams_block_b_to_a' => (int) $state['streams_block_b_to_a'],
			'socials_block_a_to_b' => (int) $state['socials_block_a_to_b'],
			'socials_block_b_to_a' => (int) $state['socials_block_b_to_a'],
			'version' => ((int) $existing['version'] + 1),
			'last_event_uuid' => $event_uuid,
			'updated_at' => $now,
		);
		
		if ((int) $existing['version'] === 0) {
			// Insert new
			$data['created_at'] = $now;
			$result = $this->wpdb->insert($this->ledger_table, $data);
			
			if (false === $result) {
				throw new Exception('Ledger insert failed: ' . $this->wpdb->last_error);
			}
		} else {
			// Update existing
			$result = $this->wpdb->update(
				$this->ledger_table,
				$data,
				array('wp_user_a' => $pair[0], 'wp_user_b' => $pair[1])
			);
			
			if (false === $result) {
				throw new Exception('Ledger update failed: ' . $this->wpdb->last_error);
			}
		}
		
		return $this->get_ledger($pair[0], $pair[1]);
	}
	
	/**
	 * Check if users are blocked
	 */
	private function is_blocked($user_a, $user_b, $blocker = null) {
		$ledger = $this->get_ledger($user_a, $user_b);
		$pair = $this->normalize_pair($user_a, $user_b);
		
		if ($blocker === null) {
			// Check if blocked in any direction
			return !empty($ledger['bb_block_a_to_b']) || !empty($ledger['bb_block_b_to_a']);
		}
		
		// Check specific direction
		if ($blocker === $pair[0]) {
			return !empty($ledger['bb_block_a_to_b']);
		} else {
			return !empty($ledger['bb_block_b_to_a']);
		}
	}

	/**
	 * Insert event into queue
	 */
	private function insert_event($uuid, $origin, $operation, $actor, $target, $payload = array()) {
		if ($this->event_exists($uuid)) {
			return true;
		}
		
		$pair = $this->normalize_pair($actor, $target);
		$now = gmdate('Y-m-d H:i:s');
		
		$result = $this->wpdb->insert(
			$this->events_table,
			array(
				'event_uuid' => $uuid,
				'origin' => $origin,
				'operation' => $operation,
				'actor_wp_id' => $actor,
				'target_wp_id' => $target,
				'pair_a' => $pair[0],
				'pair_b' => $pair[1],
				'payload' => wp_json_encode($payload),
				'status' => 'pending',
				'attempts' => 0,
				'next_attempt_at' => $now,
				'created_at' => $now,
				'updated_at' => $now,
			)
		);
		
		if (false === $result && !$this->event_exists($uuid)) {
			throw new Exception('Event insert failed: ' . $this->wpdb->last_error);
		}
		
		return true;
	}
	
	/**
	 * Mark event as processed

	private function mark_event_processed($uuid) {
		$now = gmdate('Y-m-d H:i:s');
		
		$this->wpdb->update(
			$this->events_table,
			array(
				'status' => 'processed',
				'processed_at' => $now,
				'updated_at' => $now,
				'last_error' => null,
			),
			array('event_uuid' => $uuid)
		);
	}
	
	/**
	 * Mark event for retry
	 */
	private function mark_event_retry($uuid, $error) {
		$row = $this->wpdb->get_row($this->wpdb->prepare(
			"SELECT attempts FROM {$this->events_table} WHERE event_uuid = %s LIMIT 1",
			$uuid
		));
		
		$attempts = $row ? ((int) $row->attempts + 1) : 1;
		$delay = min(3600, max(60, (int) pow(2, min($attempts, 10)) * 30));
		$status = ($attempts >= BZJ_SYNC_MAX_RETRIES) ? 'failed' : 'retry';
		$next = gmdate('Y-m-d H:i:s', time() + $delay);
		
		// Truncate error to 500 chars
		$error_msg = function_exists('mb_substr')
			? mb_substr((string) $error, 0, 500)
			: substr((string) $error, 0, 500);
		
		$this->wpdb->update(
			$this->events_table,
			array(
				'status' => $status,
				'attempts' => $attempts,
				'next_attempt_at' => $next,
				'last_error' => $error_msg,
				'updated_at' => gmdate('Y-m-d H:i:s'),
			),
			array('event_uuid' => $uuid)
		);
	}
	
	/**

	private function get_event_queue($user_a, $user_b) {
		$pair = $this->normalize_pair($user_a, $user_b);

			"SELECT event_uuid, origin, operation, status, attempts, next_attempt_at, last_error, created_at, updated_at
			 FROM {$this->events_table}
			 WHERE pair_a = %d AND pair_b = %d
			 ORDER BY id DESC LIMIT 20",
			$pair[0],
			$pair[1]
		), ARRAY_A);
		
		return $rows ?: array();
	}
	
	/**
	 * Process event queue

	public function process_event_queue() {
		$now = gmdate('Y-m-d H:i:s');
		
		$rows = $this->wpdb->get_results($this->wpdb->prepare(
			"SELECT * FROM {$this->events_table}
			 WHERE status IN ('pending', 'retry')
			 AND next_attempt_at <= %s
			 ORDER BY id ASC
			 LIMIT 50",
			$now
		));
		
		foreach ((array) $rows as $row) {
			$this->process_event_row($row);
		}

		$this->mark_event_processed($row->event_uuid);

	/**
	 * Reconcile recent relationships
	 */
	public function reconcile_recent() {
		$rows = $this->wpdb->get_results(
			"SELECT wp_user_a, wp_user_b
			 FROM {$this->ledger_table}
			 WHERE updated_at >= UTC_TIMESTAMP() - INTERVAL 7 DAY
			 ORDER BY updated_at DESC
			 LIMIT 100"
		);
		
		foreach ((array) $rows as $row) {
			$this->reconcile_pair((int) $row->wp_user_a, (int) $row->wp_user_b);
		}
	}
	
	/**
	 * Reconcile pair - refresh ledger from BuddyBoss
	 */
	public function reconcile_pair($user_a, $user_b) {
		if (!$this->acquire_pair_lock($user_a, $user_b)) {
			return false;
		}
		
		try {
			$this->refresh_ledger_from_buddyboss($user_a, $user_b);
			return true;
		} finally {
			$this->release_pair_lock($user_a, $user_b);
		}
	}
	
	/**
	 * Refresh ledger from BuddyBoss state
	 */
	private function refresh_ledger_from_buddyboss($user_a, $user_b) {
		$changes = array();
		
		// Check connection state
		if (function_exists('friends_check_friendship_status')) {
			$status = friends_check_friendship_status($user_a, $user_b);
			
			switch ($status) {
				case 'is_friend':
					$changes['bb_connection_state'] = 'is_friend';
					$changes['bb_connection_requested_by'] = 0;
					break;
				case 'pending':
				case 'awaiting_response':
					$changes['bb_connection_state'] = 'pending';
					$changes['bb_connection_requested_by'] = ($status === 'pending') ? $user_a : $user_b;
					break;
				default:
					$changes['bb_connection_state'] = 'none';
					$changes['bb_connection_requested_by'] = 0;
			}
		}
		
		// Check follow states
		if (function_exists('bp_is_following')) {
			$changes['bb_follow_a_to_b'] = bp_is_following(array(
				'leader_id' => $user_b,
				'follower_id' => $user_a,
			)) ? 1 : 0;
			
			$changes['bb_follow_b_to_a'] = bp_is_following(array(
				'leader_id' => $user_a,
				'follower_id' => $user_b,
			)) ? 1 : 0;
		}
		
		// Check block states
		if (function_exists('bp_moderation_is_user_blocked')) {
			$changes['bb_block_a_to_b'] = bp_moderation_is_user_blocked($user_b, $user_a) ? 1 : 0;
			$changes['bb_block_b_to_a'] = bp_moderation_is_user_blocked($user_a, $user_b) ? 1 : 0;
		}
		
		$this->save_ledger($user_a, $user_b, $changes);
	}
	
	// ===== PAIR LOCKING =====
	
	/**
	 * Acquire pair lock
	 */
	private function acquire_pair_lock($user_a, $user_b) {
		$pair = $this->normalize_pair($user_a, $user_b);
		$lock_name = 'bzj_sync_' . $pair[0] . '_' . $pair[1];
		
		// Use MySQL GET_LOCK for atomic locking
		$result = $this->wpdb->get_var($this->wpdb->prepare(
			"SELECT GET_LOCK(%s, 0)",
			$lock_name
		));
		
		if ((int) $result === 1) {
			$this->held_locks[$lock_name] = true;
			return true;
		}
		
		return false;
	}
	
	/**
	 * Release pair lock
	 */
	private function release_pair_lock($user_a, $user_b) {
		$pair = $this->normalize_pair($user_a, $user_b);
		$lock_name = 'bzj_sync_' . $pair[0] . '_' . $pair[1];
		
		if (isset($this->held_locks[$lock_name])) {
			$this->wpdb->get_var($this->wpdb->prepare(
				"SELECT RELEASE_LOCK(%s)",
				$lock_name
			));
			unset($this->held_locks[$lock_name]);
		}
	}
	
	// ===== CONTEXT STACK (for loop prevention) =====
	
	/**
	 * Push context
	 */
	private function push_context($context) {
		$this->context_stack[] = $context;
	}
	
	/**
	 * Pop context
	 */
	private function pop_context() {
		array_pop($this->context_stack);
	}
	
	/**
	 * Get current context
	 */
	private function current_context() {
		if (empty($this->context_stack)) {
			return null;
		}
		return end($this->context_stack);
	}
	
	/**
	 * Check if operation is contextual duplicate (for loop prevention)
	 */
	private function is_contextual_duplicate($operation, $actor, $target) {
		$ctx = $this->current_context();
		
		if (!$ctx) {
			return false;
		}
		
		return isset($ctx['operation'], $ctx['actor'], $ctx['target']) &&
			$ctx['operation'] === $operation &&
			(int) $ctx['actor'] === (int) $actor &&
			(int) $ctx['target'] === (int) $target;
	}

	/**
	 * Map external platform ID to WordPress user ID
	 */
	private function map_external_to_wp($platform, $external_id) {
		$meta_key = ($platform === 'streams') ? 'wo_user_id' : 'qd_user_id';

	}

	private function get_external_id($wp_user_id, $platform) {

		$value = get_user_meta($wp_user_id, $meta_key, true);

	}

	/**
	 * Validate UUID v4
	 */
	private function is_uuid($value) {
		return (bool) preg_match(
			'/^[0-9a-f]{8}-[0-9a-f]{4}-[1-5][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i',
			(string) $value
		);
	}
	
	/**

	 */
	private function log($message, $context = array()) {
		$this->log_buffer[] = array(
			'timestamp' => gmdate('c'),
			'message' => (string) $message,
			'context' => $context,
		);
	}
	
	/**
	 * Flush logs to file
	 */
	public function flush_logs() {
		if (empty($this->log_buffer)) {
			return;
		}
		
		$log_dir = rtrim(ABSPATH, DIRECTORY_SEPARATOR) . DIRECTORY_SEPARATOR . 'data' . DIRECTORY_SEPARATOR . 'logs';
		
		if (!is_dir($log_dir)) {
			wp_mkdir_p($log_dir);
		}
		
		$log_file = $log_dir . DIRECTORY_SEPARATOR . BZJ_SYNC_LOG_FILE;
		
		foreach ($this->log_buffer as $entry) {
			$line = wp_json_encode($entry, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE) . PHP_EOL;
			@file_put_contents($log_file, $line, FILE_APPEND | LOCK_EX);
		}
		
		$this->log_buffer = array();
	}

    if (function_exists('bzj_get_sso_secret')) {

        if ($secret) {
            return $secret;
        }
    }
    
    // Try environment variable
    $secret = getenv('BUZZ_SSO_SECRET');
    if ($secret) {
        return $secret;
    }
    
    // Try constant
    if (defined('BUZZ_SSO_SECRET')) {
        return BUZZ_SSO_SECRET;
    }
    
    // Try option
    return get_option('bzj_shared_secret', '');
}

/**
 * Sign a request for external platform
 */
function bzj_sign_request($payload) {
    $secret = bzj_get_shared_secret();
    if (!$secret) {
        throw new Exception('Shared secret not configured');
    }
    
    $timestamp = time();
    $json_body = wp_json_encode($payload, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE);
    $signature = hash_hmac('sha256', $timestamp . '.' . $json_body, $secret);
    
    return array(
        'timestamp' => $timestamp,
        'signature' => $signature,
        'body' => $payload,
    );
}

/**
 * Send command to BuddyBoss via REST (from Streams)
 */
function bzj_streams_send_command($operation, $actor_id, $target_id) {
    $event_id = wp_generate_uuid4();
    $payload = array(
        'origin' => 'streams',
        'operation' => $operation,
        'event_id' => $event_id,
        'actor_id' => $actor_id,
        'target_id' => $target_id,
    );
    
    try {
        $signed = bzj_sign_request($payload);
        
        $response = wp_remote_post(
            home_url('/wp-json/bzj/v1/connection-management'),
            array(
                'timeout' => 10,
                'sslverify' => apply_filters('https_local_ssl_verify', false),
                'headers' => array(
                    'Content-Type' => 'application/json',
                    'X-BZJ-Timestamp' => (string) $signed['timestamp'],
                    'X-BZJ-Signature' => $signed['signature'],
                ),
                'body' => wp_json_encode($signed['body']),
            )
        );
        
        if (is_wp_error($response)) {
            throw new Exception($response->get_error_message());
        }
        
        $status = wp_remote_retrieve_response_code($response);
        $body = json_decode(wp_remote_retrieve_body($response), true);
        
        if ($status >= 400) {
            throw new Exception($body['message'] ?? 'Command failed');
        }
        
        return $body;
        
    } catch (Throwable $e) {
        error_log('BZJ Streams Command Error: ' . $e->getMessage());
        throw $e;
    }
}
