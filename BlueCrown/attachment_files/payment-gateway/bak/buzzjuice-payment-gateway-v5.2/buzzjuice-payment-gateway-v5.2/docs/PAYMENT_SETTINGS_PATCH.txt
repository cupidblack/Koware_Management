PAYMENT SETTINGS

In `streams/admin-panel/pages/payment-settings/content.phtml` retain:
- WooCommerce Payment Method
- WooCommerce Store URL
- Market Handler Product ID
- Pro Package-1..4 Handler Product IDs
- Wallet Topup Handler Product ID
- Crowd Fund Handler Product ID

Remove the visible fields for:
- WooCommerce API URL
- WooCommerce API Key
- WooCommerce API Secret
- WooCommerce Webhook Secret

Reason: PGB 5.2 authenticates Streams -> WordPress with `BZJ_PGB_SECRET`; WordPress creates the WooCommerce order natively. WooCommerce credentials must not be stored in the Streams admin.

If the existing settings POST still writes the four removed fields, remove those four `Wo_UpdateConfig()` branches from `streams/requests.php`.
