### **2.3 Logger Class: `shared/payment-gateway/class-pgb-logger.php`**

```php
<?php
/**
 * PGB Logger Class
 * 
 * Handles logging for all payment gateway bridge operations.
 */

if (!defined('ABSPATH')) {
    exit('Access denied');
}

class PGB_Logger {
    
    private $log_dir;
    private $logging_enabled;
    private $debug_mode;
    
    public function __construct($log_dir = null, $logging_enabled = true, $debug_mode = false) {
        $this->log_dir = $log_dir ?: PGB_LOG_DIR;
        $this->logging_enabled = $logging_enabled;
        $this->debug_mode = $debug_mode;
        
        if (!is_dir($this->log_dir)) {
            @mkdir($this->log_dir, 0755, true);
        }
    }
    
    /**
     * Log a message
     * 
     * @param string $message Log message
     * @param string $log_file Log file name
     * @param string $level Log level (info, warning, error, debug)
     */
    public function log($message, $log_file = 'pgb-general.log', $level = 'info') {
        if (!$this->logging_enabled && $level !== 'error') {
            return;
        }
        
        if (!$this->debug_mode && $level === 'debug') {
            return;
        }
        
        $timestamp = date('Y-m-d H:i:s');
        $log_level = strtoupper($level);
        $log_entry = "[{$timestamp}] [{$log_level}] {$message}" . PHP_EOL;
        
        $log_path = $this->log_dir . '/' . $log_file;
        
        @file_put_contents($log_path, $log_entry, FILE_APPEND);
    }
    
    /**
     * Log error
     */
    public function error($message, $log_file = 'pgb-errors.log') {
        $this->log($message, $log_file, 'error');
    }
    
    /**
     * Log warning
     */
    public function warning($message, $log_file = 'pgb-warnings.log') {
        $this->log($message, $log_file, 'warning');
    }
    
    /**
     * Log debug info
     */
    public function debug($message, $log_file = 'pgb-debug.log') {
        $this->log($message, $log_file, 'debug');
    }
    
    /**
     * Clear log file
     */
    public function clear($log_file) {
        $log_path = $this->log_dir . '/' . $log_file;
        if (file_exists($log_path)) {
            @unlink($log_path);
        }
    }
    
    /**
     * Get log file contents
     */
    public function get_logs($log_file, $lines = 100) {
        $log_path = $this->log_dir . '/' . $log_file;
        if (!file_exists($log_path)) {
            return '';
        }
        
        $file = new SplFileObject($log_path, 'r');
        $file->seek(PHP_INT_MAX);
        $last_line = $file->key();
        $lines_needed = min($lines, $last_line);
        $start_line = max(0, $last_line - $lines_needed);
        
        $file->seek($start_line);
        $content = '';
        while (!$file->eof()) {
            $content .= $file->fgets();
        }
        
        return $content;
    }
}
```

### **2.4 WooCommerce Bridge: `shared/payment-gateway/class-pgb-woocommerce-bridge.php`**

```php
<?php
/**
 * PGB WooCommerce Bridge Class
 * 
 * Handles all WooCommerce API interactions and order creation/processing.
 */

if (!defined('ABSPATH')) {
    exit('Access denied');
}

class PGB_WooCommerce_Bridge {
    
    private $logger;
    private $config;
    private $api_url;
    private $api_key;
    private $api_secret;
    
    public function __construct($logger = null, $config = array()) {
        $this->logger = $logger;
        $this->config = $config;
        
        // Get WooCommerce config from Streams
        $this->load_woocommerce_config();
        
        // Register WooCommerce hooks
        $this->register_hooks();
    }
    
    /**
     * Load WooCommerce configuration from Streams config
     */
    private function load_woocommerce_config() {
        // Get Streams WoWonder config
        global $wo;
        
        if (!empty($wo['config'])) {
            $this->api_url = rtrim($wo['config']['wow_api_url'] ?? '', '/') . '/wc/v3';
            $this->api_key = $wo['config']['wow_api_key'] ?? '';
            $this->api_secret = $wo['config']['wow_api_secret'] ?? '';
        }
        
        // Validate configuration
        if (empty($this->api_url) || empty($this->api_key) || empty($this->api_secret)) {
            if ($this->logger) {
                $this->logger->error('WooCommerce API configuration incomplete', 'class-pgb-woocommerce-bridge.log');
            }
        }
    }
    
    /**
     * Register WooCommerce hooks
     */
    private function register_hooks() {
        // Listen for WooCommerce order completion
        add_action('woocommerce_order_status_completed', array($this, 'handle_order_completion'), 10, 1);
        add_action('woocommerce_payment_complete', array($this, 'handle_payment_complete'), 10, 1);
    }
    
    /**
     * Create WooCommerce order via REST API
     */
    public function create_order($order_data) {
        if (!$this->api_url || !$this->api_key || !$this->api_secret) {
            if ($this->logger) {
                $this->logger->error('WooCommerce API not configured', 'class-pgb-woocommerce-bridge.log');
            }
            return array('success' => false, 'message' => 'API not configured');
        }
        
        try {
            $response = $this->send_api_request(
                $this->api_url . '/orders',
                'POST',
                $order_data
            );
            
            if ($response['http_code'] === 201) {
                $order = json_decode($response['body'], true);
                if ($this->logger) {
                    $this->logger->log('Order created successfully: ' . $order['id'], 'class-pgb-woocommerce-bridge.log');
                }
                return array(
                    'success' => true,
                    'order_id' => $order['id'],
                    'payment_url' => $order['payment_url'] ?? '',
                    'order' => $order
                );
            } else {
                if ($this->logger) {
                    $this->logger->error(
                        'Order creation failed: ' . $response['http_code'] . ' - ' . $response['body'],
                        'class-pgb-woocommerce-bridge.log'
                    );
                }
                return array(
                    'success' => false,
                    'message' => 'Order creation failed',
                    'error' => json_decode($response['body'], true)
                );
            }
        } catch (Exception $e) {
            if ($this->logger) {
                $this->logger->error('Exception creating order: ' . $e->getMessage(), 'class-pgb-woocommerce-bridge.log');
            }
            return array('success' => false, 'message' => $e->getMessage());
        }
    }
    
    /**
     * Fetch order from WooCommerce
     */
    public function get_order($order_id) {
        if (!$this->api_url) {
            return null;
        }
        
        try {
            $response = $this->send_api_request(
                $this->api_url . '/orders/' . $order_id,
                'GET'
            );
            
            if ($response['http_code'] === 200) {
                return json_decode($response['body'], true);
            }
            return null;
        } catch (Exception $e) {
            if ($this->logger) {
                $this->logger->error('Error fetching order: ' . $e->getMessage(), 'class-pgb-woocommerce-bridge.log');
            }
            return null;
        }
    }
    
    /**
     * Update WooCommerce order
     */
    public function update_order($order_id, $data) {
        if (!$this->api_url) {
            return false;
        }
        
        try {
            $response = $this->send_api_request(
                $this->api_url . '/orders/' . $order_id,
                'PUT',
                $data
            );
            
            if ($response['http_code'] === 200) {
                return true;
            }
            return false;
        } catch (Exception $e) {
            if ($this->logger) {
                $this->logger->error('Error updating order: ' . $e->getMessage(), 'class-pgb-woocommerce-bridge.log');
            }
            return false;
        }
    }
    
    /**
     * Send API request to WooCommerce
     */
    private function send_api_request($url, $method = 'GET', $data = null) {
        if (!filter_var($url, FILTER_VALIDATE_URL)) {
            return array('http_code' => 0, 'body' => '', 'error' => 'Invalid URL');
        }
        
        $curl = curl_init();
        $headers = array('Content-Type: application/json');
        
        // Add Basic Auth
        if ($this->api_key && $this->api_secret) {
            $auth = base64_encode($this->api_key . ':' . $this->api_secret);
            $headers[] = 'Authorization: Basic ' . $auth;
        }
        
        $options = array(
            CURLOPT_URL => $url,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_HTTPHEADER => $headers,
            CURLOPT_CUSTOMREQUEST => strtoupper($method),
            CURLOPT_SSL_VERIFYHOST => 2,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_TIMEOUT => 30,
        );
        
        if (!empty($data)) {
            $options[CURLOPT_POSTFIELDS] = json_encode($data);
        }
        
        curl_setopt_array($curl, $options);
        
        $response = curl_exec($curl);
        $http_code = curl_getinfo($curl, CURLINFO_HTTP_CODE);
        $error = curl_error($curl);
        curl_close($curl);
        
        if ($this->logger && $error) {
            $this->logger->error('cURL Error: ' . $error, 'class-pgb-woocommerce-bridge.log');
        }
        
        return array(
            'http_code' => $http_code,
            'body' => $response,
            'error' => $error
        );
    }
    
    /**
     * Handle order completion from WooCommerce webhook
     */
    public function handle_order_completion($order_id) {
        if ($this->logger) {
            $this->logger->log('Order completed: ' . $order_id, 'class-pgb-woocommerce-bridge.log');
        }
        
        // Trigger the order processor
        do_action('pgb_order_completed', $order_id);
    }
    
    /**
     * Handle payment completion
     */
    public function handle_payment_complete($order_id) {
        if ($this->logger) {
            $this->logger->log('Payment completed for order: ' . $order_id, 'class-pgb-woocommerce-bridge.log');
        }
    }
}

?>
```

### **2.5 Order Processor: `shared/payment-gateway/class-pgb-order-processor.php`**

```php
<?php
/**
 * PGB Order Processor Class
 * 
 * Processes orders after WooCommerce completion.
 * Handles Streams database updates, affiliate processing, etc.
 */

if (!defined('ABSPATH')) {
    exit('Access denied');
}

class PGB_Order_Processor {
    
    private $logger;
    private $config;
    private $streams_db;
    private $wp_db;
    
    public function __construct($logger = null, $config = array()) {
        $this->logger = $logger;
        $this->config = $config;
        
        // Connect to databases
        $this->connect_databases();
        
        // Register hooks
        $this->register_hooks();
    }
    
    /**
     * Connect to Streams and WordPress databases
     */
    private function connect_databases() {
        // Load db_helpers from shared
        if (function_exists('get_wowonder_db')) {
            $this->streams_db = get_wowonder_db();
        }
        
        if (function_exists('get_wp_db_conn')) {
            $this->wp_db = get_wp_db_conn();
        }
    }
    
    /**
     * Register hooks
     */
    private function register_hooks() {
        add_action('pgb_order_completed', array($this, 'process_completed_order'), 10, 1);
        add_action('woocommerce_order_status_completed', array($this, 'on_order_completed'), 10, 1);
    }
    
    /**
     * Process completed order
     */
    public function process_completed_order($order_id) {
        try {
            // Get WooCommerce order
            $wc_order = wc_get_order($order_id);
            if (!$wc_order) {
                $this->logger->error('WooCommerce order not found: ' . $order_id, 'class-pgb-order-processor.log');
                return;
            }
            
            // Extract metadata
            $pgb_data = $this->extract_order_metadata($wc_order);
            if (!$pgb_data) {
                $this->logger->error('PGB metadata not found in order: ' . $order_id, 'class-pgb-order-processor.log');
                return;
            }
            
            // Get Streams user
            $streams_user = $this->get_streams_user_by_email($wc_order->get_billing_email());
            if (!$streams_user) {
                $this->logger->error('Streams user not found for email: ' . $wc_order->get_billing_email(), 'class-pgb-order-processor.log');
                return;
            }
            
            // Update transaction in Streams
            $this->update_streams_transaction($pgb_data['wow_order_id'], $wc_order, $streams_user['user_id']);
            
            // Handle specific transaction types
            $this->handle_transaction_type($pgb_data, $wc_order, $streams_user);
            
            // Process affiliate rewards
            $this->process_affiliate_rewards($wc_order, $streams_user);
            
            $this->logger->log('Order processed successfully: ' . $order_id, 'class-pgb-order-processor.log');
            
        } catch (Exception $e) {
            $this->logger->error('Error processing order: ' . $e->getMessage(), 'class-pgb-order-processor.log');
        }
    }
    
    /**
     * Extract PGB metadata from WooCommerce order
     */
    private function extract_order_metadata($wc_order) {
        $pgb_data = array();
        
        // Try to get from order meta
        $wow_order_id = $wc_order->get_meta('wow_order_id');
        if ($wow_order_id) {
            $pgb_data['wow_order_id'] = $wow_order_id;
            $pgb_data['wow_post_id'] = $wc_order->get_meta('wow_post_id');
            $pgb_data['userid'] = $wc_order->get_meta('userid');
            return $pgb_data;
        }
        
        return false;
    }
    
    /**
     * Get Streams user by email
     */
    private function get_streams_user_by_email($email) {
        if (!$this->streams_db) {
            return false;
        }
        
        $query = $this->streams_db->prepare(
            "SELECT user_id, email, username FROM Wo_Users WHERE email = ?",
            array($email)
        );
        
        $result = $this->streams_db->get_row($query);
        return $result;
    }
    
    /**
     * Update transaction in Streams database
     */
    private function update_streams_transaction($wow_order_id, $wc_order, $user_id) {
        if (!$this->streams_db) {
            return;
        }
        
        $update_data = array(
            'payment_status' => $wc_order->get_status() === 'completed' ? 'completed' : 'pending',
            'payment_method' => $wc_order->get_payment_method(),
            'woo_order_id' => $wc_order->get_id(),
            'amount' => $wc_order->get_total(),
            'transaction_dt' => current_time('mysql'),
        );
        
        $where = array('order_id' => $wow_order_id);
        
        $this->streams_db->update('Wo_Payment_Transactions', $update_data, $where);
    }
    
    /**
     * Handle specific transaction types
     */
    private function handle_transaction_type($pgb_data, $wc_order, $streams_user) {
        $wow_post_id = $pgb_data['wow_post_id'] ?? null;
        $user_id = $streams_user['user_id'];
        $amount = $wc_order->get_total();
        
        // Get first line item for product ID
        $items = $wc_order->get_items();
        $product_id = reset($items)->get_product_id();
        
        global $wo;
        
        // Check transaction type by product ID
        if ($product_id == $wo['config']['wow_wallet_topup_id']) {
            $this->handle_wallet_topup($user_id, $amount);
        } elseif ($product_id == $wo['config']['wow_crowdfund_id']) {
            $this->handle_crowdfund_contribution($wow_post_id, $user_id, $amount);
        } elseif (in_array($product_id, array(
            $wo['config']['wow_pro_package_id'],
            $wo['config']['wow_pro_package_id_2'],
            $wo['config']['wow_pro_package_id_3'],
            $wo['config']['wow_pro_package_id_4'],
        ))) {
            $this->handle_pro_membership($wow_post_id, $user_id, $wc_order);
        }
    }
    
    /**
     * Handle wallet topup
     */
    private function handle_wallet_topup($user_id, $amount) {
        if (!$this->streams_db) {
            return;
        }
        
        $this->streams_db->query($this->streams_db->prepare(
            "UPDATE Wo_Users SET wallet = wallet + ? WHERE user_id = ?",
            array($amount, $user_id)
        ));
        
        $this->logger->log("Wallet updated for user $user_id: +$amount", 'class-pgb-order-processor.log');
    }
    
    /**
     * Handle crowdfunding contribution
     */
    private function handle_crowdfund_contribution($funding_id, $user_id, $amount) {
        if (!$this->streams_db) {
            return;
        }
        
        $insert_data = array(
            'funding_id' => (int)$funding_id,
            'user_id' => (int)$user_id,
            'amount' => (float)$amount,
            'time' => time(),
        );
        
        $this->streams_db->insert('Wo_Funding_Raise', $insert_data);
        
        $this->logger->log("Crowdfunding contribution recorded for funding $funding_id: $amount", 'class-pgb-order-processor.log');
    }
    
    /**
     * Handle pro membership activation
     */
    private function handle_pro_membership($pro_type, $user_id, $wc_order) {
        if (!$this->streams_db) {
            return;
        }
        
        $pro_time = time();
        $update_data = array(
            'pro_time' => $pro_time,
            'is_pro' => 1,
            'pro_type' => (int)$pro_type,
        );
        
        $this->streams_db->update('Wo_Users', $update_data, array('user_id' => $user_id));
        
        $this->logger->log("Pro membership activated for user $user_id with type $pro_type", 'class-pgb-order-processor.log');
    }
    
    /**
     * Process affiliate rewards
     */
    private function process_affiliate_rewards($wc_order, $streams_user) {
        // Trigger addon for affiliate processing
        do_action('pgb_process_affiliate_rewards', $wc_order, $streams_user);
    }
    
    /**
     * On order completed callback
     */
    public function on_order_completed($order_id) {
        $this->process_completed_order($order_id);
    }
}
```

```php
/**
 * PGB Streams Handler Class
 * 
 * Handles integration between Streams (WoWonder) and the Payment Gateway Bridge.

if (!defined('ABSPATH')) {

class PGB_Streams_Handler {
    
    private $logger;
    private $config;
    private $wp_db;
    private $streams_db;
    
    public function __construct($logger = null, $config = array()) {
        $this->logger = $logger;
        $this->config = $config;
        
        // Connect to databases

        // Register Streams hooks

    /**
     * Connect to databases
     */
    private function connect_databases() {
        if (function_exists('get_wowonder_db')) {
            $this->streams_db = get_wowonder_db();
        }
        if (function_exists('get_wp_db_conn')) {
            $this->wp_db = get_wp_db_conn();
        }
    }
    
    /**
     * Register Streams hooks
     */
    private function register_streams_hooks() {
        // These hooks are called from Streams code
        add_action('pgb_prepare_payment_data', array($this, 'prepare_payment_data'));
        add_action('pgb_validate_order_data', array($this, 'validate_order_data'));
    }
    
    /**
     * Prepare payment data for WooCommerce order creation
     */
    public function prepare_payment_data($streams_post_data) {
        try {
            // Validate required fields
            $required = array('amount', 'product_name', 'product_price', 'product_units', 'transaction_kind');
            foreach ($required as $field) {
                if (empty($streams_post_data[$field])) {
                    return array(
                        'success' => false,
                        'message' => "Missing required field: $field"
                    );
                }
            }
            
            // Sanitize input
            $sanitized = $this->sanitize_payment_data($streams_post_data);
            
            // Generate order ID
            $order_id = uniqid('pgb_');
            
            // Prepare order data for WooCommerce
            $order_data = $this->build_woocommerce_order_data($sanitized, $order_id);
            
            // Store temporary transaction record
            $this->store_temp_transaction($order_id, $sanitized);
            
            return array(
                'success' => true,
                'order_data' => $order_data,
                'order_id' => $order_id,
            );
            
        } catch (Exception $e) {
            if ($this->logger) {
                $this->logger->error('Error preparing payment data: ' . $e->getMessage(), 'class-pgb-streams-handler.log');
            }
            return array(
                'success' => false,
                'message' => $e->getMessage()
            );
        }
    }
    
    /**
     * Sanitize payment data from Streams
     */
    private function sanitize_payment_data($data) {
        return array(
            'amount' => floatval($data['amount']),
            'product_name' => htmlspecialchars(trim($data['product_name']), ENT_QUOTES, 'UTF-8'),
            'product_price' => floatval($data['product_price']),
            'product_units' => intval($data['product_units']),
            'product_owner_id' => intval($data['product_owner_id'] ?? 0),
            'transaction_kind' => preg_replace('/[^a-zA-Z0-9_-]/', '', $data['transaction_kind']),
            'wow_currency_code' => htmlspecialchars($data['wow_currency_code'] ?? 'GHS', ENT_QUOTES, 'UTF-8'),
            'wow_post_id' => isset($data['wow_post_id']) ? intval($data['wow_post_id']) : 0,
            'address_id' => isset($data['address_id']) ? intval($data['address_id']) : 0,
        );
    }
    
    /**
     * Build WooCommerce order data
     */
    private function build_woocommerce_order_data($sanitized, $order_id) {
        global $wo;
        
        // Get WordPress user ID
        $wp_user_id = $this->get_wordpress_user_id($wo['user']['user_id']);
        
        $line_item = array(
            'name' => $sanitized['product_name'],
            'product_id' => (int)($wo['config']['wow_market_id'] ?? 694),
            'quantity' => $sanitized['product_units'],
            'price' => $sanitized['product_price'],
            'total' => $sanitized['amount'],
            'meta_data' => array(
                array('key' => 'wow_order_id', 'value' => $order_id),
                array('key' => 'wow_post_id', 'value' => $sanitized['wow_post_id']),
                array('key' => 'userid', 'value' => $wo['user']['user_id']),
            ),
        );
        
        return array(
            'customer_id' => (int)$wp_user_id,
            'currency' => $sanitized['wow_currency_code'],
            'set_paid' => false,
            'line_items' => array($line_item),
            'meta_data' => array(
                array('key' => 'wow_order_id', 'value' => $order_id),
                array('key' => 'wow_post_id', 'value' => $sanitized['wow_post_id']),
                array('key' => 'userid', 'value' => $wo['user']['user_id']),
                array('key' => '_buzzjuice_origin', 'value' => 'streams'),
            ),
        );
    }
    
    /**
     * Get WordPress user ID from Streams user ID
     */
    private function get_wordpress_user_id($streams_user_id) {
        if (!$this->streams_db) {
            return 0;
        }
        
        $result = $this->streams_db->get_row($this->streams_db->prepare(
            "SELECT wp_user_id FROM Wo_Users WHERE user_id = ?",
            array($streams_user_id)
        ));
        
        return $result ? (int)$result->wp_user_id : 0;
    }
    
    /**
     * Store temporary transaction record
     */
    private function store_temp_transaction($order_id, $sanitized) {
        if (!$this->streams_db) {
            return;
        }
        
        global $wo;
        
        $insert_data = array(
            'userid' => (int)$wo['user']['user_id'],
            'amount' => $sanitized['amount'],
            'order_id' => $order_id,
            'kind' => $sanitized['transaction_kind'],
            'currency_code' => $sanitized['wow_currency_code'],
            'payment_status' => 'pending',
            'timestamp' => time(),
        );
        
        $this->streams_db->insert('Wo_Payment_Transactions', $insert_data);
    }
    
    /**
     * Validate order data

        // Additional validation as needed
```

```php
/**
 * PGB Client Streams
 * 
 * Main client interface for Streams to interact with Payment Gateway Bridge.
 */

if (!defined('ABSPATH')) {
    exit('Access denied');
}

class PGB_Client_Streams {
    
    private $logger;
    private $config;
    private $wc_bridge;
    private $streams_handler;
    
    public function __construct() {
        $this->logger = new PGB_Logger(PGB_LOG_DIR, true, false);
        
        // Load required classes
        if (!class_exists('PGB_WooCommerce_Bridge')) {
            require_once PGB_BRIDGE_DIR . '/class-pgb-woocommerce-bridge.php';
        }
        if (!class_exists('PGB_Streams_Handler')) {
            require_once PGB_BRIDGE_DIR . '/class-pgb-streams-handler.php';
        }
        
        $this->wc_bridge = new PGB_WooCommerce_Bridge($this->logger);
        $this->streams_handler = new PGB_Streams_Handler($this->logger);
    }
    
    /**
     * Initialize payment from Streams
     * 
     * Called from Streams payment modal
     */
    public function init_payment($payment_data) {
        try {
            // Validate Streams user
            global $wo;
            if (!$wo['loggedin']) {
                return $this->error_response('User not authenticated');
            }
            
            // Prepare payment data
            $prep_result = $this->streams_handler->prepare_payment_data($payment_data);
            if (!$prep_result['success']) {
                return $this->error_response($prep_result['message']);
            }
            
            // Create WooCommerce order
            $wc_result = $this->wc_bridge->create_order($prep_result['order_data']);
            if (!$wc_result['success']) {
                return $this->error_response($wc_result['message']);
            }
            
            // Return success response
            return array(
                'success' => true,
                'status' => 200,
                'url' => $wc_result['payment_url'],
                'order_id' => $wc_result['order_id'],
            );
            
        } catch (Exception $e) {
            $this->logger->error('Payment init error: ' . $e->getMessage(), 'pgb-client-streams.log');
            return $this->error_response('Payment initialization failed');
        }
    }
    
    /**
     * Check payment status
     */
    public function check_payment_status($order_id) {
        return $this->streams_handler->get_transaction_status($order_id);
    }
    
    /**
     * Get error response
     */
    private function error_response($message) {
        return array(
            'success' => false,
            'status' => 400,
            'message' => $message,
        );
    }
}
```

```php
if (!defined('ABSPATH')) {

     */

    /**
     * Process affiliate rewards
     */
    public function process_rewards($wc_order, $streams_user) {
        // Check if AffiliateWP is active
        if (!function_exists('affwp_get_referral_by_order')) {
            if ($this->logger) {
                $this->logger->log('AffiliateWP not available', 'pgb-addon-affiliate-wp.log');
            }
            return;
        }
        
        try {
            // Get affiliate context from order meta or cookies
            $affiliate_id = $this->get_affiliate_context($wc_order);
            
            if (!$affiliate_id) {
                if ($this->logger) {

                }
                return;
            }
            
            // Create referral
            $referral_id = $this->create_referral(
                $affiliate_id,
                $wc_order->get_id(),
                $wc_order->get_total(),
                $streams_user
            );
            
            if ($referral_id) {
                if ($this->logger) {
                    $this->logger->log(
                        "Referral created: ID=$referral_id, Affiliate=$affiliate_id, Order={$wc_order->get_id()}",
                        'pgb-addon-affiliate-wp.log'
                    );
                }
            }
            
        } catch (Exception $e) {
            if ($this->logger) {
                $this->logger->error('Error processing affiliate rewards: ' . $e->getMessage(), 'pgb-addon-affiliate-wp.log');
            }
        }
    }
    
    /**
     * Get affiliate context from order meta
     */
    private function get_affiliate_context($wc_order) {
        // Check order meta for affiliate snapshot
        $snapshot = $wc_order->get_meta('_buzzjuice_affwp_context_snapshot');
        
        if ($snapshot) {
            $snapshot_data = json_decode($snapshot, true);
            return $snapshot_data['affwp_affiliate_id'] ?? null;
        }
        
        return null;
    }
    
    /**
     * Create AffiliateWP referral
     */
    private function create_referral($affiliate_id, $order_id, $amount, $streams_user) {
        if (!function_exists('affwp_add_referral')) {
            return false;
        }
        
        $referral_data = array(
            'affiliate_id' => (int)$affiliate_id,
            'reference' => 'woocommerce|' . $order_id,
            'campaign' => 'buzzjuice_streams',
            'status' => 'unpaid',
            'amount' => (float)$amount,
            'context' => 'woocommerce_order',
            'description' => 'Streams purchase: ' . ($streams_user['username'] ?? 'Unknown'),
        );
        
        return affwp_add_referral($referral_data);
    }

        }
    }
```

### **7.1 Payment Handler: `shared/payment-gateway/js/pgb-js-payment-handler.js`**

```javascript
/**
 * Buzzjuice Payment Gateway Bridge - JavaScript Client
 * 
 * Handles payment modal interactions and API calls
 */

class BuzzjuicePaymentGateway {
    constructor(config = {}) {
        this.config = config;
        this.apiEndpoint = config.apiEndpoint || '/wp-json/pgb/v1/';
        this.processing = false;
        this.init();
    }
    
    init() {
        // Bind payment button
        document.addEventListener('click', (e) => {
            if (e.target.closest('[data-pgb-pay]')) {
                this.handlePaymentClick(e);
            }
        });
    }
    
    handlePaymentClick(e) {
        e.preventDefault();
        
        if (this.processing) {
            return;
        }
        
        const button = e.target.closest('[data-pgb-pay]');
        const formData = new FormData(button.closest('form') || document.querySelector('[data-pgb-form]'));
        
        this.initPayment(Object.fromEntries(formData));
    }
    
    async initPayment(paymentData) {
        this.processing = true;
        
        try {
            const response = await fetch(this.apiEndpoint + 'init-payment', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                },
                body: JSON.stringify(paymentData),
            });
            
            const result = await response.json();
            
            if (result.success && result.url) {
                // Redirect to WooCommerce payment page
                window.location.href = result.url;
            } else {
                this.showError(result.message || 'Payment initialization failed');
            }
        } catch (error) {
            console.error('Payment error:', error);
            this.showError('An error occurred during payment initialization');
        } finally {
            this.processing = false;
        }
    }
    
    showError(message) {
        // Show error modal/notification
        if (window.jQuery) {
            jQuery('#error_post_text').text(message);
            jQuery('#error_post').modal('show');
        } else {
            alert(message);
        }
    }
    
    async checkOrderStatus(orderId) {
        try {
            const response = await fetch(this.apiEndpoint + 'order-status/' + orderId);
            return await response.json();
        } catch (error) {
            console.error('Status check error:', error);
            return null;
        }
    }
}

// Initialize on DOM ready
if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', () => {
        window.pgbPaymentGateway = new BuzzjuicePaymentGateway();
    });
```

## **PHASE 9: CRITICAL ENHANCEMENTS & BEST PRACTICES**

### **9.1 Error Handling & Validation Framework**

All classes implement comprehensive error handling:

```php
// Example from any class
try {
    // Operation
    $result = perform_operation();
    if (!$result) {
        throw new Exception('Operation failed');
    }
    $this->logger->log('Success', $log_file);
    return $result;
} catch (Exception $e) {
    $this->logger->error($e->getMessage(), $log_file);
    return false;
}
```

### **9.2 Security Measures**

- **Input Sanitization**: All user input is sanitized via `htmlspecialchars()`, `intval()`, `floatval()`, and regex filters
- **SQL Injection Prevention**: Using prepared statements with `$db->prepare()`
- **CSRF Protection**: Admin actions include nonce verification
- **SSL Verification**: cURL requests validate SSL certificates by default
- **Authentication Checks**: All operations verify `is_loggedin()` and user permissions

### **9.3 Database Consistency**

- Transaction records are created BEFORE payment
- Status updates use prepared statements
- Verification queries check database state
- Rollback capability through error logging

### **9.4 Multi-Currency Support**

Currency conversion is handled through the integration addon:

```php
// In pgb-int-currency-switcher.php
class PGB_Currency_Converter {
    public function convert($amount, $from, $to) {
        // Use WooCommerce currency switcher plugin
        // Or implement conversion rates
    }
```
