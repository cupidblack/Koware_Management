## Output structure

The unified prompt provides eight parts: execution/authority; calendar/IDs; world/roles/technology; six-stage research synthesis; separated output contracts; derivative media; failure/QA/approval; and runtime activation. It includes exact calendar formulas, source URLs, an all-ten-working-day rhythm, eighteen logical record types, an eight-section private appendix, and explicit restricted-answer constraints. All text is included in the delivered Markdown file without `TODO`, filler passage or artificial data values.

Before changing an approved production workflow, ratify: the calendar and local timezone; `S/CH/T/TP/E` crosswalk; Eternal Dreamfall reading-cycle anchor; approved character-canons and diary use rights; Edubeam episode-specific limits; actual repository storage paths and revision policy; challenge release exceptions and secure key custody; and applicable comic/video production guidelines. Until these are ratified, apply the newly generated prompt as a **proposed working baseline**, not proven approval.
