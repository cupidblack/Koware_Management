## 4. Material conflicts that this candidate deliberately does **not** pretend to settle

**Authority conflicts:** The prompt cannot ratify itself. A previous assistant's statement “complete functional prompt” means the text was drafted, not that the studio approved it or a repository now stores it. The owner determines whether v0.08 or a specialist variant becomes canonical; until then preserve the actually approved baseline and clearly mark this new version as a candidate.

**Scheduling:** The public Probe can provide historical/current timestamps and an apparent phase boundary; it does **not** prove the production calendar, time zone, phase numbering, ID crosswalk or truncation policy. For a definitive dated story, an effective approved calendar must exist. Where only a previously provided snapshot is available, only an explicit provisional/retrospective run may use it, correctly dated. Incomplete last episodes need owner policy.

**Study cycle:** An original 250-entry five-year reading plan is not self-evidently a week-for-week map across every civil week in 2025–2029. Whether entries are skipped, special weeks added, a 50-week-year convention used, or additional study content exists is a human curriculum decision. The model may recommend mapping options but should not invent a particular entry of the week.

**Fictional technology:** Advanced Edubeam powers and probe-side object transfer are engaging original story leads, but a fictional capability's appearance in v0.03.05 does not grant that power in early Foundation episodes. Locked era canon outranks aspirational late-stage description. Safety-sensitive depictions should not be presented as an actual scientific protocol.

**Private characters and records:** A file named for a real person, a draft alias, a readable GitHub biography, or an individual's proximity to the fictional story does not equal public consent to publish their likeness, voice, personal diary or private home details. A past one-day editorial waiver is narrow. If a lead's identity is unresolved, do not publish a pretend canonical profile.

**Challenge custody:** A plain Markdown “RESTRICTED” heading is not access control. An unsolved quiz can exist as a **noncompetitive** story draft without C. A formal prizes/points competition needs approved secure answer custody, fairness/reveal rules and anti-abuse safeguards. Never generate a key in the public review package.

**Media economics:** Google video tools, image-to-video services, editors, limits and licenses change. A prompt cannot guarantee any free daily credit, native output format, voice clone rights or unlimited batch generations. At commissioned runtime verify the provider/account; otherwise label script and prompts as plans, not rendered assets. A 160-second day does not guarantee a 20-minute compilation.
