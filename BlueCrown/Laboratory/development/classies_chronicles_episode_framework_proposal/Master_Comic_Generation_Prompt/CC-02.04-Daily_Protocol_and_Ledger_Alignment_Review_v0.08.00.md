No ninth B section is added. A's terminal public question is not violated by appending B because B is a **physically separate internal** artifact. Restricted C is omitted entirely from ordinary output.

### 5.2 Exact Q gates and nineteen families

The daily gates **must be** `Q01_SCOPE`, `Q02_CALENDAR`, `Q03_THREE_CLOCKS`, `Q04_IDENTIFIERS`, `Q05_CANON`, `Q06_ROLE_PROJECT`, `Q07_STUDY`, `Q08_VERSE_HS`, `Q09_RESEARCH`, `Q10_RIGHTS`, `Q11_STORY`, `Q12_CHALLENGE`, `Q13_RECORDS`, `Q14_DERIVATIVES`, `Q15_INTEGRITY`, `Q16_BOUNDARIES`. Master §26A's eight editorial lenses supplement these IDs; they are not a replacement or a second gate namespace. Both updated companions preserve the **nineteen exact** logical family names in master §22; `calendar_probe_record` remains an alias, not an unauthorized twentieth requirement. The *logical document edition* and any deployed `schema_version` are independent; any schema migration requires separate approval and tests.

### 5.3 Durable state and safety checks

The event log retains draft/approved/corrective entries while only **accepted**, in-sequence, nonrevoked events influence the accepted state projection. Each character's knowledge, Edubeam location, charge, role and outstanding obligation has its own lineage. Rights apply to specific audiences and modes, not just generic “consent = yes.” Revision changes can stale any downstream images/clip assets; stale flagging is not proof of regeneration. A B6 handed to another provider transfers only actually authorized sources, actual episode IDs and accepted-vs-proposed distinctions—not hidden model memory, restricted answer C or unreleased private diary content.
