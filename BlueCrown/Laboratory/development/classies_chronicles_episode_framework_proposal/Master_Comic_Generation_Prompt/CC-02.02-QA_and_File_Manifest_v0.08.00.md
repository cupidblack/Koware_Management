## Scope and residual risks

The document set has **no omitted sections, dummy production IDs, synthetic approved sources or unfilled data placeholders**. It intentionally uses explanatory missing-value semantics to prevent invented runtime records. Real chronicles still require current owner-authorized calendars, accessible evidence, accepted continuity, rights and actual editorial decisions. Unit tests show internal textual consistency and illustrative date mathematics, **not** a claim that the workflow was piloted, the project owner ratified it or the repository was changed.

The `reference/` directory contains pinned copies for deterministic offline checking. Verify these against the current repository before a new adoption or production run; changes to the master will require companion review and potentially updated checks.
