# 5. An important improvement: Sequential comic generation

I recommend that we don't simply generate five unrelated images from five independent prompts.

Instead, introduce a **Chronicle Comic Sequence**.

The process should be:

1. Complete and approve the daily written chronicle.
2. Divide the story into five visual sequences.
3. Establish the characters and locations appearing in each sequence.
4. Prepare a Character & Scene Reference Sheet.
5. Generate page 1.
6. Use the approved character and scene references when generating subsequent pages.
7. Check continuity between pages.
8. Generate the final challenge page.
9. Review the complete comic sequence.

This reduces inconsistencies involving:

* Character faces.
* Clothing.
* Hairstyles.
* Locations.
* Equipment.
* Lighting.
* Temporal settings.
* Story progression.

It also makes it easier to generate comics using different image-generation platforms.
