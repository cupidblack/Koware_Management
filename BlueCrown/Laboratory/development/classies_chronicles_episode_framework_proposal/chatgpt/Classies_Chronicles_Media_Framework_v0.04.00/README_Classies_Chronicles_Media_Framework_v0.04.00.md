## Relationship with the technical production set

This package **does not replace** the Unified Master Prompt, Daily Chronicle Protocol, Episode Continuity Ledger, Master Comic Generation Prompt, or currently approved Studio Blueprint. It adds the focused media adaptation layer: *source-verified story/comic → scenes/acts/shots → prompt pack → short clips/still motion → narration and sound → edit/export → independent QA/rights checks → episode-owned handover.*

## What is and is not completed

The specification and review files are drafted in full. No specific daily chronicle or comic pages were commissioned in this request, so no actual scene-level filled video prompts, voice tracks, generated clips, CapCut projects, or released exports are claimed. Under an actual media commission, the system uses the real authorized chronicle and approved visual assets to generate **fully populated** clip prompts and video assets as far as tools and permissions allow.

**Document status:** PROPOSED; human review/adoption required. No GitHub update, audio/video rendering, archive write or publisher action performed.

## Runtime examples, not imposed quotas

- Four page / four act groups / ten-second final acts → 16 acts, 160 seconds (02:40).
- Four page / five act groups / ten-second final acts → 20 acts, 200 seconds (03:20).
- Other comic page counts and target runtimes remain possible by explicit commission; each actual timeline must be recalculated, not merely relabeled.

## Suggested adoption

Review the conflict matrix and source-rights authority; obtain a human adoption decision; carry out the pilot's small 10-second test before the 160- or 200-second full segment; record actual provider free credit/rights at execution; retain the resulting assets under the episode archive through the approved production manifest and revision controls.
