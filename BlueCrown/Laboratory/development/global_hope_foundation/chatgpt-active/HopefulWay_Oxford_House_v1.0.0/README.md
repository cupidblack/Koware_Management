# HopefulWay Oxford House — v1.0.0 implementation kit
Start with 01_MASTER_PLAYBOOK.md, then follow 05_DEPLOYMENT_AND_QA.md in order. This release candidate supersedes the draft campaign proposal and integrates reviewed prior recommendations with actual installable/configurable assets. Production approvals and runtime tests remain required.

- 01_MASTER_PLAYBOOK.md — consolidated operational plan, deadlines, privacy, admission, viability and expansion.
- 02_COMMUNICATIONS.md — WhatsApp messages, follow-ups, cover letter, applicant messages, factsheet and speaker guide.
- 03_Intake.gs — Google Apps Script to create the unpublished branched form, separate restricted registers, dashboard, notification and approved deletion workflow.
- 04_hopefulway-form-redirect.php — source of WordPress redirect plugin; upload `hopefulway-form-redirect.zip` on each WordPress installation.
- 05_DEPLOYMENT_AND_QA.md — step-by-step build, configuration, operating guide and acceptance matrix.
- 06_CONVERGENCE_AND_TRACEABILITY.md — original 23 points, cross-platform decisions, limitations and assumptions.

No placeholder data is included; account-specific URLs are generated/configured at deployment, actual policies/fees supplied by authorized owners, and real recipient details added to approved stationery. Source material remains in its authoritative location. Do not store live responses or private letters in a public repository.
