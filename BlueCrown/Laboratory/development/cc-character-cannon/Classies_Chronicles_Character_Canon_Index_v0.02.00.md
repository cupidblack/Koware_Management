## Operating model

- Approved reusable **character** reference belongs in `04_CANON/CHARACTERS/`; episode-owned appearances, mission state, scene outcomes and challenge controls stay in approved episode archives.
- A diary URL must remain `null` until authorized; record consent, scope and verification outside publicly available character files where necessary.
- To maintain art continuity after the separate graphics operation, update each character `visual_collage_url` with the actual approved asset path.
- Use `CHARACTER_CANON_MANIFEST.csv` for repository reconciliation and `validate_character_canons.py` to verify file count, unique IDs, source mappings and links.
