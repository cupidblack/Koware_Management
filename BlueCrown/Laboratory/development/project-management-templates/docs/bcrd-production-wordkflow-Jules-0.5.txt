--------------------------------------------------------------------------------
OVERVIEW & OPERATING PRINCIPLES
--------------------------------------------------------------------------------
This workflow template establishes an evidence-based, highly durable AI engineering pipeline structured strictly around the 49 Project Management processes. Each stage uses a sequential numeric prefix ranging from 0004.1 ("Develop Project Charter") through 9004.7 ("Close Project or Phase").

AI AGENT ROLE ROSTER:
1. ChatGPT / Codex (Architecture & Strategy Lead):
   - Responsible for project initiation, chartering, architectural design, specifications, ADRs, task packet generation, and overall technical strategy.
2. GitHub Copilot (Primary Implementation Agent):
   - Responsible for primary code implementation, feature development on task branches (`pgb/bzj-pgb-xxx`), PR creation, and applying code fixes.
3. Google Jules (Independent Reliability & CI Review Agent):
   - Responsible for independent code verification, test creation, CI/CD pipeline checks, edge-case analysis, and ensuring non-regression.
4. Claude Code (Adversarial Security & Architecture Review Agent):
   - Responsible for attacking transaction boundaries, identifying race conditions, verifying security controls, idempotency, and data safety.

SECTION STRUCTURE TEMPLATE:
Every process section follows a standardized layout containing section notes, role-assigned prompts, reference links, and response container blocks.
