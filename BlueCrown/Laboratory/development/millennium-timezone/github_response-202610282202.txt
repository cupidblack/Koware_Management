The right fix is to centralize the calculation in `shared/millennium-timezone`, use the existing `koware_iapd` connection helpers, and replace same-domain HTTP calls with direct PHP function calls. - Keep the historical calendar formula in `millennium-timezone.php`
- Keep the phase/probe logic in `millennium-probe.php`
- Use file logs for TTL-based refresh metadata
- Use `koware_iapd.millennium_timezone_*` for shared state only
- Replace endpoint-to-endpoint calls with `require_once` + function calls

```php name=shared/millennium-timezone/millennium-timezone.php
function mtz_log($message, array $context = []): void {

function ordinal($n): string {
    if ($n > 3 && $n < 21) return $n . 'th';
    switch ($n % 10) {
        case 1: return $n . 'st';
        case 2: return $n . 'nd';
        case 3: return $n . 'rd';
        default: return $n . 'th';
    }
}

function jubilee($year): string {
    $hebrew = $year + 3760;
    $raw = ($hebrew - 2503) / 50;

    $int = floor($raw);
    $dec = $raw - $int;

    $yy = floor(($dec * 100) / 2);

    return $int . 'Y' . str_pad((string)$yy, 2, '0', STR_PAD_LEFT);
}

/**
 * Original historical date engine preserved as-is.
 */
function palmier_time(): array {
    global $historicalHourMap;

    try {
        $now = new DateTime('now', new DateTimeZone('UTC'));
        $epoch = new DateTime('1899-12-30 00:00:00', new DateTimeZone('UTC'));

        $diffDays = ($now->getTimestamp() - $epoch->getTimestamp()) / 86400;
        $j = (((($diffDays / 365.262541748) + 1900) / 7) - 2 - 184) * 365.262541748;

        $hist = clone $epoch;
        $days = (int) round($j);

        if ($days >= 0) {
            $hist->modify("+{$days} days");
        } else {
            $hist->modify("{$days} days");
        }

        $weekday = (int) $now->format('w');
        $base = $historicalHourMap[$weekday] ?? 0;

        $secToday = ($now->format('H') * 3600) + ($now->format('i') * 60) + (int) $now->format('s');
        $progress = $secToday / 86400;
        $histSec = $progress * 14400; // 4 hours

        $h = floor($histSec / 3600);
        $m = floor(($histSec % 3600) / 60);
        $s = floor($histSec % 60);

        $hour = ($base + $h) % 24;
        $hist->setTime($hour, $m, $s);

        return [$now, $hist, null];
    } catch (Throwable $e) {
        mtz_log('ENGINE_FAIL', ['message' => $e->getMessage()]);
        return [null, null, $e->getMessage()];
    }
}

/**
 * Build the machine-readable payload.
 * Useful for both top-level endpoint and internal callers.
 */
function mtz_build_calendar_result(): array {
    global $daysShort, $daysFull, $months;

    [$now, $historical, $error] = palmier_time();

    if (!$now instanceof DateTime || !$historical instanceof DateTime) {
        throw new RuntimeException('Palmier date calculation did not return valid dates.');
    }

    $currentUtc = clone $now;
    $currentUtc->setTimezone(new DateTimeZone('UTC'));

    $historicalUtc = clone $historical;
    $historicalUtc->setTimezone(new DateTimeZone('UTC'));

    $weekdayIndex = (int) $currentUtc->format('w');
    $historicalWeekdayIndex = (int) $historicalUtc->format('w');

    $base = [
        'status' => $error ? 'warning' : 'ok',
        'timezone' => 'UTC',
        'generated_at' => gmdate('Y-m-d\TH:i:s\Z'),
        'day' => $daysShort[$historicalWeekdayIndex] . $daysFull[$weekdayIndex],
        'date' => ordinal((int) $historicalUtc->format('d')),
        'month' => $months[(int) $historicalUtc->format('n') - 1],
        'jubilee' => jubilee((int) $currentUtc->format('Y')),
        'reference_year' => (int) $historicalUtc->format('Y'),
        'local' => $historicalUtc->format('Y-m-d\TH:i:s\Z'),
        'current' => $currentUtc->format('Y-m-d\TH:i:s\Z'),
        'historical_iso' => $historicalUtc->format('Y-m-d\TH:i:s\Z'),
        'error' => $error ?: null,
    ];

    return $base;
}

}

function mtz_get_last_successful_refresh(): ?array {
    $items = mtz_read_cache_file();

    if (!is_array($items) || empty($items)) {
        return null;
    }

    $last = end($items);
    if (!is_array($last)) {
        return null;

    return $last;

function mtz_should_refresh(?array $last): bool {
    if (!$last) {
        return true;
    }

    $timestamp = $last['generated_at'] ?? $last['timestamp'] ?? null;
    if (!$timestamp) {
        return true;
    }

    $epoch = strtotime((string) $timestamp);
    if ($epoch === false) {
        return true;
    }

    return (time() - $epoch) >= MTZ_CACHE_TTL;
}

function mtz_get_timezone_payload(): array {
    $last = mtz_get_last_successful_refresh();
    $shouldRefresh = mtz_should_refresh($last);

    if (!$shouldRefresh) {
        $payload = $last;
        $payload['cache'] = [
            'generated_at' => $payload['generated_at'] ?? gmdate('Y-m-d\TH:i:s\Z'),
            'cache_age_seconds' => max(0, time() - strtotime($payload['generated_at'])),
            'stale' => false,
        ];
        $payload['probe'] = $payload['probe'] ?? mtz_get_probe_payload();
        return $payload;
    }

    $payload = mtz_build_calendar_result();
    $payload['probe'] = mtz_get_probe_payload();
    $payload['timestamp'] = time();
    $payload['cache'] = [
        'generated_at' => gmdate('Y-m-d\TH:i:s\Z'),
        'cache_age_seconds' => 0,
        'stale' => false,
    ];

    $payload['cache']['cache_age_seconds'] = isset($last['generated_at'])
        ? max(0, time() - strtotime($last['generated_at']))
        : 0;

    $payload['cache']['stale'] = false;

    $logEntry = $payload;
    $logEntry['cache'] = $payload['cache'];

    mtz_write_cache_file($logEntry);
    mtz_store_snapshot_db($payload);

    return $payload;
}
```

```php name=shared/palmier/oscillator/palmier-oscillator.php
function bzj_now(): int {
    return time();
}

function bzj_day_of_year($t = null): int {
    $t = $t ?? bzj_now();
    return (int) date('z', $t) + 1;
}

function bzj_year_phase($t = null): float {
    $t = $t ?? bzj_now();
    $start = strtotime(date('Y-01-01 00:00:00', $t));
    $end = strtotime(date('Y-12-31 23:59:59', $t));
    return ($t - $start) / max(1, $end - $start);
}

function bzj_smooth($x): float {
    return (1 - cos(M_PI * $x)) / 2;
}

function bzj_palmier_variance($t = null): float {
    $t = $t ?? bzj_now();
    $d = bzj_day_of_year($t);

    $anchors = [
        213 => 0,
        258 => 1,
        288 => 0,
        319 => 1,
        365 => 0,
        46  => 1,
        74  => 0,
        105 => 1,
        151 => 0,
        182 => 1,
    ];

    ksort($anchors);
    $keys = array_keys($anchors);

    for ($i = 0; $i < count($keys); $i++) {
        $a = $keys[$i];
        $b = $keys[($i + 1) % count($keys)];
        $va = $anchors[$a];
        $vb = $anchors[$b];

        if ($b < $a) $b += 365;
        $dMod = $d < $a ? $d + 365 : $d;

        if ($dMod >= $a && $dMod <= $b) {
            $f = ($dMod - $a) / max(1e-9, ($b - $a));
            $s = bzj_smooth($f);
            $pv = ($va + ($vb - $va) * $s) * PALMIER_MAX;
            return round($pv, 5);
        }
    }

    return 0.00000;
}

function bzj_solar_variance($t = null): float {
    $d = bzj_day_of_year($t ?? bzj_now());
    $phase = (($d - 3 + 365) % 365) / 365;
    $w = 0.5 - 0.5 * cos(2 * M_PI * $phase);
    return round($w * SOLAR_MAX, 5);
}

function bzj_lunar_variance($t = null): float {
    $t = $t ?? bzj_now();
    $days = (bzj_year_phase($t) * 365.2422);
    $synodic = 29.530588;
    $phase = fmod($days, $synodic) / $synodic;
    $w = 0.5 - 0.5 * cos(2 * M_PI * $phase);
    return round($w * LUNAR_MAX, 5);
}

function bzj_passover_window($year): array {
    $m = $year % 19;
    $start = 84 + round(($m / 19) * 31);
    $end = 90 + round(($m / 19) * 36);
    return [$start, $end];
}

function bzj_passover_variance($t = null): float {
    $t = $t ?? bzj_now();
    $year = (int) date('Y', $t);
    $d = bzj_day_of_year($t);
    [$start, $end] = bzj_passover_window($year);

    if ($d < $start || $d > $end) {
        return 0.00000;
    }

    $x = ($d - $start) / max(1, $end - $start);
    return round(sin(M_PI * $x) * PALMIER_MAX, 5);
}

function bzj_norm($v, $max): float {
    return ($max > 0) ? min(1, $v / $max) : 0;
}

function bzj_oscillation_value($t = null): float {
    $lv = bzj_lunar_variance($t);
    $sv = bzj_solar_variance($t);
    $pv = bzj_palmier_variance($t);
    $psv = bzj_passover_variance($t);

    $avg = (
        bzj_norm($lv, LUNAR_MAX)
        + bzj_norm($sv, SOLAR_MAX)
        + bzj_norm($pv, PALMIER_MAX)
        + bzj_norm($psv, PALMIER_MAX)
    ) / 4;

    return round($avg * PALMIER_MAX, 5);
}
```

```php name=shared/palmier/gold_calc/gold_calc_helpers.php
    $slots = ['00:00:00','06:00:00','12:00:00','18:00:00'];
    $now = new DateTime('now', new DateTimeZone('UTC'));
    foreach (array_reverse($slots) as $slot) {
        if ($now->format('H:i:s') >= $slot) return $now->format('Y-m-d') . ' ' . $slot;
    }
    return (new DateTime('yesterday', new DateTimeZone('UTC')))->format('Y-m-d') . ' 18:00:00';
}

function logExists($file, $slot) {

// Returns array: ['date1'=>[...], 'date2'=>[...]]
function loadCsvFull($file) {
    $lines = file($file);
    if (!$lines) return [];
    $lines[0] = preg_replace('/^\x{FEFF}/u', '', $lines[0]);
    $rows = array_map('str_getcsv', $lines);
    $header = array_map('strtolower', $rows[0]);
    unset($rows[0]);
    $data = [];
    foreach ($rows as $row) {
        $entry = array_combine($header, $row);
        if (isset($entry['date'])) $data[$entry['date']] = $entry;
    }
    ksort($data);
    return $data;
}

// Prefer 'close' if valid, fallback to 'open'
function getRate($row) {
    if (isset($row['close']) && $row['close'] != '' && $row['close'] != 0) {
        return (float) $row['close'];
    }
    if (isset($row['open']) && $row['open'] != '' && $row['open'] != 0) {
        return (float) $row['open'];
    }
    return null;
}

// Finds exact/interpolated rate or skips currency if ineligible
function findRateMeta($data, $targetDate){
    $dates = array_keys($data);
    $prev = null;
    $next = null;

    foreach ($dates as $d) {
        $row = $data[$d];
        $value = getRate($row);

        if ($value === null) continue;
        if ($d == $targetDate) {
            return [
                'type' => 'exact',
                'date_used' => $d,
                'rate' => $value
            ];
        }
        if ($d < $targetDate) $prev = ['date' => $d, 'value' => $value];
        if ($d > $targetDate && !$next) $next = ['date' => $d, 'value' => $value];
    }

    if (!$prev || !$next) return null;

    $t1 = strtotime($prev['date']);
    $t2 = strtotime($next['date']);
    $t = strtotime($targetDate);

    $interp = $prev['value'] + ($next['value'] - $prev['value']) * (($t - $t1) / ($t2 - $t1));
    return [
        'type' => 'interpolated',
        'date_used' => $targetDate,
        'rate' => $interp,
        'prev' => $prev,
        'next' => $next
    ];
}

// Format: 1'2345'6789.0123 (groups of 4)
function formatPalmierNumber($num) {
    $num = number_format($num, 4, '.', '');
    $parts = explode('.', $num);
    $int = strrev(implode("'", str_split(strrev($parts[0]), 4)));
    return $int . '.' . $parts[1];
}
```

6) Step 6: Stop writing calculation logs to the database

Your note is correct: logs should stay as flat files, not database rows. The `palmier_logger.php` file currently writes to `Wo_UserActivityLog`, which is business activity tracking and not a calculation-history log.

Do not store the actual calculation history in the database. Keep it file-based for historical records. If you still need per-user activity tracking, separate it from the timezone calculation log:

- `koware_iapd.millennium_timezone_snapshot` — current shared state
- `koware_iapd.millennium_timezone_cache` — cache metadata
- file log `shared/millennium-timezone/millennium-timezone.log` — history / audit
- file log `shared/millennium-timezone/millennium-probe.log` — probe refresh history
- file log `shared/palmier/oscillator/palmier-oscillator.log` — local oscillator cache history

A safe pattern for `palmier_logger.php` is to replace the DB insert with a file append, for example:

```php name=shared/palmier/palmier_logger.php
<?php
require_once __DIR__ . '/../db_helpers.php';

function bzj_log_activity_file($user_id, $action_type, $ref_id = null, $ref_type = null, $value = 1, $source_table = null) {
    $entry = [
        'timestamp' => time(),
        'user_id' => (int) $user_id,
        'action_type' => $action_type,
        'ref_id' => $ref_id,
        'ref_type' => $ref_type,
        'value' => (float) $value,
        'source_table' => $source_table,
    ];

    $logDir = __DIR__ . '/logs';
    if (!is_dir($logDir)) {
        @mkdir($logDir, 0775, true);
    }

    $logFile = $logDir . '/palmier-user-activity.log';

    @file_put_contents(
        $logFile,
        json_encode($entry, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE) . PHP_EOL,
        FILE_APPEND | LOCK_EX
    );
}
```
