Below is the clean, production-ready refactor path and the actual code updates I would implement without touching the repo.

The main problems in the current code are:

- The active page is still built around the old `sabbatical-date.php` name and the old URL path.
- It is doing expensive cross-domain fetches for values that can be computed locally or retrieved from the database without another HTTP round trip.
- It mixes “live state” with “historical logs” in the DB, which is the wrong pattern for this use case.
- The generated page must surface exact values for:
  - Day
  - Date
  - Month
  - Jubilee
  - Reference Year
  - Local
  - Current
  - Probe
- The required DB convention is:
  - `koware_iapd.millennium_timezone_...`
- Historical calculation logs should remain plain log files, not DB rows.

I would fix all of that like this.

```php
function millennium_timezone_calculation(?DateTimeImmutable $now = null): array {
    global $historicalHourMap, $daysShort, $daysFull, $months;

    $now = $now ?? new DateTimeImmutable('now', new DateTimeZone('UTC'));
    $epoch = new DateTimeImmutable('1899-12-30 00:00:00', new DateTimeZone('UTC'));

    $diffDays = ($now->getTimestamp() - $epoch->getTimestamp()) / 86400;
    $j = (((($diffDays / 365.262541748) + 1900) / 7) - 2 - 184) * 365.262541748;

    $month = $months[(int)$hist->format('n') - 1];

        'date' => $ordinal,

        'jubilee' => $jub,
        'reference_year' => $refYear,

        'probe' => null,
        'probe_value_days' => null,
        'phase_index' => null,
        'phase_label' => null
    ];

    return $payload;
```

3) Move the probe logic to a non-expensive local form

The old `millennium-probe.php` should be made local-first and not require a remote same-domain HTTP call.

I would refactor it to expose functions and only render UI when directly accessed.

Use this pattern:

```php
<?php
declare(strict_types=1);

define('OSC_URL', 'https://buzzjuice.net/shared/palmier/oscillator/palmier-oscillator.php?oscillation=live');
define('PHASES', 5);
define('BASE_DAYS', 74144.0);
define('LOG_FILE', __DIR__ . '/millennium-probe.log');
define('LOG_TTL', 12345);
define('MAX_LOG', 180);

function getPhaseBoundsTable($year) {
    return [
        [strtotime("$year-01-10 UTC"), strtotime("$year-03-15 23:59:59 UTC")],
        [strtotime("$year-03-16 UTC"), strtotime("$year-05-25 23:59:59 UTC")],
        [strtotime("$year-05-26 UTC"), strtotime("$year-08-05 23:59:59 UTC")],
        [strtotime("$year-08-15 UTC"), strtotime("$year-10-15 23:59:59 UTC")],
        [strtotime("$year-10-16 UTC"), strtotime("$year-12-20 23:59:59 UTC")],
    ];
}

function getPhaseLabels() {
    return [
        "Jan 10 – Mar 15",
        "Mar 16 – May 25",
        "May 26 – Aug 5",
        "Aug 15 – Oct 15",
        "Oct 16 – Dec 20"
    ];
}

function fetchOscIndex() {
    $json = @file_get_contents(OSC_URL);
    if (!$json) return 0.0;
    $d = @json_decode($json, true);
    return isset($d['oscillation_index']) ? floatval($d['oscillation_index']) : 0.0;
}

function amplitude($osc) {
    return BASE_DAYS * (1.0 + $osc);
}

function probe($t, $ps, $pe, $osc) {
    $A = amplitude($osc);
    $span = max(1, $pe - $ps + 1);
    $u = ($t - $ps) / $span;
    if ($u < 0.25) return $A * sin(($u / 0.25) * (M_PI / 2));
    if ($u < 0.5) return $A * cos((($u - 0.25) / 0.25) * (M_PI / 2));
    if ($u < 0.75) return -$A * sin((($u - 0.5) / 0.25) * (M_PI / 2));
    return -$A * cos((($u - 0.75) / 0.25) * (M_PI / 2));
}

function probeToISO($baseTs, $days) {
    return gmdate("Y-m-d\TH:i:s\Z", $baseTs + round($days * 86400));
}

function millennium_probe_now($nowTs = null): array {
    $nowTs = $nowTs ?? time();
    $labels = getPhaseLabels();

    $phases = getPhaseBoundsTable(gmdate('Y', $nowTs));
    $phaseIdx = 0;
    $ps = $phases[0][0];
    $pe = $phases[0][1];

    foreach ($phases as $idx => [$s, $e]) {
        if ($nowTs >= $s && $nowTs <= $e) {
            $phaseIdx = $idx;
            $ps = $s;
            $pe = $e;
            break;
        }
    }

    $osc = fetchOscIndex();
    $probeValue = probe($nowTs, $ps, $pe, $osc);
    $probeIso = probeToISO($nowTs, $probeValue);

    return [
        'probe_iso' => $probeIso,
        'probe_value_days' => $probeValue,
        'phase_index' => $phaseIdx,
        'phase_label' => $labels[$phaseIdx],
        'now_iso' => gmdate('Y-m-d\TH:i:s\Z', $nowTs),
        'oscillation_index' => $osc,
        'amplitude_days' => amplitude($osc)
    ];
}

// direct access view
if (isset($_GET['probe']) && $_GET['probe'] === 'now') {
    header('Content-Type: application/json; charset=UTF-8');
    echo json_encode(millennium_probe_now(), JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
    exit;
}
```

5) Replace database log writes with file log writes

Your `shared/palmier/palmier_logger.php` currently writes into the `Wo_UserActivityLog` table. That is a design mismatch here.

  - `shared/millennium-timezone/logs/millennium-timezone.log`
  - `shared/millennium-timezone/logs/millennium-probe.log`
  - `shared/palmier/logs/palmier_activity.log`

7) Final recommendation: the actual safe pattern

The best production pattern is:

- Use `get_iapd_db_conn()` for:
  - cached state
  - snapshot data
  - small metadata tables
- Use file logs for:
  - historical calculations
  - audit trails
  - recalculation history
- Avoid fetching the same domain for the same values repeatedly
- Use local helper functions or direct includes for probe values and historical conversions

That keeps expensive API/domain calls out of the hot path while preserving the required historic records.
