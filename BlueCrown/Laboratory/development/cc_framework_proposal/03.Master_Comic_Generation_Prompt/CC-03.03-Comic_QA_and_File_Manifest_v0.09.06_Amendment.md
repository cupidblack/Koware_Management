### 3.5 Mandatory geometry stop before every next sheet (v0.09.06)

For each sheet **including S01**, perform the following before changing the accepted production cursor:

1. Open the generated **actual image bytes**. Record SHA-256, measured source width/height, file format and provider-reported size separately. A prompt or chat preview never replaces this measurement.
2. Establish four genuine page rectangles in TL/TR/BL/BR. If split by exact halves, verify even W/H and zero shared gutters, then crop and measure all four. If authoring included real gutters, record each actual rectangle and inspect its boundaries and readability; do not infer page ratio from full sheet.
3. Each *individual extracted page* must satisfy `w>0`, `h>0`, `16*w == 9*h`. One failure sets sheet geometry FAIL. Store observed dimensions and per-page results; don't fabricate a correction or simply mark `PASS` on the strength of a written instruction.
4. Measure meaningful source illustration detail independently of final exported size. A 2×2 sheet of 1080×1920 gives cells 540×960; this passes aspect but may fail preferred native-detail specification. If the approved minimum is 1080×1920 genuine native page art, record `C19` FAIL/BLOCKED until acceptable detail exists.
5. Validate final rendered/lettered 9:16 output at phone view, together with narrative/rights/continuity. Passing ratio alone does not advance release readiness.
6. On any failure retain `Sxx_REPAIR_REQUIRED`, keep previous accepted cursor and source file unchanged, attempt only an authorized same-ID fix, and **STOP before next sheet**. Any provisional storytelling continuation using nonconforming art must explicitly retain `RELEASE_BLOCKED_GEOMETRY`; it is not a C11 PASS.

**Generation-route decision:** if a provider cannot produce genuine 9:16 four-cell sheets reliably, render P pages individually at actual supported exact 9:16 dimensions and assemble with lossless pixel copies. If the provider also cannot deliver genuine 9:16 individual pages, block and disclose; do not fabricate compliance by resizing or padding. A 2:3 original may be preserved as a nonconforming look reference.

## 5A. Aspect-ratio measurement, evidence fields and reproducible tests (v0.09.06)

Add these fields to the existing sheet and page records (do not replace the v0.09.05 fields):

- `grid_columns`, `grid_rows`, `separators_or_gutters`, `row_major_page_ids`, `exact_page_crop_rectangles`;
- `extracted_page_actual_size`, `extracted_page_sha256`, `ratio_numerator_check:16*w`, `ratio_denominator_check:9*h`, `ratio_exact_pass` per page;
- `native_art_dimensions`, `export_dimensions`, `transform_history` (crop/assemble/outpaint/upscale/re-letter), `native_quality_status` independently of ratio;
- `sheet_ratio_exact_pass`, `cell_geometry_pass`, `sheet_to_cell_consistency`, `mobile_readability_status`;
- `C11_PAGE_ASPECT`, `C19_EXPORT_QUALITY`, `blocking_repairs`, `accepted_cursor_hold`, `user_provisional_exception_if_any`.

Valid geometry states: `NOT_MEASURED`, `PASS_EXACT_RATIO`, `FAIL_EXACT_RATIO`, `BLOCKED_NO_BYTES`, `EXCEPTION_AUTHORIZED_FOR_DRAFT_NOT_RELEASE`. An allowed draft exception never becomes `PASS_EXACT_RATIO` and never makes a page release-ready. No missing dimension is represented by zero or a fabricated path.

### 5A.2 Mechanical checker and assembly policy

Use the accompanying Python/Pillow validator **`cc03_geometry_guard_v0.09.06.py`** to inspect actual sheet/page assets, report original dimensions, compute SHA-256, derive exact row-major crop boxes for zero-gutter 2×2 assets, extract 4 page crops when requested, refuse nonconforming pages in lossless `assemble`, and issue JSON evidence. The checker **must not** auto-stretch/crop/outpaint to manufacture 9:16. It cannot verify stories, text fidelity, subject identity, consent, upstream copyright, color intent or publishing approval; human QA is still mandatory.

**Equality requirement:** no relative error tolerance such as `abs(width/height - 9/16) < 0.02` for strict master pages. Deviations may be drafts only with overt owner exception; *exact 9:16* means exact integer cross multiplication.
