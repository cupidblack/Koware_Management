## 3. Key findings

### 3.1 Upstream compatibility

The CC-01.01 v0.09.01 candidate already specifies sixteen different complete 9:16 portrait pages, four sequential 2×2 sheets, page-to-source beat mapping, consistent realistic graphic-novel art, exact C01–C22 gates and independent render/export/QA/editorial/publishing states. The updated CC-03.01 retains these requirements and makes their execution more deterministic.

The CC-02.02 logical ledger ID remains `CC-02.02 / CC-ECLPM`, even though the supplied physical filename includes a different numbered prefix. The refactor does not rename or migrate that file or its schema.

The nineteen canonical continuity record families remain unchanged. `calendar_probe_record` remains a compatibility alias, not a twentieth family. Daily Q01–Q16 and comic C01–C22 remain separate exact gate sets.

### 3.2 Visual direction correction

The predecessor's blanket prohibition on cartoon-like characteristics conflicts with the user's requested blend of realism and selective animation/toony effects. The revised direction establishes a realistic foundation with context-sensitive expressive exaggeration. It permits temporary, localized effects such as slightly widened eyes, raised brows, impact lines, sweat cues and controlled comedic reactions, while prohibiting permanent identity drift, childish proportions and uncontrolled anatomy distortion.

### 3.3 Geometry clarification

A 2×2 grid of four equal 9:16 pages remains 9:16 overall. For 1080×1920 pages, the no-gutter sheet is 2160×3840. The predecessor's dimensions are mathematically correct. The updated prompt explicitly requires measurement of the composite and each cell, because a correctly proportioned outer sheet can still contain wrongly proportioned page cells.

### 3.4 Duplicate-generation control

The previous workflow needed an explicit page registry and pre-render idempotency check. The new system assigns every page a unique ID, sheet ID and cell; checks completed assets before each render; prohibits repeating initial-generation pages; and confines corrections to identified failed pages and dependent neighbours. An alternate style is a separate revision, never an accidental second initial output set.

## 6. Non-negotiable production invariants

1. The exact authorized Output A revision is the narrative source.
2. The initial default is sixteen distinct pages, not sixteen render attempts.
3. Each page has a unique page ID and appears once in the initial set.
4. Four pages are grouped per 2×2 sheet in row-major order.
5. Each page is 9:16; each no-gutter 2×2 sheet is also 9:16.
6. The same visual style and character appearance locks apply across all sheets.
7. Realism remains the foundation; toony effects are selective and temporary.
8. No page is regenerated without a documented failure or explicit revision request.
9. The public challenge is exact, terminal and answer-free.
10. Q01–Q16, C01–C22 and the nineteen ledger families remain unchanged.
11. A rendered asset is not automatically canon, accepted, committed or published.
12. Any upstream dependency change can stale affected comic pages.
