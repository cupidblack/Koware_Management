## 4. Utility tests

The companion `cc_comic_sheet_tool.py` supports:
- Validating a 9:16 page.
- Assembling exactly four equal 9:16 pages into a 2×2 9:16 sheet.
- Slicing a no-gutter equal-cell 2×2 sheet into four pages.
- Rejecting malformed dimensions and incorrect page counts.
- Running synthetic geometry self-tests.

Synthetic utility tests do not establish comic narrative fidelity, lettering quality, character continuity, rights, answer secrecy or visual style acceptance.
