### 8.1 Mandatory output-geometry acceptance contract (v0.09.06)

**Normative hierarchy:** each *published comic page*, not merely its prompt, must pass the exact 9:16 raster test. A native generated image, a constructed collage, an extracted page, a repaired/outpainted page and a final export are distinct artifacts; retain their origins. The preferred page export is **1080 × 1920 px or a higher exact 9:16 resolution**. It is a target, not a false guarantee of what an image provider will return. Compliant geometry **does not** prove sufficient native art detail, good lettering, accurate content, rights clearance or release readiness.

- **Exact predicate:** a page with positive integer pixel dimensions `(w,h)` passes if and only if `16*w == 9*h`. A 2×2 sheet with *no* exterior border/gutter, all four equal cells and unambiguous boundaries passes only if `(W,H)=(2w,2h)`, so `16*W == 9*H`. The sheet itself must be independently measured; its ratio alone does not prove the four internal cells have correct boundaries.
- **Grid-general formula:** for `c` columns by `r` rows of equal genuine 9:16 pages without spacing, `sheet_width/sheet_height = (c*9)/(r*16)`. Example: `2×2` (columns×rows) is 9:16, `4×4` is 9:16, `2×3` is 3:8, `4×2` is 9:8. Calculate from declared column and row counts; never assume that a portrait collage's appearance establishes 9:16 page geometry.
- **Size and detail:** four 1080×1920 genuine pages need at least a 2160×3840 sheet before any additional margins. If a provider creates only a 1080×1920 2×2 collage, the effective page area is 540×960, which may pass aspect but **fails the preferred native detail target**. A 1024×1536 2×2 output has 512×768 pages, fails aspect and fails preferred detail. Enlarging a 512×768 image to 1080×1920 does not invent native detail.
- **In-page branding/gutters:** incorporate page borders and mastheads *inside* each 9:16 page canvas. Do not add shared outside margins or variable-width separators to the sheet and then treat a simple 50% crop as a finished page. If a nonzero shared separator is intentional, record explicit non-overlapping cell coordinates and validate every extracted page individually; a sheet-ratio-only check is insufficient.
- **Strict per-stage provenance:** capture `requested_size`, `provider_reported_size` if known, `measured_original_width/height`, `cell_rectangles`, `measured_extracted_page_width/height`, `origin=GENERATED_NATIVE|ASSEMBLED_NATIVE_PAGES|CROPPED|OUTPAINTED|RESAMPLED|UNKNOWN`, and `export_width/height`. Never relabel resampling or padding as original/native generation.
- **Formatting enforcement:** all final pages must be true 9:16 *and* individually proofed at viewing scale. Lower-resolution or geometrically repaired pages may remain `GEOMETRY_PASS / C19_EXPORT_QUALITY_BLOCKED`. No absolute promise of 1080×1920 native generation is made when provider capability is unknown.

### 8.2 Provider capability preflight and deterministic fallback (binding)

1. **Before the first render of any run**, determine from actual provider settings, documentation, or measured test output whether the chosen generation mode can deliver four internal 9:16 pages at acceptable detail. Requested prompt words, the word "portrait", model branding or a nominal `size` parameter are **not evidence**. Record `GEOMETRY_CAPABILITY=VERIFIED|NOT_VERIFIED|UNSUPPORTED`, source of the capability finding, and date.
2. Prefer **four separately rendered, genuine 9:16 page images, assembled losslessly** when sheet-native mode cannot demonstrate correct internal pages and readable dialogue. This remains one `SHEET_STEP` delivery; only one finished composite is shown for that step, with individual asset files retained for QA. If native 9:16 individual generation is not supported, do not quietly generate 2:3 and continue.
3. A planned collage may be used directly only when pixel inspection confirms all four complete pages, correct boundaries, page count/order, aspect and readable detail. Validate immediately after **S01**, before authorizing any later S sheet; repeat after **every Sxx**. A prior success does not waive subsequent checks.
4. If neither approach produces compliant output, set `GEOMETRY_CAPABILITY=UNSUPPORTED`, `C11_PAGE_ASPECT=FAIL or BLOCKED` according to observed evidence, `Sxx_REPAIR_REQUIRED`, and **STOP before next sheet**. Disclose the provider constraint; offer an explicit user-approved non-destructive art extension/redraw workflow without pretending that a different-size output passed.
5. Existing 2:3 art may be **reference-only**. Any geometry correction must preserve the same P/S IDs, source-authorized composition, faces, dialogue and evidence. Acceptable correction options are (a) regenerate the same pages in the correct canvas, (b) composition-aware outpainting/extension into new 9:16 boundaries, or (c) re-layout approved panels and deterministic lettering onto genuine 9:16 canvases. Simple stretching, uncontrolled cropping, fake peripheral padding, or lowering the font to an unreadable size cannot be release fixes. Record the original as immutable and the correction as a **new revision**.
6. Do not equate visual owner approval with format/rights approval. `STYLE_REFERENCE_ACCEPTED` can coexist with `PAGE_GEOMETRY_FAIL`.

**First-batch gate:** `RENDER → MEASURE SOURCE → EXTRACT/CHECK FOUR CELLS → CHECK CONTENT/LETTERING → ACCEPT OR REPAIR → CHECKPOINT → STOP`. In particular `S01` cannot advance the accepted geometry cursor while its extracted pages remain 2:3. An editor may authorize provisional narrative continuation with a nonconforming reference; that does not authorize a compliant/release-ready claim.

### 13.2 Binding geometry clause to compile into every rendering call

Append the following *specific*, outcome-checkable geometry instruction to image requests, customizing IDs and the provider-supported size instead of relying on descriptive words alone:

> Produce ONLY the authorized `Sxx` four-page composite in a strict 2-column × 2-row grid, row-major `[Paa,Pbb,Pcc,Pdd]`. Each cell MUST be one complete **9:16 portrait comic page** including all its internal panels, lettering, panel boundaries and a safe area around readable text. No exterior whitespace, captions or page-crossing art. When genuinely supported, output a zero-gutter sheet of **2160×3840** pixels (four **1080×1920** page canvases); otherwise use the approved single-page generation-and-lossless-assembly fallback. Never substitute a **1024×1536** or other **2:3** collage and call its quadrants 9:16. Do not stretch, trim speech bubbles or pad with fake blank margins to meet the ratio. If provider geometry differs, mark this same sheet as nonconforming and STOP for correction instead of proceeding to `Sxx+1`.

The instruction does **not** override the provider's technical size limits and is not itself an acceptance test. After generation, read file pixels (not preview dimensions), measure all sheet and page canvases, and apply the `C11` gate. Keep the previous accepted art and `page_id` continuity unchanged. Preserve one-image-per-step user-facing behavior.

## 15A. Fail-fast release barrier for aspect and resolution (v0.09.06)

At each sheet checkpoint enforce these **non-bypassable internal subtests** under the existing C gates (do not create C23):

| Subtest | Required objective evidence | Failure consequence |
|---|---|---|
| `SC_PROVIDER_SIZE_PREFLIGHT` | Provider mode/size support verified or explicitly marked unknown before rendering | Choose page-first method, or BLOCK rather than promise dimensions |
| `SC_SHEET_NATIVE_DIMENSIONS` | Original sheet file opened, intrinsic `(W,H)` and SHA-256 recorded | Keep `RENDERED_DRAFT`, do not advance |
| `SC_CELL_BOXES_VALID` | Exactly four non-overlapping equal page rectangles in TL/TR/BL/BR, no missing/cross-boundary content | Repair same S/P IDs |
| `SC_PAGE_RATIO_EXACT` | For each extracted page: `16*w == 9*h` using actual integer pixels | `C11_PAGE_ASPECT=FAIL`, `Sxx_REPAIR_REQUIRED` |
| `SC_SHEET_TO_PAGE_CONSISTENCY` | Combined sheet dimensions/cell boxes agree, or actual deliberate gutters are explicitly accounted for | Cannot certify geometry from sheet alone |
| `SC_NATIVE_EXPORT_PROVENANCE` | Generator/assembly, cropping, outpainting, any upscale and original native detail all separately labeled | `C19_EXPORT_QUALITY=BLOCKED` when undisclosed or substandard |
| `SC_FIRST_SHEET_STOP_GATE` | Failure in S01 blocks further S batches for geometry-approved production; provisional continuation explicitly noted | STOP, preserve cursor and original art |
| `SC_MOBILE_LEGIBILITY` | Final page fonts/evidence checked at intended phone display size | Repair lettering or fail `C13`/`C19` |

**Truthful conditions:** `ratio_pass` is a raster property; `native_detail_pass` is a separate provenance/quality property; `editorial_pass`, `rights_pass` and `release_pass` are separate still. A 1080×1920 upscaled 512×768 image may satisfy only `ratio_pass`, not `native_detail_pass`. Do not mark C11 PASS when any actual page fails. Do not mark C19 PASS solely because the output dimensions meet 1080×1920. QA must document actual measured failures, not assert a test was passed because this text requires it.

**Known Day 05 regression (20 Nov 2026):** four locally available images measured 1024×1536, yielding 16 extracted 512×768 cells, all 2:3. The previous report labeled those draft pages non-release-ready. This edition prevents their erroneous batch acceptance in future production; it does not silently regenerate, approve or publish them.
