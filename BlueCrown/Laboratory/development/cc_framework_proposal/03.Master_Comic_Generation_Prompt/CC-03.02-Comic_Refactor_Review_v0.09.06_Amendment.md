## 8. v0.09.06 corrective review — measured ratio failure and enforceability

**Scope:** additive supplement to CR-095-01…22 and historical CR-094 decisions. The actual issue was *not lack of a 9:16 instruction*. CC-03.01 v0.09.05 §8, §11, §14 and `C11_PAGE_ASPECT` already specified strict 9:16 and rejected native 2:3. The remaining production failure was that the user-facing renderer continued from one 1024×1536 (2:3) collage to the next without enforcing the measured-geometry hard stop. A `9:16` prompt is intent, not a raster guarantee.

### 8.1 Incident evidence and limitations

| Evidence | Confirmed observation | Interpretation |
|---|---|---|
| Day 05 Part 5, 20 Nov 2026, four original collage files | Each file locally measured **1024×1536 px** | Full collage ratio 2:3; all fail exact 9:16 |
| Four equal 2×2 crops per sheet | Each crop **512×768 px**, 16 page crops total | Every extracted page ratio 2:3; not 9:16 |
| Production finalization report | Correctly flagged C11 geometry failure and provisional status | Disclosure happened *after* all sheets, too late to prevent repeated nonconforming batches |
| Target layout | 9:16 individual pages, target 1080×1920 | Correct genuine source sheet for 2×2 target pages: 2160×3840 |
| Tool/source capability | Native 2160×3840 rendering **not verified** | A size request can be ignored/rounded by some providers; fallback must be decided by actual capability |
| Narrative and rights acceptance | Outside scope of mechanical measurements | No automatic approval inferred from aspect repair |

These measurements are taken from the current conversation's four mounted Day 05 collages, not mistaken for the different Day 04 first-image reference described by CC-03.02 v0.09.05. They cannot establish that every generator or every future run behaves identically. No new public release is authorized by this review.

### 8.2 Root-cause model

`R-096-A` **Specification existed but was non-executable:** explicit 9:16 wording did not translate into a tested post-render control. `R-096-B` **Collage output-size mismatch:** a 2×2 grid on a 1024×1536 canvas produces 2:3 cells, so layout count did not imply page format. `R-096-C` **Stepping accepted non-compliant originals:** visual inspection/continuation ran without a blocking C11 result. `R-096-D` **Aspect and detail were conflated:** resampling a draft to 1080×1920 can change dimensions but cannot supply native source detail. `R-096-E` **Provider size capability remained unproven:** relying on a natural-language ratio instruction was insufficient.
